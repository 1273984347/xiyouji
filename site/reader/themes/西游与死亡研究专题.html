西游与死亡研究专题：向死而在的西行

轨标：跨界趣谈

A4 主题专题扩容·死亡研究新维度（W382·2026-08-07） 版本：v2.3.11 与 时间哲学专题（时间本体）、西游与存在主义专题（存在哲学）、长生之道专题（长生欲望）、长生之后神仙为什么死了专题（神仙之死个案）形成"取经生死五题"之"死亡本体"新维度：时间哲学问"时间是什么"，存在主义问"如何存在"，长生之道问"如何不死"，本专题问"死亡本身是什么"——以死亡学（thanatology）视角重读西游的求长生、吃唐僧肉与轮回转生

理论框架：菲利普·阿里耶斯《面对死亡的人》（死亡态度史·被驯化的死亡/被禁止的死亡）+ 西格蒙德·弗洛伊德《超越快乐原则》（死亡驱力·爱欲与死欲）+ 马丁·海德格尔《存在与时间》（向死而在·本真/非本真存在）+ 恩斯特·贝克尔《拒斥死亡》（死亡恐惧·英雄主义系统）

二、理论框架

2.1 菲利普·阿里耶斯：死亡态度史

菲利普·阿里耶斯（Philippe Ariès，1914-1984）法国历史学家，代表作《面对死亡的人》（L'Homme devant la mort，1977）：以长时段心态史重构西方死亡态度变迁——中世纪是"被驯化的死亡"（tamed death）：死亡是公共事件、熟悉而可接受，临终者在床前与人共处，死亡被仪式驯化；近代以来转为"被禁止的死亡"（forbidden death）：死亡被医疗化、隔离化、私人化，成为不可言说的羞耻；现代人把死亡逐出日常生活。

与取经叙事对照：西游世界是"被驯化的死亡"的极乐版本——死亡在书中从不缺席，却也从不终结：地府有生死簿（第3回 line 41"该寿三百四十二岁，善终"），死亡被写成"名录上的一行字"，可查、可勾、可改；妖怪被杀即"现出本相"，死亡是叙事的句号而非恐怖。唐僧面对死亡威胁的反应（第77回狮驼岭"骨肉无存"的谎报）则是"被禁止的死亡"的雏形——取经团队必须以"师父没死"维持叙事的可继续性。阿里耶斯式读法：西游的死亡观介于"被驯化"与"被禁止"之间——神佛驯化死亡（长生、轮回），凡人恐惧死亡（吃唐僧肉、求超度）。

2.2 弗洛伊德：死亡驱力

西格蒙德·弗洛伊德（Sigmund Freud，1856-1939）奥地利精神分析学创始人，代表作《超越快乐原则》（Jenseits des Lustprinzips，1920）：在创伤性重复（强迫重复）现象中发现"死亡驱力"（Todestrieb）——生命有机体有一种回归无机状态（死亡）的深层倾向；生命是爱欲（Eros，联结与保存）与死欲（Thanatos，分解与毁灭）的永恒斗争；重复强迫是死欲在心理层面的表达。

与取经叙事对照：西游的叙事引擎是死亡驱力与爱欲的拉锯：八十一难中妖怪的"吃人"冲动（死欲的向外投射）与师徒的"求生"意志（爱欲的保存功能）循环交战；而金蝉子十世轮回（第100回 line 43"贬汝之真灵，转生东土"）则是死欲的宇宙级表达——每一次转生都是一次"重复强迫"：同样的取经使命、同样的死亡风险、同样的再次出发。悟空打杀六贼（第14回 line 47"一个唤做眼看喜"）则是死欲的内向执行——欲望（六贼）作为"非我"被毁灭，爱欲借毁灭自我之欲望而自我保存。弗洛伊德式读法：取经的终点不是经，而是对死亡驱力的最终驯服——成佛意味着死欲被完全纳入爱欲秩序（不再轮回、不再被吃）。

2.3 海德格尔：向死而在

马丁·海德格尔（Martin Heidegger，1889-1976）德国哲学家，代表作《存在与时间》（Sein und Zeit，1927）：此在（Dasein）的存在方式是"向死而在"（Sein zum Tode）——死亡不是将来发生的偶发事件，而是此在最本己的、不可替代的、随时可能的可能性；面对死亡，此在有两种姿态：本真存在（直面死亡，承担自己的能在）与非本真存在（沉沦于"常人"的安慰——"人们都会死"，以平均化的死亡逃避自己的死亡）。

与取经叙事对照：师徒四人是对"向死而在"的四种示范：悟空直面死亡（他死过一次——被勾魂、被压五行山，故无所畏），八戒沉沦于常人（"死也要做个饱死鬼"的享乐主义，以吃喝消解死亡），沙僧逆来顺受（把死亡交给"命"），唐僧则是最典型的非本真存在——每逢险境便仓皇失措、以泪洗面（第32回），以"常人"的恐惧逃避"此在"的责任，直到凌云渡（第98回 line 15"那个原来是你"）才被迫直面"自己的死"——脱胎换骨即本真存在的瞬间：认出死尸是自己，死亡从"他人的事"变为"我的事"。海德格尔式读法：取经即"向死而在"的修行——每一难都是一次死亡预习，成佛则是"本真地向死而生"的完成态。

2.4 恩斯特·贝克尔：拒斥死亡

恩斯特·贝克尔（Ernest Becker，1924-1974）美国文化人类学家，代表作《拒斥死亡》（The Denial of Death，1973，普利策奖）：死亡恐惧是人的根本动机——人知道自己必死，这是所有焦虑的原点；为对抗死亡恐惧，人构建"英雄主义系统"（heroic systems）：把自己嵌入不朽的象征秩序（事业、功名、宗教、后代），以"象征性不朽"拒斥肉体死亡；英雄主义系统既是文明的动力，也是暴力的源头（他人对自身英雄体系的威胁）。

与取经叙事对照：取经是西游世界最大的"英雄主义系统"：唐僧以"取经"嵌入佛国的不朽叙事（成佛=象征性不朽），悟空以"功果"（封斗战胜佛）赎买不死，八戒以"净坛使者"换取免死，沙僧以"金身罗汉"安顿肉身——每个人的取经动机都是拒斥死亡。妖怪则是英雄主义系统的竞争者：吃唐僧肉（第27回 line 13"长寿长生"）是直接攫取他者的不朽，占山为王是建立自己的小宇宙（狮驼城"有三个毒魔"line 57）。贝克尔式读法：西游的正邪之战，是两种"不朽方案"的战争——佛国的系统（修行得正果）与妖怪的系统（吃人夺长生）争夺同一个死亡恐惧的市场。

三、维度一：不死焦虑——悟空求长生与妖怪吃唐僧肉

西游的起点与对手盘都是"不死焦虑"：

焦虑主体 不死方案 文本证据
悟空（起点） 访仙学道、勾销生死簿 第1回 line 25（"常躲过阎君之难"）、第3回 line 41（勾名）
妖怪（对手） 吃唐僧肉 第27回 line 13（"长寿长生"）
神仙（体制） 蟠桃、人参果、仙丹 第5回（蟠桃会）、第24回（人参果）
唐僧（目标） 取经成佛 第100回 line 43（金蝉子→旃檀功德佛）

悟空"学一个不老长生"（第1回 line 25）开启全书——整部西游是对这最初的死亡恐惧的回应：大闹天宫（因不被邀请参加不死之宴）、被压五行山（不死者的囚禁）、取经（以功果兑换真正的不朽）。妖怪的吃唐僧肉则是同一恐惧的镜像：他们比悟空更绝望——悟空可以学、可以闹、可以修，妖怪只能"吃"。死亡焦虑在西游中从不缺席：它生产了七十二变（躲避三灾的技艺）、生产了紧箍咒（以疼痛保证"不死承诺"的执行），也生产了八十一难的全部敌意。

四、维度二：向死而在——死亡威胁作为八十一难的叙事引擎

八十一难的本质是"死亡的定期预习"：每一难都构拟一种死法——被蒸（狮驼岭）、被煮（红孩儿）、被挖心（比丘国）、被淹（通天河）、被刺（盘丝洞）……死亡威胁是唯一的叙事引擎：

  • 威胁的结构功能：妖怪抓唐僧→死亡倒计时→搬救兵→解除威胁——死亡是"被悬置的钟摆"，它的每一次摆动都生成一难（第77回狮驼岭"夹生吃了"的谎报 line 41，把死亡推到叙事前台）。
  • 唐僧的非本真姿态：唐僧在死亡面前永远惊慌失措、跌马流泪，以泪水和念经应对——海德格尔式的"常人"逃避（"人们都会死"式的自我安慰：菩萨会来救）；他的成长（第98回主动面对死尸 line 15）是全书最深的死亡教育。
  • 悟空的本真姿态：悟空是唯一"死过"的人（第3回勾销生死簿、第7回被压、第33回被装葫芦）——死亡对他已"去神秘化"，故他是团队的死亡翻译官（第98回 line 15"师父莫怕，那个原来是你"）。

向死而在的完成：凌云渡脱胎（第98回 line 15）是取经的死亡仪式——死尸（旧身）被水送走，"那个原来是你"，唐僧第一次认出自己的死亡并跨过它（第98回 line 19"脱却胎胞骨肉身"）。成佛（第100回）即"不再有死亡可向"的存在——取经的终点是死亡的终结，而通向终点的路是死亡的重演。

五、维度三：被驯化的死亡——地府、生死簿与"管理化"的死亡

阿里耶斯"被驯化的死亡"在西游中达到极致——死亡被彻底"管理化"：

  • 生死簿（第3回 line 41）：死亡被写成行政档案（"该寿三百四十二岁，善终"）——阎王不是死亡的执行者，而是死亡的管理员；死亡成为可查、可改、可勾销的"记录"。
  • 唐太宗游地府（第10回 line 1）：帝王亲历死亡管理现场——"却说太宗与魏征在便殿对弈"（line 1），魏征梦中斩龙，太宗被迫入冥对案，又因崔判官改簿而还阳——死亡在此是"行政事故"（龙王告状、对案、改判），可谈判、可贿赂、可逆转。
  • 轮回体制（第100回 line 43）：金蝉子"贬汝之真灵，转生东土"——死亡不是终结而是"调动"：天界以转生作为惩罚手段（贬），以转世作为修行课程（十世取经），死亡被纳入奖惩体系。
  • 超度仪式：水陆法会、盂兰盆、放焰口——死亡被仪式化为可操作的宗教程序（第12回"水陆大会"line 11）。

被驯化的死亡的另一面：死亡一旦被管理，就不再恐怖，也便失去意义——这就是为什么西游的神仙"长生"却普遍空虚（玉帝的焦虑、老君的无为）：长生者（被驯化者）失去了向死而在的紧迫性，本真性随之流失——长生之后神仙为什么死（或倦怠），是"被驯化的死亡"的必然代价。

六、维度四：死亡的悖论——神仙会死、六贼之死与金蝉子轮回

西游的死亡观充满悖论：

  • 神仙也会死：蟠桃、人参果、仙丹的存在证明"神仙会死"（否则无需不死之药）——不死系统本身承认死亡的威胁；三灾利害（雷灾、火灾、风灾）是长生者的"定期死亡考试"。
  • 六贼之死（第14回 line 47"一个唤做眼看喜"）：悟空初出五行山便打死六贼（眼看喜、耳听怒、鼻嗅爱、舌尝思、意见欲、身本忧）——这是全书第一次"杀人"，对象却是"欲望的具象"：死亡的暴力在此是"修行的开始"（杀灭六识），死亡的悖论由此确立——杀生可以是修行，慈悲可以是残忍。
  • 金蝉子轮回（第100回 line 43）：因"不听说法，轻慢我之大教"而被贬——死亡（转生）是惩罚，也是课程；十世轮回的唐僧"十世修行的原体"（第27回 line 13）成为妖怪垂涎的珍馐——不死者的肉，成了必死者的药，死亡的悖论达到极致：最慈悲者（金蝉子）的死，成就了最贪婪者（妖怪）的永生幻想。
  • 佛的"死亡"：如来、观音等最高神不出现在生死簿中（第1回 line 25"佛与仙与神圣三者，躲过轮回"）——死亡在最高处消失，而通向"无死亡"的路（取经）却必须穿越全部死亡。

七、维度五：拒斥死亡——取经作为"英雄主义系统"

贝克尔式读法给取经一个总体解释：取经是集体性的拒斥死亡工程：

  • 象征性不朽：成佛（第100回 line 43 的封号）是"英雄主义系统"的终极勋章——斗战胜佛、净坛使者、金身罗汉，都是把必死之身写进不朽名单。
  • 系统的竞争：妖怪的"吃唐僧肉"（第27回 line 13）是英雄主义系统的替代方案——不以修行为代价攫取不朽；佛国（如来）与妖界（各洞魔王）争夺的是同一个东西：死亡恐惧的定价权——谁提供更可信的不朽，谁就拥有信徒/部众。
  • 英雄主义的暴力：贝克尔警告英雄主义系统是暴力的源头——西游中每次"除妖"都是对异己不朽方案的毁灭（妖怪被杀=其长生方案被证伪）；沙僧流沙河吃人、八戒的杀生，都以"取经大业"（系统目标）获得赦免——为不朽而杀人，是拒斥死亡的阴暗面。

与时间哲学（时间本体）、存在主义（存在方式）、长生之道（不死欲望）不同，本文是纯正的死亡学视角：追问死亡在西游中的态度史（阿里耶斯）、心理动力（弗洛伊德）、存在论位置（海德格尔）与文化功能（贝克尔）——死亡不是时间的附属、不是存在的背景、不是长生的反面，而是西游叙事真正的发动机。

九、文化隐喻：明代幽冥信仰与死亡日常

西游的死亡书写是明代死亡文化的镜像："被驯化的死亡"——明代的慎终追远、七七斋醮、水陆法会（第12回"水陆大会"line 11）把死亡组织进仪式日常；冥判文化——唐太宗游地府（第10回 line 1）对应明代的阎王殿、城隍庙与《玉历宝钞》式的幽冥官僚制：死亡被想象为"另一个衙门"，可告状（泾河龙王）、可改判（崔判官）、可回阳；炼丹求仙——嘉靖朝崇道炼丹（"不死焦虑"的宫廷版）与悟空求长生（第1回 line 25）同构：明代帝王与猴王共享同一份对阎君的恐惧。西游的死亡观因此是明代生死观的百科全书：既怕死（吃唐僧肉），又不怕死（生死簿可勾），既信轮回（金蝉子），又恋此生（长生）——多重死亡态度的叠加，正是明代人心态史的浓缩。

十、影视改编与延伸思考

  • 1986 央视版：唐僧之死的视觉化（狮驼岭"分食"段）以特效渲染死亡恐怖，把"被驯化的死亡"转译为"被消费的死亡"；凌云渡脱胎的写意处理则保留了对死亡的仪式化理解。
  • 《大话西游》：至尊宝的"死过一次才知爱谁"——死亡作为认知装置（向死而在的通俗版）；结尾夕阳武士的"不死"（转世重逢）把轮回处理为爱情的续命。
  • 《黑神话：悟空》：玩家的死亡（Boss 战失败）是游戏循环的常态——死亡成为学习机制（死一次、学一次），与八十一难的"死亡预习"同构；黑神话对"长生"的祛魅（长生=诅咒）直指死亡恐惧的现代反思。
  • 延伸思考：当代的"抗衰老产业""元宇宙永生""冷冻技术"是后现代的"拒斥死亡"；社交媒体是新的"英雄主义系统"（点赞=象征性不朽）——贝克尔会说，我们与白骨精共享同一份"长寿长生"（第27回 line 13）的焦虑。
