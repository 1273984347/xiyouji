西游与经济学专题：资源主权、项目预算、财产权与产出核算

轨标：跨界趣谈 A4 主题专题扩容 Batch 9·经济学专题 W086·2026-07-26 与 A2 西游与经济学（W073·A2 Batch 7）形成"随笔浅尝 + 专题深化"双层结构

关联回目：第3回 line 589 / 第8回 line 981 / 第32回 line 2629 / 第98回 line 7050

一、开篇引文

第3回 line 589，"四海千山皆拱伏 九幽十类尽除名"——悟空下东海龙宫，强取如意金箍棒。

第8回 line 981，"我佛造经传极乐 观音奉旨上长安"——如来启动取经项目，菩萨奉旨招贤。

第32回 line 2629，"平顶山功曹传信 莲花洞木母逢灾"——太上老君两个看炉童子下界为妖，带五件法宝。

第98回 line 7050，阿傩、伽叶传经——"传了五千零四十八卷，乃一藏之数"。

四个片段，串成《西游记》的经济学骨架：资源主权（金箍棒）→ 项目预算（取经）→ 财产权差异（坐骑盗器）→ 产出核算（一藏之数）。这不是简单的"佛道博弈"故事，是明代经济结构的寓言化预演。

二、理论框架

经济学有五大支柱：

  • 亚当·斯密《国富论》（1776）：市场+分工。"看不见的手"协调个体追求自利而成公益
  • 马克思《资本论》（1867）：剩余价值+剥削。资本家通过占有生产资料剥削工人
  • 凡勃伦《有闲阶级论》（1899）：炫耀性消费。财富不仅是物质，是地位符号
  • 奥斯特罗姆《公共事物的治理》（1990）：公共池塘资源（CPR）的自治八原则。公有资源不必然悲剧，可自治
  • 诺斯《制度、制度变迁与经济绩效》（1990）：制度是游戏规则。有效率制度是经济增长的关键

这五家共同回答："财富如何创造、分配、积累？"

明代经济对应五大命题： - 市场：明代中后期形成全国性市场（如松江棉布市场） - 剥削：明代田赋+丁银+苛捐杂税，赋役黄册制度 - 炫耀性消费：明代士大夫的"雅物"经济（文房四宝、古玩、书画） - 公有资源：明代的官田、皇产、卫所屯田 - 制度变迁：明代一条鞭法（1581）—赋役合并、折银征收

三、主题分析

3.1 资源主权：龙宫金箍棒的产权悖论

第3回 line 589，悟空下东海龙宫，"四海千山皆拱伏"。

如意金箍棒原是大禹治水定海深浅的"定子"——一个公有基础设施。后来归东海龙宫管理，成为"龙宫镇海之宝"——公有资源转为国有资源。悟空来取，敖广不敢不献——"拱伏"二字点明主权的转移。

这里有三个产权层级：

  1. 自然状态：金箍棒是大禹所定，本是公共物品（类似公共池塘资源 CPR）
  2. 国有化：龙宫管理后成为"镇海之宝"——公有资源被收归国有
  3. 私有化：悟空强取后成为"俺老孙的兵器"——国有资源被强制私有化

这是奥斯特罗姆《公共事物的治理》的核心问题：公有资源如何避免悲剧？奥斯特罗姆的答案是"自治八原则"——利益相关者自主协商、自我监督。但《西游记》给出了第三种路径：强制私有化——当一个更强大的武力出现时，公有资源直接被私有化。

这是经济学最深的悖论：产权不是天然的，是权力塑造的。悟空有金箍棒，所以他"拥有"金箍棒；龙宫没有武力抗衡，所以"失去"金箍棒。亚当·斯密的"看不见的手"前提是产权清晰，但产权清晰的根基是"看得见的拳头"。

3.2 项目预算：取经项目的资源调配

第8回 line 981，"我佛造经传极乐 观音奉旨上长安"——如来启动取经项目。

取经项目是经济学上典型的"中央计划项目"：

  • 项目出资人：如来（董事会）
  • 项目经理：观音（CEO）
  • 执行团队：唐僧+悟空+八戒+沙僧+白龙马（员工）
  • 项目预算：5 个高级编制（金紧禁三箍 + 锦襕袈裟 + 九环锡杖）
  • 项目周期：14 年（实际执行）
  • 项目目标：传经东土（产能输出）
  • 项目产出：5048 卷经书（一藏之数）

这是诺斯《制度、制度变迁与经济绩效》的核心问题：有效率制度如何形成？取经项目的制度设计有三个特征：

  1. 层级授权：如来→观音→唐僧→悟空→八戒沙僧。每一级只对上级负责，下一级不可越级
  2. 绩效激励：取经成功后五圣成真（"高级编制"），失败则被妖怪吃掉（"末位淘汰"）
  3. 风险分散：紧箍儿咒约束悟空（核心员工），观音随时介入（人力资源部），如来兜底（最终担保）

但这种制度有一个致命缺陷——缺乏市场反馈。取经项目的"客户"是东土众生，但众生没有投票权——他们必须接受传来的经。这是中央计划经济的典型困境：生产者决定消费者，消费者没有选择权。

3.3 财产权与特权：坐骑盗器的体制内特权

第32回 line 2629，"平顶山功曹传信 莲花洞木母逢灾"——金角银角带五件法宝下界。

这是经济学上典型的"体制内特权"：

  • 金角银角是太上老君的看炉童子，体制内身份——下界后可以带法宝
  • 法宝包括：紫金红葫芦、羊脂玉净瓶、七星剑、芭蕉扇、幌金绳——5 件高级装备
  • 这些法宝在体制内（天庭）不算违法，下界后才"成为"法宝——体制内对资源调用的豁免
  • 对比：野生妖魔（如白骨精、蜘蛛精）没有法宝，因为体制外身份不允许调用资源

这是凡勃伦《有闲阶级论》的炫耀性消费的体制内版本。凡勃伦说有闲阶级通过消费奢侈品彰显地位——金角银角通过调用体制内法宝彰显天庭身份。炫耀性消费的逻辑是"我有资格消费你消费不起的东西"——这与"我有资格调用你调用不到的法宝"是同构的。

马克思《资本论》的"剩余价值"在这里有一个变体：体制内特权 = 体制外剥削。金角银角不需要"劳动"获取法宝，他们通过身份继承（童子身份）调用资源。这相当于资本家通过占有生产资料剥削工人——但更隐蔽，因为身份看似"自然"。

3.4 产出核算：五千零四十八卷的经济总量

第98回 line 7050，"传了五千零四十八卷，乃一藏之数"——取经项目最终产出。

这是经济学上的"产出核算"。5000+48 不是随意的数字，是明代经济总量的隐喻：

  • 5040 是柏拉图《理想国》的"理想城邦公民数"——亚里士多德《政治学》也提到这个数字是最优城邦规模
  • 5048 是佛教"一藏之数"——这是一个封闭的、自洽的、可核算的总量
  • 5000+48 的拆分：5000 是"整数"（基础），48 是"零头"（精确）——这是明代田赋核算的精度要求

诺斯《制度、制度变迁与经济绩效》指出：有效率制度需要可核算性。取经项目的"一藏之数"提供了完美的核算单位——既不太大（无法管理），也不太小（失去意义）。这是经济学的"规模最优"原则。

但更深一层：取经项目的产出（5048 卷经书）= 取经团队的成本（5000+48 年功德）= 如来的预算（5000+48 编制数）。这是一个完全自洽的经济循环——投入=产出，预算=结算。

这是亚当·斯密"看不见的手"的反例——取经项目的完美核算不是市场自发形成的，是如来中央计划的。但它达到了市场无法达到的完美——这暗示中央计划在特定条件下（如封闭系统、有限目标、强大担保）可以超越市场。

四、古今对位

4.1 资源主权 vs 当代产权理论

明代：龙宫金箍棒的产权转移——公有→国有→私有。 当代： - 公有资源：空气、地下水、公共海域（公地悲剧） - 国有资源：石油、天然气、稀土（国家所有权） - 私有资源：个人财产（私有产权） - 当代对应：美国西部水资源法——"先到先得"（prior appropriation doctrine）+ 中国矿权法——"国家所有+特许开采" - 悟空强取金箍棒 vs 美国石油抢夺：19 世纪美国石油抢夺战——谁先钻井谁拥有地下油藏。武力的强弱决定了产权的归属

4.2 项目预算 vs 当代项目管理

明代：取经项目的中央计划模式。 当代： - 中央计划项目：阿波罗登月计划、中国高铁、欧洲伽利略导航系统 - 层级授权：CEO→CTO→项目经理→工程师 - 绩效激励：股票期权+末位淘汰 - 风险分散：母公司担保+项目经理兜底 - 当代对应：SpaceX 的"火星殖民计划"——马斯克是出资人（如来），CEO 是项目经理（观音），执行团队是星舰+宇航员（唐僧+悟空）。取经项目是当代大型科技项目的文学原型

4.3 财产权差异 vs 当代体制内外差异

明代：金角银角带法宝下界，野生妖魔无法宝。 当代： - 体制内特权：国有企业垄断、公务员福利、事业单位编制 - 体制外生存：民营企业、个体工商户、自由职业者 - 当代对应：中国石油/中国电网（央企，"金角银角"）vs 民营加油站/民营电力（"野生妖魔"）——体制内调用资源的能力远超体制外 - 明代八议 vs 当代"双规"：明代八议让官员享有司法豁免，当代"双规"让党员干部先于司法处理——体制内的特权延续

4.4 产出核算 vs 当代经济统计

明代：5000+48 卷的完美核算。 当代： - GDP 核算：季度 GDP+年度 GDP - 企业财报：季度财报+年度财报 - 当代对应：中国五年规划——"五年"是周期，"规划"是预算。取经项目 14 年周期对应中国 5 年规划的"中长期规划" - 明朝黄册制度 vs 当代经济普查：明代每 10 年编一次赋役黄册，登记全国人口土地；当代每 5 年一次经济普查——都是从中央层面对经济总量的核算

五、结语

《西游记》是一部经济学的文学预演。

吴承恩不懂亚当·斯密，但他写出了产权的权力根源（龙宫金箍棒）。不懂马克思，但他写出了体制内特权对体制外的剥削（金角银角）。不懂凡勃伦，但他写出了身份的炫耀性消费（带法宝下界）。不懂诺斯，但他写出了中央计划的有效性边界（取经项目）。不懂奥斯特罗姆，但他写出了公有资源被强制私有化的悲剧（金箍棒）。

这不是巧合，而是经济学的直觉。经济学最深的命题——产权如何形成、市场与计划的边界、体制内外的不平等、产出如何核算——本就藏在文学的母题里。吴承恩用神话语言提出的，正是经济学至今未解的硬问题。
