cypher MATCH (n:尘境)-[:遮蔽]->(m:识体) WHERE m.xiyou_entity CONTAINS '凡胎' RETURN n.buddhist_entity, n.xiyou_entity, m.ai_entity

四、Neo4j 导入脚本

```cypher // 1. 创建约束 CREATE CONSTRAINT IF NOT EXISTS FOR (n:Node) REQUIRE n.id IS UNIQUE;

// 2. 导入节点 LOAD CSV WITH HEADERS FROM 'file:///yuanqi_nodes.csv' AS row CREATE (n:Node { id: row.id, node_type: row.node_type, buddhist: row.buddhist_entity, ai: row.ai_entity, xiyou: row.xiyou_entity, desc: row.description });

// 3. 导入关系 LOAD CSV WITH HEADERS FROM 'file:///yuanqi_edges.csv' AS row MATCH (a:Node {id: row.source}), (b:Node {id: row.target}) CALL apoc.create.relationship(a, row.relation, {property: row.property, value: row.value}, b) YIELD rel RETURN count(rel); ```

注：当前 CSV 为种子数据集（20 节点 / 20 边），覆盖 W321–W325 全部核心映射。后续可将 342 篇文档逐一抽取"种子"扩充为完整图谱——这正是"阿赖耶识索引"的工程雏形（见例.txt 模块四）。
