Journey Team · MBTI Dynamic Evolution

— fourteen years on the road: five personalities grinding, clashing, harmonizing, and completing

Data note:Personality drift for the five pilgrimage-team members across four narrative stages is encoded on the eight MBTI dimensions (E/I/S/N/T/F/J/P), each scored 0-10. Stage boundaries follow chapters: Formation (Ch. 8-22), Conflict (Ch. 27-58), Harmony (Ch. 59-90), Consummation (Ch. 91-100).
Data source: the MBTI dataset embedded in this page — the five pilgrims' personality drift across the four stages, encoded by this project from the canonical novel (Wu Cheng'en, 16th c.); the Chinese dataset edition of the same data is published at ../data/mbti-evolution.html.

Panel 1 · Stage-Switching Radar

Click a button below to switch narrative stage; the radar draws the currently selected character only, smoothly transitioning to that stage's personality snapshot. Switch character with the dropdown or the dot plot below; the dot plot ranks all 5 characters by preference intensity for the current stage — the mean of the four pair differences |E-I| / |S-N| / |T-F| / |J-P|, since each MBTI pair sums to 10 and its plain mean would be a flat 5.0 for everyone. Defaults to "Formation".

Caliber: axis values are read from the dataset described in this page's data-source note (not from the chart itself); chart scale 8 axes × 1 series.

Panel 2 · Dimension Evolution Lines

One chart per person; 4 lines show how the 4 dimension-pair differences (E-I / S-N / T-F / J-P) change across stages. Difference > 0 leans toward the left trait, < 0 leans right, and approaching 0 means the pair tends toward balance.

Panel 3 · Stage × Dimension Heatmap

5 rows (characters) × 16 columns (4 stages × 4 dimension pairs). Color depth = absolute dimension difference: dark = strong preference, light = approaching balance. Hover for exact values.
