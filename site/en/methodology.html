What This Project Is ↔ hybrid & static-first

This is a hybrid, deeply annotated edition of Journey to the West (Wu Cheng'en, 16th c.). "Hybrid" because it pairs a full Chinese commentary library with interactive data visualizations; "static-first" because the site is plain HTML + D3.js that opens directly via file:// — no backend required for reading. The only external dependency is the D3 v7 CDN; every visualization either embeds its data or loads it locally, so the pages work offline.

The Seven-Part A4 Template ↔ how essays are built

Thematic monographs (A4) follow a fixed seven-part structure so readers always know where they are: framing → theoretical scaffold → source evidence → analysis → cross-references → caveats → conclusion. This discipline is what lets 200+ topical documents stay navigable rather than sprawling.

Visualization Design Language ↔ classical rice-paper

The aesthetic is a "digital woodblock" — inspired by Ming block-print books, rice paper, cinnabar punctuation, and ink washes. Core tokens: paper #faf7f2, ink #23201A, cinnabar accent #c8463a, indigo #3a6b8c. Dashboard controls reuse a separate "Name That UI" component language, but recolored to the project's tokens — the two visual languages are kept strictly separate.

Dual-Index Traceability ↔ never update one side

Every change is logged twice: CHANGELOG.md is the forward timeline (what shipped, in which version/W), and scripts/output/file-index.md is the reverse file index (which file, in which version/W). Updating only one is treated as a defect — the two must agree, which is what makes the project auditable across sessions.

Data Trust ↔ zero fabrication

Numbers come from dataset/*.json, themselves bridged from the project's own authoritative generators (e.g. the 81-tribulation classification). A delivery gate (scripts/verify_delivery.py) enforces that all six canonical documents carry the same version/W, that no page references a W beyond the documented maximum (scope-drift check), and that declared counts stay consistent. The rule is simple: bridge existing data, never invent it.
