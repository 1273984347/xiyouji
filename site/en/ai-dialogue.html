How the Dialogue Works

1Tokenization

User input is split into tokens by punctuation and spaces, forming the matching basis. Chinese uses substring-inclusion matching, so no tokenizer is needed.

2Match a Celebrity

Tokens are compared one by one against the keywords arrays of the six celebrities; whoever has the most hits wins. Celebrity keywords carry higher weight than reply keywords.

3Pick a Reply

Within that celebrity's replies, a second match runs on each reply's own keywords; the top-scoring ones are picked at random, and the same reply is never repeated.

4Fallback When No Match

Returns a generic reply plus a random celebrity's Journey to the West quote, so the conversation never runs dry — every celebrity has a Journey-to-the-West perspective.
