口径说明：以下结论取自本页离线内置的「八十一难」聚合示例（离线模式下直接可见；在线模式随数据集切换而变化，数字以所选数据集为准）。

成因为主：81 难中「真火锻性」28 难最多，「如来/观音安排」27 难次之，「天界/西域佛祖下凡收徒」16 难，「人心自生的障碍」仅 10 难——外部剧本合计 71 难，是难度的首要来源。
结局看后台：「被收走（有后台）」44 难，「被打死（无后台）」37 难，两者仅差 7 难；有靠山不等于全身而退，37 难仍以身死收场。
难度集中在中档：高难 22 难、中难 41 难、低难 18 难；中难占全部 81 难约一半（41/81），高难约每四难一见（22/81）。
三维口径互补：本页把 81 难拆成成因/结局/难度三条聚合线——成因解释「为何难」，结局解释「如何收场」，难度解释「多难」，三维交叉可定位具体难次。
离线可见范围：无数据 API 时本页内置「八十一难（离线示例）」，按成因/结局/难度三条口径各聚合一次；启动数据 API 后可切换全部数据集浏览、钻取并导出 CSV / JSON。
