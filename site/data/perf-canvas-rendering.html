贰 · 三项关键优化技术

THREE OPTIMIZATION TECHNIQUES
① requestAnimationFrame 批量更新
将力模拟的 tick 回调合并到单帧内绘制，避免每个 tick 触发 DOM 写入；Canvas 模式下更进一步——所有节点坐标计算完成后只触发一次 redraw。
simulation.on('tick', () => { // ❌ 传统：每个 tick 都触发 DOM 重排 // svgNodes.attr('cx', d => d.x).attr('cy', d => d.y); // ✅ 优化：rAF 合并 + Canvas 单帧重绘 if (!rafPending) { rafPending = true; requestAnimationFrame(() => { rafPending = false; drawCanvas(); // 一次性 beginPath + stroke }); } });
② Canvas 离屏渲染（OffscreenCanvas + 缓存）
使用 document.createElement('canvas') 创建离屏画布，预先绘制静态背景（网格、装饰、标签层），主画布只需 drawImage 拷贝，减少每帧重绘开销。支持 OffscreenCanvas 的浏览器可移至 Worker 线程。
// 离屏画布预绘静态层 const offscreen = document.createElement('canvas'); offscreen.width = W; offscreen.height = H; const offCtx = offscreen.getContext('2d'); // 预绘背景、坐标轴、装饰纹理 …… // 主画布每帧仅重绘动态节点 + 拷贝静态层 function drawCanvas() { ctx.drawImage(offscreen, 0, 0); // 一次贴图 ctx.beginPath(); for (const n of visibleNodes) { ctx.moveTo(n.x + r, n.y); ctx.arc(n.x, n.y, r, 0, 2 * Math.PI); } ctx.fill(); // 单次 fill 批量提交 }
③ 虚拟化（仅渲染可见区域）
对超过 1000 节点的大图，按视口剔除不可见节点；对节点边按距离阈值过滤；缩放/平移时按 LOD（Level of Detail）切换渲染精度（远视图仅画点，近视图才画标签）。
const visibleNodes = nodes.filter(n => n.x >= viewX0 && n.x <= viewX1 && n.y >= viewY0 && n.y <= viewY1 ); const visibleEdges = edges.filter(e => visibleNodes.includes(e.source) && visibleNodes.includes(e.target) ); // 1000+ 节点 → 实际仅绘制 ~200 可见节点 // 性能从 O(N) 降至 O(visible N)

叁 · 关键洞察与适用边界

KEY INSIGHTS & APPLICABILITY
渲染机制差异：SVG 每个节点是一个真实 DOM 元素（<circle>），浏览器需维护事件冒泡+样式计算+布局；Canvas 全部是位图像素，绘制后无 DOM 开销。
拐点 500：节点数 < 200 时 SVG 与 Canvas 差距小（~10ms）；节点数 > 500 时 SVG 耗时陡升至 100-300ms，Canvas 仍稳定在 10-30ms。
交互取舍：SVG 自带事件绑定（每元素可 onClick），Canvas 需自行做 hit-testing（计算距离 / 四叉树）。若图交互需求高，建议 SVG < 300 节点，否则转 Canvas + 自实现 hit-testing。
项目应用：本项目 character-semantic-network.html / intertextuality-network.html / narratology-13d-network.html 节点数已超 300，建议未来引入 Canvas 渲染分支；< 100 节点的图（如 guanyin-six-roles-network.html）保留 SVG。
动画场景：力模拟迭代期间 Canvas 优势最明显——SVG 每帧需更新 N 个 DOM 属性，Canvas 仅需重绘位图。对于本项目 timeline / sentiment-arc 等动画曲线，建议同样启用 Canvas + rAF 节流。
移动端：iOS Safari 在 SVG 节点 > 500 时滚动卡顿明显，Canvas 渲染保持 60fps。本项目 PWA 化后建议优先迁移大图至 Canvas。
