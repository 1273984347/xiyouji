壹 · 地府权力体系概览

UNDERWORLD SYSTEM OVERVIEW · DIYU BUREAUCRACY
定义：西游世界地府并非单一审判机构，而是由"十殿阎王科层 + 崔判官执行 + 地藏王监督 + 阳间桥梁 + 佛门接引"五层结构组成的复合体系。 十殿阎王——秦广、楚江、宋帝、五官、阎罗、卞城、泰山、都市、平等、转轮，按亡魂罪孽分殿审判，是地府的科层主体； 崔判官（崔珏）——掌生死簿，受魏徵私人请托改太宗阳寿，是地府最关键的执行枢纽； 地藏王菩萨——佛门驻地狱代表，发"地狱不空誓不成佛"宏愿，监督而不干预审判； 阳间桥梁——魏徵（斩龙人）与刘全（进瓜人）以肉身或梦游出入阴阳，是地府与阳间的接口； 佛门接引——谛听（地藏王坐骑）与接引佛祖（凌云渡）承担地府与灵山的接驳功能。 地府体系的核心政治学悖论：名义上独立于天庭，实质上接受天庭（魏徵梦中斩龙受玉帝敕令）与灵山（地藏王监督）双重渗透。
