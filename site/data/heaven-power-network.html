壹 · 天庭权力结构概览

HEAVEN SYSTEM OVERVIEW · TIANGONG BUREAUCRACY
定义：西游世界天庭并非单一行政机构，而是由"玉帝集权 + 武将执行 + 文官辅佐 + 边缘星宿 + 佛道制衡"五层结构组成的复合体系。 玉帝——三界共主，居凌霄宝殿，掌天庭最高决策权，降旨调兵与封赏册封； 武将体系——托塔天王李靖统兵，哪吒为先锋，二郎神听调不听宣，天蓬元帅与卷帘大将分掌水军与仪仗； 文官体系——太白金星为首席使臣，负责招安与外交，文曲星/武曲星辅佐朝政，月老掌姻缘； 边缘星宿——赤脚大仙闲散超然，风雨雷电四神司职自然，二十八星宿轮值护法； 佛道制衡——如来佛祖与太上老君虽非天庭臣属，却通过"玉帝请佛降妖"与"老君献宝收徒"形成对天庭的宗教渗透与权力制衡。 天庭体系的核心政治学特征：名义上统御三界，实质上对佛道两界只能"请"而不能"调"，对人间只能"降旨"而不能"直管"——天庭的"集权"是相对的，其实质是三界博弈中的最大公约数。
