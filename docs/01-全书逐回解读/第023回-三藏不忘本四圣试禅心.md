# 第023回 三藏不忘本 四圣试禅心

> 轨标：教学讲解
> 对应原著：第二十三回
> 数据指标：Forming 阶段结束后首次 Storming 震荡，四人参考一人落选（八戒），通过率 75%

## 原文回目

**第二十三回 三藏不忘本 四圣试禅心**

回目两句，前句"三藏不忘本"是因，后句"四圣试禅心"是果。"不忘本"对"试禅心"——一个是修心的内功，一个是考验的外加。**这一回讲的是：队伍刚凑齐，考验立刻就到。** 吴承恩不让这支队伍有一天安稳日子。

"四圣"是黎山老母、观音、文殊、普贤四位菩萨，化身母女四人。母女四人对应师徒四人——四个考验，四个答卷，一份判词。

## 剧情梗概

师徒行至一座庄院，见一寡妇携三女，家财万贯，欲招师徒四人为婿。唐僧脸色大变，"如雷惊的孩子，雨淋的虾蟆"，坚决不从。悟空、沙僧亦不动心。

独八戒动心，借口喂马，私下去找寡妇央求。八戒既要妻又要财，甚至愿意"招赘"——连师父都不跟了。寡妇取一方汗巾，言"撞天婚"：让他蒙眼去撞，撞着谁就娶谁。八戒撞了一夜，撞得嘴青脸肿，一个也没撞着。

次日清晨，庄院不见，师徒寻八戒，见他被绑在树上，羞愧难当。半空中黎山老母、观音、文殊、普贤现出真身，留下一张简帖："信救清净之体，何来色欲之私？"——八戒是这一回唯一落选的人。

## 重点要点

### 一、Forming 结束后的第一次 Storming

按 Tuckman 团队发展四阶段，第二十二回沙僧归队是 Forming 的终点，第二十三回立刻进入 Storming：

| 阶段 | 回目 | 标志事件 |
|:---|:---|:---|
| Forming 终点 | 第 022 回 | 五人集结完成 |
| Storming 起点 | 第 023 回 | 四圣试禅心 |
| Storming 高峰 | 第 027-028 回 | 三打白骨精，悟空被逐 |
| Performing 重启 | 第 031 回 | 八戒义激猴王 |

**吴承恩不让队伍有"蜜月期"。** 队伍刚齐，考验就来。这不是巧合，是组织规律——人凑齐的那一刻，就是矛盾开始的那一刻。

### 二、八戒 = 团队弱点暴露（欲望维度）

这一回的"答卷"是高度结构化的：

| 成员 | 对招婿的反应 | 答卷 |
|:---|:---|:---|
| 唐僧 | 雷惊雨淋，坚辞不受 | 通过 |
| 悟空 | 笑而推托，识破亦不点破 | 通过 |
| 沙僧 | 默然不动 | 通过 |
| 八戒 | 私下央求，既要妻又要财 | **落选** |

四人四答，三人不动，一人动。**八戒不是"坏人"，是"正常人"。** 他代表的是这支队伍里最"人"的部分——贪财、好色、怕苦、想家。吴承恩把他写成反面教材，不是批判，是暴露：**一支以"圣"为目标的队伍，必须先把"人"的弱点处理掉。**

### 三、考验设计 = 上级对下级的合规测试

四圣试禅心，从组织视角看，是一次**自上而下的合规审计**。

| 维度 | 设计 |
|:---|:---|
| 考官 | 黎山老母（主考）+ 三大菩萨（副考） |
| 考题 | 财色双诱（家财万贯 + 母女四人） |
| 考场 | 取经路上临时搭建的"庄院" |
| 判定 | 三人通过，一人落选 |
| 惩戒 | 八戒被绑树上（轻罚，留用） |

**这是观音作为 PM 的第一次正式"考勤"。** 前二十二回是"招人"，这一回是"筛人"。筛掉的是"心"，不是"人"——八戒没被开除，只是被绑了树。**组织对弱点的处理向来如此：不开除，但要让你知道我知道。**

### 四、"不忘本"的佛教修心含义

回目"三藏不忘本"，"本"是什么？是唐僧的"出家之誓"，是金蝉子的"佛门根本"。

"不忘本"三个字，在这一回有双重指向：
- **对唐僧**：不忘出家的本心，不被色欲动摇
- **对八戒**：忘了本（出家人的根本戒律），所以被绑

**"不忘本"不是道德，是技术。** 佛教讲"本心"——本心不丢，外物就不能动你。唐僧"如雷惊的孩子"，是本心在起作用；八戒"心痒难挠"，是本心已失。一个守住，一个丢失，差别只在这一念之间。

## 名句赏析

> 那长老如雷惊的孩子，雨淋的虾蟆，只是呆呆的坐在那里，半晌不肯言语。

"雷惊的孩子，雨淋的虾蟆"——两个比喻，一雅一俗，一急一钝。**孩子是惊，虾蟆是麻木。** 唐僧的反应不是"愤怒拒绝"，是"吓懵了"。这八个字写出了一个出家人面对色诱的真实状态：不是定力多深，是吓得多狠。

> 八戒道：「娘啊，你物件有多少？都要我也用得着。」

这是八戒的"贪"被写到极致的一句话。"物件有多少，都要"——**他不是要某一样，是要全部。** 财也要，色也要，连丈母娘也要。吴承恩用这一句把八戒的"贪"画到了顶点。

## 个人札记

这一回读完，最让人不舒服的是那个"庄院"。

它出现得无声无息，消失得也无声无息。四个菩萨化身的母女，坐在堂上，谈笑风生，跟师徒说家事、说招婿、说田产。**那不是妖怪的幻境，是上级的考场。** 唐僧不知道自己被考，八戒也不知道自己被考——所有人都以为是"遇到了好事"。

可"好事"恰恰是最难的考题。**人不怕难，人怕"好"。** 难来时人硬撑，好来时人软。八戒不是坏，是软——软在财色面前，软在家常温情的想象里。

他被绑在树上，羞得不敢抬头。师徒来解他，他还在嘴硬。**这是中国人对"丢脸"的全部处理方式——不认，但要记住。** 八戒此后再没好色到这种地步，不是他改了，是他被记住了。

四圣走了，留下一张简帖。简帖上写的是"信救清净之体，何来色欲之私"——**可这句话是写给八戒看的，还是写给唐僧看的？** 我猜是写给唐僧看的。告诉这个领导者：你队伍里有一个会动心的人，你自己看着办。

唐僧看了简帖，没说话。他此后也没处理八戒。**一个领导者对下属弱点的最大处理，就是"知道但不处理"。** 因为他知道，这支队伍离不了八戒——离了八戒，连个挑担的都没有。

合规测试不过，不代表开除。**组织对"人"的容忍，向来比对"事"的容忍要高。**

延伸思考：
1. 四圣试禅心，若八戒也通过了，这一回还成立吗？八戒的"落选"是设计的必要还是偶然？
2. 唐僧"如雷惊的孩子"——是定力深，还是吓懵了？二者有何区别？
3. 观音为何要联合三大菩萨一起考？一位菩萨不够吗？这是"考勤"还是"立威"？
