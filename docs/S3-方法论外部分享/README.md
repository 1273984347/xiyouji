## 改写规则

1. **脱敏**：删除所有项目特定引用（W### 编号、commit hash、绝对路径、内部文件名交叉引用、内部 skill 路径）
2. **通用化**：将项目内部案例抽象为通用场景，保留方法论本质
3. **受众转换**：从项目接手者转为 AI 代理协作/项目管理/工程实践领域的技术人员
4. **结构保留**：保持原文核心结构 + 增加引子 + 可复用清单 + 总结
5. **发布平台适配**：适合博客/公众号/知乎/掘金
