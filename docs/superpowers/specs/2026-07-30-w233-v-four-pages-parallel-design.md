## 四、架构 + 组件 + 数据流

### 单文件架构（复用 W229 V2 模板）

每页约 640 行，结构统一：

```
<!DOCTYPE html>
├── <head> 古典宣纸风 CSS + @font-face Noto Serif SC + JetBrains Mono
├── <body>
│   ├── skip-link + breadcrumb + h1 + subtitle
│   ├── hero 渐变 + KPI 卡片（4-6 个）
│   ├── Section 1-6（每 Section 含 1 个 D3.js 图表 + 说明文字）
│   ├── 跨页面导航（4 页互相链接）
│   ├── noscript fallback
│   └── footer 双索引
└── <script> D3.js v7 + EMBEDDED_DATA（支持 file:// 协议·无 fetch）
```

### 组件清单

- D3.js v7 CDN + EMBEDDED_DATA fallback
- 古典宣纸风配色系统（#faf7f2/#c8463a/#3a6b8c/#7a5230/#5a7a3a 5 色 + 渐变）
- KPI 卡片组件（复用 W229）
- 5 类图表组件按页选用：radar / heatmap / timeline / sankey / scatter / bar / pie / boxplot / polar / stacked
- 跨页面导航栏（4 页互链 + 返回 dashboard）
- footer 双索引（与 W232 文档一致的 4 索引类型）

### 数据流

- 每页 EMBEDDED_DATA 内联 JSON（支持 file:// 协议·与 W229 一致）
- 数据源：
  - W233-1：W232 文档三组对照 + 明代思想史时间线
  - W233-2：原著 100 回五众心理分析（基于 character-sentiment-arc 数据扩展）
  - W233-3：妖怪谱系（15 代表妖怪能力量化）
  - W233-4：A6 诗词 7 篇文档 + 原著诗词分布
- 无外部 API 调用、无 fetch
- 时间维度动画（W233-2 心理曲线 + W233-4 诗词时间线）支持播放/暂停/滑块
