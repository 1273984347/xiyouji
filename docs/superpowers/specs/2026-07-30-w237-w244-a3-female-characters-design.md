## 四、执行策略

### 4.1 dispatching-parallel-agents 八 subagent 并行

- 八个 subagent 独立无共享状态无竞态
- 每个 subagent 负责一篇专题
- 每个 subagent prompt 包含：理论家/核心概念/line 号候选/九段式模板/footer 格式

### 4.2 Preflight 三轨验证

- Grep 验归属：每个 line 号 Grep 验证归属该回目
- Read 验内容：每个 line 号 Read 验证内容匹配核心概念
- 数据驱动：基于"原著回目 - line 号"映射表

### 4.3 DRL R1b 主代理 spot-check

- P0：footer 双索引缺失 / h1 缺失 / placeholder 残留
- P1：四理论家不齐全 / 四核心概念不齐全 / line 号归属错误
- P2：术语表不规范 / 跨学科呼应缺失
- P3：措辞 / 标点 / 格式细节
