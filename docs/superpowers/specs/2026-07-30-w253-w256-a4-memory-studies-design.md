## 一、方向背景与定位

### 1.1 A4 现状

- A4 主题专题现 91 篇，含十七维叙事学框架 + 十二全新维度
- 已有相关专题：时间叙事学专题、历史叙事学专题、创伤叙事学专题
- **缺口**：尚未覆盖记忆研究（Memory Studies）这一独立学科方向

### 1.2 记忆研究学科定位

记忆研究（Memory Studies）是 20 世纪后半叶兴起的跨学科领域，区别于：
- **时间叙事学**：关注时间结构（时序/时长/频率），记忆研究关注记忆内容与建构
- **历史叙事学**：关注历史叙事的真实性，记忆研究关注记忆的选择性与集体性
- **创伤叙事学**：关注创伤的不可叙述性，记忆研究关注记忆的日常运作与伦理

### 1.3 与现有专题的差异化

| 现有专题 | 关注点 | 记忆研究专题 | 差异化 |
|:---|:---|:---|:---|
| 时间叙事学 | 时间结构 | 记忆内容 | 结构 vs 内容 |
| 历史叙事学 | 历史真实 | 记忆建构 | 真实 vs 建构 |
| 创伤叙事学 | 创伤断裂 | 记忆运作 | 断裂 vs 运作 |

### 1.4 跨方向呼应

- 与 A5 文化背景（明代历史）呼应：记忆作为历史的文化建构
- 与 A3 人物深化（身体政治学）呼应：身体作为记忆载体
- 与 V 可视化呼应：记忆的可视化（如记忆地图、记忆网络）

### 2.1 W253 文化记忆专题

**理论框架**：文化记忆研究（Cultural Memory Studies）
**核心理论家**：扬·阿斯曼（Jan Assmann·《Das kulturelle Gedächtnis》1992）
**四核心概念**：
1. **文化记忆**（Kulturelles Gedächtnis）：通过仪式、文本、图像传承的长期记忆
2. **仪式重复**（Rituelle Wiederholung）：文化记忆通过仪式周期性激活
3. **经典文本**（Kanonischer Text）：文化记忆的物质载体
4. **文化身份**（Kulturelle Identität）：文化记忆建构群体身份

**line 号锚点**：
- 第12回 line 1200（观音显象·文化记忆的唤醒）
- 第98回 line 8900（真经·经典文本的获得）
- 第100回 line 914（详解.txt 斗战胜佛·记忆的圆成）
- 第14回 line 1443（心猿归正·文化记忆的接入）

**西游应用主线**：
- 取经作为文化记忆的仪式重复（八十一难作为记忆仪式）
- 真经作为经典文本的文化记忆功能
- 唐僧作为文化记忆的承载者（金蝉子转世·前世记忆的文化传承）
- 成佛作为文化身份的终极建构

**九段式结构**：
1. 元信息区（W253·v2.2.45·文化记忆研究·A4 方向第 92 篇）
