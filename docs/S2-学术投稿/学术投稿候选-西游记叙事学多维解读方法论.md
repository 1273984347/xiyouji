## 一、摘要

本文以《西游记》为研究文本，提出"多维叙事学解读方法论"——一种结合经典叙事学、感官叙事学、文本叙事学、社会叙事学、自然叙事学五大类共十七个维度的系统化解读框架。研究以四位理论家为镜（每维度引用 4 位理论家 + 4 个核心概念 + 4 个 line 号原文锚点 + 25-40 个术语），形成"理论框架—文本锚点—古今对位—延伸思考"四段式分析结构。研究产出包括：79 篇主题专题、56 篇人物深度分析、61 个 D3.js 可视化页面、132 个数据维度、55 条学术引用。本文总结该研究流程中沉淀的方法论经验：DRL 真循环审查机制、三 skill 闭环（审查—收尾—沉淀）、E1 跨 session 验证铁律、双索引可追溯机制、Preflight 三轨验证、十七维叙事学框架演化路径。

**关键词**：西游记；叙事学；多维解读；数字人文；可视化；DRL 真循环

## 二、研究背景与问题

### 2.1 数字人文视野下的古典文学研究

数字人文（Digital Humanities）作为 21 世纪兴起的研究范式，强调以计算方法与传统人文学科结合，对经典文本进行多维度、可计算、可视化的解读。《西游记》作为中国古典四大名著之一，现有研究多集中于文本考据、版本演变、思想主题等单一维度，缺乏跨维度的系统化解读框架。

### 2.2 现有研究的局限

现有《西游记》研究的局限主要表现在三方面：

- **维度单一**：多数研究聚焦于单一主题（如权力政治、宗教思想、人物形象），缺乏跨维度的对照与整合
- **缺乏可计算性**：定性分析多，定量分析与可视化呈现少
- **缺乏可追溯性**：论证过程依赖研究者个人记忆，难以被第三方独立验证

### 2.3 研究问题

本研究提出三个核心问题：

1. 如何构建一个**多维叙事学解读框架**，使《西游记》的解读既覆盖经典叙事学维度，又能扩展到感官、文本、社会、自然等新兴维度？
2. 如何将该框架**可计算化与可视化**，使解读结果能够以 D3.js 交互式图表呈现？
3. 如何保证研究流程的**可追溯性与可验证性**，使每个论证步骤都能被第三方独立验证？

### 3.2 四理论家对照法

每个维度引用四位理论家，确保理论多元性与对照性。例如 W191 网络叙事学的四位理论家：

## 四、研究流程：DRL 真循环与三 skill 闭环

### 4.1 DRL 真循环审查机制

为保证研究质量，本研究采用 DRL（Deep Review Loop）真循环审查机制。DRL 真循环的核心是"审查→修复→重新审查"的循环，直到连续 N 轮重新审查均未发现新问题才判定收敛。本研究将 N 设为 0（比赛级标准），即每轮审查必须零问题才算收敛。

DRL 真循环包含 4 层过拟合防护：
1. **P2 残留 N**：P0/P1 必须降到 0；P2 允许残留 N 条（生产 N=3）
2. **边际收益 gate**：修复成本 > 问题危害×3 → 接受残留
3. **过拟合警报**：震荡 3 轮不单调 / 回归率 >30% → STOP 报告
4. **严重度门槛**：P3 及以下不报

### 4.2 三 skill 闭环

研究流程采用三 skill 闭环：
- **deep-review-loop**（审查端）：DRL 真循环审查
- **mem-wrap-up**（收尾端）：7 步收尾流程（含 Step 4a 项目层 spot-check + Step 7a memory 层 spot-check）
- **self-evolution**（沉淀端）：11 维度复盘（dim 1/5/9/11 为关键维度）

三 skill 严格按"审查→收尾→沉淀"单向闭环执行，任一 skill 跳过视为闭环断裂。

### 4.3 E1 跨 session 验证铁律

研究中沉淀的 E1 铁律（29 次复现 + 3 次毕业判据）：
- **E1 跨 session git tracked 验证**：跨 session 接续时，prior session 报告"edits made to N files"，主代理必须用 `git ls-files <file>` 验证文件是否实际被 git tracked
- **E1 升级版修复落地验证**：prior session 报告"修复已落地"时，主代理必须用 Grep spot-check 验证文件内容是否实际包含修复后的值
- **Subagent 工具证据不可盲信**：subagent 报告"已保护 X 不受影响"的声明，主代理必须用独立工具调用 spot-check

### 4.4 双索引可追溯机制

研究采用双索引可追溯机制：
- **正向时间线索引**：CHANGELOG.md 按 W### ID 顺序记录所有变更（W001-W193）
- **反向文件索引**：file-index.md 按文件路径反查"该文件被哪些 W### 改过"

双索引互为校验，使每个文件变更都可双向追溯。

### 4.5 Preflight 三轨验证

每个新专题在创建前必须通过 Preflight 三轨验证：
- **Track 1**：line 号归属验证（关键词在 `text-search.html` 的实际位置）
- **Track 2**：内容匹配验证（七段式结构完整 + 术语含双字段）
- **Track 3**：章节归属验证（line 号位于预期回目范围内）

## 六、讨论与启示

### 6.1 多维叙事学框架的可迁移性

本研究构建的十七维叙事学框架不限于《西游记》，可迁移到其他古典文学研究。每维度的"四理论家对照法"+"四回目 line 号锚点"+"古今对位"三段式分析结构，可作为通用古典文学解读模板。

### 6.2 数字人文研究流程的可复制性

本研究沉淀的 DRL 真循环 + 三 skill 闭环 + E1 验证铁律 + 双索引可追溯 + Preflight 三轨验证 五件套方法论，可复制到其他数字人文研究项目。该流程保证了研究的可追溯性、可验证性、可复现性。

### 6.3 可视化作为研究方法

本研究将可视化不视为"研究的呈现方式"，而视为"研究方法本身"——通过 D3.js 力导向图、桑基图、雷达图的交互式探索，研究者可以发现定性分析难以发现的关联模式。例如通过十六维叙事学关系图谱，可直观发现"感官叙事学"与"文本叙事学"的交叉关联。

## 七、局限与未来工作

### 7.1 局限

- **理论框架西方中心**：当前十七维叙事学引用的理论家以西方学者为主（约 70%），中国传统文论（如刘勰《文心雕龙》、钟嵘《诗品》、司空图《二十四诗品》、严羽《沧浪诗话》）仅在 W193 人物赋、W194 景物诗等少数专题中作为主框架
- **可视化交互深度不足**：当前 61 个可视化页面以静态展示为主，缺乏跨页面联动与维度下钻
- **i18n 缺失**：当前所有文档与可视化页面为中文，未进行英文国际化

### 7.2 未来工作

- **中国文论维度补全**：将刘勰、钟嵘、司空图、严羽、王国维五位中国文论家作为独立的"中国叙事学"维度专题
- **跨页面联动可视化**：将 61 个独立可视化页面整合为可跨页面联动的统一仪表盘
- **i18n 与英文学术投稿**：将核心方法论文档与可视化页面进行英文国际化，向 Digital Scholarship in the Humanities / Journal of Cultural Analytics 等期刊投稿
