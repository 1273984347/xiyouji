### 2.5 按图型族的专属内容层打磨项（用户 2026-11-18 标注 9 个图表后增补）

**为什么增补**：原计划只按「页面能力」（来源/结论/tooltip/图例）列判据，太粗；实际上**不同图型的内容层问题完全不同**——树图是「标签压在色块里糊成一团」、热力图是「色阶跨度大导致深浅难辨 + 行标签被裁」、气泡图是「圆点连成一片互相遮挡」⇒ 必须按图型族分别定口径与验收。

**图型族页数**（含该特征的页数·各族有交叉·全量普查 157 页含图型特征）：气泡/散点 138 · 垂直条形 120 · 水平条形 111 · 时间线 71 · 折线/面积 63 · 热力矩阵 51 · 树图 treemap 48 · 饼/环 44 · 力导向图谱 40 · 网络/弦图 42 · 桑基 34 · 矩阵/象限 28 · 地理地图 6。

| 图型族 | 内容层专属问题（须逐族验收） | 验收口径 |
|---|---|---|
| 树图 treemap | 标签落在色块内会糊成一团（用户标注 ① dashboard 三个 treemap 块内字不可读）· 小块标签须隐藏并转图例 · 面积即数值须标占比 | 块内标签**不重叠且可读**；无标签块在图例可查；面积与数值一致 |
| 桑基 sankey | 细流带（<3px）不可读 · 两端节点语义标签 · 排序稳定性 | 细带须聚合或标注；两端标签齐全；同数据两次渲染节点序一致 |
| 热力矩阵 | 色阶跨度大 ⇒ 深浅难辨（用户标注 ② 人物×回目矩阵）· 行列标签被裁（「孙悟空」显示成「悟空空」） | 色阶分档 + 独立色标 legend；行标签完整不截断；单元格值可读 |
| 气泡/散点 | 圆点连成一片互相遮挡（用户标注 ③ 出场时间分布）· 大小编码须有图例 · 轴须等比 | 重叠圆点比例有上限；大小图例齐全；轴比例一致 |
| 水平条形 | 条外双值标注（「96 回 / 6,197 次」）须对齐不裁 · 条长与轴刻度一致 | 标注不出条形图区；数值与条长一致 |
| 力导向图谱 | 节点标签截断与相互重叠（EN graph-explorer 目视实证） | 标签完整或缩放显示；重叠率达标 |
| 地理地图 | 密集节点名互相遮挡 · 投影正确性 · 端点（长安/灵山）可辨 | 标签避让生效；路线连线与地理路径一致 |
| 时间线 | 刻度密度（第5回…第100回）与事件点对齐 · hover 详情 | 事件点与刻度对齐；hover 详情可用（实测） |
| 可筛选表格 | 筛选组合与计数回显一致 · 空态说明 | 筛选后计数与表体一致；空结果有说明 |

> **增补纪律**：① 每族先取 1 页做样板 → 主会话目视 → 再铺（E-254：禁凭推测改 172 个图表面）；② 族级口径须写进判据（方向/阈值/下限/触发时机）；③ 用户标注的 9 个图表**逐个落到族**，不允许「归到某一族就不管了」。

## 6. 风险与不做清单

| 风险 | 处置 |
|---|---|
| 补「结论段」变成凑数文本 | 结论必须与本页数据一致；目视抽验每族 1–2 页；无信息量的页改为「删图 + 正文给结论」 |
| 补「来源标注」写成模板话 | 标注须含**具体口径**（真值源路径 + 生成命令 + 快照日期），不得只写「数据来源：见数据集」 |
| 标签裁切根修改 172 页 → 大面积视觉回归 | 先做样板页 + 目视，再铺；每族一批 |
| EN 页 A/C 同页冲突 | 开工前切分表；同页同区块只允许一人写 |
| 基线冻结把在途缺陷冻成合规 | 重冻结放在**三线全部交付之后**；逐槽 `--strict` 复核 |
| 真值英文缺口用编造内容填 | 禁编造；M1 走人工英译，宁可留缺口并登记 |

**不做**：不改现役视觉语言（用户裁决保留宣纸刻本）；不做新设计方向；不碰 `site/reader` 636 页版面归并（批三至批五）；不顺手改 `check_gov_doc_claims` 报的 5 项既存漂移（属另一批口径订正，本批只如实识别不混入结论）。
