# W1262 设计系统规范 ·「中性骨架 + 浓彩原文层」（v3 终裁 · C 路线）

> 全站视觉重设计的正本规范（第三轮，按简报 §9 方向终裁重写，覆盖 §0/§8）。文体沿 HIG：**加粗句首 = 规则**，后接机制解释。
> 色板对比度为机器复算（WCAG 2.1 相对亮度公式），色盲安全以 Machado & Oliveira & Fernandes (2009) 严重度 1.0 模拟矩阵 + CIE76 ΔE 复算；复算脚本 `_palette_check.py` 随本目录交付，可重跑验证。
> 令牌名与承载类名为冻结接口（§3.2/§3.3），本文只约束取值与用法。

## 0. 设计观点

**这个站点是一座安静的美术馆：墙是素墙，画是重彩。** 全站分两层语域，接缝即语义——像学术校勘本里正文与神注的字体之分：

- **工具语域（默认全站）**：中性灰阶素墙、hairline 结构、仪器图表、sans 正文——身份是「精度」。按钮、表格、导航、KPI、表单全部中性，阅读经济学非协商。
- **原文语域（语义触发）**：凡《西游记》自己的声音出现处——hero 主视觉、精选卡艺术区、回目与章节题、引文块、KPI 批点记号位——切换到原著的视觉血统：**版画劲线**（黑白节奏 + 套色错位）、**壁画矿物颜料**（朱砂/石青/石黄/石绿/胭脂/青金/赭石/墨灰，≤8 色相）、**傩面戏妆的强对比**（黑轮廓压纯色块）、**连环画的叙事势能**（动态不对称构图）。
- **明暗分工**：亮色主题是白盒子画廊（中性冷灰素墙）；**暗色主题是入窟**——壁画的本来居所，深暖底上饱和颜料发色，是浓彩层的主场。

三条接缝纪律（防俗艳）贯穿全部组件：① **正文永不殖民**——浓彩只进 display/艺术/装饰位；② **颜料纪律**——色相 ≤8、全过色盲+对比度复算、禁霓虹禁糖果渐变、浓彩 ≠ 饱和度拉满；③ **素墙挂画**——每件浓彩件都被安静的 chrome 框住。

## 1. 色板

**颜色全部语义化，界面层禁止按背景色「挑颜色」。** 明暗两套取值独立调校：亮色是中性素墙（冷灰），暗色是入窟（深暖底）——暖调只属于暗色的洞窟地面，亮色永远保持画廊白。

## 3. 间距 / 圆角 / 海拔

**间距 = 4px 网格算术**（`--space-N`=N×4px；`--gap-section: 96px`）。**圆角三档**：控件 8px、卡片 12px、徽章/按钮全圆；印章 rx 2.5。**海拔五档**（暖墨系阴影无纯黑）：elev-1 分段激活 → elev-2 hover 浮起（`--shadow-lift`）→ elev-3 tooltip → elev-4 抽屉；暗色纵深靠表面阶梯，阴影只作陪衬。

## 4. 材质、分层与接缝纪律

**模糊/玻璃只许功能层**：全站唯一材质点是顶部导航（blur 14px + 82% 纸色，`@supports` 回退纯色）；tooltip 实底墨面板；卡片图表一律实底；氛围靠静态手段（hero 乌丝栏底纹，纯 repeating-linear-gradient）。

**接缝三条硬规则（§9 原文，逐条落实）：**
1. **正文永不殖民**：浓彩只出现在 `.art-panel`（坛城）、`.viz-card__art`（精选卡艺术区）、`.section-title`/`.viz-title` 的鱼尾记号与套色规则条、`.cite-block`（朱批栏线）、`.kpi-card::before`（批点短线）、印章。正文段落、表单、表格、导航的底色与文字色永远是工具语域取值。
2. **颜料纪律**：全站颜料 = `--series-1..8` 恰 8 个色相；每件浓彩件至多 3–4 个色相（经济性）；全部过 `_palette_check.py` 复算；禁霓虹、禁糖果渐变、禁饱和度拉满。
3. **素墙挂画**：坛城住在 `.art-panel`（hairline 边 + canvas 底的安静画框）；精选卡艺术区住在 `.card` 边框内；鱼尾/套色规则条贴在素墙的 hairline 上。每件浓彩件都有安静 chrome 包围。

**文化器件配额（≤2 件做透）**：① 百回坛城（签名元素，§10）；② 朱砂印「解」（导航 24px / 首页落款 32px / 页脚 26px——版画落款的位置语法）。鱼尾与套色规则条是器件 1 的语法延伸（版心记号 + 套印痕），不是独立器件。

**z 轴**：`--z-nav 100` < `--z-mask 200` < `--z-drawer 300` < `--z-tooltip 500`。

## 5. 图表层规范（工具语域）

**界面是文人的，图表是度量的：图表保持仪器精度，颜色用颜料谱。**

- **轴线**：1px `--axis-line`；**网格**：1px `--grid-line`；**刻度标注**：11px `--font-data` tabular，`--ink-faint`。
- **条形**：直角矩形 rx 2px、行距 36px；身份组取 `--series-1/2/3`；数值标注于条端右侧 8px。
- **悬停**：命中区整行；行外条形 opacity 0.45（150ms）。
- **tooltip**：`.chart-tooltip` 实底墨面板，派生类 `.tt-name .tt-row .tt-key .tt-val .tt-sep`，跟随、视口钳制、`.visible`、150ms opacity、`pointer-events: none`。
- **图例**：`.chart-legend` + `.legend-item`（12px 色块 + 文字）。
- **峰值强调**：唯一朱色给极值。
- **空态**：`.empty-state`（图标圈 + 衬线题 + 上下文文案 + 清除动作）。
- **小屏**：<768 横向滚动（svg min-width 560/480px），禁止压碎。

## 6. 组件规则

- **顶导航 `.topnav`**：64px、底部 hairline；品牌 = 朱印 + 宋体 wordmark；当前项朱色下划线；<768 抽屉（Esc 可关）。

- **徽章 `.badge` / `.data-status-badge`**：26px 全圆，`data-status="calibrated|sample|draft"` 三态，色点 + 文字。
- **分段过滤 `.filter-tabs` / `.filter-tab`**：sunken 底 pill 容器，激活项纸面浮起 + 加粗 + 计数变朱；`aria-pressed`。
- **搜索 `.search-box`**：44px pill，focus 转朱，输入即搜。
- **表格 `.table-wrap` / `--sticky` / `.table-anim`**：表头衬面 sticky、行 hairline、数值右对齐 mono；入场 stagger ≤540ms。
- **空态 `.empty-state`**：图标圈 + 衬线题 + 上下文文案 + 清除动作。
- **目录行 `.toc-row`**：双列目录网格（衬线题 + mono 计数 + 描述 + 箭头 + 界栏线）。
- **精选卡 `.viz-card` + `.viz-card__art`**：非对称网格（7+5、6+6）；艺术区 = 套色版画 SVG（劲线 2.5–3px、颜料色块 2px 错位套印、对位规线十字、每件 ≤4 色相）；hover elev-2。
- **引文块 `.cite-block`**（原文语域）：楷体 + 2px 朱砂左栏线（朱批语法）。
- **书口鱼尾 `.section-title::before` / `.viz-title::before`**：12×10px（题级 14×11px）朱砂实心 clip-path 鱼尾，每题恰一枚。
- **套色规则条 `.section-head::after`**：64×3px 朱砂短版压在 section-head 的 hairline 上（套印痕）。
- **印章 `.brand-mark` / `.seal-mark`**：SVG 方印「解」（宋体阴文）；导航 24px、落款 32px、页脚 26px；恒 `--accent` + `--text-on-accent`。

- **页脚 `.site-footer.dark-band`**：墨色横带 + 印 + 双协议。

## 7. 动效

**三档时长硬约束**：反馈 ≤150ms（hover/按压/tooltip/图表行高亮/坛城刻度高亮）；状态 ≤250ms（过滤、tab、抽屉、主题切换）；入场 ≤600ms（reveal、条形生长、行 stagger、坛城旋转入场）。白名单：KPI 计数 900ms（`--dur-count`）。

- **只动 transform / opacity**；颜色过渡属反馈态；tooltip 位置为一次性赋值。
- **缓动三系**：out-quart / out-expo / soft。禁 bounce、禁无限循环。
- **坛城入场**：整体 rotate(-8°→0°) 600ms + 外环/标注 opacity 480ms + 百根刻度沿环序 opacity 420ms（delay = i×1.8ms，末根 598ms ≤600ms）——连环画式的环读势能，一次性可打断。
- **reduced-motion 双守卫**：CSS 全局停帧 + reveal/表格/坛城强制落位；JS `const RM = matchMedia('(prefers-reduced-motion: reduce)').matches` 短路（计数落终值、条形跳过生长、坛城直接定格）。
- **入场一次性**：IO 触发即 `unobserve`；组内 stagger 45ms 上限 180ms；1.6s 兜底全量落位；无 JS 恒可见——fail-open。
- **KPI 计数**：IO 一次、900ms easeOutExpo、终值精确还原、终值本在 HTML——fail-open。
- **tooltip 契约**：跟随、钳制、`.visible`、150ms opacity。

## 8. 响应式

**断点 1024 / 768 / 480；375px 无横向滚动是交付判据。** 1024 下 hero 双栏→单栏（坛城居中收窄 ≤480px）、KPI 4→2 列、精选卡 6+6；768 下导航抽屉、目录单列、精选卡全宽、表格图表横向滚动；480 下坛城标注随 viewBox 等比缩小（保持完整，不裁切）。触控目标全站 ≥44×44px。

| 动效敏感 | prefers-reduced-motion | CSS+JS 双守卫（含坛城定格） |
| 键盘 | 跳链 + Esc | skip-link、抽屉 Esc、tooltip 信息有表格等价物 |
| 屏幕阅读器 | 语义替代 | 坛城 `role="img"` + aria-label + 14 条隐藏清单；图表 aria-label + 表格等价；结果行 `aria-live`；印章 `role="img"` |

## 10. 签名元素：百回坛城

**签名必须同时是内容与仪器——v3 把「量」与「画」焊成一个形。** 百回坛城 = 百回刻度带的环形化：100 根刻度环行成圆（每刻一回）、每十回一根高标（宋体小字环标）、朱色刻度是已批注回目（悬停读真实回目原文，14 条逐字可考，其余显示「尚无批注」）、五段套色弧 = 五相五方（石青/朱砂/石黄/白/玄，套印错位 2.5°）、版画劲线外环在右上破口、内_field 三道墨浪带一道石绿套色、右上角套印错位的日轮。**中心是活的读数**：悬停任何刻度，坛城芯从「一百回」翻成「第 N 回 + 回目」——仪器（可读坐标与状态）与内容（一百回与批注）在同一件东西上，同时它是全站唯一的浓彩主视觉（素墙挂画）。可访问性：`role="img"` + aria-label + 视觉隐藏回目清单；交互信息有 tooltip 与清单双通道。
