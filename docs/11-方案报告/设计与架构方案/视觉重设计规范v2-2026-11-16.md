## 1. 五条不可协商原则

1. **数据优先于装饰** —— 不承载信息、不建立层级、不引导视线的元素一律删。
2. **一套令牌，两个令牌集** —— 暗色**不是**亮色的反色，是独立取值的一组。
3. **对比度是门禁不是审美** —— 正文 ≥ 4.5:1，图形与文字标签 ≥ 3:1，逐页实测，禁目测。
4. **标签零缺陷是准入条件** —— 标签不得超出 svg 视窗（四向），不得相互重叠。
5. **一次声明，全站生效** —— 令牌与组件写在 site/tokens.css + site/system.css 单一事实源，页面只消费不重定义。

```css
html[data-theme="dark"] {
    --series-1: #E0604F;   /* 朱砂提亮 对背景 5.06:1 */
    --series-2: #669EAA;   /* 靛   对背景 3.66:1  */
    --series-3: #C1BE8B;   /* 赭   对背景 9.35:1 */
    --series-4: #879B85;   /* 苔   对背景 5.99:1 */
    --series-5: #76749E;   /* 青灰 对背景 6.39:1 */
    --series-6: #7C6175;   /* 紫檀 对背景 3.25:1 */
    --series-7: #92B7B0;   /* 雾青 对背景 8.33:1 */
    --series-8: #8E7782;   /* 陶   对背景 4.89:1 */
}
```

**色盲可辨性是硬约束**：8 槽的两两配对在 Machado 2009 两型矩阵（deuter / protan）
下的最小 CIEDE2000 ΔE 必须 ≥ 10（门槛即第 29 槽的既有阈值）。

- 亮色组实测 **最小 ΔE = 12.03**；暗色组实测 **最小 ΔE = 11.04**。
- 暗色组是**独立取值**（不是亮色反色）——同一色相下用**亮度阶梯**拉开可辨度。
- 搜索方法与结果可复算：`tmpe/w1261/palette_search2.py`（亮）/ `palette_dark.py`（暗）
  在「暖色锚点 + 对比度 ≥3 + 两两 ΔE ≥10」的约束下搜索。
- 暖色槽位密度是约束瓶颈：**朱砂与赭同属暖色族，二者 ΔE 天然偏低** ⇒
  第 8 槽最终取紫梅（而非陶土）——陶土与朱砂/赭构成三暖色，ΔE 落到 8.6–8.7（不达标）。

> 旧令牌 `--chart-1..6` 与 `--accent-2..4` **已就地重定向**到本层（不追加第二套声明，
> 以免同主题重名产生 `_override_2` 键并击穿门禁第 5 项「暗色计数」）。
> 页面**只消费不重定义**——若页面需新的语义名，在 `tokens.css` 定义后使用。

## 4. 图形语言（十族画法定规）

| 族 | 画法定规 |
| --- | --- |
| 柱/条形 | 柱宽 ≥ 2px 且 ≤ 类别间距 60%；值标签仅标极值与末位；轴刻度按可用宽度抽稀（间隔 ≥ 标签宽 + 12px） |
| 折线/面积 | 线宽 ≥ 1.5px；线端留 2px 余量；多系列 ≤ 4 条，超出改分面 |
| 散点 | 节点半径 ≥ 2.5px；点标签仅对 top-N 或选中项；重叠点抖动或半透 |
| 环形/饼 | 标签一律外置 + 引线；扇区 ≤ 8；单扇区 ≥ 3% 才独立标注 |
| 桑基 | 节点标签置于节点外侧不压连线；连线透明度 ≥ 0.35 |
| 弦图 | 矩阵外轴标签留 ≥ 8px 间隙 |
| 力导向 | 节点标签仅对度数 ≥ 阈值的节点显示；标签加表面色描边（paint-order） |
| 树图 | 矩形内文字垂直居中不换行超 1 行；小矩形不标注（改 hover） |
| 热力图 | 色阶单调明度（色盲可辨）；单元格数值仅在色阶浅端标注 |
| 3D | 提供降级 2D 形态与静态回退图（file:// 不可用 WebGL 时） |

**公共实现**：site/system.css 的 W1261 图表图形层覆写块治理 122 页使用 d3 标准轴的页面。
**实测类名（首版规则曾全无匹配对象·盲审发现）**：轴组类名逐页自造
（.chart-axis / .bar-axis / .curves-axis …），图表容器也逐页自造
（.chart-block / .curves-wrap …）⇒ 唯二通用锚点是 d3 自产的 .tick 组与 .domain 轴线，
故规则最终按 **svg 级**下发（svg text / svg .tick text / svg .domain）。
轴线用 --axis-line、网格线用 --grid-line（仅横向·极浅）、轴标签用 --text-tertiary
（对 bg 5.02 亮 / 5.85 暗）并加表面色描边衬底、数据标签用 --text-secondary +
paint-order: stroke fill、网络图节点标签加 3px 表面色描边、图例 chip 化 2px 圆角。

## 5. 标签与碰撞的工程判据

    裁切：文本 bbox 超出所属 svg 视窗任一边 > 1.5px
    重叠：同 svg 内两两文本 bbox 相交面积 / 较小者面积 > 0.3

**规格必须写明的三项边界**（缺一 ⇒ 换人复跑必然对不上）：
① 越界方向（四向 / 仅水平）② svg 宽度下限（多窄不参与判定）③ 是否需滚动触发 reveal 后再量。

**对比度判据另需写明「背景取法」（本批实测踩坑）**：
文字可能落在**SVG 内绘制的形状**上（色块里的白字、节点里的标签）。
若背景一律取「DOM 祖先背景」，会把「白字写在朱砂块上」（实际 cr≈4.5，可读）
误判为「白字写在浅色页底上」（cr≈1.04，近乎不可读）⇒ **假阳率极高**
（本批首版探针报 1088 处 / 71 页，修正背景取法后大幅收敛）。
⇒ 判据须写明：**先取 SVG 内最近绘制形状（path/rect/circle/polygon/ellipse），
无则回落到 DOM 祖先背景**；且「零命中」必须 fail-closed（见 E-236）。

> 直接来自 W1259 的教训：交付者按「仅水平」判定报 87 页，独立复算按「四向」得 108 页——
> **两个数字都对，差异来自判据宽窄**。规范必须把边界写死。

## 5.5 图表文字的可读性配对（深墨 + 表面色描边）

**规则**：图表内的标签一律用**深墨字 + 表面色描边衬底**（paint-order: stroke fill），
禁「浅墨字 + 深色描边」。

**为什么**（对比度算术，不是审美偏好）：
- 描边承担「与底色分离」的职责，字芯只负责「自身可读」；
- **深墨字 + 浅描边**：字芯在任何底色上都与自己的描边成反差（描边即表面色）⇒ 深浅底皆可读；
- **浅墨字 + 深描边**：字芯在**浅底**上与底色同明度 ⇒ 字本身隐形，只剩一圈描边（实测 cr 2.31，不达标）。

**类名治理**：标签类名逐页自造（.river-zone-label / .tri-vertex-label / .node-label …），
CSS 无法枚举 ⇒ 用属性后缀选择器 `svg [class$='-label']` 覆盖，
配合轴规则与数据标签规则按上下文改回各自墨色。

**边界**：.river-zone-label 一类压在 **6% 透明度淡色底**上的标签，即使深墨 + 表面描边，
合成后仍约 2.54:1（略低于 3:1 门槛）⇒ 属**各页绘制参数**（淡色底的透明度设计），
须逐页调整底色透明度，不在本批 CSS 公共层的可治范围。

### 9.1 W1261 追加的已知边界

1. **暗色序列色与亮色不同源**：暗色组为独立取值（同色相 + 亮度阶梯），实测最小 ΔE 11.04
   （门槛 10）——比亮色组（12.03）更紧，因暗色底本身对比更宽容、可用色域更窄。
2. **页面内 347 处旧色板字面量已迁移**到新序列色；但仍有少量页面私有淡色（`#e8dfd0` 类）
   留在 colorMap 中 ⇒ 它们与卡片边框色（`--border-subtle`）的 ΔE 偏低（第 29 槽已冻结为存量），
   属**各页绘制参数**，须逐页调整淡色底深度。
3. **图表标签压在半透明淡色底上**仍约 2.54:1（略低于 3:1）⇒ 属各页底色透明度设计。
