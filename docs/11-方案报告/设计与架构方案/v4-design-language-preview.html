C · 字体体系：三族分工保留 + 九个排版角色

宋（标题）/ 黑（正文）/ 等宽（数字与拉丁标记）的分工是项目气质资产，v4 不动。 新增的是「角色层」：语义 → 族 + 字重 + 字号 + 行高 + 字距 + 颜色，一次定义、全站引用。
