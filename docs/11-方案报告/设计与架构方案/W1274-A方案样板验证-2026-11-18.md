## 2. 改造形态

块0 的**顶层规则**逐条比对公共层索引（选择器集合 + 声明**双逐字相同**）：

- 命中 ⇒ 剥离（认定为公共层规则）
- 未命中 ⇒ **保留**（页私有层，或同选择器的覆写版，如 `.data-status-badge` 的 `var(--radius-pill)`；或 @font-face（url 已按目录改写））

替换为（相对路径按页目录计算，顺序与原内联一致：tokens 在前、system 在后）：

    <link rel="stylesheet" href="../../tokens.css">
    <link rel="stylesheet" href="../../system.css">
    <style>
    /* W1274：公共层规则已外链（tokens.css + system.css）·本页私有层保留 */
    …本页私有层…
    </style>

工具：`scripts/relink_public_css.py`（`--dry-run` / `--apply` / `--self-test`·幂等·带 `MIN_STRIP_RULES` 阈值 150 的 fail-closed 门槛）。

### 3.1 一次被目视抓出的实现缺陷（已修）

第一版替换区间覆盖了**整个 style 块（含开闭标签）** ⇒ `<style>` 丢失 ⇒ **CSS 源码被当正文渲染**（整页显示 @font-face 源码）⇒ 而当时的探针与门禁**全绿**（取样 computed style 没命中）⇒ **只有目视亲验能抓到**。⇒ 修法：替换时**重建 `<style>` 包裹**；并给基线探针补「正文是否混入 CSS 源码」检测（`cssLeak`：正文含 `@font-face` / `color-scheme` 即判红）⇒ 后续批沿用。

## 4. 指标口径随路线重设（用户裁决项）

第 76 槽原口径按「类归属」计（11.9%）⇒ 与实际生效面脱节。⇒ 处置：**保留原口径与棘轮不动**（直接改会让棘轮瞬判红），**新增独立维度**「公共层实际加载面（外链页占比）」：

- 当前：**8 / 875 = 0.91%**（下限 0.80%·目标 100%）
- 随铺开推进而上升（棘轮只增不减）⇒ 铺完 867 页即 100%

## 6. 边界与未验证项

1. 变量块（`:root`）在页内副本里与 `site/tokens.css` **不是逐字相同**（副本展开了部分 var()）⇒ 本批保守保留在页内（实测 accent/paper/ink 一致 ⇒ 视觉无差）；
2. 徽标 `.data-status-badge` 的圆角：页内覆写版 `var(--radius-pill)`（=999px）优先于公共层 20px ⇒ **改造后仍是 999px**（与改造前一致）⇒ 但这意味着公共层的 20px 裁决**未生效于这 867 页**（存量语义漂移·另批处理）；
3. 铺开后需复核「页内变量块 vs 外链 tokens.css」的优先级与 CSP 哈希（外链不产生内联哈希·不需重算·但页内保留块的哈希仍在 874 页 CSP 里⇒ 需确认 generate_csp 覆盖）。
