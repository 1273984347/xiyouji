# 详解西游记 · 设计系统正本（SPEC）

> **设计语言：读数台（Reading Bench）**
> 刻度承担分组，读数承担结论，颜色只承载数据编码与状态；其余一切安静、精确、留白。
>
> 本文件是设计正本：令牌取值以 tokens.css 为准，类样式以 system.css 为准，
> 文中所有对比度与 ΔE 数值均由 _palette_check.py 实测复算（WCAG 2.1 + Machado 2009 色盲模拟 + CIEDE2000）。

## 0. 三个必答问题

### 0.1 读者能在 3 秒内读懂这张图说了什么吗？

能，但前提是版面把「标题 / 数值 / 图形 / 结论」按读图顺序排好，四者各司其职、不互相抢戏。数据可视化页的视觉权重自上而下是：

| 层级 | 承担者 | 版面位置 | 视觉权重手段 | 读者在此获得什么 |
|---|---|---|---|---|
| ① 这是什么图 | 页标题（衬线 28px）+ 元信息行（口径 / 更新日期 / 状态徽章） | 首屏第 1–2 行 | 唯一的大字号衬线标题，旁侧只用小号等宽字 | 口径是什么、数据可不可信 |
| ② 最关键的几个数 | KPI 行 4 卡 | 标题正下方 | 全页最大字号（36px 等宽数字），首个读数用强调色 | 规模与极值 |
| ③ 主体图形 | 图表区 | 版面最大面积 | 横向条形 + 直接标注数值 + 网格刻度 | 谁多谁少、差距多大 |
| ④ 结论 | 洞察框 | 图下方 | 衬线正文 + 青色小标题，与正文区区分 | 所以呢 |

三秒内读者依次读到：**口径 → 极值 → 形态 → 结论**。四者不重叠：标题不承载数据，KPI 不重复图形已有的维度，结论不引入图形里没有的新数字。

### 0.2 签名元素是什么？

**「十回尺」**——一把以「回」为单位的刻度尺（100 格刻度 + 难数齿 + 读数窗），只出现在数据可视化页的「八十一难 · 十回段分布」图上。

它同时是**内容**与**仪器**：

- **内容**：齿的数量就是该十回段真实发生的难数（5·9·11·10·9·8·10·7·6·6，合计恒为 81）；齿高即是读数，不是装饰纹样。
- **仪器**：尺身提供位置坐标（一格 = 一回），右上角的读数窗把「段 / 难数 / 占比」三个读数同步给出（悬停或点击某段即改写读数窗），像仪表盘上的数字窗。
- **唯一性**：全站只此一处。落地页刻意不放刻度尺——重复出现会把签名元素降级成装饰花纹。

### 0.3 明暗两态是同一套设计还是两种不同的设计？

**是同一套设计，但不是同一套取值的反相。** 判断依据三条：

1. **结构完全同构**：令牌名、令牌数量（109 项）、类名、栅格、字阶、动效时长全部一致；切换主题不改变任何布局。
2. **取值各自独立**：109 项中 63 项两态取值不同（其余为字号、字体栈、动效时长等与主题无关的结构量）。亮态是「白釉」——冷调纸白底 + 墨青黑字 + 深青釉强调；暗态是「夜釉」——深墨青底 + 亮青釉强调。
3. **物理逻辑不同，所以不能反相**：浅底上强调色必须**更深**才够对比（accent 对纸面 5.69:1），深底上强调色必须**更亮**（8.69:1）；数据序列色同理。简单反相会把强调色变成低对比的浅青，或把数据色变成看不清的深色。

## 1. 设计观点

站点有 875 个页面，其中 90 个是数据可视化页、636 个是长文阅读页。读者来这里的两种姿态截然相反：**长文要「沉浸」，数据要「判读」**。同一套设计必须同时伺候两者，于是分工如下：

- **长文侧**：衬线标题 + 1.8 行高的中文正文 + 42rem 阅读宽（container-read），界面尽量退到边上去。
- **数据侧**：等宽数字、刻度、直角、发丝线、无装饰阴影；颜色出现的地方一定是在编码数据，不是在装饰。

两者由同一组令牌缝合：**强调色（青釉）在数据侧是「读数」，在长文侧是「眉题短线」**——同一个青，含义不同但语气一致。

明确不做的三件事（BRIEF-A §A3 已列，此处复述为纪律）：不做宣纸/毛笔/朱砂的东方古典质感；不做等宽字 + 网格背景的终端科技风；不做米白 + 极细线 + 大留白的无装饰杂志风。

## 2. 色板

### 2.1 彩色池（数据编码）

全站**同一张图内最多共现三色**，因此色盲可分性按「共现子集」判定：

| 令牌 | 亮态 | 暗态 | 角色 | 气质来源 |
|---|---|---|---|---|
| chart-1 | #0E6E63 | #4FC9B6 | 主数据（师徒四人） | 青釉 |
| chart-2 | #533C28 | #BB9472 | 异常与对照（妖魔） | 窑变褐 |
| chart-3 | #2A5692 | #5D8DD0 | 结构关系（神佛） | 靛青 |
| chart-4 | #5A6470 | #9AA6B2 | 中性石墨（**仅单序列**） | 墨灰 |
| chart-5 | #5E7A2E | #A8C063 | 扩展苔绿（**仅单序列**） | 苔绿 |
| chart-6 | #3C4644 | #A7AFAA | 扩展墨灰（**仅单序列**） | 墨灰 |

chart-4..6 是中性/扩展位：**不与彩色池同图共现**。理由是实测结论——灰色在三类色觉障碍模拟下与青、褐、靛的 ΔE00 最低只有 4.2，灰色一旦与彩色同图出现就会吃掉一个色位；把它们隔离到单序列场景，既保住 6 个 API 令牌，又不牺牲可读性。

series-1..6 与 chart-1..6 同值；series-7/8 是青、靛的重负载变体（#0A4A42/#2E8B7D、#1E3E6B/#3D74B8），供表格小标记与深色底使用，同样不与彩色池共现。

## 3. 字阶与字体

| 层级 | 令牌 | 值 | 字体 |
|---|---|---|---|
| 展示 | type-display / size-hero | clamp(2.5rem, 6vw, 3.75rem) | 衬线 |
| 标题 | type-title | 1.75rem | 衬线 |
| 副标题 | type-subtitle | 1.25rem | 衬线 |
| 导语 | type-lead | 1.125rem | 无衬线 |
| 正文 | type-body / size-body | 1rem | 无衬线 |
| 说明 | type-caption / type-label | 0.8125rem | 无衬线 |
| 眉题 | type-eyebrow | 0.75rem（字距 0.14em） | 无衬线 |
| 微标 | size-micro | 0.6875rem | 无衬线 |
| 读数 | type-number | 2.25rem | 无衬线 + tabular-nums |

- **display 层用衬线**（font-display → font-serif → Songti SC / STSong / SimSun / Noto Serif CJK SC）：标题是「书」的入口，衬线把读者从仪表盘切换到阅读状态；正文与全部数字用无衬线（font-text / font-data），避免衬线在 13px 的中文说明文字下发虚。
- 数字一律 font-variant-numeric: tabular-nums（KPI、表格、tooltip 读数、段标签），保证纵向对齐。
- 正文行高 1.8，标题行高 leading-tight: 1.2；中文段落不做两端对齐（避免字距拉伸）。
- 中文的限宽用 em（按字数）而非 ch（按数字宽度，中文会偏窄导致折行难看）。

## 5. 组件规则

- **卡片 card / kpi-card**：直角 + 1px 发丝边框 + 表面色差，靠发丝线与底色差分层，不靠阴影，也不靠彩色左边条。KPI 行用 1px 间隙 + 间隙底色做分隔线，像仪表盘上的格线。
- **按钮 btn / btn-primary**：最小触控高度 44px；主按钮用强调色实底，次按钮用描边；按下仅 transform: translateY(1px)。
- **徽标 badge / data-status-badge**：胶囊形、小字、带图标或实心点；状态色 + 点形 + 文字三重编码。
- **筛选 filter-tabs / filter-tab**：标签高 44px；选中态为「强调色描边 + 淡强调底 + 强调色文字 + 半粗字重」，不靠色块铺满。
- **检索 search-box**：输入框与按钮同高 44px，聚焦时边框转强调色。
- **图表 chart-wrap / chart-container / chart-block**：画布用 surface-canvas；容器可横向滚动，图表本体设 min-width: 560px，窄屏横向滚而不压碎。
- **提示 chart-tooltip**：绝对定位跟随指针，opacity 150ms 过渡；位置按容器边界钳制，绝不出框。
- **表格 table-wrap / table-wrap--sticky**：表头 sticky、数字右对齐等宽、行悬停淡底。
- **空状态 empty-state**：虚线边框 + 图标 + 标题 + 说明 + 「清除筛选」按钮。
- **引证 cite-block**：暖纸底 + 发丝边框 + 衬线正文 + 口径来源；**不用彩色左边条**。
- **图标**：16 枚，24×24 栅格、1.7–1.8px 描边、stroke: currentColor、几何坐标手写（无 transform 凑对齐），以 symbol + use 同文档内联。

## 6. 动效契约

| 档位 | 时长 | 令牌 | 用在哪里 |
|---|---|---|---|
| 反馈 | ≤150ms | dur-fast: 150ms | 悬停、焦点、tooltip 显隐、状态切换 |
| 状态 | ≤250ms | dur-base: 250ms | 齿色变化等状态类过渡 |
| 入场 | ≤600ms | dur-slow: 600ms | 揭示 js-reveal、条形生长 bar-anim、表格行入场 table-anim |
| 白名单 | 900ms | —— | 仅 KPI 数字滚动 |

- 只动 transform / opacity；**绝不**让 width/height/top/left 参与动画（审计脚本逐条扫描）。
- 无无限循环动画。
- **双守卫**：CSS 侧 @media (prefers-reduced-motion: reduce) 全局停帧；JS 侧 const RM = matchMedia('(prefers-reduced-motion: reduce)').matches 短路时长归零。
- KPI 数字滚动由 IntersectionObserver 触发一次，900ms，**终值文本本来就在 HTML 里**，动画结束精确写回终值；observer 不可用时直接显示终值（fail-open）。
- 缓动三系：ease-out-quart（反馈）、ease-out-expo（入场）、ease-in-out-soft（状态）。

## 7. 无障碍

- 正文 ≥ 4.5:1，图形要素 ≥ 3:1（见 §2.4 实测）。
- 触控目标 ≥ 44×44px（按钮、筛选标签、检索框、导航链接、抽屉链接均已实测）。
- 全局 :focus-visible 焦点环（2px 强调色 + 2px 偏移），覆盖所有交互元素。
- 状态不只靠颜色：徽章 = 颜色 + 圆点 + 文字；图表序列配直接数值标注与文字身份组。
- 图表序列色经 Machado 2009 三类色觉障碍模拟 + CIEDE2000 复算（见 §2.5）。
- 跳过导航 skip-link 位于每个页面首部。
- 装饰性图标全部 aria-hidden，信息性图标带 aria-label。

## 9. 签名元素：十回尺

    读数窗：第 21–30 回 · 11 难 · 占 81 难的 13.6%
    ┌──────────────────────────────────────────────────────────┐
    │ ▌▌▌      ▌▌▌▌▌    ▌▌▌▌▌▌▌  ▌▌▌▌▌    …                 │ ← 齿：一齿 = 一难
    │ │││││││ ││││││││ │││││││││ │││││││ │                 │
    │ └┴┴┴┴┴┴ └┴┴┴┴┴┴ └┴┴┴┴┴┴┴ └┴┴┴┴┴ │                 │ ← 刻度：一格 = 一回
    │ 1–10 回  11–20 回  21–30 回  31–40 回 …                  │
    └──────────────────────────────────────────────────────────┘

- 结构：10 个十回段，每段 = 齿列（底部对齐，高 = 难数）+ 10 根回刻度 + 段标签。
- 峰值段（第 21–30 回，11 难）用 accent-2 标出，**异常自己跳出来**，不靠读者去找。
- 读数窗为仪器部分：悬停或点击某段即改写「第 X–Y 回 · N 难 · 占 81 难的 Z%」。
- 齿色切换 ≤250ms；悬停高亮只改颜色，不动布局。
