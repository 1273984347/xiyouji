# 方向丙 · Neo-Xuan（新宣纸 · 几何化）

> W1260 视觉重设计样板 · 方向丙 · 契约 `tmpe/w1260/DESIGN_CONTRACT.md`（唯一事实源）
> 目录 `docs/11-方案报告/设计与架构方案/视觉重设计样板/丙-NeoXuan/`

## 0 一句话

保留暖宣纸底，把「古籍感」从**材质**整体搬到**执行语言**：几何、大留白、高对比、衬线标题配无衬线正文。

## 1 理念

现站把《详解西游记》的气质做成了「材质」——纸纹噪点、做旧光晕、衬线全文、拟物卡片。材质是低带宽的表达：看多了只剩一层底色，内容本身没有获得重量。

本方向承认暖宣纸底是**项目气质资产**（删掉它等于否认项目身份），但拒绝继续用材质说话。于是把识别度全部搬到三件事上：

1. **几何**：一切形体由直线、矩形、2px 圆角构成，没有一处弧线是「画」出来的。
2. **留白**：章节序号与标题之间、标题与图之间、图与图之间，用大间距和竖向细分隔线呼吸，而不是用底纹填满。
3. **对比**：墨、朱砂、靛、苔、赭各司其职，数据墨水永远比装饰元素更响。

气质落点：东方编辑设计（LINE / 极简东方杂志），不是仿古，不是终端。

## 2 为什么保留暖底，仍然算「推翻」

「推翻」发生在执行语言层，不发生在色相层。逐条对照：

| 维度 | 现站 | 方向丙 | 性质 |
| --- | --- | --- | --- |
| 材质 | 纸纹噪点 + 光晕 + 做旧滤镜 | 全部删除，无噪点、无光晕、无渐变、无阴影 | 材质 → 几何 |
| 正文 | 全文衬线（DESIGN §2.4 的主要可读性负担） | 仅标题与章节序号用衬线，正文/数据/轴标签全无衬线 | 衬线正文 → 无衬线正文 |
| 卡片 | 拟物浮层 + 阴影 | 纯平面 + 1px 极淡描边 | 拟物 → 平面 |
| 章节识别 | 靠小标题字号差 | 靠 56px 大号数字序号（01/02/03/04）+ 竖向细线 | 装饰 → 信息 |
| 图例 | 图例框（独立容器） | 顶部内联 chip | 容器 → 内联 |
| 轴刻度 | 长横线 | 竖排短线（Y 轴置于轴线左侧，X 轴植于基线之下） | 惯例 → 规整 |
| 网格线 | 横向浅网格 | 取消网格线，只留轴线 + 刻度 | 装饰 → 信息 |
| 数据标签 | 尽量多标 | 只标极值，其余交给 tooltip | 密度 → 留白 |
| 暗色 | 与亮色同构 | 独立令牌集，暖纸转深墨褐，五色同色相提亮 | 滤镜 → 令牌 |

结论：暖底只是**同一个色相坐标**，执行层已整体更换——这不是换皮，是换语法。

## 3 色彩理由

亮色态五色严格采用契约 §1 方向丙给定值：

- 暖纸 `#F5F0E4`——保留宣纸，但压低饱和、提亮明度，让高对比墨色能承载；
- 墨 `#1C1A17`——不用纯黑，带一点暖偏，与纸底同色温，避免生硬；
- 朱砂 `#C0392B`——比现站更纯更饱和，全站唯一强调色，同时承载「对话字数」与「负面情绪」两个语义；
- 靛 `#2C5F7C`——冷色对位，承载「叙述字数」与「中性情绪」这类体量语义，不与朱砂争；
- 苔 `#5E7A4E`——低饱和绿，只给「正面情绪」这一唯一需要正向语义色的场合；
- 赭 `#A97C3F`——暖中间调，给诗词柱与均值参考线这类次要信息。

分工即节制：每种颜色只干一件事，没有一处是「为了好看」。

**暗色态是独立的一套令牌**（不是 filter 反色）：暖纸转深墨褐 `#1A1714`，五色同色相提亮为 `#E0604F / #5FA3C6 / #9BB87E / #D9A55F`，使图形在暗底上仍 ≥ 3:1。

## 4 字体理由

- **标题衬线**：`Noto Serif SC / Source Han Serif SC / Songti SC / STSong / SimSun`。文化身份只落在标题这一层。
- **正文无衬线**：`system-ui / Segoe UI / PingFang SC / Microsoft YaHei / Noto Sans SC`。中文小字号下无衬线的可读性显著优于衬线；现站全文衬线是主要负担，本方向把它拆掉。
- **数据与轴标签无衬线**：`font-variant-numeric: tabular-nums`，数字中性、可对齐，不与标题争夺气质。
- 零外域字体：不引 Google Fonts，只依赖系统字体栈，保证 `file://` 双击即开且零请求。

## 5 图形语言

- 圆角统一 2px；线宽统一：数据笔画 2px、轴线与刻度 1px、图标 1.5px。
- 坐标轴刻度用**竖排短线**：Y 轴短竖线置于轴线左侧，X 轴短竖线植于基线之下。
- 图例做成**顶部内联 chip**，随标题行右对齐，不另立图例框。
- 节点大小由数据驱动且有下限：折线节点半径随该回对话字数映射到 `[2, 4]`，下限 2px 保证 100 点密排不糊。
- 数据标签**只标极值**：最长回、最高占比、最低占比；其余信息在 tooltip 里。
- 环形图标签外置 + 引线，按角度锚定（`middle / start / end`），实测零重叠零裁切。
- 折线用直线段（`curveLinear`）而非平滑曲线，保持几何规整。
- 诗词密度图：8 根柱（仅含诗词的回目）+ 一条底线 + 8 个落位标记构成的全书 100 回分布带。
- 零拟物：全平面，无阴影、无渐变、无光晕、无纸纹。

## 7 已知取舍与代价

1. **轴标签对比度下调**：为同时满足「自态 ≥ 4.5」与「跨态 ≥ 3.0」（亮暗两色互相换底也不低于 3），轴标签单列为 `--nx-axis-text` 令牌：亮态 `#746C60`、暗态 `#8A8276`。代价是轴刻度比正文轻（4.55 vs 6.58），需靠字号与位置补偿。
2. **赭色只做图形**：`#A97C3F` 对纸底仅 3.27:1，因此只用于柱与参考线，绝不做小字；暗色态提亮到 8.07 后才可放宽。
3. **暖底 + 朱砂与现站语汇相近**：辨识度主要靠大号数字序号与几何化图形，而非配色本身——与方向甲（冷白底 + 直角 + 2px 朱砂竖线）的分界靠「底色冷暖 + 圆角 2px + 序号制式」三条。
4. **暗色五色并非同一支色号**：同色相提亮必然偏色，两套令牌需分别维护。
5. **诗词图不是严格逐回柱状**：92 个零值回无法成柱，改为「8 根柱 + 100 回落位带」，信息更准但形态与其他三图不同构。
6. **衬线标题依赖系统字体栈**：Windows 的 SimSun 与 macOS 的 Songti 字面差异明显，标题行宽会有差异。
7. **无纸纹 = 丢掉一部分年代感**，这是有意取舍：年代感交给排版气质，不交给滤镜。

## 9 数据来源
