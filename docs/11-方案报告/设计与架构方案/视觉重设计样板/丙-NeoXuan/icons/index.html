规范

  • 画布 viewBox='0 0 24 24'，输出 24px 与 16px 两档。
  • 描边 stroke-width='1.5'，端点与转角统一 round。
  • fill='none' stroke='currentColor'，着色跟随文字色，明暗两态共用同一份几何。
  • 不使用 transform='translate(...) scale(...)' 缩放凑合，坐标直接落在 24×24 栅格上。
  • 图形居中，最大描边外沿距画布边不小于 2px。
  • 装饰性图标一律 aria-hidden='true'，语义由可见文本或按钮标签承担。
