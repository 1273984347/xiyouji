## 视觉语言

- **名称**：墨栏 / INK-RULE。签名元素＝**百回拓片条**（一百格出场频次带，主体深墨、主角朱砂标出）。
- **承载层暖 / 数据层冷**：暖宣纸底 `#EDE7D9`、暗色为深墨底 `#14110D`（非反相）；
  朱砂 `#A8321F` 是唯一强调色；序列色取自传统颜料：石青 / 赭石 / 胭脂 / 松绿 / 藤黄 / 绛紫。
- **字体**：衬线标题 + 正文宋体族；数据区用等宽数字，账簿式 KPI 格（数字为主、说明为辅）。
- **反 SaaS**：无卡片阴影堆叠、无圆角药丸标签、无渐变光晕；分隔靠墨栏（细墨线 + 留白节奏）。

## 主会话亲视结论（2026-11-17）

已逐张打开渲染图目视确认（非仅探针读数）：

- 暖宣纸底 + 朱砂强调 + 墨栏分隔成立，**不再读作「装腔的仿古皮肤」**；
- 百回拓片条、账簿式 KPI、序列色图表三者共同给出「这是一套有人负责的读数系统」的身份感；
- 暗色为深墨底而非机械反相，明暗两态气质一致；
- 主页「三种用法，三条路」区用深墨底做明度反转，层次靠墨色而非阴影。
