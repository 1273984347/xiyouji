## 这是什么

一套从零发明的全站视觉语言，服务**长文连续阅读**读者（636 页 reader 族＝站点 73%）。
方向定位（BRIEF-B）：读者是「要连着读下去的人」——要的是版心、眉批、旁注、校记，像读一本文库里的注释本。

## 视觉语言

- **名称**：墨栏。签名元素＝**鱼尾对版标**（长文页版心眉，行间带鱼尾与回次标记）。
- **长文页形态**（甲2 没有的部分）：正文 40em + 旁注 15rem 双栏；旁注首行与正文首行对齐；
  引文用楷体；本回提要、关系图、校记、上下回导航齐备；**零入场动画**（不做「滚动才显现」）。
- **色彩**：冷灰纸 `#E2E3DD` / 暗底近墨 `#111316`，石青 `#1F5A86` 为强调色；
  序列色由脚本在色盲可辨约束下机器求解。

## 主会话亲视结论（2026-11-17）

已逐张打开渲染图目视确认（非仅探针读数）：

- **长文阅读页成立且是本轮最强单件产出**：版心眉 → 大标题 → 导语 → 本回提要 → 双栏正文与旁注
  → 楷体引文 → 关系图 → 校记 → 上下回导航，阅读动线完整，确有「读一本注释本」的手感；
- 暗色态同构（深墨底，旁注/提要/校记的层级关系保持），明暗两态气质一致；
- **首页与数据页偏通用仪表盘**：冷灰底 + 石青强调 + KPI 四卡 + 横向条形，
  排版干净但**身份感弱**——一眼读作「现代数据站」，与现役宣纸刻本的物质感差距明显；
  这也是暖/冷比例停在 17.6/41.8 的直接原因。

## 已知边界

1. **首页/数据页身份弱**——若整体采纳乙2，读者进站第一眼即失去题材气质；
2. 公共层覆盖率仍为现状基线（113/953 = 11.9%），本样板不解决「逐族归并页面私有类」；
3. 长文页样板的真实数据仅一段（第二十七回），尚未在 636 页规模上验证版面稳定性。
