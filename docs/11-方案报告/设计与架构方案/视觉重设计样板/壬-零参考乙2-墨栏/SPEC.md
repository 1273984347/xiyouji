# 详解西游记 · 设计系统正本（方向乙：长文连续阅读）

> 设计语言：**墨栏** —— 以木刻本版的**栏线与界**为骨架、以拓片**墨分五色**为色阶、以纸为底的版面语言。
> 目标不是「这页好看」，而是**读 30 分钟不累**：界面退到背景里，让正文、回目、引文、旁注自己说话。
> 本文档所有数值均由仓内脚本机器复算得出（_palette_check.py / _audit.py / _shoot.py），非目测。

### 0.2 签名元素是什么？它与《西游记》的哪个具体事物同源？

**签名元素 =「鱼尾对版标」**，位于长文页顶部的**版心眉**（sample-reader.html → .reader-headrule）。

它同源于**线装书每半叶中央那条「版心」里的鱼尾**：

- 线装古籍的版心在折叠后的书页正中，上鱼尾记书名回数、下鱼尾记叶码；木版印刷时，版心同时是**上下两半叶的对版规矩**（刻工据此把两次雕版对齐）。
- 我把这条窄竖栏搬成阅读页顶部的**常驻横条**：左端是鱼尾标（28×14 的实心楔形，底边带缺口，纯 SVG path，无贴图），右端是**回数与叶码**（"第 3 段 / 共 11 段"，随滚动实时更新）。
- 因此它同时是**内容**（第几回、读到第几段）与**仪器**（书页的对版规矩与定位尺），而不是装饰。
- **全站只出现这一处**：仪器只该出现在它工作的那个面上。落地页与数据页沿用同一套纸墨栏线，但不放版心——那两页的任务不是连续阅读。

### 0.3 明暗两态是同一套设计还是两种不同的设计？判断依据

**判断：同一套设计的两次「调光」，不是两种设计。**

依据三条：

1. **色相家族不变**：石青 / 朱砂 / 赭黄 / 绛紫 / 石绿 / 青碧 / 檀褐 / 淡墨八支颜料在两态中同色相同彩度关系；颜色在本系统里承担语义（身份组 = 神佛 / 妖魔 / 师徒），若两态用不同色相，语义就会随主题漂移。
2. **暗态不是反相**：反相会把朱砂翻成青、把石青翻成橙。暗态实际做的是"换灯"：纸从日光下的 #F3F3EE 换成灯下的 #1A1D21，墨从 #1C1D18 换成反照的 #E8E7DF，同一支颜料在各自底色上**重新取一个可读的明度档**（石青 #004174 → #5178B1）。
3. **暗态色板是推导出来的，不是另挑的**：_palette_search.py 取亮态同一批颜料，统一上移 ΔL×23 再做色域收边，因此两态的色相关系同源，且两态的两两 ΔE 都守住同一阈值（见 §2.3）。

层级关系（谁比谁重）、度量（栏宽/字号/行高/间距）、签名元素、组件结构，两态完全一致。

## 1. 设计观点

1. **版面先于装饰。** 这套语言的第一笔不是颜色而是**线**：双线（文武边）分节、细线分栏、发丝线分文块。读者感到的是"这是一本被排过的书"，而不是"这是一个仪表盘"。
2. **纸墨是底色，不是滤镜。** 纸色只做底（--bg 案面 / --paper 页），不做纹理贴图；墨色只分五级（焦浓重淡清），不铺渐变。
3. **内容层级由字体分工承担。** 正文宋体（刻本正文字体）、引文楷体（手抄/批注字体）、界面黑体（现代界面字体）、数据无衬线 + tabular-nums（数字需要等宽对齐）。四种字体各自承担一种"声音"，读者不用看标签就知道这段是什么。
4. **仪器不许装饰化。** 鱼尾、界栏、叶码都是功能物；凡不能报出"它在报什么"的视觉元素，一律不做。

### 2.3 数据序列色（机器求解，非目测）

| 槽 | 颜料 | 亮态 | 暗态 |
|---|---|---|---|
| 1 | 石青 | #004174 | #5178B1 |
| 2 | 朱砂 | #642D23 | #A36457 |
| 3 | 石绿 | #47654C | #80A085 |
| 4 | 赭黄 | #A27A41 | #E4B67A |
| 5 | 绛紫 | #9C73A1 | #DCB0E0 |
| 6 | 青碧 | #006F6E | #55ABAA |
| 7 | 檀褐 | #765228 | #B58B5E |
| 8 | 淡墨 | #424242 | #797979 |

**求解口径**（_palette_search.py）：固定八个颜料色相槽 → 在「对底色 ≥ 3:1」的亮度带内枚举明度/彩度 → 以「两两 min(常视 ΔE00, protan/deutan/tritan 模拟 ΔE00)」最大为目标做坐标下降。暗态由亮态同批颜料统一上移 ΔL×23 推导。

**实测**（CIEDE2000 + Machado 2009 模拟）：

| 指标 | 亮态 | 暗态 | 判定阈值 |
|---|---|---|---|
| 两两常视 ΔE00 最小 | **13.9**（series-3/6） | **13.0**（series-4/7） | ≥ 12 |
| 两两模拟 ΔE00 最小 | **9.1**（series-4/5 · tritan） | **9.3**（series-3/7 · protan） | ≥ 8 |
| 序列色对纸面对比度最小 | 3.50:1（chart-4） | 3.64:1（chart-2） | ≥ 3:1 |

**阈值为何是 12 而不是 15**：八支序列色要同时在近白底（--paper / --surface-raised）上满足 ≥ 3:1，相对亮度被压在 Y ≤ 0.2583（L* 约 58 以内）这个窄带里，明度差用尽后只剩色相可用；实测该约束下全八色两两常视 ΔE00 的上限约 14。阈值取 12 是留余量的实测量，不是拍脑袋。演示图表实际同时用到 3 色（石青 / 朱砂 / 赭黄），其两两常视 ΔE00 ≥ 30、模拟 ≥ 24，并另有图例与直接标注作冗余编码。

字体栈零外域依赖："Songti SC", "STSong", "Source Han Serif SC", "SimSun", "宋体", serif 等，全部系统字体。

## 4. 间距、栏宽与版式度量

- 间距基数 4px：--space-1..9 = 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 72 px；--gap-tight 8、--gap-loose 24、--gap-section 56。
- **正文栏宽 40em**（17px 下约 680px，约 40 个汉字/行），落在契约要求的 38–42em 内。
- **旁注栏宽 15rem**（240px），落在 14–16rem 内；与正文栏之间 2.5rem 栏距。
- 首行缩进 2em（--indent-2），中文正文惯例。
- 圆角：--radius-sm 2px（卡片），--radius-pill 999px（仅状态点）。**卡片一律 2px 直角**，不做圆角卡片。

## 5. 组件规则（节选，均为冻结类）

- **topnav**：高 60px，吸顶，backdrop-filter: blur(10px) + 半透明纸色（功能层允许模糊），下缘 1px --border-subtle。
- **hero**：上缘 3px 双线（文武边），左栏标题 + 右栏"版面样张"，样张即把读者页的两栏结构缩小演示。
- **kpi-grid / kpi-card**：4 列、1px 间隙 + 底色画格线，读起来像一张分栏统计表而非四张浮动卡片；数字 tabular-nums。
- **filter-tabs / filter-tab**：高 44px（触控目标），选中态为墨底纸字（刻本标签的印色反相），不靠颜色单独表意（另有 aria-selected）。
- **chart-wrap / chart-container / chart-legend / chart-tooltip / chart-loading**：图表容器带发丝边框；tooltip 绝对定位跟手、视口钳制、150ms 透明度过渡、.visible 切换；载入态默认 hidden（chart-loading.hidden 强制不显示）。
- **table-wrap / table-wrap--sticky / table-anim**：表头吸顶、行入场只动 opacity + transform（4px 上移）。
- **cite-block**：楷体 + --paper-warm + 上下发丝线 + 左侧中性线，右下角出处（小字右对齐）。
- **dark-band**：拓片段（墨底反白），全站每页至多一处。
- **data-status-badge**：状态点 + **字形标记**（✓ / ▤ / 数字），状态不只靠颜色。
- **empty-state**：虚线框 + 标题 + 提示 + 恢复按钮，过滤无结果时出现。
- **图标族**：14 枚 24×24 描边 SVG，stroke: currentColor、1.7–1.8px、几何精确、无 transform 凑合对齐。

## 6. 动效契约

- 时长三档：反馈 --dur-fast 120ms / 状态 --dur-base 200ms / 入场 --dur-slow 250ms；白名单两处：hero 强调 600ms、KPI 数字滚动 900ms。
- 只动 transform / opacity（颜色类过渡仅用于 hover 反馈，不参与位移）。
- 无无限循环动画（chart-loading 的载入条是静态发丝线，刻意不脉冲）。
- **长文页不做任何入场动画**：读长文时"内容自己出现"本身就是干扰。
- 双守卫：CSS prefers-reduced-motion 块全局停帧；JS const RM = matchMedia('(prefers-reduced-motion: reduce)').matches 短路时长归零（KPI 滚动直接落终值）。
- KPI 数字滚动：IntersectionObserver 触发一次、900ms、缓动 1-(1-t)^3，**终值精确还原**（HTML 内终值文本本就存在，data-final）。

## 9. 签名元素

见 §0.2。要点复述：

- 形态：28×14 实心楔形，底边带三角缺口（单路径 + fill-rule: evenodd，非贴图、非图标族）。
- 位置：长文页顶部版心眉左端，**全站唯一一处**。
- 内容：右端承载回数与**叶码**（"第 N 段 / 共 11 段"，随滚动实时更新）。
- 同源：线装书版心的鱼尾，兼作木版印刷的对版规矩。
- 仪器性验证：读者在 30 分钟里扫一眼就知道"我在第几回的第几段"，无需滚动条或面包屑。
