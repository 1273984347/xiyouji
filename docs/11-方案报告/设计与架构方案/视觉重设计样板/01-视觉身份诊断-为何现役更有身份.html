三、我的错误在哪（可复用的教训）

我给两个零参考 agent 的简报里埋了两条禁令——它们不是让 agent 做坏了，而是把唯一正解挡在了答案空间外：

我写的原文agent 的理解后果
「文化标识来自内容本身，不靠页面装饰去『装』」用传统色/宋体 = 装饰性装腔 ⇒ 主动回避放弃唯一能与题材同源的材料层
「禁默认 Tailwind 靛蓝/紫罗兰做主强调色」紫色家族一并回避连现役用得最多的紫檀（6070 次）也被排除
修正后的简报：禁的是「装腔的仿古」（烫金花边/卷轴造型按钮）与「现代 UI 库默认紫」（#6366F1/#8B5CF6），不忌讳纸色 / 宋体 / 朱砂 / 紫檀 / 绛紫等传统颜料；题材描述也从标签（「明代世情」）改成可用指令（「一本有物质感的古籍——纸、墨、朱、印、线装、拓片」）。

四、以后判任何新方向的五个问题

  1. 它有没有身份？先问这个，再问「对不对」。色盲安全 / 对比度 / 零依赖只保证它不坏，不保证它属于这个站点。
  2. 暖承载与冷数据配比是多少？（可量化：全站通用色的族分布）若整版倒向单一温度，即便漂亮也没有「这是一本古籍」的第一层信号。
  3. 是「装腔」还是「传统」？判据：去掉装饰后，材料语言（纸/墨/朱/印/线装）是否还在。
  4. 多方向的产出若收敛到同一类解法，先怀疑简报，而不是以为「共识即正确」。
  5. 它与内容的同源点能一句话说清吗？说不清 = 没身份。
