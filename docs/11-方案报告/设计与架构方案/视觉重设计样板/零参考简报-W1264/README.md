## 修订后的验收口径（新增）

**先问「有没有身份」，再问「对不对」**：

- **身份判据（可量化）**：全站通用色（覆盖 ≥80% 页面）的**暖承载 / 冷数据**配比——现役暖红 115 : 绿青 30；甲乙为暖红 10–14 : 绿青 44–49；
- **一句话说得清与内容的同源点吗**？说不清 = 没身份；
- **多方向若收敛到同一解法**，先怀疑**简报**把它们逼到同一处，而不是以为「共识即正确」。
