# 方向补充 · 甲（你这一份）

> 在通用契约之上，**你这一份的额外立场**（它决定你与另一位设计师的分工）：

## A1. 你优先服务的行为：数据探查 + 快速判读

站点 90 个可视化页是「用数字提问、用图形回答」的地方。读者来这里不是看装饰，是为了**看懂一个结论**：谁最强、哪段最密、哪个模式反常。
你的设计首先要让**数字与图形本身**成为主角：数值可扫读、对比一眼成立、异常自己跳出来。

## A2. 你必须回答的三个具体问题（写进 SPEC.md §0）

1. **一位读者在 3 秒内能读懂这张图说了什么吗？** 你的版面上，标题/数值/图形/结论四者各占什么位置、什么视觉权重？
2. **你的「签名元素」是什么？** 它必须同时是**内容**与**仪器**（不是纯装饰），且只出现一处。
3. **你的明暗两态是同一套设计还是两种不同的设计？** 说出你的判断依据。

## A3. 你的设计语言必须是「读数字」的语言

参考坐标（**只作为密度与秩序的抽象参照，不是风格照抄**）：
- **金融终端**：数字列对齐、密度高、状态一眼可辨、克制的强调色
- **科学期刊图表版式**：留白与分隔线承担分组，颜色只承载数据编码
- **仪器面板**：刻度、读数、单位三者不混

**明确不做的方向**（避免落入常见窠臼）：
- 不做「暖色宣纸 + 毛笔插画 + 朱砂点缀」这一类东方古典质感
- 不做「深色终端 + 等宽字 + 网格背景」这一类黑客/科技风
- 不做「米白 + 极细线 + 大留白 + 无装饰」的极简杂志风

## A4. 你的落点

本方向若成立，读者打开数据页的第一反应应是「这数据讲得很清楚」，而不是「这页好看」。
