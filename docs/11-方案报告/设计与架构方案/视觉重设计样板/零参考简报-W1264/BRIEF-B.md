# 方向补充 · 乙（你这一份）

> 在通用契约之上，**你这一份的额外立场**（它决定你与另一位设计师的分工）：

## B1. 你优先服务的行为：长文连续阅读

站点 636 页长文阅读页是「一次读一篇、读完一篇再读一篇」的地方。读者在这里是**沉浸**的：界面必须退到背景里，让正文、回目、引文、注释的层次自己说话。
你的设计首先要让**长时段阅读不累**：字面、栏宽、段距、层级、引文与正文的区分、翻页动线。

## B2. 你必须回答的三个具体问题（写进 SPEC.md §0）

1. **一个读者连续读 30 分钟，你的版面上有什么会让他分神？** 逐条列出并说明你的处置。
2. **你的「签名元素」是什么？** 它必须同时是**内容**与**仪器**（不是纯装饰），且只出现一处。
3. **你的明暗两态是同一套设计还是两种不同的设计？** 说出你的判断依据。

## B3. 你的设计语言必须是「读长文」的语言

参考坐标（**只作为密度与秩序的抽象参照，不是风格照抄**）：
- **学术专著排版**：字号阶、栏宽与行长、引文与注释的字体分工、章节编号
- **注释本/校勘本**：正文与旁注的关系、批注的视觉身份
- **数字阅读器的沉浸态**：翻页、进度、跳读的克制表达

**明确不做的方向**（避免落入常见窠臼）：
- 不做「暖色宣纸 + 毛笔插画 + 朱砂点缀」这一类东方古典质感
- 不做「深色终端 + 等宽字 + 网格背景」这一类黑客/科技风
- 不做「米白 + 极细线 + 大留白 + 无装饰」的极简杂志风

## B4. 你的落点

本方向若成立，读者打开长文页的第一反应应是「读起来不累、层次清楚」，而不是「这页好看」。
