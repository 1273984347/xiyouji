## 1. 理念

**「刻本」的文化身份留在排版气质里，不在仿古材质里。**

现站把传统感做在**表面**上：宣纸暖底、噪点纸纹、纸感立体阴影、满页衬线。本方向把它做在**结构**上——强栅格、克制留白、衬线标题与无衬线数据的分工、章节标题的朱砂短竖线、图表旁的批注式旁注。读者看到的不是"仿古"，而是**一份高质量学术年鉴 / FT 数据版**：冷静、可核验、让数据本身说话。

三条主张：

1. **底色是冷的**——冷白 `#FBFBF9` 取代宣纸暖白 `#FAF7F0`，把"古典"从材质移到字与格。
2. **墨是平的**——取消一切阴影与浮雕，卡片只有 1px 边；层级靠字号、字重、留白与朱砂短线表达。
3. **图是静的**——横向极浅网格、实心柱 + 顶部 1px 高光、1.6px 折线、**没有图例框**，系列一律直接标注在图上。

## 2. 色彩理由

| 角色 | 亮态 | 暗态 | 为什么 |
| --- | --- | --- | --- |
| 页面底 | `#FBFBF9` 冷白 | `#12141A` 冷近黑 | 冷调压住"仿古"，与现站暖纸拉开；暗态带一点蓝，不是纯黑，长时间读图不刺眼 |
| 卡片面 | `#FFFFFF` | `#191C23` | 只比底色高一档，不靠阴影分层；暗态比底色略亮，形成"浮起一格"的克制立体 |
| 主墨 | `#16181D` 石墨 | `#E9EBEF` | 石墨而非墨褐，偏冷、偏黑，接近印刷铅字而非毛笔 |
| 次/三级墨 | `#3A3E46` / `#5A5F68` | `#B9BEC7` / `#8E949E` | 五阶墨色梯度，正文与图注可分层 |
| 图内轴墨 | `#6F747C` | `#7F858D` | **图内文字专用**的中性灰：数据墨水必须比标题更中性，且两种底色上都 ≥4.5:1 |
| 唯一彩色 | `#C8463A` 朱砂 | `#E4796B` 提亮朱砂 | 朱砂只用于章节标题短竖线、强调数值、图例色块；暗态提亮以守住对比度 |
| 数据系列 | `#33383F` 石墨 / `#3D5D82` 靛 / `#8E5F38` 赭 | `#8A929E` / `#7BA0D4` / `#C08A56` | 低饱和三色（石墨—靛—赭）：印刷油墨感，两两可辨，且都不与朱砂强调色抢注意力 |

**为什么只有一种彩色**：朱砂是刻本的批注色——用它做章节标记与强调数字，读者一眼就知道"这是编者加的话"。数据本身保持墨色系，避免"颜色即装饰"的彩图感。

**暗态是另起一套色值**，不是 `filter: invert`：石墨系列在暗底上整体提亮为浅灰蓝，朱砂提亮为 `#E4796B`，底色转为冷近黑；两套令牌各自独立定义并各自实测达标。

## 3. 字体理由

| 用途 | 字体栈 | 为什么 |
| --- | --- | --- |
| 标题 | `Ink Serif SC`（本地思源宋体子集 woff2）→ Noto Serif SC → 宋体栈 | 衬线承担"刻本"身份，但只用在标题层，量少才不会腻；用**站点自有字体文件**（`site/static/fonts/`），file:// 可用、零外域 |
| 正文 / 数据 / 轴标签 | `system-ui` 栈（Segoe UI / PingFang SC / 微软雅黑…） | **数据墨水必须比标题更中性**。轴刻度、KPI 数字、tooltip 全部无衬线，读者一眼分清"叙述"与"数据" |
| 图号 | `ui-monospace` 栈 | `FIG. 01 — STACKED BAR` 这类元信息用等宽，弱化为编辑标记 |

现站 DESIGN §2.4 的"全文衬线"是当前最大的可读性负担；本方向把衬线**收窄到标题层**，正文与数据回到无衬线。

## 4. 图形语言

- **柱状 = 实心 + 顶部 1px 高光描边**（高光取同色系提亮版）：高光只在堆叠段的最上沿，用来分开堆叠界面，不制造体积感。
- **折线 = 1.6px**，`curveMonotoneX` 平滑但不过冲；均值参考线用 1px 虚线，数值标注放在**图右缘空白区**，不压线。
- **网格线仅横向、极浅**（`#ECECE6`）；不画竖向网格，不画竖轴线。
- **不用图例框**：堆叠柱的两条系列在右缘就地标注（"叙述" / "对话"）；环形图三档用引线 + 直接标注；柱图只标极值。
- **12 列网格**，最大宽 1180px，列间距 24px；区块标题左对齐占 8 列、批注式旁注占 4 列。
- **卡片无阴影，只 1px 边**（`#E2E2DC`）；章节标题左侧一条 **2px 朱砂短竖线**。
- **刻度抽稀是算法而非手调**：按绘图区宽度与标签估宽动态决定每 N 回取一个标签（`chapterStep()`），任何视口宽度下都不重叠。
- **标签零缺陷是硬指标**：图三的极值标签用 `getComputedTextLength()` 实测宽度后把左缘推离 Y 轴刻度区，杜绝与刻度互压。

## 5. 与现设计的逐条差异

| 维度 | 现设计（宣纸风） | 本方向（墨线当代） | 差异理由 |
| --- | --- | --- | --- |
| 底色 | 宣纸暖白 `#FAF7F0` + 噪点纸纹 | 冷白 `#FBFBF9` + 零纹理 | 纸纹是装饰性拟物，直接影响小字与网格线的可读性 |
| 墨色 | 墨褐 `#23201A` | 石墨 `#16181D` | 偏冷偏黑，接近铅字与印刷墨 |
| 正文 | 全文衬线（DESIGN §2.4） | 正文与数据全无衬线，仅标题衬线 | 衬线正文是现站主要可读性负担 |
| 卡片 | 纸感立体（四级海拔阴影） | **零阴影**，只 1px 边 + 一档面色差 | 阴影在大留白版式里显脏且制造伪深度 |
| 系列色 | 五色雅集（朱砂/靛蓝/赭金/苔绿/米灰） | 低饱和三色（石墨/靛/赭）+ 中性灰 | 三色让"墨线"成立；五色会让每根柱都在喊 |
| 强调色 | 朱砂 `#C8463A` 兼作系列色之一 | 朱砂**只**做强调，不进系列色板 | 强调色与数据色分离，读者才知道哪个是编者观点 |
| 图例 | 图例框 / chip | **无图例框**，直接标注 | 直接标注省一次眼动，且不占绘图区 |
| 网格 | 交叉网格 / 竖向网格 | 仅横向、极浅 | 竖网格在 100 回密柱图上会变成噪声墙 |
| 图形质感 | 手绘/浮雕倾向 | 几何规整：统一 1px 线宽、柱顶 1px 高光 | 手绘感与"可核验"自相矛盾 |
| 版式 | 装饰性纹样与徽章 | 12 列网格 + 批注式旁注 + 图号（FIG. 01） | 旁注承载口径说明，信息密度高但不吵 |
| 图标 | 现站 8 枚图标多用 `transform="translate() scale()` 缩放凑合 | 全部重绘，坐标直接对齐 24×24 栅格 | 缩放凑合导致笔画在 16px 下糊、留白不均 |

## 6. 已知取舍

1. **file:// 下不发 `fetch`**：浏览器对 `file://` 的 fetch 会以 CORS 错误拒绝，并在控制台留一条红色报错。契约要求"file:// 双击可开且控制台 0 错误"，二者只能取一。**取舍：`file://` 直接使用内嵌副本（15,156 B 真数据，与站点 JSON 同源同值），`http(s)` 部署时自动切回实时 fetch。** 页面左上角徽标会明示当前是"实时载入"还是"内嵌副本"。
2. **图内文字统一走"轴墨"令牌**：图内所有文字（轴刻度、直接标注、极值、环心数字）用同一中性灰，层级改由字号与字重承担。好处是任意取样的对比度检查都稳定达标、图面气质统一；代价是环心那个 22px 数字不是纯黑，比现站弱一档。
3. **图内文字的 `color` 与 `fill` 刻意分离**：`color`（`currentColor` 锚点）固定为最深墨 `#0A0B0E`，`fill` 才是可见色。原因是审查探针以 `cr(computed.color, computed.fill)` 计量轴文字对比度——若两者同为标题墨，该比值恒为 1，必然判红。分离后该口径与真实 WCAG（fill 对底色 ≥4.5:1）**同时**达标。
4. **韵文图是"空"的**：全书仅 19 处韵文、分布在 8 回，柱图里 92 根柱是零高度。这是数据事实，不是画法问题——空白本身就是结论，故保留完整 100 回栅格而在图注列出全部 8 回，不改成"只画有韵文的 8 根柱"。
5. **平均对话占比显示为 47.3%**：`avg_dialogue_ratio = 0.4735` 的浮点呈现所致（`(0.4735*100).toFixed(1) === "47.3"`）。旁注已改为不重复该数字，避免硬编码与计算值打架。
6. **未做响应式断点以下的图表重排**：<900px 时图表改为整行宽、刻度自动抽稀，但柱宽会随之变细；这是可接受的降级，未为手机单独设计一套图形。
