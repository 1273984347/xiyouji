## 4. 门禁扩展（65 / 66）与「五处同改」清单

两条新槽均为**恒跑核心槽**（`_SCOPE_CORE`），挂槽必须五处同改，漏一处即启动期断言红或计数链失真：

1. `verify_delivery.py` → `EXPECTED_SECTION_NAMES` 追加 `"导航一致性"`、`"数据徽标"`
2. 同文件 → `_SCOPE_CORE` 追加两个 section 名
3. 同文件 → `_STRICT_GATES` 追加两条 `_StrictGate`（marker / timeout / fail_msg 齐备，缺汇总行即判「疑似未真正执行」）
4. `AGENTS.md` §4.2 计数（64→**66** 三处）+ 条目 65/66 摘要；`docs/agent/gates.md` 标题与全量定义
5. `docs/00-导读/文档规范.md` 现役段数（71 段）——由「门禁段自洽锁」实跑比对兜住

**判据设计要点（避免同类门禁的三处老坑）**：

- 第 65 槽的真值 **import 自导航正本**（`_load_truth()`），不复制常量——复制即两面漂移；且取 `it[0]` 而非解包，正本元组日后加字段不会炸门禁。
- 第 66 槽除「态 == 分类器结果」外，硬校验 **label 逐字等于 `STATUS_TEXT`**，专防「实时/快照/示例」三态被改写回「数据源：」旧行话（本批 check 阶段实证过的回潮）。
- 两槽退出码统一 0 通过 / 1 判红 / 2 基础设施缺失（fail-closed，禁静默跳过假绿）。

## 5. 统计双轨与 CSP 例外域全集

**例外域全集（4 个，改一处必同步改两处）**：

```
script-src  https://www.googletagmanager.com
connect-src https://region1.google-analytics.com  https://analytics.google.com  https://1273984347.goatcounter.com
```

`scripts/output/_w1167_analytics.json` 的 `goatcounter_endpoint` 与 `generate_csp.py` 的 `ANALYTICS_CONNECT_HOSTS` 同源——两处不一致时由第 56 槽 CSP 增量漂移判红兜住，不靠人工记忆。

**为什么是双轨**：GA4 在大陆网络可达性差，单轨会让大陆读者数据系统性缺失。GoatCounter 历史账号 W806 曾按「实测 404=死号」退役，本批复验为 **HTTP 400（缺参）= 账号在活**，故恢复；其脚本自托管于 `site/static/js/goatcounter.js`，不破 `file://` 双击可用性。

**SRI 取舍（诚实声明）**：gtag 由 Google 高频轮换、无法钉 SRI，防线=CSP host 白名单；GoatCounter 自托管无此风险；D3/Three 等稳定库仍按 W424 先例可钉。**未钉 SRI 的外域脚本面 = GA4 一处**，评审时不要把它当成「已全量钉住」。

## 6.1 本批根修的三个判据缺陷（不是页面缺陷，是「守门的东西本身错了」）

这三条比六项交付更值得留下，因为它们每一个都**已经在零红灯状态下工作过**：

| # | 缺陷 | 为什么此前不红 | 根修与回归锁 |
| --- | --- | --- | --- |
| ① | `git status --porcelain`（非 `-z`）把中文路径转成八进制转义，**加 `core.quotePath=false` 也照转**；乱码路径进了 spec 与 file-index（实测 522 行） | 目录名不存在 ⇒ `collect_paths` 按磁盘遍历静默丢弃 ⇒ 登记面少几百行而无人见 | 取数面改用仓内既有 `-z` 解法；在 `batch_spec.paths_from_rows` 与 `fi_group_rows` 双入口加 fail-closed 守卫（正则要求 ≥3 段连续八进制三元组，`photos/200/301/` 这类真数字目录不误伤）；单测锁 8 例形态 |
| ② | `media_block()` 只取**首个**同名 `@media` 块，而 `system.css` 实有 6 个 `max-width:768px` 块 ⇒ 规则写在后面几块就被判「缺失」 | 640px 恰好只有一块，所以 A2/A6 一直"通过"——**侥幸通过不等于判据正确** | 新增 `media_blocks()` 聚合全部匹配块，A1–A7 一律改走它；汇总行的「契约 N 项」改由 `CONTRACT_IDS` 派生（硬编码计数在加 A7 当场失真，此类数最容易漏改） |
| ③ | 第 64 槽 A 层只校验 `min-height`，不校验宽度维度 ⇒ 正本「EN」标签宽 20px（WCAG 2.5.8 判**双维** ≥24px）在 6 页越界 | B 层探针能抓到，但探针 84 秒**刻意不进 pre-commit** ⇒ 静态面不留锁就能静默回退 | 升格为 A7 静态契约（`.site-mainnav .nav-item` 双维 ≥24），自测补「只设高度」负样本（现 7 例），`inline_css --force` 重分发 851 页后探针复跑 FAIL 6 → 0、溢出 0 |

**统计守卫的重指向**（同属③类「防线不能因裁决翻转而被删」）：`scripts/check_no_goatcounter.py` 原为 W806「GoatCounter 存在即红」。G0-1 拍双轨后若删守卫或加豁免都是补丁——现把判据从「不得存在」改为「**必须等于具名例外全集**」：C1 标签须在注入器 MARK 块内 / C2 端点须等于配置正本 / C3 脚本唯一 / C4 写入口唯一（且**分追踪标签与事件属性两态**，初版用前缀子串把导航的 `data-goatcounter-click` 误判成追踪标签，现网当场 1 FAIL 自证）/ C5 配置正本 ↔ CSP 白名单双源一致。自测 2 正 6 负（**正样本含「规范形态必须放行」**——否则重指向只是换了个误报器），单测 5 例同步。
