## 0. v3 改判记录（§8 在飞方向为何停建 · 哪些资产复活 · 浓彩层推导）

**停建**：v2「全站暖纸文人调」按用户终裁停建。停建理由不是执行缺陷而是方向判断：全站统一的暖纸文人调把「温度」铺满了每一个像素——表单、表格、图表轴、按钮全在宣纸上，结果温度被稀释成底色，数据页尤其违和（仪器精度被迫穿上长衫）。用户要的其实是**分区**：安静的地方极安静，浓烈的地方才浓烈。这正是 C 路线「中性骨架 + 浓彩原文层」的洞察——语域分离，接缝即语义。

**复活的资产**（v1「批校本」→ v3）：
- 中性素墙整套令牌（冷灰阶 `#F2F1EE/#FBFAF7` 系、暖墨阶文本、中性 hairline 结构）原样复活——v1 已全过复算，直接回滚；
- 仪器图表语言（轴/网格/mono 刻度/条形几何）原样复活；
- sans 正文与三档动效契约原样复活；
- 百回刻度带的**内容语义**（100 刻度、十回高标、朱色批注、14 条真实回目、tooltip 契约）全部保留——只换形体（横带→环）；
- 朱砂唯一强调色的纪律保留。

**v2 的遗产**（被 v3 间接继承）：暖墨砚底暗色面板——在 v3 里它获得了真正的身份：不是「文人调的暗色」，而是**入窟的洞窟地面**（壁画本来就在幽暗处）；楷体引文层保留（手批的声音）；颜料命名的序列色保留。

**浓彩层的设计推导**：原文语域的视觉血统按 §9 四个词展开——
1. **版画劲线**：黑轮廓（key block）承担全部造型，色块只做「套印」——每件浓彩件都是一次套色印刷：色块相对墨线偏移 2–2.5px（套印错位是手工印刷的物证，2x 放大下依然「有意为之」）；亮色主题勾线=墨（key block 传统），暗色主题勾线=赭石（壁画以赭石勾线传统）。
2. **壁画矿物颜料**：颜料谱 = 序列色谱（8 色相，恰好 §9 点名的朱砂/石青/石黄/石绿/胭脂/青金/赭石+墨灰）；石青、石绿压在暖暗底上正是青绿山水的材料关系；每件作品 ≤4 色相（经济性）。
3. **傩面戏妆强对比**：纯色块必须被黑轮廓框住才允许出现——「色块无轮廓」是糖果色，是禁的；坛城的五相环、精选卡的节点、日轮全部黑描边。
4. **连环画叙事势能**：构图全部动态不对称——路线从左下冲向右上、外环劲线在右上破口、日轮偏离圆心、浪纹偏向内_field 左下；坛城入场按环序依次点亮（连环画的翻页势能）。

## 1. 押注的签名元素：百回坛城

**押注：把百回刻度带环形化，让「量尺」长成「坛城」。** 一百根刻度环行成圆——每刻一回、每十回一根高标（宋体环标）、朱色刻度是已批注回目（悬停读真实回目原文，14 条逐字可考，其余诚实显示「尚无批注」）；五段套色弧 = 五相五方（石青/朱砂/石黄/白/玄——五行山的宇宙论正是小说的骨架）；版画劲线外环右上破口；内_field 三道墨浪（取经人渡的河）加一道石绿套色；右上角一枚套印错位的朱砂日轮。**中心是活读数**：悬停任意刻度，坛城芯从「一百回」翻成「第 N 回 + 回目」。

为什么它配当签名：
1. **形体即意义**：横带是「进度条逻辑」（西方的），环是「回环结构」（取经的环形叙事、坛城的宇宙论）——同一份 100 回数据，环比带更属于这部小说；
2. **内容与仪器合一**（§9 标准）：每根刻度是坐标、每个颜色是状态、中心是读数——没有任何一根线条是纯装饰；
3. **它是两层语域的接缝示范**：住在素墙的安静画框里（挂画），内部却是全站最浓的套色版画——用户第一眼看到它，就同时看懂了「墙」与「画」的关系；
4. **诚实**：只有 14 根朱色刻度有真回目，其余「尚无批注」——样例身份明示。

## 2. 字体策略

**四层声音，零外部依赖**：正文系统无衬线（阅读经济学）；display 宋体（经典的声音）；数据等宽 + tabular-nums（仪器）；引文楷体（手批的声音，≥20px 专用）。v3 的语域分工在字体上同样成立：界面与数据是「印刷」，引文是「手写」——校勘本的字体之分。印章用宋体阴文（印刷传统而非手写）。

## 3. 色板推导

**一套颜料，两个世界。** 推导分三层：

1. **素墙（工具语域）**：v1 的中性冷灰阶原样复活（`#F2F1EE` 系）——它已通过全部复算，且被终裁追认为「画廊白墙」。暖墨阶文本（`#26231D` 系）保留：中性不等于冷黑。
2. **窟（暗色）**：v2 的暖墨砚底暗色面板原样复活并获得新身份——洞窟地面。深暖底（`#151110/#1E1813`）上，序列色整体换亮值（L* 44.6–88.0），饱和颜料发色；勾线从墨换成赭石（`#846342`，对窟底 3.35:1）——壁画勾线的矿物传统。
3. **颜料（两层共用）**：8 色相 = §9 点名清单（朱砂/石青/石黄/石绿/胭脂/青金/赭石/墨灰）+ Okabe-Ito 骨架；色相与饱和度继承 Okabe-Ito，明度阶梯由优化器在色盲约束下拉开（三轮未动， protan/deutan/tritan 全组合最小 ΔE ≥11）；数据图表与原文语域共用同一谱——「数据和壁画说着同一种颜色语言」。

**刻意避开的**：糖果渐变、霓虹、饱和度拉满（接缝规则②）；紫蓝渐变（黑名单）；纯黑纯白（阶梯代替）。

## 4. 动效哲学

**动效是纪律的表达：三档时长、两个属性、零循环、双守卫**（与 v1/v2 一致，从未改判）。v3 新增的只有坛城入场：整体 rotate(-8°→0°) + 外环淡入 + 百根刻度沿环序点亮（delay = i×1.8ms，末根含时长 598ms ≤600ms）——环读势能一次性播完，reduced-motion 直接定格。其余全部继承：反馈 150 / 状态 250 / 入场 600 / KPI 计数 900（白名单）；tooltip 契约不变；fail-open 三件套（无 JS 恒可见、1.6s 兜底、终值在 HTML）。

## 5. 删掉了什么（Chanel 镜子原则）

- **删掉暖纸文人调的全站铺陈**（v2 的宣纸表面、笺纸衬色、乌丝栏横向刻度带）——温度改由暗色洞窟与浓彩件承担；
- **删掉第二强调色的任何复活企图**：石青/石黄只活在画框内与数据里；
- **删掉装饰性渐变、emoji、每节眉题**（眉题全站至多 1 次）；
- **删掉具象人物**：版画件全部用抽象几何（五相环、浪、日、路线、网络、热力格、情绪山）——画不好宁可不画（§9 原文）；
- **删掉卡片默认阴影**：静置靠 hairline，hover 才浮起；
- **删掉横带刻度**：被坛城吸收（横带的 CSS 已从 system.css 移除，不留死代码）；
- **删掉假数据**：所有数字来自简报口径，副图总和恒 81，占比由同一总数现算。

## 6. 契约冲突与裁决

1. **简报内部矛盾**：KPI 示例「总出场 2,632」与给定序列之和 2,692 相悖 → 取序列之和（硬数据优先），占比全部由同一总数现算，页面自洽（v1 起沿用）。
2. **工艺指南 vs 零依赖契约**：指南禁手绘 SVG 图标、禁系统字体；契约要求零依赖 file:// → **契约优先**，手绘 16 枚图标族 + 系统字体栈（v1 起沿用）。
3. **「素墙挂画」与 hero 构图**：坛城若裸放在 hero 上会违反接缝规则③ → 加 `.art-panel` 画框（hairline + canvas 底 + 图注），浓彩件永远带框。
4. **套印错位 vs 几何精确**：错位只出现在「颜料块相对黑轮廓」的装饰位（恒 2–2.5px、方向统一），数据与 UI 的几何仍然精确——错位是语法不是失误。
5. **暗色暖底 vs 工具语域的中性**：暖调只属于暗色的地面（入窟是 §9 明文），亮色永远画廊白；暗色 chrome 的结构纪律（hairline、阶梯、间距）与亮色完全同构。
6. **遗留字面勘误**：对比度脚本中按钮文字对的测试字面量曾残留 v2 的 `#FDF6EA`，已订正为 v3 现值 `#FFF8F5`（5.00:1）。
