**执行口径（与第 48 门禁同源·不自相矛盾）**

1. **模板是结构的唯一来源**：章节标题、表格列名、编号前缀按模板写；仓内惯例把「一份报告」拆成《执行前计划》+《任务计划执行与经验沉淀报告》两件落库，属**件型分流**而非降级——两件合起来须覆盖模板 §12 十项。
2. **等效形式**：仓内已有的等价写法（如「本批不做 / 不做项」承担「待确认事项」职能、「0. 任务背景」承担「执行摘要」职能）按等效计。
3. **模糊词**：模板 §10 的禁用词表按字面执行——「大概 / 可能 / 较好 / 差不多 / 尽快 / 尽量 / 合理 / 适当 / 优化一下 / 详细 / 及时」一律改成量化或「假设…；待验证…；验证方式…」形态。
4. **不编造**：数据缺失写【假设】/【待补充】并给验证方法，不补数、不推测。
5. **门禁只拦新引入的缺项**：存量不合规件按增量口径豁免、只提示；存量补齐后豁免自动解除（第 48 门禁 fail-closed·crash 即拦）。
6. **模板即任务**：提示词原文页标注「提示词 ≠ 任务·执行其中任务须单独授权」——照模板写不等于获准执行模板所描述的动作（仓外动作须用户逐项批准）。
