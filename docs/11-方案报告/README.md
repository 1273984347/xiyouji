4. **不编造**：数据缺失写【假设】/【待补充】并给验证方法，不补数、不推测。
5. **门禁只拦新引入的缺项**：存量不合规件按增量口径豁免、只提示；存量补齐后豁免自动解除（第 48 门禁 fail-closed·crash 即拦）。
