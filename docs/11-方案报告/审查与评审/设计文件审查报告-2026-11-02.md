## 三、发现清单（按严重度排序）

### P1-1 · EN 站 24 页使用私有 `.tooltip{}` 盒样式块，违反 DESIGN.md §5.4

- **证据**：24 个 `site/en/*.html` 含 `.tooltip { position:absolute; background: var(--dark); … }`；ZH 站 0 页。样本：`site/en/aesthetics.html`、`site/en/character-semantic-network.html`。
- **影响**：tooltip 盒样式与全站统一契约不一致，且暗底 `var(--dark)` 违反 §5.4「禁暗底金/奶油色」，EN 页与 ZH 页视觉分叉。
- **建议**：24 页 `.tooltip` 收敛为 `.chart-tooltip`；门禁补扫描 `(?<![-\w])\.tooltip\s*\{`。

### P1-2 · EN 站 50 页有 d3 transition 但无 `MOYUN_RM` JS 守卫，违反 §5.3

- **证据**：EN 站 `.duration()` 为裸数字（`.duration(600)`），ZH 站同位置为 `.duration(MOYUN_RM?0:600)`；`site/en/chart-design.html` 的 `MOYUN_RM` 计数 = **0**，ZH 版 = **31**。全站 `MOYUN_RM` 仅 37 页、其中仅 7 页做 prototype 级 patch。
- **影响**：用户开启「减少动态效果」后，EN 页图表仍全量动画（含 1800/1900/2000ms 延时），a11y 契约失守。
- **建议**：EN 站补 `MOYUN_RM` 守卫（与 ZH 同构）；`check_motion_ban.py` 增「d3 页无 RM 标记」检查。

### P1-3 · DESIGN.md §4C「v4 令牌零消费、纯加法」断言已失效

- **证据**：独立复算（位置级剔除内联副本后）`--space-*` 真实消费 **854/855 页**、`--container-*` **639 页**；而 `--gap-*`（6 语义档）、`--type-*`（9 排版角色）、`--grid-*`（2 个）仍 **0 消费**。
- **影响**：规范正文与现役代码脱节——下游 Agent 据 §4C 判断「令牌未启用」会误判；且真正承载设计语言的**语义角色族完全未落地**，已落地的只是数值刻度族。
- **建议**：§4C 补「W1076 起已消费」现况口径，并把 gap/type/grid 三族零消费登记为待办。

### P2-4 · DESIGN.md §4A.8 体积与页数数字过期

- **证据**：实测 system 毛重 **29,353 B**（文档记 28,441）、净重 **23,541 B**（文档记 23,052）；内联副本实为 **328 页**（文档记「约 225 页」）。tokens 侧 23,039 / 16,245 B 与文档一致。
