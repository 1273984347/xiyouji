## 0. 结论先行

本轮共 **90 条编号发现**（第一批 45 + 第二批 32 + `site/reader`/`dataset` 全量补充 13），其中优先处理的是三类：

1. **门禁假绿**：`ledger_backfill` 自测恒返回 0、`check_script_coverage` 常用词即算覆盖、`check_structure` 只查圆括号、`check_data_drift` 只覆盖 60/89 页、`check_chart_values` 覆盖缺口不进退出码、`check_commit_scope` 空/坏 spec 放行、`check_doc_numbers` 208 份 spec 只有 1 份声明判据。

4. **第二批（剩余 64 个门禁）再发现 32 条**（P1 12）：三类新根因——CI 形态下取数链恒空（`git status`/`git diff` 在干净检出或浅克隆为空）、扫描面漏 `site/reader` 102 页与 EN 站、判据被注释或纯子串满足。详见 §7。
5. **全量补充（reader 622 页 + dataset 46 JSON）再发现 13 条**：207 页可见「待补」占位、199 条 GitHub 链接 `docs/source/` 前缀失效（去掉 `docs/` 后 18/18 存在）、33 页多 h1；dataset README 索引 41/44 且体积失真、17/44 有 `meta`、edge 3/9 事件零引文、9 节点 `chapter=0` 哨兵、两套权重量纲、4 个 sankey 使用数字索引。详见 §9。
