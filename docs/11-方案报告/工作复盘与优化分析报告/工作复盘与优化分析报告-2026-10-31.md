## 5. 经验沉淀

1. **诊断分级前置**：只读诊断（不改文件）+ 三分法归因，让后续每批的修法零归因成本——适用于任何「门禁红但不知为何」的开场。
2. **多 Agent 共树的三条铁线**：台账先落者得号 / 索引是全局共享资源（一方开跑收官另一方必须停手）/ 级联产物必须可重放（spec 存 json 就能零丢失让路）。
3. **收编死会话产物的检查单**：先跑其自测 → 核对 §11.2 管控面 → 台账补行 → CHANGELOG 记账 → 释放死号。
4. **门禁绿 ≠ 全部声明面被扫**：C5e 只扫两类载体时 SKILL.md 漂了两批（W1058 实证）——「对账面与真实声明面必须同宽」。
5. **影子先行的完整闭环示范**：G-03 报数（W1053）→ 清偿（W1054/55）→ 升格即绿——比「直接收紧然后修红灯」少了所有返工。
6. **提交流程契约化**：三问自检进钩子（每提交物理弹出）——纪律从「靠人记得」到「机器替人提问」。
