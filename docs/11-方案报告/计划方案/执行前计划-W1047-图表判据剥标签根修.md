## 0. 任务背景（执行摘要）

`scripts/check_chart_data.py` 的 `strip_invisible()` 负责从 HTML 抽可见文本供 R1/R2/R3 三项判据使用。W1045 批的逐处复核发现两处互锁的根因：

- **根因 A（标签起点过宽）**：`<[^>]+>` 的起点只要是 `<` 就当标签 ⇒ **JS 比较符 `<=` 被当标签起点** ⇒ 匹配段跨行时把**标签之间的正文整段吞掉**。实测 4 页：`site/data/perf-canvas-rendering.html`（吞掉 `n.x <= viewX1 && … n.y >= viewY0` 一整段多行 JS）、`site/data/game-webnovel.html`（吞掉「灰<6.5」）、及两份 en 版。
- **根因 B（剥离顺序）**：顺序是 script → style → 注释 ⇒ **注释里的 `<script>` 字面量**触发 script 剥离 ⇒ 一路吞到后面真正的 `</script>` ⇒ 注释自己的 `-->` 被吞 ⇒ 注释剥离失配 ⇒ 注释残留（实测 `site/_template.html` 的「脚本区」注释）。旧式 `<[^>]+>` 恰好把这段残片当标签吞了 ⇒ **掩盖了根因 B**。

而朴素修法「排除符补 `\n\r`」会伤**多行合法标签**（`site/data/ai-dialogue.html` 的跨行 `<input>` 剥不干净）⇒ 形成两难。

**本批解法（根因修法·非绕过）**：① 剥标签改按**标签语法**约束（标签名必须字母开头 ⇒ `<=` 不匹配；属性段允许跨行 ⇒ 多行合法标签仍剥净）；② 剥离顺序改为**注释优先**。
