### 5.5.1 批 A 明细（判据与口径 · 不动视觉）

**A-1 力导向族规模判据（拟新增 R6）**
- 现状：22 个签名页在用；`check_chart_data.py` R1–R5 无节点/边数判据；DESIGN §4B 力导向行写了「节点 >200 禁用」但**无机器判据、无声明位、无基线**——与 W1341 发现的「雷达族裸区」同构。
- 做法（顺序不可换）：① 先取证逐页节点数；② 若存在 >200 页，照搬 R5 成熟范式——页内声明 `<!-- chart-force-meta: nodes=N edges=M -->` + 基线 `scripts/output/force-family-baseline.txt` 冻结存量；③ R6 挂进 `check_chart_data.py` 并补自测负样本。
- 禁区：不得先改页面再补判据；不得为让判据变绿而删节点。

**A-2 布局形态登记**
- 现状：W1341 §八 第 3 项已证伪「19 页力导向掩盖层级」——实为 `forceX(d => _gx[d.type]) + forceY(...)` 的**分层 + 力导向混合布局**；但 §4B 力导向行只登记了「力导向图」，事实形态留在表外。
- 做法：§4B 力导向行「该图型」补「力导向 / 分层+力混合（`forceX/forceY` 按类型锚定）」；「禁用条件」补「层级 >3 层须用树图」。改表体行数须同批改 `EXPECT_SPEC_ROWS`。
- 边界：这是**登记事实**，不是放宽红线——混合形态仍受 A-1 规模上限约束。

**A-3 评分口径标注**
- 现状：27 页雷达的轴取值来源全站无处声明；`six-senses-narratology-network.html` 正文自述「四条轴里只有引用度一条拉开差距，其余三条完全齐平」＝ 3/4 面积是常量。
- 做法：`#dataSource` 区增固定行 `口径：<人工判定 | 可复算规则>（依据：…；样本：N 处 / N 回）`；文本级判据挂 R7（grep 存在性），不新建脚本。
- 接线：属内容可信度轨（铁律 13），禁模糊措辞（文档规范 §4.9）。

### 5.5.2 批 B 明细（无障碍与测试）

- **B-1 键盘可达路径**：聚焦图表后 Tab/方向键在「图 → 数据摘要 → 数据表 → 图」间移动，Esc 退出；沿用现有运行时注入 + `window.__chartA11y` 幂等闸，**不改页面静态 DOM**（零内联哈希需求）。
- **B-2 数据表 fallback**：每图配可展开等价数据表，满足「数值不依赖 hover」；生成方式二选一——构建期静态注入（页数多）或运行时由 `EMBEDDED_DATA` 生成（零页面改动）。
- **B-3 视觉回归基线**：按「族 × 视口 × 主题」建矩阵，复用 `visual_regression_probe.py` 的 computed-style 对拍 + 截图工作流；新增基线须用户批准。

### 5.5.3 批 C 明细（地图族与高密度渲染）

- **C-1 地图族编码治理（5 页）**：`journey-map-interactive` / `journey-geo-semiotics` 为真投影（`d3.geo*`），`journey-route` / `customs-pass-route` / `journey-spacetime` 为自绘示意——须声明归属，禁两法混用；路线编码（起讫/途经/难易序）统一；同回目跨页方位一致。**禁外部底图**（铁律 5）。
- **C-2 >200 节点受控出口**：给 §4B「节点 >200 禁用」开受控出口——>200 改 Canvas 2D + 分页/聚合，而非砍数据；前置为 A-1 实测结论；帧率地板先测后立，禁写「性能良好」。
- **C-3 3D 两页处置**：`character-relationship-3d` / `journey-geo-3d`——① 补 z 语义承载真维度，或 ② 降为 2D。**须用户裁决**（属删功能级）。WebGL 不可用回退不可撤（`graph-fallback.js`）。
