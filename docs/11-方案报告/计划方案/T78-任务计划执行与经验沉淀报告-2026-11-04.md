## 4. 复盘
**本章结论**：本章要求已逐项落实，明细见本章各表与第 3 节实测读数。

### 4.1 做对了什么

1. **先实测再谈**：用 gh pr list 取真实分布（20 个 / 7 个纯回填），把"感觉"变成可讨论的数字，用户因此能直接裁定口径。
2. **纪律与工具同批**：识别出"新纪律会让第 51 槽假红"这个连锁后果，并在同一批根修 ⇒ 纪律生效日即无死角。
3. **不放宽判据**：并集只在"新增段 > 1"这一明确场景生效，真代提仍红（负样本实测）。
4. **自己写错的两处如实登记**：单测预期与探针 lambda 各错一次，记进 §2.1 而不是抹掉。

### 4.2 待改什么

1. **本批教训待入坑表**：「多批同 PR ⇒ 门禁归属须支持多批·并集应动全集·真代提仍判红」应入坑表（拟 E-172 起），待并行会话 W1125 合并、计数链基线稳定后入。
2. **纪律的跨会话落地靠人**：铁律已入仓，但其他会话是否照做仍需回执确认 ⇒ 需要一次「纪律生效后首个工作日」的 PR 数复核（目标：单会话单日 ≤ 1）。
3. **合并窗口未制度化**：当前只约束"单会话当日一 PR"，未约束"一天何时合"⇒ 若多会话同日下午各自合并，仍会有多次 CI 轮次 ⇒ 后续可考虑固定合并窗口（待用户裁定）。
4. **未处理项**：档 3 消费方式全量施工待第三方原型合并与口径重建后另批；存量 .py 全仓语法巡检待做。
