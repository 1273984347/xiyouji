## 一、执行摘要

**背景**：W889 展示面复位批已提交（`5b156543`）并推送 origin/dev，PR #51（dev→main）已就绪。但合 main 被 CI 拦下——CI 实证三类红项：

| 红项 | CI 原始表现 | 是否 required | 归属 |
|:---|:---|:---|:---|
| `Unit Tests (pytest)` | **2 failed**, 827 passed, 5 skipped | **是**（阻塞合并） | W876/W887 的有意变更未同步判据 |
| `Code Quality (ruff + black)` | Found **6 errors** | 否 | W836/W860 批引入 |
| `pip audit` | **25 个 CVE** | 否 | Pillow 12.3.0（上游新版本→旧版本出现新 CVE） |

另有一项**本地红 / CI 绿**分歧族：本地 pytest **静默退出·零输出·exit 1**，CI 全绿——根因是 `os.kill(pid, 0)` 在 Windows 上等价 TerminateProcess。

**本批动作（四类）**：

1. **过期断言同步（2 处）**：不改动上游有意变更（W887 扩 en 范围 / W876 改 chart-3 与暗色 accent 值），只把**测试判据**更新到新契约，并保留原契约的关键前提。
2. **ruff 六项清零**：全仓口径 6 errors → 0。
3. **跨平台存活探针根修**：Windows 改非终止式存在性查询；`RunLock` 默认参数改运行时解析（顺带修掉测试落到真锁路径的隔离缺陷）。
4. **依赖漏洞清零**：Pillow 12.3.0 → 13.0.0（25 个 CVE 归零），pytest 全量在其下实测通过。

**关键判断**：三类红项**均非 W889 引入**——它们是 W836/W860/W876/W887 四批的成果未同步判据留下的欠账，且因 PR #51 自 2026-10-18 未合并过、这些批次从未进 main，CI 从未在 main 上绿过。本批是**清偿欠账**，不是掩盖失败：每一处都保留了原契约的关键前提与可复算的验证命令。

## 四、决策记录与理由

### D-1 改判据，不回退上游变更

**备选**：① 改测试期望（本批选择）② 回退 W876 值切换 / W887 范围扩展 ③ 跳过该用例。
**选择理由**：W876/W887 的变更在提交信息与 CHANGELOG 段中均记录了目的与验收数据（en 迁移 110 页、chart-3 命中 42 消费页），属**有意变更**；回退将使已落地的迁移成果与页面内容不一致（改 234 页的成本远超改 2 条断言）。**跳过**被 N-01 禁止。
**权衡**：改判据有「迁就实现」的风险——故保留原契约关键前提（zh 审计面须被门禁完整覆盖 / 暗色不得偷新增 chart-3/5），并在测试 docstring 中写明旧契约与新契约的来源批次。
**可复用结论**：判据与上游变更不同步时，先判定「谁是新的事实源」，再改判据；同步时必须留下旧契约与变更来源批号的对照。

### D-2 收敛 `DEFER_HOLD_CHECKS`（实现侧）而非在测试里跳过

**备选**：① 改实现（删两条已改值项，本批选择）② 在测试里过滤掉 chart-3 那条。
**理由**：`DEFER_HOLD_CHECKS` 是**实现里的契约声明**，其语义是「尚未落地的撞名项必须原值未动」；chart-3 与暗色 accent 已被 W876 落地改值 → 它们不再属于该集合。改实现使契约本身与事实一致，测试自动复验；改测试则留下一个自相矛盾的契约（声明「必须未改」但实际已改）在仓内。
**权衡**：需同步确认 `DEFER_HOLD_DARK_SNEAK`（暗色不得新增 chart-3/5）仍成立——实测暗色块不含这两个名 ✓，故保留。

### D-3 Windows 存活探针用 OpenProcess + GetExitCodeProcess（不引 psutil）

**理由**：`psutil` 会给 `scripts/requirements.txt` 增加一个依赖（并连带引入其自身的 CVE 面与 pip-audit 判据）；`ctypes` 直调 kernel32 无新增依赖，且 `PROCESS_QUERY_LIMITED_INFORMATION` 是 Windows Vista+ 的标准查询权限，**不终止目标进程**。
**权衡**：Windows 分支无法在 CI（ubuntu-latest）自动覆盖 → 已在代码中标注 `pragma: no cover` 并把本地实测写进报告与 CHANGELOG 段（不留假绿）。

### D-4 独立成 W890 批，不并入 W889
