## 0. 任务背景（读者无需回看会话即可理解）

本项目《详解西游记》是 857 页静态站（`site/`），正文 615 篇，含「回目 / 人物 / 主题 / 文化 / 随笔 / 诗咏」六库。内页题图是 reader 页配的竖版插画，用途是给长文页面在首屏提供视觉锚点，同时承载该页题目的意象。

题图资产层的现行规格（实测自 `assets/promo/plate-set/`）：

| 项 | 规格 |
|---|---|
| 母版画幅 | 1200×1600（精确 3:4） |
| 站点版画幅 | 宽 1200，高随主体顶浮动（1056–1301）·**只裁上部留白，保留下部「地面留白」** |
| 风格 | 中国传统工笔白描线描：宣纸底 #FAF7F0 + 纯墨线（无实心填充/渐变/阴影）+ 赭金 #8A6D3B 局部 + 单点朱砂 #C8463A 点睛 |
| 构图 | 主体上方留约一成呼吸空间（**不设专用标题区**，页面标题在图外）+ 完整全身立像居画面中下部 |
| 禁项 | 无文字 / 书法 / 印章 / 水印 / 题跋 / 边框 / 展柜 |

**存量与缺口（实读磁盘）**：

- 已有母版 **52 张**（W945 16 + W948 12 + W952 12 + W953 12 + W974 12），`site/static/images/` 同名站点版 webp **52 个**。
- reader 库共 **622 页**，其中 **63 页**有题图 ⇒ **缺口 559 页**（people 180 / themes 189 / essays 45 / poetry 14 / culture 35 / 回目页 94 / 其余 2）。
- `site/reader/people` **216 页**、`site/reader/themes` **210 页**、`site/reader/essays` **45 页**、`site/reader/poetry` **14 页**、`site/reader/culture` **35 页**、回目页 **100 页**。

**本批定位**：同族续批第四组，12 张。与第三组（W974）的差别是**题材结构不同**——第三组为「人物 6 + 主题 6」且全部落 people 库；本批按用户问卷裁定的**四库混合**铺开：people 4 + themes 3 + essays·poetry·culture 3 + 回目页 2。跨学科与制度类页面（essays·poetry·culture + 抽象 themes 专题）的题图取**人物立像 + 具象核心物**（行者展舆图、门神执桃符、书生捧考卷），而非纯器物构图——母版段逐字含「主体为完整全身立像、占画面高度约五成」硬约束，纯器物构图会与母版段冲突并触发 J4 判红（依据见 D-03）。

**用户已裁定的四问（2026-10-27 问卷答复）**：

| 问 | 裁定 |
|---|---|
| 素材用在哪里 + 画幅 | 内页专题题图 · 3:4 竖版 1200×1600（沿用 plate-set 母版） |
| 需要几张 | 12 张 |
| 有没有参考风格 | 沿用 plate-set 宣纸线描（母版风格段逐字复用） |
| 题材范围 | people 人物库 + themes 专题库 + essays·poetry·culture 三库 + 九十九回回目页（四库混合） |

**开工前的合规动作**：动工前实读发现 **W982 批已暂存未提交**，占 CHANGELOG / AGENTS / HANDOVER / 台账等共享面；`preflight_check.py --self W983` 判红（touches 交集 = AGENTS.md、CHANGELOG.md）。处置 = 先按协议收官 W982（内容批 `c99377b8` + 收官回填 `5fb2ffe2`，verify 全量 55/55 段全绿、pytest 677 passed / 3 skipped），再复跑 preflight → 交集 0 → 才登记 W983 认领行（`fd9b0cc4`）。

### 5.2.3 不完成定义

本批出现下列任一情形即判**不完成**，不得声明收官：

1. 12 张母版未全部通过 J1–J10（任一张 FAIL）；
2. 母版风格段与 W953 母版不逐字相同（跨批风格同族断裂）；
3. 站点版存在「主体顶被切 / 主体底被切 / 下部地面留白 ≤ 0」任一情形（人物悬空或截断）；
4. 12 张中任一张经人眼放大复核判定题材误读或形制错误且未重出；
5. 既有 52 张母版或站点版内容被本批改写（本批 prep 脚本作用域限定在 `raw/round12`）；
6. 12 个落位页中有任一页在接入前已有题图（重复插图）或不存在（无处可放）；
7. 站点门禁出现核心 FAIL，或第 48 门禁判红；
8. 收官报告未落 `docs/11-方案报告/计划方案/` 且未在 `docs/11-方案报告/README.md` §六 登记。
