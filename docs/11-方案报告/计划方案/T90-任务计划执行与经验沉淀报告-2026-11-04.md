## 0. 任务背景（读者无需回看会话即可理解）

《详解西游记》仓（xiyouji）是一个多 Agent 并行协作的静态站点仓：12 个会话同时在线、6 棵 git worktree 各施工一条批次线，全部批次共享同一批治理文件（台账 / CHANGELOG / README §六 登记表 / 坑表计数链 / file-index 段面）。

本批要解决的问题是：**这些批次各自能看到「当前状态」，但看不到彼此的意图**，于是出现三类后果 —— ① 同一登记号被两批同时认领；② 两批同时跑收官链，整面重写互相覆盖；③ 仲裁时依据的读数本身过期（工作树快照 / 门禁打印值），把整条号段与计数链推歪。本批的任务是把这三类后果在施工前消掉，而不是在合并后补救。
