## 执行摘要

本批为《取经录》产出**成套 Hero 横幅素材**：12 张 16:9 图（母版 5472×3072 jpg + 站点用 1920×1078 webp），画风=古画绢本·朱砂石青，题材按 3/3/3/3 铺满山水洞天佛寺 / 妖魔鬼怪 / 取经人物群像 / 法宝灵器。

**过程关键转折**：v1 用纯文字风格块生成 12/12 成功，但自审（量化 + 12 张逐张目视 + 程序化印章扫描）判定**风格一致性不合格**——同一套 prompt 落成 3 个画风档（4 张可用 / 3 张带杂质 / 5 张断层）。根因修法不是再调措辞，而是**以 A 档成品作 reference_images 锁风格** + 人物题材点景化 + 强色彩题材配额纪律，重做 8 张后 12 张收敛同一画风档；05 号因"熔岩红"主导二次生成才压住。

**验收结论**：画幅 12/12 一致 · 留白区边缘密度 0.049–0.108 vs 主体区 0.202–0.304（12/12 成立）· 零文字零印章 · 留白保守实测 25%–35%。独立盲审判 FAIL 并推动 12 类事实订正（逐张清单 8 处描述 / 体积 / 4K·16:9 标签 / 题图族留白位 / 未上线口径 / webp AIGC 标识缺口），已逐条落地。

**未完成项**：素材面未上线（站内 site/static/images/ 无本族文件）· 本批提交需用户点名授权 · 6 条已知瑕疵已登记。

## 二、执行记录

### 2.1 v1：12/12 成功，但自审判定不合格

- 生成：两批提交（10 + 2，因 requests 数组上限 10），12/12 成功、无失败项。
- 自审三层证据：**量化**（留白区边缘密度 / 色相分布 / 留白宽度）· **12 张逐张目视** · **程序化印章扫描**（高饱和朱红簇连通域 + 逐簇放大）。
- **判定**：落成 3 个画风档——A 档（厚重青绿绢本设色）4 张可用 · B 档（带杂质）3 张 · C 档（画风断层）5 张（06 写意泼墨 / 07·08 白描淡彩 / 09 工笔重彩 + 游戏立绘感 / 10 现代矢量纹样）。

### 2.2 根因与根因修法

**根因**：文字风格块锁不住视觉一致性——12 张独立生成、各自解释"绢本设色"；人物题材被模型带向"工笔重彩人物画"传统（与青绿山水底色分属两套系统）。

**已实施的修法**：① 以 A 档成品作 reference_images，prompt 明确"图 1 只提供画风 / 色板 / 绢本质感 / 留白规则，题材另指"；② 人物题材统一约束"点景小人物 · 体量不过山体三分之一 · 铁线描 · 面部只勾轮廓 · 不做工笔重彩 / 游戏立绘"；③ 逐张补负向约束（禁荧光蓝 / 禁饱和红橙 / 禁矢量色块 / 禁写意泼墨）；④ 强色彩题材加配色配额纪律（朱砂占画面十分之一以内）。

**结果**：重做 8 张 8/8 成功；05 号二次生成 1/1 成功；**12 张收敛同一画风档**。累计 21 次提交 21 张成功、0 失败。

### 2.3 执行偏差与修正

| 偏差 | 修正 |
| --- | --- |
| 首轮留白测量用"与背景像素距离"判据，被老绢老化裂纹骗出 0.84–0.99 假墨量 | 改边缘密度 + 冷色像素分布两法交叉 |
| 05 号两轮仍被"熔岩红"主导（年画插画感） | 加配色配额纪律（朱砂 <= 十分之一）后第三次生成收敛 |
| 文档先于实测落笔：三处数字（留白 1/3、体积 6–8 MB、4K/16:9 标签）失真 | 盲审驱动逐条订正为实测值 |
| T103 报告初版缺 8 个模板判据段 | 按模板补齐（AC/A/E 表 + 摘要 + 附录 + 自评结论等） |

## 五、决策记录与理由

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 风格锁法 | 参考图（reference_images）而非加长 prompt | 文字风格块已实证锁不住；参考图是唯一带视觉锚点的手段 |
| 参考图选取 | A 档 01 云海佛刹（工笔青绿 + 铁线描 + 矿物颗粒最典型） | A 档里设色最完整、构图最"教科书" |
| 人物处理 | 点景小人物 + 只勾轮廓 | 保留青绿山水底色；代价是角色辨识度下降（已登记） |
| 强色彩题材 | 加配色配额（朱砂 <= 十分之一） | 负向词压不住"熔岩红"主导，配额是硬约束 |
| 提交范围 | 只提交本批路径，共享"现役批次面"回填并入在途批 | 避免代提他人在途内容；符合"回填不单独成 PR"口径 |
| 交付形态 | jpg 母版 + webp 轻量版双份 | 母版供后续裁切/再加工；webp 供页面（与既有两族结构一致） |
