## 执行摘要

W1284 承接 W1283 的两项遗留：① 清掉 graphic 口径实测出的**存量违例**（W1283 收尾时为 182 条 / 27 页）；② 把 **graphic 全量基线接入 CI**（W1283 只交付了测量能力，未自动拦截）。

**本批的关键突破是「工具与判据的同源化还差最后一处」**：W1283 对齐了四处口径，但工具在**图形过滤**上仍比门禁宽——页面里 `fill:none` 的装饰性 path（波纹底板/网格）被工具当成「覆盖图形」，导致底色取不到 ⇒ 工具直接放弃 ⇒ **真违例永远不修**（实测 visual-art 48 条全部因此未清）。补上「跳过 fill=none / alpha 过低的图形，且底色取不到时继续找下一个候选」后，存量由 182 条降至 **89 条 / 16 页**；再补齐 8 页漏接入的工具，降至 **70 条 / 9 页**。

**CI 接入方案（不碰禁改清单）**：第 80 门禁脚本改为**默认双口径判定**——body 与 graphic 各自对拍自己的基线（基线声明 `bg_mode`·口径隔离·互不放行），**末行合并汇总**取两口径基线外新增之和 ⇒ `verify_delivery.py` 的挂槽取末行即得两口径总判定，**无需修改 verify_delivery.py**（属 AGENTS 铁律 8 禁改清单）。门禁自测 18 → **22 项**，探针自测 9 → **10 项**。

### 2.2 最后一处同源缺口：图形过滤（实证）

W1283 已对齐「矩形档中心点判据 / 无覆盖图形时回退最近 CSS 背景 / 图形底色乘提亮系数 / 光晕分离度按 alpha 合成」四处，但仍有一处：**工具未跳过 `fill:none` 的图形**。

实测（`site/data/visual-art.html` 明态，文字 `20` 与 `黄风岭`）：

| 项 | 工具 | 门禁 |
|---|---|---|
| 覆盖图形候选 | 命中 1 个：`path` **fill=none**（900×255 波纹底板） | 跳过 fill=none ⇒ **无覆盖图形** |
| 底色 | 取不到（fill=none 解析失败）⇒ **直接放弃不改** | 回退最近 CSS 背景 = 米底 rgb(245,240,228) |
| 结果 | 浅赭字 CR 1.58 / 浅米字 CR 1.06 **留在原地** | 判红 |

**修法**：工具的图形候选筛选加「跳过 fill=none / 透明 / alpha<0.3」；且**底色取不到时继续找下一个候选**而非放弃（门禁 `pickCoveringShape` 的 `if (!sh.fill) continue` 语义）。

### 4.2 判据级根因：探针的匿名 SVG 分组缺陷

worker 在 `famous-time-travel` 清偿时发现：该页含 **2 个 `<svg>`**，明信片正文本属第二幅插画，却因两幅 SVG **都没有 id** ⇒ 探针的 `svgId` 全部取空串 ⇒ texts 与 shapes 归进**同一组** ⇒ 正文被几何配对到**第一幅插画的矩形** ⇒ 底色错配 ⇒ CR 2.10 假红。

**全站影响面实测**：147 页含多 SVG，其中 **23 页**存在「多个 SVG 无 id」⇒ 同样中招。

**修法（判据侧根治·非逐页加 id）**：探针在 `COLLECT` 内按 DOM 顺序给无 id 的 SVG 分配稳定键（`#anon-N`），texts 与 shapes 共用同一映射 ⇒ 同页多 SVG 互不串扰。**效果：全站 27 条 → 2 条**（大量原「违例」实为错配假红）。

### 4.2b 另两处判据/工具缺陷（收尾时暴露·一并根修）

**① 探针的「稳定」判据只看数量 ⇒ 颜色动画中途采集 ⇒ 假阳性**

原 waitStable 只比较「svg 数 | text 数 | scrollHeight」⇒ 文字 fill 的渐变动画期间数量不变 ⇒ **提前返回** ⇒ 采到中间态颜色。实测 pilgrim-team「无底洞·最后大难」：动画完成是**深墨**（CR 14），动画中途是**浅金**（CR 2.85）⇒ 门禁误判。**修法**：稳定判据加入**样式指纹**（采样 text 的 fill/opacity/stroke-width）+ 等待上限 1200 → 3000ms。

**② 工具不监听 resize ⇒ 窄屏布局变化后不重算 ⇒ 真违例漏修**

同一文字在宽屏压深色面板（可读）、窄屏落到浅色纸底（不可读）⇒ 底色变了但 **DOM 未变** ⇒ MutationObserver 不触发 ⇒ 工具不重算。**修法**：加 resize 监听（节流重算）。

**③ 官方探针按文案去重 ⇒ 同页同名文字的不同底色被掩盖**

探针的 seen 集合按文案去重（body 与 graphic 两口径都去重）⇒ 同页同名文字只判第一次 ⇒ 若两次落点底色不同 ⇒ 其一被漏。**现状**：未改（改动会放大全站判定面，登记为遗留）。

### B. 术语与口径说明

- **双口径判定**：门禁同时判 body（页面底色口径·W1265）与 graphic（图形底色口径·W1282）两套判据，各对自己的基线，末行合并汇总。
- **page_sha**：页面内容哈希前 12 位，防「页面改了但探针未重跑 ⇒ 报告陈旧 ⇒ 漏检」。
- **匿名 SVG 稳定键**：无 id 的 `<svg>` 按 DOM 顺序分配 `#anon-N`，避免同页多 SVG 的 texts/shapes 混组。
- **存量 / 基线外新增**：基线内记「存量」不计 FAIL；基线外新增 = FAIL；基线缺失 = fail-closed。
