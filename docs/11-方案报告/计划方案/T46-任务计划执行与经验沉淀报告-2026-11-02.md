## 0. 背景与结论速览（执行摘要）

W1084 把「改两行颜色 ⇒ 元素数由 532 塌到 108」的真因查实了：**改了内联脚本没同步重算 CSP 哈希 ⇒ 该页内联 `<script>` 整块被浏览器拒执行**（页面只剩静态 HTML），并据此把档 1「`.style()` 直喂 `var(--chart-N)`」的可行性由「已证伪」改判为「可行」。

本批就是**在同步 CSP 的前提下把档 1 真的做出来**，并逐条验六条判据。结论：

- **施工完成**：`site/en/global-pattern.html` 2 处硬编码色 → `var(--chart-1)`；随后重算 CSP（`generate_csp.py` → `--check` 零漂移）。
- **渲染完整性**：元素总数 **586**、可见 **532（light）/ 533（dark）**、卡片区元素 **8**、可见 **8**、CSP 违规 **0** ⇒ 与改动前**逐值相同** ⇒ **没有塌缩、没有渲染中断**。
- **令牌跟随成立**（关键证据）：`#timeline` 的**计算样式**读数显示 —— 浅色 `stroke` 含 `rgb(200,70,58)`（#c8463a 浅色令牌同值）；暗色 `stroke` **多出 `rgb(224,96,79)`**（暗色令牌 #e0604f）⇒ 1 CE 参考线随主题切到暗色令牌。`fill` 同样：浅色 `rgb(200,70,58)` → 暗色 `rgb(224,96,79)`。
- **一个必须纠正的预判**：本批动工前预判「行 1903 的 text fill 被该页暗色 `svg text { fill: var(--ink) !important }` 顶掉 ⇒ 暗色不变」—— **实测该预判错误**：暗色下 text 的计算 fill 是 `rgb(224,96,79)` 而非 `var(--ink)` 的 `rgb(35,32,26)` ⇒ 那条 `!important` 规则**并未生效**，原因是该页暗色由 `prefers-color-scheme` 触发、**不设 `data-theme="dark"` 属性** ⇒ 选择器不匹配。**教训**：CSS 优先级不能靠读规则猜，须实测计算样式。
- **判据覆盖边界（重要）**：J2 视觉回归「零差异（1065 元素逐属性对拍）」**不能**用作颜色证据 —— J2 的属性集（28 项）是 color / background / font / line-height / padding / margin / border / radius，**不含 SVG `stroke`/`fill`** ⇒ 颜色变化在 J2 里**根本测不出来**。令牌跟随是靠探针新增的**计算样式读数**证成的。

### 3.3 判据覆盖边界（必须披露）

J2 视觉回归报告「**零差异**（1 页 × light+dark · 1065 元素逐属性对拍）」，但 J2 的采集属性集是 **28 项**：color / background-color / font-size / font-family / line-height / padding-\* / margin-\* / border-\* / border-radius-\* —— **不含 SVG 的 `stroke` / `fill`**。⇒ **该「零差异」不能作为「图表颜色未变」的证据**；令牌跟随是靠探针新增的**计算样式读数**证成的（§3.2）。这同时是本批新增的 E-82。

## 4. 复盘

### 4.1 做对了什么

1. **把「改内联脚本 ⇒ 重算 CSP」做成施工动作的内置步骤**（而非收尾步骤）⇒ 直接对治 W1080/W1082 的失败模式。
2. **不拿「零差异」当颜色证据**：核对 J2 属性集后发现覆盖缺口 ⇒ 补测计算样式 ⇒ 令牌跟随拿到了可复算的直接证据（而非目测）。
3. **预判被实测推翻时立刻订正**：动工前的「行 1903 暗色被 `!important` 顶掉」被计算样式证伪 ⇒ 当场改结论、改文档（不护着自己的预判）。

### 4.2 该改什么

1. **J2 应补 SVG `stroke`/`fill` 属性**（或增设「图表色专项判据」）⇒ 否则后续每一批图表色改动都会在 J2 里「零差异」通过，判据面形同虚设（E-82）。
2. **`reserve_w.py` 的 `ledger_max()` 应只匹配台账行首的 `W#` 列**（`^\|\s*W(\d+)`）⇒ 文档里的预写号不应影响取号（E-83）。
3. **「读 CSS 规则猜优先级」不可靠**：本批预判 `!important` 生效 ⇒ 实测未生效（因该页暗色不设 `data-theme` 属性）⇒ 凡涉及优先级与主题选择的结论，一律以计算样式实测为准。

### 4.3 交接口径（下一批）

1. **先裁决口径**：`.style()` 色字面量取「实测 347 处 / 83 页」还是「W1079 定案 28 处」⇒ 决定扩展批的页数与批次切分（裁决 5：每批 ≤10 页灰度 ⇒ 页数决定批数）。
2. **扩展批的施工纪律照本批**：改内联脚本 ⇒ `generate_csp.py` ⇒ `--check` ⇒ 探针验证（元素数逐值相同 + 计算样式令牌跟随）⇒ J2 对拍（**并披露其不含 `stroke`/`fill`**）⇒ 残留扫描。
3. **档 2 开工前必须先核「暗色亮度补偿选择器 `svg path[fill^="#"]`」**：`.attr→.style` 改写会让内容属性不再是 `#` 开头 ⇒ 该补偿规则不再命中 ⇒ 逐处核视觉。
