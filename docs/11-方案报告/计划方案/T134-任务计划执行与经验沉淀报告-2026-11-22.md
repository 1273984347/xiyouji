## 三、施工

1. **探针加缓存（三重键）**：缓存文件路径按底色口径分文件（scripts/output/_svg_probe_cache_<bg_mode>.json）；文件头记录 version / probe_sha（探针脚本自身 sha·口径版本）/ params（阈值·底色口径·扫描面·状态集·工具开关）⇒ 任一不匹配 ⇒ **全量重采**。
2. **页级复用**：运行前算每页当前 sha ⇒ 命中「页 sha 相同 且 该行非 fatal/unstable」的条目直接复用 ⇒ 只对变化页启动浏览器采集（**全命中时浏览器完全不启动**）⇒ 复用结果与实测结果汇入同一 rows ⇒ **报告结构与口径一字未改**。
3. **缓存写入只收稳定行**：fatal / unstable 行**不入缓存** ⇒ 避免把「采集未达稳定态」的坏状态固化进缓存（fail-closed 的关键细节）。
4. **CI 跨 run 携带**：探针 step 前加 cache restore、还原报告 step 后加 cache save；key = 探针脚本 sha ⇒ 探针逻辑一变即 key 变 ⇒ 不会复用不匹配的旧缓存。
5. **缓存件不入库**：.gitignore 排除缓存件 ⇒ 本地缓存不会污染工作树、不会随批提交、**CI 只复用 CI 自己产出的缓存**（避免本地与 CI 的渲染环境差异被跨环境复用）。

## 六、经验沉淀

- **增量缓存的键必须含「口径版本」**：只按页内容 sha 做键 ⇒ 一旦改了探针规则（阈值 / 几何配对 / 底色口径），旧结果会被复用 ⇒ **假绿**（最危险的一类缓存失效）。⇒ 本批键取**三重闸**：页 sha + 探针脚本 sha + 口径元数据 ⇒ 任一不匹配即全量重采。
- **缓存只收「好状态」**：fatal / unstable 行不入缓存 ⇒ 否则一次抖动会把坏状态固化，后续每次都判红或漏检。
- **actions/cache 命中时不会更新** ⇒ 增量场景必须 **restore + 显式 save** 两步（只用 cache action ⇒ 增量只生效一次，第二次起永远是旧缓存）。
- **判据可以零改动地享受提速**：只要**产物结构不变**，复用结果与实测结果等价 ⇒ 第 80 槽一行未改即受益 ⇒ **优化优先做在采集侧，不动判据侧**。
- **缓存不入库 ⇒ 天然隔离跨环境差异**：本地与 CI 的渲染环境不同（file:// fetch 失败等 ⇒ env_blocked）⇒ 缓存若随仓入库会被跨环境复用 ⇒ 不入库 + CI 自产自用 ⇒ 零污染。

| 编号 | 适用场景与边界 | 量化效果 | 证据来源 | 可迁移性 |
|---|---|---|---|---|
| E-01 | 任何带缓存的探针或门禁；缓存键必须包含口径版本，仅按页 sha 会假绿 | 口径变更即全量重采，误复用风险降为 0 | 本批三重键实现与 332s→0s 实测 | 高（跨项目通用） |
| E-02 | 缓存只允许收稳定结果；fatal/unstable 行不得入缓存 | 避免一次抖动固化坏状态 | 本批缓存写入规则与复验 | 高 |
| E-03 | GitHub Actions 增量缓存必须 restore + 显式 save；只写 cache action 只生效一次 | 跨 run 命中率从一次提升为持续 | CI 配置与两轮实测 | 中高（仅 Actions） |
| E-04 | 优化优先做在采集侧；产物结构不变时判据侧可零改动受益 | 第 80 槽判据一行未改即提速 | 报告结构对比与门禁结果 | 高 |
| E-05 | 缓存件不入库，天然隔离本地与 CI 的渲染环境差异 | 跨环境复用污染为 0 | .gitignore 与 CI 自产自用 | 高 |
