## 0. 背景与结论速览（执行摘要）

**本批针对**：档 2（D3 .attr(fill|stroke, "#调色板色")）的最后 4 处 / 4 页。本批完成后**档 2 全站归零**。

**核心判定**：

1. **施工**：保留 .attr 直接写 var(--chart-N)（#3a6b8c→--chart-2 · #e9b885→--accent-soft · #c8463a→--chart-1）· 逐处命中数断言 = 1 · 改后重算 CSP（4 页更新）⇒ 856 页零漂移 · **全站调色板色残留 0**。
2. **静态勘查预判**（施工前先做）：4 页的补偿规则命中形态已逐页读出 —— 仅 en/philosophy 的 rect 命中 svg rect[fill^="#"] ⇒ 预期 filter 补偿失配；另 3 处不命中按字面值匹配的补偿规则 ⇒ 预期纯令牌跟随。**实测与预判逐项吻合**。
3. **稳定值对拍**：4 处差异且全部为预期 —— stroke rgb(200,70,58)→rgb(224,96,79)（--chart-1 暗色）· stroke rgb(58,107,140)→rgb(127,168,201)（--chart-2 暗色）· fill rgb(233,184,133)→rgb(232,169,159)（--accent-soft 暗色）· filter brightness(1.12) saturate(1.05)→none（补偿失配）。
4. **第 4 处另测**：en/social-media 的图标 path 为**零尺寸元素**（0x0）⇒ 不在 J2 采集面（探针跳过零尺寸）⇒ 差异清单不含它 ⇒ 另用 Playwright 实测：attr_fill=var(--chart-1)，computed fill 浅色 rgb(200,70,58) / 暗色 rgb(224,96,79) ⇒ **令牌跟随成立**。
5. **采集波动的定性**：en/philosophy 的暗色热力图数值标签异步渲染 ⇒ 同态两拍元素数可差 5~6（实测施工前 {5072, 5078, 5078}、施工后 {5078, 5073}）⇒ 取**稳定值**（5078）对拍得元素数零差异 ⇒ 差异非本批引入（E-89）。

**本批不做**：档 3（echarts 配置色 348 处 + 裸字面量 1443 处）· tokens.css 暗色 SVG 映射表消解 · 暗色补偿失配的 ΔL\* 阈值机器判据（待用户裁决阈值）。

**本章结论**：档 2 已归零；下一批应先做档 3 的落层分类盘点（echarts 自解析颜色串，不吃 CSS 变量）。

## 4. 复盘

### 4.1 做对了什么

1. **先勘查后施工**：施工前逐页读补偿规则与令牌定义 ⇒ 差异预判 4/4 与实测吻合 ⇒ 验收时「差异与预判一致」成为可判据的通过条件。
2. **多拍取稳定值**：识别出该页元素数会波动 ⇒ 不靠单拍下结论 ⇒ 既没把波动当回归，也没漏掉真实差异。
3. **缺证据就补测**：零尺寸元素不在采集面 ⇒ 单独实测 computed 值 ⇒ 不让「不在清单」等于「没发生」。

### 4.2 该改什么

1. **J2 采集器应加「渲染完成」自检**：采集后立即再采一次，元素数不一致则重采（带重试上限）⇒ 让快照自带稳定性标记，减少人工多拍。
2. **diff 入口应支持按元素身份配对**：本批首次对比出现 522 条索引错位假差异（元素数不同 ⇒ 后续元素整体错位）⇒ 判读时必须先看元素数/身份差集，再看属性差异；工具层可加「按身份配对」模式。
3. **补偿失配的可接受幅度仍无机器判据**：建议以暗色 ΔL\* 差值上限作阈值（待用户裁决）。

### 4.3 交接口径（下一批 = 档 3 落层分类盘点）

- **范围**：档 3 = echarts 配置色 348 处 + 裸字面量 1443 处（归档盘点脚本口径）⇒ **建议先做只读落层分类盘点批**（echarts 自解析颜色串 ⇒ 须「读令牌喂图表」，与 SVG 表现属性层不同源；裸字面量还需区分「数据值」与「颜色值」）。

- **待用户裁决**：暗色补偿失配是否设 ΔL\* 阈值判据。

### A.2 判据口径

- **盘点口径**：12 色调色板 · 只扫 script 块 · 正则不要求闭合括号 · 单双引号皆可 · 大小写不敏感。
- **取证口径**：两拍必须同采样面（同 --pages 子集 · 同 --floor · 同隔离模式）；且必须**多拍取稳定值**（同态连采可能不一致，见 E-89）。

- **采集面边界**：J2 采集器跳过 display:none / visibility:hidden / 零尺寸元素 ⇒ 落在该类的改动需另测 bbox 与 computed 值。
