## 0. 背景与结论速览（执行摘要）

**本批针对**：档 3（1412 处 / 145 页 ⇒ 15 批）铺开前的硬前置——两个图表令牌在暗色块无定义。上一批（W1103）建立 ΔL* 判据时实测出「暗色 2 处无覆盖」，本批把它变成实际可用的暗色值，并用双态视觉取证证明补齐不产生视觉回归。

**核心判定**：

1. **缺口是实测而非估计**：站内浅色令牌 22 个 · 暗色覆盖 20 个 · 暗色无覆盖 6 个；其中图表色 2 个须补（--chart-3 = #B38F58、--chart-5 = #D8CFBC），另 4 个（--dark / --dark-text / --line / --rebel）为设计有意沿用，不补。
2. **取值有判据而非口味**：暗色令牌值 = 该色在现有补偿机制下的等效呈现值。站内弱补偿为前缀型 brightness(1.12) ⇒ #B38F58 → #C8A063（ΔL\* 6.66 / ΔE76 7.32）、#D8CFBC → #F2E8D3（ΔL\* 8.90 / ΔE76 8.94）⇒ 令牌化后暗色态与原补偿呈现逐值一致。
3. **补齐不是零风险改动**：var(--chart-3) 与 var(--chart-5) 已在 42 页 / 114 处在用 ⇒ 补暗色值会改变这些页面的暗色态呈现 ⇒ 必须双态取证，不能按「只是补个值」处理。
4. **零差异已用可复现方法证明**：J2 探针对最小充分集（6 页 × 亮/暗 = 11170 元素）逐属性对拍 ⇒ 零差异；且以「注释法改前 / 恢复改后」两拍复算仍为零差异 ⇒ 结论可复现。

**本章结论**：档 3 的前置从「缺两个暗色值」推进到「暗色值已就位且视觉零影响已证」，档 3 的字面值→令牌替换可随时开工。

## 4. 复盘

### 4.1 做对了什么

1. **取值有判据**：没有另造色，而是取补偿机制等效值 ⇒ 后续档 3 替换时天然零差异。
2. **先查使用面再改值**：识别出 42 页 / 114 处引用面，把「补值」升级为「需取证」的判断。
3. **取证可复现**：注释法两拍 + 最小充分集，让「零差异」结论不依赖任何历史快照。

### 4.2 该改什么
