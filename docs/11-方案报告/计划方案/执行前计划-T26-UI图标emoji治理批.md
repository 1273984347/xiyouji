## 执行摘要

本批把「禁止 emoji 表情充当图标」从一句口头要求变成**可复跑的机检判据 + 零残留的站点现状**。

**问题量化**：全仓 emoji 共 34,530 处 / 2,189 文件，其中绝大部分在 Markdown 正文（题材内容）。真正承担「图标职能」的是 **1,910 处 UI 图标位**，分布 **629 个页面**，只用 **21 种字符**（👍👎☆🔍📚📜📖📻📌👶🎒🎓🌱🜂✒📊🌐⏸☰✕✓✗★ 等）。

**做法**：自绘 **27 枚东方线描 SVG 图标**（24×24 / stroke 1.5 / currentColor，与既有 `.icon-moon` / `.icon-sun` 同族），落 `site/static/icons/ui/` 作单一事实源；建 **2 个可复跑脚本**（基准扫描器 + 替换器，每条规则带独立预期命中数，不符即报错退出）；用 **内联 SVG** 承载 HTML 结构位、**mask-image** 承载 CSS `content` 位。

**结果**：UI 图标位 **1,910 → 0**（基准扫描器复扫）；另补治 47 处后续发现的图标位（JS 按钮文本、静态播放按钮、检索标签前缀、段首提示标记、结论标签前缀），累计替换 **1,957 处**；正文装饰 emoji **381 处**（含 ✅78 / ✓200）与箭头符号 **5,000+ 处**按用户裁决**原样保留**。

## 0. 任务背景（读者无需回看会话即可理解）

站点《详解西游记》（857 页纯静态站，`file://` 可直开）历史上大量用 emoji 充当界面图标：阅读页反馈按钮是「👍 有帮助 / 👎 待改进」、收藏按钮是「☆ 收藏本页」、搜索框是一个 🔍、年龄段页签是 👶🎒📚🎓。这类用法的代价是**跨平台字形不一致**（Windows / macOS / Linux / 移动端渲染各异）、**暗色模式不可控**（emoji 自带彩色，无法跟随主题）、**无语义**（屏幕阅读器读出「thumbs up」而非「赞同」）。

用户 2026-10-25 下达指令并经两问裁决后，本批立项。

| D-06 | 收藏按钮的 JS 态切换如何改 | ① JS 内硬编码 SVG 路径；② 从 DOM 克隆现有图标 | **② DOM 克隆** | 避免在 JS 里维护第二份路径副本 ⇒ 图标源唯一 | 单一事实源原则 | 依赖 HTML 里存在静态 SVG（已保证） | 路径零重复 | **状态切换类图标用 DOM 克隆而非硬编码路径，可保住单一事实源** |
