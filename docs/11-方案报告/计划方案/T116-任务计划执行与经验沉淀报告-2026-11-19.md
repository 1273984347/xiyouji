## 执行摘要

W1283 承接 W1282 的存量面：第 80 门禁 graphic 口径实测全站 **1236 条 / 89 页**低对比标签（用户口径「646 条」为 site/data 单站去重口径）。本批把这类缺陷从「逐页改代码」转为「**通用工具 + 判据同源**」：新增公共资源 `site/static/js/label-contrast.js`（浏览器引入即自动执行，按**渲染后实际底色**自适应前景色与描边），**89 页各加一行外链 script**（页面零逻辑改动，CSP `script-src 'self'` 已放行外链、不需重算哈希）；同时把门禁判据与该工具的四处口径**对齐同源**（矩形档中心点判据 · graphic 无覆盖图形时回退最近 CSS 背景 · 图形底色乘滤镜提亮系数 · 光晕分离度按 alpha 合成后计算）。**结果：存量从 1236 条降到 182 条 / 27 页（降约 85%）。** 另由并行 worker 完成英文 treemap 长标签根治（字号自适应 → 折行 → 才截断 + 原生 title 兜底，**截断数 3 → 0**）。

## 一、执行前计划

**目标**：① 清掉 W1282 测出的全站标签低对比存量；② 根治英文 treemap 长标签截断导致的信息不完整。

**关键判断（先算再定）**：全站 14 页 treemap 之外，缺陷分散在 89 页且**各页 JS 各自生成 fill**（无公共层单一入口可覆盖）⇒ 逐页改代码不可行 ⇒ 转为**通用工具**：把「按底色选前景色」做成页面侧公共资源，各页只加一行引入。**页面零逻辑改动 ⇒ 工具可迭代而不必重改页面**（这是本方案风险可控的关键）。

**取证优先**：先用第 80 门禁 graphic 口径（已具备归一化几何配对）实测全量存量，再抽样目视复核每一类命中，确认「探针命中数 ≠ 缺陷数」（本批实测：中心点配对口径 1290 处含大量假阳性；归一化后 1236 处才是真面）。

## 三、施工

### 3.1 通用工具 `site/static/js/label-contrast.js`（新增公共资源）

浏览器引入即自动执行（DOMContentLoaded + DOM 变更节流 + 主题变更监听），按**渲染后实际底色**自适应：

- **底色链**：几何覆盖图形（getBBox + getCTM 归一化到同一 viewBox 用户空间）→ 最近 CSS 背景 → body；
- **图形分档**：rect 档「文字中心点落在图形 bbox 内 且 交集比 ≥ 0.6」· circle/ellipse 档「中心点落在真实椭圆内」· path/polygon 档「bbox 完全包含才计」（保守）；
- **暗色态**：公共层会给图形加 `brightness()` 提亮 ⇒ 底色按**视觉实际值**（乘系数）计算，否则暗态方向性错误；
- **动作**：前景色取白/深墨中对比更高者；白与深墨**都**达不到判红线时改为切换**不透明描边**（光晕分离度是唯一解）；描边随前景切换，避免「深字压深描边」。

### 3.2 判据与工具同源化（四处对齐·E-285 纪律）

| 处 | 原判据 | 同源后 |
|---|---|---|
| 矩形档判据 | 只看交集比例 | **加「中心点须落在图形 bbox 内」**（否则边缘文字被误算覆盖） |
| graphic 无覆盖时的回退 | body 底色 | **最近 CSS 背景**（工具按卡片底判达标、门禁按 body 判红 ⇒ 工具改完仍被判红） |
| 图形底色 | computed fill 原值 | **× filter 提亮系数**（暗态公共层提亮图形而计算色仍是原色） |
| 光晕分离度 | 纯描边色 | **alpha 合成到底色后**（白描边 0.88 覆金黄底：纯白口径 3.18 / 合成口径 2.79 ⇒ 差 0.4 就判红不同） |

### 3.3 英文 treemap 长标签根治（并行 worker 交付）

三层策略：**字号自适应**（12→10px 逐 0.5px 实测 `getComputedTextLength()`）→ **放不下则按空格折行**（≤3 行，且校验单元格高度）→ **实在放不下才截断**；任何情况挂 SVG 原生 `<title>` 提供完整名称（因 `t.text()` 以 textContent 赋值会清空子元素，`<title>` 须在其后追加）。**截断数 3 → 0**。

### 3.4 工具自身三处坑（实证·均已修）

1. **去抖在 DOM 持续变化时会被无限推迟**（页面 count-up 动画使 clearTimeout 反复重置 ⇒ apply 永不执行 ⇒ 修复静默失效）⇒ 改为**节流**（每 200ms 至少跑一次）+ 补跑轮次。
2. **只监听 `data-theme` 不监听 `prefers-color-scheme`** ⇒ 门禁以 colorScheme 模拟明暗四态时，CSS 已变而工具算出的内联色未变 ⇒ 改完仍被判红。
3. **UMD 漏导出 `auto`** ⇒ 引入即抛 `api.auto is not a function`。

**任务目标**：把「图表内文字看不清」的全站存量转成可拦截、可回归的工程能力，并根治英文长标签截断。

### C. 术语与口径说明

- **graphic 口径**：第 80 门禁第三种底色口径——底色取几何上真正覆盖该文字的 SVG 图形的**视觉实际**填充色（computed fill × filter 提亮系数）；无覆盖图形时回退**最近 CSS 背景**（与页面侧修复工具同源）。
- **判红线**：3.0（WCAG 图形对象最低可读线）；**择优线** 4.5（WCAG AA 正文线，10px 小字适用）。
- **光晕分离度**：描边色按 alpha **合成到底色**后与底色的对比度——≥ 3.0 即视为光晕已提供可读性分离。
- **存量**：门禁基线内的违例记「存量」不计 FAIL；基线外新增 = FAIL；基线缺失 = fail-closed。
