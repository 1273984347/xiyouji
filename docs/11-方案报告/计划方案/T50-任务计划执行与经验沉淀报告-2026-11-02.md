## 0. 背景与结论速览（执行摘要）

用户给出一份「高质感大厂 AI 客户端源码拆解」的规范要点（微对比分层 / 暗色字重 / 流式打字 / 排版防抖 / 动效性格 / 中文防误发 / 滚动跟随 / 单层边框 / 同心圆角 / 分屏防误操作 / 长文件名 / Select 与 Dropdown 分离 / 热区标准 / 多语言排版），要求先判断**哪些能落到本站**。

**结论一句话**：22 条规范中 **11 条可直接落地**（其中 6 条是真实缺口）、**7 条部分具备或需改造**、**4 条当前无落点或与本站美学冲突**。本站并非「没有设计系统」——相反，`tokens.css` 已有 **132 个令牌**、纸感四级海拔、2% 级微明度色阶，**已符合视频第 1 条的核心主张**；真正的缺口集中在**暗色字重、焦点态、输入防误发、滚动跟随、热区下限、组件语义分离**六处。

**三个反直觉发现（写在这里以免下一批做错）**：

1. **「不用生硬边框」这条在本项目要改的不是颜色而是「层数」**——本站卡片是 `border: 1px solid var(--line)` **加** `box-shadow: var(--elev-1)`（system.css:222-237）＝两层视觉边界；而视频主张「最多一层外边框、框内按钮不画边框仅底色变化」⇒ 改的是**结构**，不是把边框颜色调淡。这条影响面 857 页 + ~250 页内联副本，属**高影响面改造**，不可只动共享层。
2. **「聚焦不显示轮廓线」与本站现状正好相反**——全站焦点态是 `outline: 2px solid var(--accent)`（system.css:42-46），只有搜索框例外且是**单环**（system.css:705-709）而非视频要求的双环。改这一条须走「共享层 + 副本传播同批一次做完」，否则源-副本失同步。
3. **「弹簧动效」与本站已定美学冲突，不照搬**——`tokens.css:96` 明确写着「克制雅致，**不上弹跳**」⇒ 视频的过阻尼/欠阻尼弹簧会直接推翻这条已生效的裁决。可照搬的是**「动效分类」的方法论**（本站已有 `--dur-fast/base/slow` 三级 + `--ease-out-quart/expo/in-out-soft` 三系，缺的只是「按语义分档」的判据表）。

#### 核心二：暗色模式字重降档（对应 S-04）——**单点改动·最高性价比**

- **现状**：`tokens.css:171-201` 暗色令牌块无任何 `font-weight`；全站 9,944 处 500/600/700 字重在暗色原样生效。
- **改法**：在暗色块内加 `h1{font-weight:600}`（原 700）、`h2/h3{font-weight:500}`（原 600）、`h4{font-weight:400}`（原 500）一档；**数字/等宽位保持原字重**（`--font-mono` 子集只有 400/500 两档，降档会掉到合成字重）。
- **传播面**：共享层 1 处 + 同批传播 ~250 页副本。
- **判据**：明暗双态计算样式探针读 `font-weight` ⇒ 暗色 ≤ 浅色一档且 ≥400；渲染完整性（元素数/可见数）不变。

#### 核心三：流式打字 + 滚动跟随 + 中文防误发（对应 S-05 / S-12 / S-13）——**同一文件同批**

- **现状**：`site/data/ai-dialogue.html` 预置对白整块插入；Enter 直接发送（无 composition 检测）；滚动强制跟随。
- **改法**：① Enter 键加 `compositionstart/end` 门（选字中放行、选字后 500ms 拦截）；② 滚动改阈值跟随（距底 <1 行跟随 / 上翻 >3 行停 + 「跳至最新」按钮）；③ 打字机动画**暂缓**（无流式源）。
- **传播面**：**同 1 文件**（三者同批，避免三改一文件）；英文版 `site/en/ai-dialogue.html` 同批同步。
- **判据**：改内联脚本后 **CSP 哈希重算 + `--check` 零漂移**（W1084 铁律）；中文输入法模拟（composition 事件序列）下 Enter 不误发；J2 双态元素数不变。

#### 核心四：排版防抖（对应 S-07 / S-08 / S-09）——**已具备大半**

- 等宽数字：**已具备**（2,662 处），不需改。
- 孤字：**en/ 已具备**（54 处），中文站不适用⇒ **零改动**。
- Grid 无 JS 展开：**缺口但价值有限**——先在 `concept-device` / `graph-explorer` 两页试点（现仅 4 页用 grid），确认浏览器支持面后再决定是否推广；**`interpolate-size` 需 Chrome 129+**，否则退 `max-height` 近似。

#### 核心五：动效性格区分（对应 S-10 / S-11）——**方法采纳·参数不抄**

- **不引入弹簧**（与 `tokens.css:96`「不上弹跳」冲突）。
- 采纳「按语义分档」：产出**动效语义分档判据表**（定位类=零回弹 / 反馈类=短促 / 展开类=对称），把现有 `--dur-fast/base/slow` + 三系缓动挂到语义上。
- 复制对勾 2.5s 淡出：低成本高感知，建议同批实施。

## 4. 复盘

### 4.1 做对了什么

1. **先实读再判定**：没有凭视频观感下结论，而是逐条落到 `tokens.css:171-201`、`system.css:42-46/705-709/222-237/532-549/666-678`、`ai-dialogue.html:2119/2180-2193` 等具体行号 ⇒ 8 条「缺口」判定全部可被下一批直接复验。
2. **按语种/按形态分列判定**：`text-wrap` 54 处命中若合并计数会被判「中文站缺失」，实为 en/ 站已有、中文站因断行规则不同而不适用 ⇒ 分列后避免了一次假缺口。
3. **把「方法」与「参数」分开**：弹簧动效不采纳，但「动效按语义分档」的方法采纳 ⇒ 外部规范的可复用部分未被一刀切丢弃。
4. **零改动盘点**：取证批不改页面 ⇒ 结论可由 `git diff` 直接核验，符合仓内「取证批与施工批分离」的既有惯例。

### 4.2 偏差分析

- **D-B01（预算约束降级抽样）**：英文站按钮宽度只做抽样与类定义实读 ⇒ ASM-06 保持「待验证」状态，未作全站断言。
- **D-B02（登记面被在途批次截断）**：README/台账登记因 touches 交集被拆出本批 ⇒ 需在 W1094/W1088 收官后补齐，避免代提交他方在途件。

### 4.3 经验沉淀（跨项目可复用）

**「外部 UI 规范套用」必须先做「形态×层级」二维对拍，否则会产出无法施工或推翻既有裁决的建议**（2026-11-02 xiyouji W1095 实证·跨项目通用）

- **症状**：把「移动端 AI 客户端」的规范直接套到「多页静态站」，会同时出两类错：① 场景缺失（分屏/Taptic/流式打字在静态站无落点）；② 风格冲突（扁平单层边框 vs 纸感双层海拔；弹簧回弹 vs 已定「不上弹跳」）。
- **正解（二维对拍）**：
  - 形态轴：移动 App / 桌面 Web / 静态站 / 文档站 ⇒ 先判「该场景在本项目是否存在」；
  - 层级轴：表现属性（可直接换）/ 样式层 / 结构层 ⇒ 再判「改这一层会级联到哪」；
  - 两轴都过，才算「可应用」。
- **关键判据**：**「方法」与「参数」分离**——外部规范的*方法论*（动效按语义分档、边框层级收敛）通常可借，*具体参数*（弹簧系数、单层边框数）常与本站既有裁决冲突 ⇒ 冲突时保留方法、改参数，不整条丢弃也不整条照抄。
- **推广**：任何「参考外部设计规范/竞品拆解」的批，盘点阶段就应产出「形态×层级」对拍表，而不是逐条「采纳/不采纳」二元结论。

**「焦点态」类改造必须区分「outline 实现」与「box-shadow 实现」两类，且传播面通常远大于共享层**（2026-11-02 xiyouji W1095 实证）

- 现象：同一句「聚焦不显示轮廓线」，在共享层里可能**只对一个组件成立**（本站仅 `.search-box input:focus` 用 `outline:none`+单环，而全局 `:focus-visible` 仍是 `outline:2px`）⇒ 只看一个组件会误判全站已达标。
- 正解：焦点态盘点须**逐条列出所有 focus 规则并按实现分类**，再统计覆盖面。
- 推广：焦点/悬停态是「局部看似已改、全局未改」的高发区 ⇒ 断言必须覆盖选择器全集，不能抽样。
