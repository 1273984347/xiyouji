## 0. 背景与结论速览（执行摘要）

W1078 盘点确认：全站硬编码颜色里 **5,041 处落在 JS**、**57,090 处在共享内联副本**（来源是 `tokens.css` 暗色块 111 行 SVG 映射表）；W1079 实测订正：共享层 spacing 令牌化是**空项**，因此**没有「零差异的一次性大批」**。剩下的主体就是这一批：**图表色工程批**——让图表自己读令牌，映射表随之作废。

本批先做**形态取证**（不改任何页面），因为「颜色在 JS 里怎么用」直接决定能否用 `var()`、要不要 helper、改写量多大。结论：

| 形态 | 处数 | 能否直接用 `var(--chart-N)` | 成本 |
|:--|--:|:--|:--|
| D3 `.style('fill'/'stroke', '#hex')` | **28** | ✅ **可以**（style 属性解析 CSS 变量） | 极低·改字符串即可·**暗色自动跟随令牌** |
| D3 `.attr('fill'/'stroke', '#hex')` | 97 | ❌ 表现属性不解析 `var()` | 中·需改写为 `.style()`（**优先级会变**：`style` 属性 > 表现属性 ⇒ 需逐处核 CSS 类色是否被顶掉） |
| echarts `color:"#hex"`（数据字段） | 348 | ❌ 传给图表库（canvas/SVG） | 中高·须改成回调式 color 并读令牌 |
| 通用 CSS 属性值（多为上类数据字段） | 354 | 同上 | 同上 |
| 裸字面量（JS 常量表，如 dashboard 的 `LORS`） | 1,537 | ❌ 常量表 | 中·改成一次性求值的令牌常量表 |

⇒ **三档推进（W1080 实测后修正）**：档 1 = 28 处 `.style()` 形态（**原案「直喂 `var()`」已证伪并回退** ⇒ 改为「读令牌喂图表」·详见 §2.2 B-07）；档 2 = 97 处 `.attr()` → `.style()` 改写（需优先级抽样核）；档 3 = echarts + 常量表（读令牌喂图表 ⇒ 111 行映射表可整表删除 ⇒ 一次覆盖 330+ 页）。

### A.2 形态判据（互斥优先级）

1. D3 `.attr('fill'|'stroke', '#hex')` → 表现属性层（`var()` **不生效**）
2. D3 `.style('fill'|'stroke', '#hex')` → style 属性层（`var()` **生效**）
3. `style="fill:#hex"` 内联字符串 → style 属性层
4. Canvas `ctx.fillStyle/strokeStyle = '#hex'` → 绘图上下文层（`var()` 不生效）
5. 图表库配置字段（echarts `color` / `itemStyle` / `backgroundColor` / `palette`）→ 图表库层（不吃 CSS 变量）
6. 通用 CSS 属性值（`color:` / `background:` 等）→ 视落点
7. 裸字面量（常量表 / 数据字段）→ 视落点（多数属 5 或 6）
