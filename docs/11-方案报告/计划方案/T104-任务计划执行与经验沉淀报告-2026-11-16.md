## 执行摘要

把已入库的古画绢本 Hero 横幅族（\`assets/promo/silk-hero-set/\`，12 张 16:9）**接入站点**：本批为**试点 3 个专题页**——\`取经地理学专题\`（云海佛刹）、\`妖怪生态学专题\`（黑风山狼牙棒）、\`芭蕉扇-终极灭火器的关系\`（三件法宝），每页在 \`<h1>\` 之后插入一条全宽顶栏横幅。

三条关键工程决策：① **样式页内私有**，不进 \`site/system.css\`（避免触发全站 861 页内联 CSS 重写，试点把 diff 面压到 3 页）；② **暗色模式隐藏**（暖米黄绢底在暗色下会成亮斑，沿用题图族 \`.chapter-plate\` 的既有策略）；③ 附带**分支整理**（本地 5 个 + 远端 6 个已合并 \`sync/*\` 全删）。

未做：og 分享图替换、深色变体、全量 210 页接线——均待试点效果确认后另开批。

## 五、决策记录与理由

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 样式落点 | 页内私有 | 全站 861 页内联 CSS 重写成本与 diff 风险，试点阶段不划算 |
| 暗色策略 | display none | 与题图族 \`.chapter-plate\` 一致；深色变体需再生成 12 张 |
| 图片尺寸 | 原生 1920×1078 + width/height | 避免二次缩放模糊，同时 width/height 防 CLS |
| 试点规模 | 3 页 | 比例 / 留白 / 暗色任一判断错，全量 210 页返工面过大 |
| 首页 Hero | 不动 | 现用线描族 21:9 + 左 46% 留白 + 深色变体 + 轮播逻辑齐备 |
