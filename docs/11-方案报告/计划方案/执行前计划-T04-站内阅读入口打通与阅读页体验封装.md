## 0. 任务背景（读者无需回看会话即可理解）

### 0.3 本批针对的真问题（评审稿遗漏或说轻了的）

**P0-01（最严重·评审稿完全遗漏）·620 页 reader 阅读内容在站内无任何入口。**

| 判据 | 实测结果 |
|---|---|
| 站点首页主导航 5 项 | `site/index.html:353-360`：导读 `guide.html` / 逐回 `data/chapter-structure-graph.html`（**可视化**）/ 人物 `data/character-appearance.html`（可视化）/ 专题 `data/philosophy.html`（可视化）/ 数据看板 `dashboard.html` / EN —— **无一项指向 `reader/index.html`** |
| 首页「全卷索引」9 条（编号 00–08） | `site/index.html:496-527`：全部指向 `guide.html` 或 `data/*.html`；其中唯一的 `reader/` 引用是 `reader/essays/index.html`（随笔板块目录，非 100 回总目录） |
| `reader/index.html` 的站内入链 | 对 `site/` 全树（排除 `site/reader/` 自身）搜 `reader/index.html` → **0 命中**。该页（108,699 字节，链全部 100 回 + 六板块目录）**已进 sitemap**（`site/sitemap.xml` 含 `reader/index.html`），但**站内无一条路径可达** |
| reader 页顶栏 | `site/reader/ch001.html:1246-1250`：brand → `index.html`（站内阅读总目录）/ 站点首页 → `../index.html` / GitHub 源文件 —— 路径**单向**，reader 页能回首页，首页进不去 reader |
| 章节页的站内入链 | 对 `site/` 全树搜 `reader/ch0\d\d` → 仅 2 个搜索页命中（`site/data/search.html` + `site/en/search.html` 的内嵌索引）；除搜索框与搜索引擎外**无第二个入口** |

**结论：用户搜得到、爬虫抓得到，但"点"不到。** 620 页（占全站 857 页的 72.5%）的正文解读内容处于站内孤岛状态。

**P0-02 · 阅读页无「速览 / 深读」折叠。** `site/reader/ch027.html` 的「速览」「深读」字面命中数 **0**；现有结构为 8 个平铺 h2：原文回目 / 剧情梗概 / 重点要点 / 伏笔与悬念 / 名句赏析 / 个人札记 / 深度解读 / 原文全文 —— 长页在移动端阅读成本高。

**P0-03 · 无跨访客产品数据与北极星指标。** `docs/00-导读/访问统计方案.md:4,18` 明示：W806 起 GoatCounter 退役、**全站零外域统计请求、本站不再具备真实读者量统计能力**（防回退守卫 `scripts/check_no_goatcounter.py` 接 CI）；全仓搜「北极星」仅命中 `archive/` 与方法论文档，无对本产品的正式定义。

**P0-04 · 阅读页无进度 / 书签 / 字号调节。** `site/reader/ch027.html` 中 `localStorage` 命中 **0**（rum/visit-log 用 localStorage，阅读器不用）。

**P0-05 · 无每页反馈入口。** `site/reader/ch027.html` 中「有帮助」命中 **0**；Issue 模板现有 bug/feature/question 通用三分类，无「内容错误 / 体验问题 / 数据问题」。
