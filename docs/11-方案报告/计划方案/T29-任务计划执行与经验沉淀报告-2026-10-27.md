## 执行摘要

**本批做了什么**：新增 **12 张** 3:4 竖版线描墨稿内页题图（人物 6：金角大王 / 银角大王 / 黄眉大王 / 黑熊精 / 托塔李靖 / 玉兔精；主题 6：女儿国 / 车迟国斗法 / 狮驼岭 / 通天河 / 盘丝洞 / 无底洞），沿用站内 `chapter-plate` 范式接入 **12 个** reader 页面 ⇒ 站内线描题图累计 **40 → 52 张**、reader 有题图页 **51 → 63 页**。

**怎么保证成套一致**：母版（249 字符）直接从 W953 的 JSON **逐字复用**，脚本断言「批内 12 条母版逐字一致」+「与 W953 母版逐字相同」⇒ 跨三批（W952 / W953 / W974）风格同族由**构造**保证，而非事后拼凑。

**验收结果**：母版判据 J1–J10 **52/52 PASS** · 站点版裁切验算 **52/52 PASS** · 人眼题材与形制放大复核 **12/12** · 合成负样本使判据 **J2 / J3 / J6 / J8 四条同时抓出**（J10 另测 9.333 > 阈值 5.0）· 浏览器实跑 2 页确认「标题紧贴主体、无冗余留白、纸底无色边、console 0 错误」· 既有 40 张母版与站点版**逐 blob 与 HEAD 比对零改动**。

**过程中最值得记的一件事**：本批发现并修复了一个**会静默影响观感的工程缺陷**——站点版裁切线取「整图墨迹 bbox 顶」，而 bbox 顶会被**孤立噪点**污染（实测一张图顶部第 18 行仅 3 个像素就把 bbox 顶从 437 拉到 18），导致该张站点版几乎没裁、标题与主体之间仍多留约 160 px 空白 ⇒ 改用「主体顶 = 面积 ≥ 200 px² 的墨迹连通簇的最小顶」，全目录 52 张复算仅 4 张口径不同（其中 3 张为既有，登记为存量欠账、本批不重写）。详见 §8 的 E-01 / E-02。

**本批返工 3 个位**（均已留证）：黑熊精首轮 `err_code 451` 补出 ·「虎力大仙」在 people 库无落位页 ⇒ 换玉兔精 · 黄眉大王的金铙被画成圆环 ⇒ 改措辞重出两次后达标。
