## 0. 背景与结论速览

**本批针对**：图表色工程「档 3 铺开」的**施工前置**——档 3 要把全站 1412 处图表色改为读令牌，而令牌化改动的三类失败模式此前**全链无机器防线**：

1. 改内联脚本忘重算 CSP ⇒ 整脚本被浏览器拒执行（W1108 批实测：元素数 750→112）；
2. 改完不回填 stats / 门禁口径漂移 ⇒ 规模数字静默失真（W1096 实证：排除集写死小写⇒三板块篇数各虚增 1 而门禁不红）；
3. **令牌化写出自引用变量** ⇒ 变量解析为空串、页面照常渲染只是颜色不对 ⇒ 全链零红灯（W1110 批实测抓出，见下）。

**核心产出**：

1. **门禁四槽接线**（verify_delivery 从 53 槽 → **57 槽**）：第 54 槽「坑表编号唯一」（兑现 W1107 登记的「下一批接线」）、第 55 槽「PowerShell 解析」、第 56 槽「CSP 增量漂移」、第 57 槽「CSS 变量自引用」；
2. **P-3 L2 接线**：W1104 批挂账的「口径一致性待异源复算（C10）落地后接入」清偿完毕——C10 的复算式抽到 `scripts/doc_areas.py` 作**共享单一事实源**，C10 与 `agent_start.py` **同源复用**；
3. **根修 W1108 引入的 CSS 变量自引用缺陷**（本批最大产出，由施工⑤ 的双口径核档**反向抓出**）：`--chart-1: var(--chart-1)` ⇒ 浏览器判为无效值 ⇒ `getComputedStyle` 返回**空串** ⇒ 图表主题色回落为继承色；
4. **顺带收口 W1088 僵尸行**（内容早已落地但登记面仍标「在途」⇒ preflight 恒红拒绝所有碰 HANDOVER.md 的新批次）。

### 1.8 决策记录与理由（D 表）

## 4. 复盘

**做对的**：

1. **先取证再下结论**：施工⑤ 没有直接采信「24 处差异全为同向转换」的既有结论，而是逐项复算 ΔL*+ΔE76 ⇒ 数据不符 ⇒ 追根 ⇒ 抓出真实缺陷；

3. **受控对照归因**：用「同页换入改前版本再测同两个变量」把差异归因到具体提交，而非「环境差异」；

**可改进**：

1. **既有结论也需复核**：本批发现「上一批的取证结论」可能与数据不符 ⇒ 后续批次对关键结论应保留复算命令以便复核；
2. **门禁缺位是系统性问题**：四类静默缺陷（CSP / 口径 / 自引用 / 编号唯一）的共同根因都是「**没有机器判据**」⇒ 新增功能时应同步问「这类错误有谁拦」；
