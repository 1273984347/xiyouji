## 二、执行记录

### 2.1 形态选型（W1254 撤销后的重做路径）

W1254 把**完整 h1** 压进画面，三态技术指标全过但用户判定观感不佳并整批撤销。根因是形态而非参数：完整标题（含长副题）压图后首屏失去独立大标题、文字块与画面主体争重心。

本批改按用户选定的**形态①**落地：图上只放**短题名**（题识级字号 + 朱砂落款），正文标题原样保留。三条形态的实测对比见 W1254 会话记录（形态① / ② / ③ 各有实拍截图）。

### 2.2 短题名提取规则

    候选 = h1 文本
    对每个分隔符（：/——/—/–/·/｜/|）取最早出现位置 → 切首段
    若首段长度 < 4 字 → 回退为文件名（去 .html）
    例：取经地理学专题：地方感… → 取经地理学专题（7 字）
        佛学—AI—西游 三维语义映射表 → 首段「佛学」< 4 → 回退文件名「佛学AI西游三维语义映射表」

规则**按最早分隔符位置**切分而非按分隔符列表顺序——后者会把「反抗与束缚的永恒循环——《黑神话：悟空》三题」误切成「反抗与束缚的永恒循环——《黑神话》（16 字）。

### 2.4 落地样式（页内私有，209 页一致）

    .silk-hero { position: relative; }
    .silk-inscription { position: absolute; left: 5%; bottom: 7%; z-index: 2; display: flex; align-items: center;
      gap: 8px; max-width: 29%; font-family: var(--font-serif); font-size: clamp(14px, 1.3vw, 17px);
      font-weight: 600; letter-spacing: .09em; line-height: 1.4; color: var(--ink);
      text-shadow: 0 1px 2px rgba(250, 247, 240, .6); }
    .silk-inscription::before { content: ''; width: 9px; height: 9px; background: var(--accent); border-radius: 1px; flex: none; }
    .silk-inscription::after { content: attr(data-title); }
    html[data-theme="dark"] .silk-inscription { color: var(--dark-text); text-shadow: 0 1px 2px rgba(0, 0, 0, .45); }
    @media (max-width: 768px) { .silk-inscription { display: none; } }

题识层置 aria-hidden="true"——它是 h1 内容的装饰性重复，屏幕阅读器不应二次朗读；h1 文本与朗读均零改动。

**题识文字走 data-title 属性 + CSS content 渲染**（不是文本节点）：span 为空元素，文字由 `.silk-inscription::after { content: attr(data-title); }` 生成。原因是文本节点会进入页面纯文本，被内容一致性门禁的实体对提取器误配（见 §四 D-4）；移入属性后 DOM 纯文本不含题识，**矛盾数由 89 降至 87（全部为存量冻结）· 新增 0**。

### 2.5 推广结果

209 页全部改写成功，失败 0 页；唯一跳过页为 themes/index.html（目录页无横幅，预期跳过）。每页 diff 面为 1 行题识标签 + 4 行页内私有样式，未触碰 site/system.css。
