## 0. 任务背景（读者无需回看会话即可理解）

本项目《详解西游记》是一个 857 页的静态站（`site/`），正文 615 篇，含「回目 / 人物 / 主题 / 文化 / 随笔 / 诗咏」六库。内页题图是给 reader 页面配的竖版插画，用途是让长文页面在首屏有一个视觉锚点，同时承载该页题目的意象。

题图资产层的现行规格（实测自 `assets/promo/plate-set/`）：

| 项 | 规格 |
|---|---|
| 母版画幅 | 1200×1600（精确 3:4） |
| 站点版画幅 | 宽 1200，高随主体顶浮动（1056–1189）·**只裁上部留白，保留下部「地面留白」** |
| 风格 | 中国传统工笔白描线描：宣纸底 #FAF7F0 + 纯墨线（无实心填充/渐变/阴影）+ 赭金 #8A6D3B 局部 + 单点朱砂 #C8463A 点睛 |
| 构图 | 主体上方留约一成呼吸空间（**不设专用标题区**，页面标题在图外）+ 完整全身立像居画面中下部 |
| 禁项 | 无文字 / 书法 / 印章 / 水印 / 题跋 / 边框 / 展柜 |

**存量与缺口（实读磁盘）**：

- 已有母版 **40 张**（W945 16 + W952 12 + W953 12 三批），`site/static/images/` 同名 webp **40 个**。
- reader 库共 **622 页**，其中 **39 页**有题图 ⇒ **缺口 595 页**（themes 209 / people 215 / essays 44 / culture 34 / poetry 13）。
- `site/reader/people` 实测 **216 页**，`site/reader/themes` 实测 **210 页**。

**本批定位**：同族续批第三组，12 张（人物 6 + 主题 6），沿用 plate-set 母版风格段**逐字复用**（不由人工重写风格描述），保证跨批风格一致性由**构造**保证而非事后拼凑。

**用户已裁定的四问（2026-10-27 问卷答复）**：

| 问 | 裁定 |
|---|---|
| 素材用在哪里 + 画幅 | 内页题图 · 3:4 竖版 1200×1600（沿用 plate-set 母版） |
| 需要几张 | 12 张 |
| 有没有参考风格 | 沿用站内线描墨稿风（plate-set 母版逐字复用） |
| 题材范围 | 人物 + 主题混合（各占一半） |
