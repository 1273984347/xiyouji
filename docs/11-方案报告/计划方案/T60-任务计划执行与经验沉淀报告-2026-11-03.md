## 0. 背景与结论速览（执行摘要）

**本批针对**：档 3 铺开的第一支原型批——把「字面颜色」改成「读设计令牌」，并用双态视觉取证证明机理成立、不引入回归。上一批（W1106）已补齐暗色令牌缺口；本批回答的是「换色机制能不能用、会不会坏」。

**核心判定**：

1. **站内图表不是 echarts**：全站 echarts 字样 0 处；实为 D3 + 自绘 SVG（137 页含 d3 · 132 页含 color:）⇒ 台账里的「L2 = echarts 配置色」是内部层名，不是库名。
2. **换色通路成立**：chart-design 两页用 CHAIN_COLORS / MONSTER_COLORS / ACTIVITY_COLORS / STAGE_COLORS 四个常量，经 .style("--chain-color", color) **CSS 变量中转** ⇒ 常量内调色板 hex 可直写 var(--chart-N)；且该页已有 10 处 attr(fill/stroke, "var(--…)") 先例（站内有 369 处同类写法），无任何色值运算 ⇒ 换 var() 不破坏运算。
3. **视觉影响是预期改善而非回归**：令牌化后浅色态**零差异**；暗色态 24 处差异**全部为同一方向转换** rgb(200,70,58) → rgb(224,96,79)（#c8463a → --chart-1 暗色值，ΔL* 8.64，与既有族同量级）⇒ 原先暗色态写死浅色值、偏暗，改后由令牌暗色值接管、可读性提升；元素数 750 → 751 / 749 ⇒ **零损失**。
4. **抓到一个真实塌缩并当场修掉**：首轮对拍暗色态元素数 750 → 112 ⇒ 图表大面积未渲染。根因 = 改了内联 JS 却未重算 CSP 哈希 ⇒ 浏览器按策略拒绝执行该段脚本 ⇒ 整页图表失效（W1082 同型机理）。重算 generate_csp.py 后元素数恢复、差异收敛为 24 处预期颜色转换 ⇒ 探针的「元素数」指标是塌缩的第一道探测器。

**本章结论**：档 3 的「字面值 → 令牌直喂」在自研 D3 图表上**机理成立、可回滚、影响可判读**；剩余 145 页可按 ≤10 页/批铺开。
