## 二、执行记录

### 2.1 裁切方案推导（CSS 裁切 vs 物理裁图）

物理裁图（把 1200×674 裁成 800×674）会改变图片比例，在 1072px 宽的容器里 cover 后垂直只剩源高 46%，切头风险高，且要改 12 个资产文件 + 族文档。

CSS 裁切保持资产与源比例不变：figure 加 overflow: hidden；img 宽 150%、margin-left: -50%（百分比相对容器宽）⇒ 容器可见区正好对应源图右侧 2/3（水平裁 33.3%），垂直由 max-height 420 决定（源 y 中段）。**视觉等价于物理裁图，但资产零改动、可逆、无二次生成成本**。

### 2.2 最终样式（页内私有，209 页一致）

    .silk-hero { margin: 0 0 var(--space-6); overflow: hidden; }
    .silk-hero img { width: 150%; max-width: none; height: auto; max-height: 420px; margin-left: -50%;
      object-fit: cover; object-position: right center; display: block; opacity: .95; border-radius: 2px; }

同时撤销 W1255 的题识层（span 元素 + .silk-inscription 六条规则全删）。暗色双图切换规则保持不变。

### 2.3 推广结果

209 页全部改写成功、失败 0；唯一跳过页为 themes/index.html（目录页无横幅）；题识残留 grep 命中 **0**；12 张图片资产字节未变。
