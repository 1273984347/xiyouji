## 执行摘要

W1207 把静态产物里 26 处服务端地址改成构建期占位符（部署期替换），并在坑表 **E-225** 立下正解：
**占位符只许落在非哈希载体上**（外部 JS / meta / 平台层配置）。但那是一次性**人工读数**——
W1207 当批实测「内联 script 块内占位符命中 0」，此后**无任何防复发机制**：
任何人把占位符写进内联 script 块，部署期替换即改该块字节 ⇒ CSP 哈希失配 ⇒ 整段脚本被浏览器拒执行。
W1208 方案档 §13.10 明列本项为「明确未做·建议下一并挂槽」。

本批把该正解从人工一次性实测**升级为常驻机器门禁**：

- 新建 scripts/check_placeholder_hash_carrier.py，以 _StrictGate 挂进 verify_delivery.py 为**第 71 槽**（恒跑 _SCOPE_CORE）；
- 判据四项：C1 内联 script 正文（哈希输入）判红 · C2 script src 属性值判红 · C3 扫描面级兜底 fail-closed · C4 其余载体登记不判红；
- **口径同源**：直接 import generate_csp 的 SCRIPT_RE + inline_script_hashes（不复制正则——第 56 槽是复制式）；
- **双向实证**：往 site/index.html 内联块注入占位符 ⇒ 本槽判红并定位到块 #1 / sha256 前 12 位 Emuuv5mktPBa，且 generate_csp --check **同步报 DRIFT** ⇒ 断链真实可复现；复原后双绿；

### 2.3 关键设计决定

1. **引用不复制**（W1120 纪律）：第 56 槽 check_csp_drift.py 复制了 SCRIPT_RE 字面量并以注释互保；
   本槽改**直接 import** generate_csp ⇒ 两处正则从根上无法分叉（自测含「口径同源」一例）。
2. **登记而非放行**（E-223「豁免桶即逃逸口」）：合法载体也逐处登记角色与位置，
   使「7 处占位符为何都安全」可人工复核，而非一条不透明的绿灯。
3. **CSP 声明面单独归类**：csp_meta 与旁挂 meta 性质不同（前者是哈希的来源、替换后 connect-src 仍合法），
   混为一谈会在将来被误当违规加豁免、或被误判为哈希载体。
4. **不手写级联面**：CHANGELOG 段 / HANDOVER 里程碑块与更新链 / 页脚各面一律由 batch_cascade 依 spec 生成 ⇒ 避免双写冲突。

## 四、复盘

**做对的**：把判据建立在**机制事实**（CSP 哈希只吃内联块字节）而非表象（占位符出现即红）上，
因此合法形态（meta / 外部 JS / CSP 声明面）天然放行、非法形态天然拦得住，不需要维护豁免清单；
双向实证让「这条断链真实存在」从理论推演变成可复现读数。

**踩到的三个坑**：

1. **写入时换行转义**：write 工具的 content 走 JS 模板字符串时，反斜杠+n 会被解释成真实换行，
   落进 Python 源码即成语法错（守卫脚本与单测各中一次 ⇒ 两次 py_compile/ruff 才抓到）。
   ⇒ 写 Python 源码时该序列必须写两遍；或改用数组 join 拼接。
2. **自证输出与计数不一致**：T5 曾被误 append 到 cases 而非 checks ⇒ 计数 7/7 但只打印 6 行 ⇒ 留证无法自证。
   ⇒ 自证的打印循环必须与计数源同容器。
3. **存量假红被新变更放大**：N2 段数解析本就脆弱（真实 75 读成 76），本批挂槽会让两个数字继续分叉。
   ⇒ 按「修实例必修根」一并根治（改 ast），而不是把文档规范改成 77 去迎合坏解析器。

**未做（不假收敛）**：① 仓库体积仍越 1 GB 线（改写历史待 force-push 授权·非本批范围）；
② 注入后产物的守卫复扫仍须带 --expected-endpoint 声明（契约既有设计·非缺陷）；
③ 本批只覆盖 site/ 产物面，--root 可扩展到其他部署产物目录。

## 五、经验沉淀

**沉淀去向**：本批**未新增坑表条目**——E-225 已在册且正解未变，本批只是把正解从人工实测升级为常驻门禁；
按「重复坑不新增条目」纪律，坑表计数链保持 320 不变。新增的可迁移教训并入本报告 §4 与 gates.md 第 71 槽详细定义。

**可迁移的三条**（跨项目通用）：

1. **判据要建立在机制事实上**：把「什么会坏」追到字节级输入（哪部分字节进哈希），
   判据就天然只拦真会坏的形态、且不需要豁免清单——「登记而非放行」让合法形态也可复核。
2. **同源要靠引用而非自律**：仓内已有一处复制式正则（第 56 槽）并以注释互保；
   新判据改引用式 ⇒ 分叉从「靠人记得同步」变成「结构上不可能」。
3. **解析数字的判据要先自证口径**：文档里写着 75、代码里解析出 76 时，先问「哪个是错的」——
   本例真相是解析器错（行尾注释黏连），若照着坏解析器改文档，就会把错的写进权威口径。
