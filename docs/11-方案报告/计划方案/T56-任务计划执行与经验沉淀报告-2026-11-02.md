**本批针对**：上一批（W1096）收官时列出的**三项遗留**——① 归档健康探针 T2 报的 8 个批次段目录组行登记滞后；② design 全量审查的 9 项发现「只审不改」需实际收口；③ 第 31 门禁对「台账含 Git 冲突标记」与「stats 同口径自检」两个盲区待补机器判据。

**核心判定**：

1. **遗留1 根修为「自动派生」而非逐个补枚举**：`check_archive_health.py` 的段目录枚举改为磁盘 tracked 自动派生 ⇒ 新建段目录的必做动作从「改脚本 + 改 README」两处收敛为「README 补组行」一处；存量 8 条组行补齐后**归档健康探针 0 项待办**。
2. **遗留3 两个盲区各补一条判据且负样本自证**：C9（治理面禁行首 Git 冲突标记三件套）+ C10（7 个板块内容篇数**异源复算** vs `stats.json`·排除集大小写不敏感）；注入冲突标记必红、人为改错计数必红、干净输入不误报。
3. **design 9 项发现全部有明确处置**（7 项本批收口 · 1 项部分收口并登记次批）：其中 P1-2 经**异源复算**订正页数口径（原「50 页」⇒ 实为 47 页·因另 16 页使用 `REDUCE_MOTION` 变量形态守卫）。

### A.2 判据口径

- **J2 采样面**：7 页代表面（改动形态四类全覆盖）· 双主题 · 每页独立 context（隔离模式）⇒ **前后两拍必须同页序同参数同模式**。
- **J2 差异判定**：元素数差异 ⇒ 报身份多重集差集并二分「真实增删 / 同身份数量增减」；身份不同但索引相同 ⇒ 按索引配对补属性比拍（否则视觉后果不可见）。
- **正向对齐判定**：EN 与 ZH 同族页的 tooltip 元素逐属性比对（32 项）⇒ 修前 17 项不一致、修后 0 项。
- **守卫覆盖两级口径**：页级覆盖率 · 调用点级覆盖率（实参是否被守卫包裹·括号平衡扫描）⇒ 两级差异即漏网信号。
- **类名收敛完整性**：三套命名空间同时判定 —— HTML class 属性（token 精确）+ CSS 选择器 + JS 选择器字符串 ⇒ 三者一致才算收敛完成（E-100）。
- **计数链**：坑表六段条数之和 = 总数；同步位置五处 ⇒ 第 31 门禁 C5e 三向对账。
