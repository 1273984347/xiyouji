## 一、范围界定

> "三年前，正值端阳之节，朕与嫔后都在御花园海榴亭下解粽插艾，饮菖蒲雄黄酒，看斗龙舟。忽然一阵风至，半空中现出一个妖精，自称赛太岁，说他在麒麟山獬豸洞居住，洞中少个夫人，访得我金圣宫生得貌美娇姿，要做个夫人……将金圣宫推出海榴亭外，被那妖响一声摄将去了。"——第六十九回 line 55（朱紫国国王自述金圣宫被掳经过）

> "三年前到朱紫国强夺了金圣皇后，一向无缘，未得沾身，只苦了要来的宫女顶缸。"——第七十回 line 19（小妖"有来有去"自述）

> "他自穿了那衣，就浑身上下都生了针刺，我大王摸也不敢摸他一摸。"——第七十回 line 21（小妖述五彩仙衣避秽）

> "娘娘身上生了毒刺，手上有蜇阳之毒。自到麒麟山，与那赛太岁三年，那妖更不曾沾身。"——第七十一回 line 43（行者向国王解释棕衣之刺）

《西游记》女性人物谱系中，金圣宫娘娘是处境最特殊的一个：她是**全书唯一一位皇后**（朱紫国正宫），也是**全书唯一"被掳三年却全身而退"的女性**。第六十九回 line 55，国王在御花园的海榴亭下失去她——端阳节的欢宴瞬间变成掳掠的现场，"推出海榴亭外"六个字，写尽了皇后在权力面前的无力：不是她愿意去，是"被推出"；不是她主动离宫，是"摄将去了"。掳掠者是赛太岁——观音菩萨的坐骑金毛犼，一个声称"洞中少个夫人"的妖王（第六十九回 line 55）。

她的三年囚禁，是全书最沉默的一段女性史：第七十回 line 19，小妖"有来有去"用一句话概括了这三年——"一向无缘，未得沾身，只苦了要来的宫女顶缸"。赛太岁近不得她的身，因为紫阳真人送了她一件五彩仙衣（第七十回 line 21）：穿上即"浑身上下都生了针刺"，碰一下手心就痛，于是妖王"摸也不敢摸他一摸"。这件衣服保护了她，也囚禁了她——它是全书最精妙的"保护性隔离"装置：**它以"不可触碰"为代价保全"清白"**。三年后悟空救她回国，第七十一回 line 41，国王"急下龙床，就来扯娘娘玉手，欲诉离情，猛然跌倒在地，只叫：'手疼！手疼！'"——重逢的第一触，被三年前那件棕衣的余威刺穿。直到紫阳真人现身解魇，"即脱下那件棕衣，那娘娘遍体如旧"（第七十一回 line 43），夫妻才得重谐（第七十一回 line 45）。

**核心命题**：金圣宫娘娘是"被掳三年的皇后"——棕团扇使赛太岁"近不得身"，她被保护却也被隔离；她是全书唯一"被玷污风险中全身而退"的皇后，但三年监禁（掳掠+避秽）对她意味着什么，叙事始终没有给出她的视角。本文以福柯的规训理论、麦金农的性别权力分析、巴特基的女性身体规训论与戈夫曼的全控机构理论为透镜，将金圣宫娘娘从"朱紫国劫难里的道具"重读为"宫廷女性在被掳-保护-隔离-归还结构中的典型命运"，并与 W374 高翠兰（民间妻）、W364 玉面狐狸（外室）构成"宫廷-民间-妖界"的女性处境对照。

## 二、理论框架：四位理论家的金圣宫娘娘切口

### 2.1 米歇尔·福柯（规训与惩罚）：被规训与被监禁的身体

米歇尔·福柯（Michel Foucault）在《规训与惩罚》（*Discipline and Punish*, 1975）中提出：现代社会通过监狱、学校、兵营等机构对"身体"实施规训（discipline）——身体的每一个动作都被安排、被监视、被记录，权力通过"空间分配""时间编排""层级监视"将身体改造为"驯顺的身体"。福柯特别分析了"全景敞视"（panopticon）结构：被监禁者始终处于"可能被观看"的状态，权力的凝视内化为自我规训。

福柯的框架为金圣宫娘娘提供了第一层解读。麒麟山獬豸洞是书中的一个微型"监狱"：金圣宫被掳入洞中，成为赛太岁"洞中少个夫人"（第六十九回 line 55）的填充物——她不是囚犯，却比囚犯更被动：囚犯尚有身份（犯人名册），她被"摄将去了"之后，连"朱紫国皇后"的身份都被悬置，在洞中她只是"赛太岁的夫人"这个称谓的载体。第七十回 line 19 小妖的转述揭示了规训的日常："一向无缘，未得沾身，只苦了要来的宫女顶缸"——她的身体被安置在"不可碰"的禁区，而顶缸的宫女则被反复消耗（"两个来弄杀了，四个来也弄杀了"）。福柯所谓"权力的凝视"在此呈现为双重结构：赛太岁凝视着不可触碰的皇后（欲望被棕衣隔断），国王在千里之外凝视着被掳的皇后（"昼夜忧思不息"，第六十九回 line 55）；金圣宫娘娘处于两种凝视的交汇点，她的身体是权力的对象，她自己却没有凝视的资格——她连"被看见"都不是以自己的方式。

### 2.2 凯瑟琳·麦金农（性别与权力结构）：作为权力占有对象的皇后

凯瑟琳·麦金农（Catharine MacKinnon）在《迈向女性主义的国家理论》（*Toward a Feminist Theory of the State*, 1989）等著作中提出：性别不平等不是"差异"问题，而是"权力"问题——在父权社会中，性是被权力结构化的实践，女性的身体是男性支配的场所；"占有"（possession）是性别权力的核心动作，女性的"贞洁"是男性之间交换与争夺的符号。麦金农的洞察在于：性暴力不是权力的例外，而是权力本身的表现形式。

麦金农的框架为金圣宫娘娘提供了第二层解读。赛太岁抢金圣宫的理由是"洞中少个夫人"（第六十九回 line 55）——**"少"这个字是全书最直白的权力陈述**：皇后的存在意义被压缩为"填补洞中的空缺"，她的美貌（"生得貌美娇姿"）是触发掠夺的资本，她的身份（朱紫国皇后）是掠夺行为的意义所在——抢一个普通民女不足以彰显妖王的威势，抢一国之母才是"占山为王"的完整仪式。而国王的反应同样是权力逻辑：他"忧国忧民"地把皇后"推出海榴亭外"（第六十九回 line 55）——一国之君交出自己的皇后，是"保国"与"保后"之间的权力权衡；事后他"昼夜忧思不息"，三年成疾，其中混杂着感情、愧疚与被侵犯的尊严。麦金农的"占有"框架在此显影：金圣宫娘娘在两个男性权力中心（妖王/国王）之间被争夺、被交换、被悬置，她本人既无谈判资格也无反抗记录——她是权力对弈中的"皇后"棋子，连棋子的走法都不由她决定。

### 2.3 桑德拉·巴特基（女性身体的规训）：棕团扇与"防御性身体"

桑德拉·巴特基（Sandra Lee Bartky）在《肉体之痛》（*Foucault, Femininity, and the Modernization of Patriarchal Power*, 1988，收入《女性气质与支配》*Femininity and Domination*）中提出：父权对女性的规训不仅通过外在机构，更通过"身体实践"内化——节食、化妆、姿态管理，女性被训练成"驯顺而迷人的身体"；规训的现代形式是"自我规训"，女性成为自己身体的监视者。巴特基特别指出：女性身体的规训往往以"保护"或"美"的名义进行，其效果是女性与自己的身体产生疏离。

巴特基的框架为金圣宫娘娘提供了第三层解读。紫阳真人的五彩仙衣（第70回 line 21 小妖转述"当时就有一个神仙，送一件五彩仙衣与金圣宫妆新"）是全书最典型的"以保护为名的身体改造"：它"光生五彩"，是一件美丽的霞裳——以"妆新"（新娘装束）的名义送给皇后；穿上之后"即生一身毒刺"（第七十一回 line 43），美丽的外表下是防御的机制。这套装置的双面性在巴特基的框架下清晰显影：**它保护了金圣宫的"贞洁"，却把她的身体改造为"不可触碰的武器"**——她从此不能被人触碰（连丈夫都不能），不能表达亲密（重逢时国王扯手即被刺倒，第七十一回 line 41），她的身体从"被掠夺的风险"变为"永久的防御状态"。这不是她的选择，是紫阳真人单方面施加于她的改造——她既没有同意"被保护"，也没有能力脱下这件衣服。三年里，她穿着这件刺衣生活在洞中：安全，却孤独；清白，却不可亲近。巴特基所谓"女性与身体的疏离"在此达到极致：金圣宫娘娘的身体不再是她的身体，而是**一个被"保护性规训"改造的防御装置**——它以"刺"的形式存在，既拒绝妖王，也拒绝了所有可能的触碰，包括爱与自由。

### 2.4 厄文·戈夫曼（全控机构）：獬豸洞与"自我"的拆解

厄文·戈夫曼（Erving Goffman）在《收容所》（*Asylums*, 1961）中提出"全控机构"（total institution）概念：监狱、疯人院、修道院等机构对成员实施"全面的生活控制"——进食、睡眠、社交、身份全部被机构接管；机构通过"自我拆解"（mortification of self）程序（剥夺个人物品、强制统一着装、规定作息）逐步瓦解成员的既有身份，再以机构内的新身份重建其自我。戈夫曼的洞察在于：全控机构的本质不是"限制自由"，而是"重新定义人"。

戈夫曼的框架为金圣宫娘娘提供了第四层解读。獬豸洞三年的生活，符合全控机构的全部特征：她与朱紫国完全隔绝（无信息、无自由），生活被妖王的作息支配（赛太岁"天明就去，入夜……"是八戒式妖怪的作息，洞中则是妖王的意志），她的个人物品（皇后服饰、仪仗、身份）被剥夺，换上"赛太岁夫人"的处境。戈夫曼所谓"自我拆解"在她身上呈现为身份的三重剥离：**皇后的身份被剥离**（她不再是朱紫国的金圣宫娘娘，只是洞中"那个娘娘"）；**妻子的身份被悬置**（与国王的婚姻被掳掠强制中断）；**她的身体被"重新定义"**（穿上棕衣后，她成为"带刺的不可触碰者"——这是机构对她的最终定义）。三年后归国，她必须"重新学会"做皇后：第七十一回 line 45，"拜毕，即命大开东阁，酬谢四僧。那君王领众跪拜，夫妻才得重谐"——"重谐"二字意味着身份的重建：她重新成为国王的皇后，但三年间的空白（她经历过什么、承受过什么）无人追问，也无人记录。戈夫曼的"全控机构"理论在此给出最终判断：**金圣宫娘娘从被掳到归国的全过程，是一部"身份拆解-隔离-重建"的完整档案**——而档案中缺失的，恰恰是她的自我。

## 三、维度一：被掳的身体——皇后→囚徒的身份坠落

金圣宫娘娘的身份坠落，发生在端阳节的一阵风里。第六十九回 line 55，国王的叙述是全书罕见的"宫廷现场"：御花园、海榴亭、解粽插艾、菖蒲雄黄酒、斗龙舟——这是帝国秩序最典型的节日景观，皇后身处其中，是礼仪的一部分。而"忽然一阵风至"，妖王现形，自称"赛太岁"，要"金圣宫做夫人"，随即"将金圣宫推出海榴亭外，被那妖响一声摄将去了"。

注意这段叙述的三重坠落：第一重，**空间坠落**——从帝国宫廷（权力的中心）到麒麟山獬豸洞（妖王的领地），皇后的身体被移出国家秩序；第二重，**身份坠落**——从"金圣宫娘娘"（朱紫国正宫，第六十九回 line 55 国王自述"将正宫称为金圣宫"）到"赛太岁的夫人"（妖王的填充物），称谓的改变意味着她在权力话语中的位置被替换；第三重，**主体坠落**——"推出""摄将"两个动词表明，她在整个事件中没有自己的动作：被推出（国王的决策）、被摄走（妖王的力量），她是一个被搬运的身体。这具身体在三年里成为"未得沾身"的禁脔（第七十回 line 19），其"贞洁"被保护，其"人身"被监禁，其"身份"被悬置——皇后沦为囚徒，却比囚徒更甚：囚徒尚有姓名记录，她只有"金圣宫"这个称谓，连名字都没有留下。

## 四、维度二：避秽的棕团扇——保护性隔离的双面性

紫阳真人的五彩仙衣，是全书对"保护性隔离"最完整的寓言。它的正面是"保护"：赛太岁近不得身（第七十一回 line 43），金圣宫的贞洁在三年掳掠中完好无损——这符合"贞洁至上"的古典伦理；它的反面是"隔离"：第七十回 line 21，小妖说"他自穿了那衣，就浑身上下都生了针刺，我大王摸也不敢摸他一摸"——**这身刺在拒绝妖王的同时，也拒绝了一切触碰**。它把金圣宫娘娘变成了"不可触碰的存在"：三年中没有人能拥抱她，没有人能安慰她，连她自己也无法脱下这件衣服（衣服是紫阳真人单方面施加的，她既无开锁之钥，也无卸甲之权）。

这件棕衣的符号意义值得深挖：它以"保护"之名行使了"规训"之实——它规定了她身体的全部接触规则（不可碰、不可近、不可亲），它把她变成一件"安全的物品"而非"安全的人"。第七十一回 line 43，行者向国王解释："娘娘身上生了毒刺，手上有蜇阳之毒。自到麒麟山，与那赛太岁三年，那妖更不曾沾身，但沾身就害身疼，但沾手就害手疼。"——注意这套解释的语言：**全部围绕"那妖"展开**，保护的对象是"不被玷污"，而不是"娘娘的福祉"。三年里，金圣宫娘娘是这套保护装置的"受保护对象"，却不是"受益主体"：她保住了贞洁，却失去了三年的人生；她免于被玷污，却也被剥夺了被触碰的资格。紫阳真人说"我恐那妖将皇后玷辱，有坏人伦，后日难与国王复合"（第七十一回 line 43）——他的动机清晰：为了"后日难与国王复合"的伦理后果，预先给皇后穿上刺衣。**皇后的身体成为伦理风险的缓冲区**：刺衣保护的不是她，是"国王-皇后"关系的纯洁性。

## 五、维度三：帝后的重逢——"王与后"的重建

金圣宫娘娘归国后的重逢场景，是全书女性叙事中最富张力的瞬间。第七十一回 line 41，"那国王见了，急下龙床，就来扯娘娘玉手，欲诉离情，猛然跌倒在地，只叫：'手疼！手疼！'"——三年相思，第一触是刺痛。这刺痛是棕衣的余威（虽已回国，刺衣未脱），也是三年隔离的肉体化：**国王握住的不是皇后的手，是那件刺衣**——他触到的是"被规训过的身体"，而不是"他的皇后"。八戒在旁笑道："嘴脸！没福消受！一见面就蛰杀了也！"——喜剧化的台词掩盖了背后的残酷：帝后重逢的第一反应是物理性的疼痛，是身体对身体的拒绝。

随后是紫阳真人的解魇：第七十一回 line 43，"真人走向前，对娘娘用手一指，即脱下那件棕衣，那娘娘遍体如旧"——**"遍体如旧"四个字完成了身份的还原**：脱去刺衣，她重新成为"可触碰的人"，重新成为"国王的皇后"。第七十一回 line 45，"拜毕，即命大开东阁，酬谢四僧。那君王领众跪拜，夫妻才得重谐"——"重谐"是仪式性的重建：大开东阁、领众跪拜、酬谢四僧，整套帝国礼仪被重新激活，皇后的位置回到宫廷秩序之中。但三年间她"经历了什么"这一叙事空白，被仪式性的欢庆迅速覆盖——没有人问过她，在獬豸洞的三年里，她如何度过那些"未得沾身"的日夜；那件刺衣穿在身上时，她是否也曾希望有人能碰她一下。"重谐"恢复了她的位置，却没有恢复她的记忆——她是朱紫国的皇后，但三年囚禁（掳掠+避秽）对她意味着什么，叙事永远沉默。

## 六、与 W374 高翠兰、W364 玉面狐狸的谱系对照：宫廷-民间-妖界的女性处境

## 八、延伸思考

1. 紫阳真人的棕团扇保护了金圣宫的贞洁，也使她三年不可触碰（第七十回 line 21）。"保护性隔离"在现实中常常以"为你好"的名义实施——当保护以剥夺接触、剥夺自由、剥夺自我表达为代价时，它还是保护吗？"保护"与"规训"的边界在哪里？
2. 金圣宫娘娘归国后，"夫妻才得重谐"（第七十一回 line 45），但三年监禁的具体经历在叙事中完全空白。为什么《西游记》对女性被掳的"结果"（贞洁是否保全）如此在意，对女性被掳的"过程"（她经历了什么）却如此漠然？这种叙事取向本身是否就是权力结构的一部分？
3. 帝后重逢时国王"猛然跌倒在地"（第七十一回 line 41）——身体层面的疼痛揭示了隔离的遗留。当一段关系被外力（掳掠、规训、隔离）中断三年之后，"重谐"能否真正弥合裂痕？还是说，被改变的身体与被消耗的时间，永远无法"遍体如旧"？
