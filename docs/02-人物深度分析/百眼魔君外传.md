# 百眼魔君：千只眼与一根针

《西游记》里的妖怪，分两种：靠蛮力的，和靠手艺的。

靠蛮力的妖怪好对付——金箍棒下去，一棒一个；靠手艺的妖怪难缠——他们不跟你拼力气，跟你拼"技术"。车迟国那三位国师是搞"法术技术"的，呼风唤雨，斗法斗得天花乱坠；黄花观这位，是搞"生物技术"的——他会炼药，会摆阵，浑身上下长了一千只眼。

千只眼，看起来是全书妖怪里最"看得多"的配置。

但最后破他的，是一根针。

**一、黄花观的道士**

黄花观在盘丝岭上，是个正经道观——青砖黛瓦，香火缭绕，观主是个道士。路过的人谁能想到，这位仙风道骨的观主，是个妖怪？

他叫百眼魔君，又叫多目怪。与盘丝洞的七个蜘蛛精是师兄妹："他与七个蜘蛛精，结为兄妹"（第七十三回）。蜘蛛精在盘丝洞惹了祸，跑到黄花观来哭诉，师兄二话不说，要为师妹们出头——这是全书妖怪里少见的"同门情谊"：他认这个亲，所以他管这个事。

妖怪讲义气，本来不算坏事。但这位师兄讲义气的方式，暴露了他"技术官僚"的本色：不正面刚，先下药。

**二、七情迷本**

第七十二回的标题叫"盘丝洞七情迷本"——蜘蛛精的"七情"（喜、怒、哀、惧、爱、恶、欲）是"迷本"的引子；到了第七十三回，黄花观道士把"七情迷本"做成了药。

他端出三杯茶：一杯给自己的师妹，两杯给唐僧师徒。唐僧、八戒、沙僧喝了，当场倒地，"吐痰吐沫"。这药有多狠？黎山老姆假扮的孝妇说："那厮毒药最狠：药倒人，三日之间，骨髓俱烂。"

三日之间，骨髓俱烂——这不是打架，是"生化武器"。百眼魔君是全书最有"技术含量"的妖怪之一：他不屑于动刀动枪，他要的是"科学灭口"。唐僧师徒取经路上遇到的妖怪，大多是"抓了再吃"，这位是"先毒再说"——技术官僚的思路，永远比莽夫快一步。

悟空没喝那杯茶。他见茶色不对，摔了茶钟，跟道士打了起来。打了五六十回合，道士"渐觉手软"，于是使出了他的压箱底技术。

**三、一千只眼**

"原来这道士剥了衣裳，把手一齐抬起，只见那两胁下有一千只眼，眼中迸放金光"（第七十三回）——这是全书最壮观的妖怪技能之一：金光阵。

金光一出，"把个齐天孙大圣，困在金光黄雾中"。悟空是谁？大闹天宫、八卦炉里炼出来的铜头铁臂，刀砍斧剁都不伤分毫。可在这金光阵里，他"向前不能举步，退后不能动脚，却便似在个桶里转的一般"，往上跳，撞得"顶梁皮都撞软了"，自己都愣了："晦气！晦气！这颗头今日也不济了！常时刀砍斧剁，莫能伤损，却怎么被这金光撞软了皮肉？"

千只眼的金光，是全书少数能"困住"悟空的东西——比多少天兵天将都管用。这就是技术的威力：蛮力再大，进了人家的"体系"，也得乖乖转圈。

最后悟空是变成穿山甲，往地下钻了二十多里，才钻出金光阵——一个"齐天大圣"，被金光逼得钻地逃跑，狼狈得像只地鼠。

**四、一根绣花针**

破金光阵的办法，是黎山老姆指的路：紫云山千花洞，毗蓝婆菩萨。

毗蓝婆菩萨是个深居简出的老太太，三百多年没出门了。悟空去请，她推辞："我本当不去，奈蒙大圣下临，不可灭了求经之善，我和你去来。"

悟空问：您带什么兵器？

菩萨说："我有个绣花针儿，能破那厮。"

悟空差点笑出来：绣花针？老孙要一担也有。

毗蓝婆说："你那绣花针，无非是钢铁金针，用不得。我这宝贝，非钢，非铁，非金，乃我小儿日眼里炼成的。"

她的小儿是谁？"小儿乃昴日星官。"

日眼里炼成的针，不是兵器，是"光"——一千只眼睛放出的金光，被太阳里炼出的一根针破了。

"毗蓝随于衣领里取出一个绣花针，似眉毛粗细，有五六分长短，拈在手，望空抛去。少时间，响一声，破了金光。"

一声响，金光散。千只眼，败给一根针。

**五、看不清自己**

百眼魔君有一千只眼。按理说，他应该是最"看得清"的妖怪。

可他偏偏是最"看不清"的一个。

他看不清的第一件事：金光阵不是无敌的。他以为一千只眼放出的金光能困住一切，却不知道太阳里炼出来的光，天生克他的光——他研究了一辈子"发光"的技术，却没研究过"光的源头"。

他看不清的第二件事：毒药不是万能的。他毒倒了唐僧八戒沙僧，却漏了悟空；他以为"三日骨髓俱烂"能灭口，却忘了取经人背后有整个佛界天庭的"售后体系"——黎山老姆来指路，毗蓝婆来解毒，取经人的命，轮不到他的药来收。

他看不清的第三件事，也是最重要的一件：他有一千只眼，却从来看不见自己。他以为自己是"黄花观主"，是庇护师妹的"大师兄"，是修行有成的"道长"——他不知道，在别人眼里，他始终是一条七尺长的蜈蚣。蜘蛛精叫他师兄，是"同门"；他给唐僧下毒，是"报仇"；他摆金光阵，是"自卫"——每一步他都觉得自己有理，每一招他都觉得自己在"修行"。可他修的是什么道？毒药、金光、千只眼，全是杀伐之技。

技术官僚的悲哀就在于此：他们精通一切"术"，却从不问"道"为何物。车迟国的三位国师也是：呼风唤雨的技术一流，却从不想想，这风雨到底该不该由他们来呼。百眼魔君与三国师，是同一个病：**把"技术"当成了"真理"，把"手段"当成了"目的"**。

一千只眼，看穿了悟空的金刚不坏之躯的破绽（顶梁皮撞软了），却看不穿自己"是妖不是仙"的本质。等到毗蓝婆"用手一指"，他"扑的倒在尘埃，现了原身，乃是一条七尺长短的大蜈蚣精"——一千只眼终于闭上了，因为看见自己这件事，从来不需要眼睛，需要的是"自知"。

**六、收场**

毗蓝婆收了百眼魔君，没有杀他。悟空要打，菩萨拦住："天蓬息怒，大圣知我洞里无人，待我收他去看守门户也。"

一个毒杀唐僧、困住悟空的妖王，最后的归宿是给菩萨看门。

"毗蓝使小指头挑起，驾祥云径转千花洞去。"

用一根小指头挑起一条七尺长的蜈蚣——这个画面是全书的黑色幽默：他那让齐天大圣钻地逃跑的千只眼金光阵，在菩萨面前，连一根小指头都挡不住。

千只眼，不如一根针；千般技术，不如一个"正"字。

黄花观的道士，最终被千花洞的菩萨收去看门。他大概至死都不明白：自己的药、自己的阵、自己的一千只眼，到底输在哪里。

他输在"看不清自己"——而这恰恰是"多目"的宿命：眼睛越多，越看外面；越看外面，越看不见自己。

**延伸思考：**

1. 百眼魔君是全书最有"技术含量"的妖怪之一——炼七情迷本药、摆千眼金光阵，技术碾压大部分妖怪。可他的技术越精，败得越彻底：药被解，阵被破，身被收。当"技术"脱离"道"（正念、正法）之后，为什么越高明的技术，反而越容易招来更高级的克星？
2. "千只眼不如一根针"——毗蓝婆的绣花针（日眼里炼成的光）破掉千眼金光。这提醒我们：真正的破局之道，往往不在"更多、更强、更快"的同维竞争里，而在"降维"——用根本性的规律（光的源头）去破表象性的技术（光的应用）。你身边有没有"千只眼"式的困境？它的"一根针"在哪里？
3. 百眼魔君与车迟国三国师同属"技术官僚"型角色：精通法术技术，却不懂"术"与"道"的分野。在当代，专业能力很强却看不清自己位置的人并不少见——"满身眼睛"的我们，要怎样在专业精进的同时，保留一面照见自己的镜子？
