一、七绝山

七绝山不是山，是一片山。山上有七种绝——绝路、绝粮、绝水、绝医、绝药、绝人、绝生。山下有一个庄子，叫驼罗庄。庄不大，百来户人家，靠种地为生。地不多，天不好，收成勉强糊口。庄里的人皮肤黝黑，眼白混浊，手指甲里永远嵌着洗不掉的泥。这里穷得连妖怪都不来——不是不想来，是来了没东西吃。方圆几百里最值钱的就是地里那点红薯。妖怪也要挑嘴的。

但妖怪还是来了。不是一只，是一条大蟒。不是来吃人的——这条蟒很奇怪，吃牲口不吃人。牛、羊、猪、鸡、狗，它能吞的都吞。唯独不碰人。不是挑食，是它的嘴太大了，吞牛吞羊正合适。吞人反而不好咽——人的骨头太细太尖，会卡在喉咙里，要用大量的唾液慢慢化。牛骨头粗而圆，顺着喉管滑下去，顶多硌一下。所以它放过人。不是善，是人的骨相不合它胃口。

庄民一开始也怕，后来发现它真的不吃人。于是就开始习惯——习惯是一件比妖怪更可怕的事。妖怪吃牛，牛没了，地就荒了。地荒了，人就得饿着。饿着的人没力气怕妖怪，只能怕饿。饿比妖怪更真切——妖怪来，你还能跑；饿来了，你跑不了，它长在你胃里。庄里有老人说，被蟒吞下去的和饿死在地里的，最后都是同一堆黄土。区别只在于黄土是先盖在牛身上再翻到人身上，还是直接盖在人身上。

二、李老汉的牛

庄东头有个李老汉，养了一头牛。牛是他家的全部财产——犁地靠它，拉车靠它。那是头老黄牛，角上有一道被石头磕出的豁口，是他刚买它那年冬天，牛犊子自己跑出圈在冰上摔的。他把它从冰面上抱起来，牛犊子冻得四条腿直抖，他用自己棉袄裹住它抱了一夜。第二天棉袄上全是牛毛和冰碴子融化的水渍，晾干后留下一圈淡淡的盐霜。后来棉袄破了他补，补了又破，破到没法补就拆成垫牛圈的褥子。老黄牛躺在上面，反刍时嘴里的草汁把褥子晕出一块一块深色的湿痕。

那天夜里，大蟒来了。李老汉听到牛圈里有动静，披上衣服跑出去，看到大蟒已经把老黄牛卷起来了。蟒身比水桶还粗，牛的四条腿在空中乱蹬，牛眼睛瞪得很大，白眼球上全是血丝。李老汉冲上去，手里抓着一把叉草的叉子，叉尖是磨过的。他对着蟒身一阵猛扎，扎不进去——蟒鳞太厚，叉尖只在鳞片上划出几道白印。这几道白印歪歪扭扭，和他棉袄上那圈盐霜的边沿一模一样。他扎了很久，久到叉柄在手里打滑——是他的虎口震裂了，血顺着叉柄流下去，流到叉尖，渗进白印最深处那一道。蟒没有松开。蟒把牛卷得更紧了，牛的叫声从响亮变成嘶哑，从嘶哑变成呜咽，最后变成沉默。

牛死了。牛躺在地上，身体扭曲成一个不自然的弧度——是老黄牛趴着反刍时把脖子枕在自己前蹄上的弧度，但这次脖子折断了，再也抬不起来。李老汉蹲在牛圈里，把牛眼睛合上，在牛圈门口蹲了一夜。第二天早上，他去地里把犁套在自己肩上，让老伴在后面扶犁。老伴没扶过犁，犁尖插得太深，他拉不动，肩上的皮磨破了，血从麻绳绞进麻纤维。他没有停，拉不动就往前倾，倾到身体和地面成一个犁尖的角度。犁尖耕开的地沟歪歪扭扭，和李老汉虎口震裂那晚叉尖在蟒鳞上划出的白印一模一样。

三、庄里的规矩

驼罗庄的人找过法师。不是没反抗过，是反抗过，失败了。第一个法师是个道士，自称从武当山来，能降妖捉怪。他带着桃木剑和符咒，站在庄口等蟒。蟒来了，他把符咒贴在桃木剑上，剑尖指蟒，念了半天咒。蟒没有反应，从他头顶游过去，尾巴带倒了他身后的供桌，供桌上摆着他刚画完还没来得及晾干的“镇妖符”，被尾巴风掀进路边牛粪坑。第二个法师是个和尚，说是从五台山下来，能度化一切众生。蟒来的时候，他坐在庄口念《往生咒》。蟒从他身边经过，停下来，低头看了他一眼。他闭着眼睛继续念。蟒走了。不是被度化了，是蟒吃饱了。和尚捡回一条命，第二天一早就走了。走的时候留下一句话：此蟒非妖，是兽。兽不吃人，不必降。庄民们面面相觑——不必降？那牛怎么办？羊怎么办？猪怎么办？鸡怎么办？狗怎么办？地怎么办？饿怎么办？

后来庄里形成了一套规矩。每月初一十五，把一头牲口拴在庄口老槐树下。是贡，不是祭——贡是给上边的，祭是给下边的。庄民不知道该给这条蟒上贡还是下祭，索性谁也不说，只说是“那一晚的”。大蟒会来，叼走牲口，庄里太平。这规矩不是大蟒定的，是庄民自己定的。没有人要求他们这么做，但如果不这么做，大蟒会自己进庄找吃的。自己找就不知道会吃掉哪家的。有规矩至少能轮流分摊——这个月张家出鸡，下个月李家出羊，再下个月王家出猪。公平。穷人的公平，就是用最穷的方式分配最穷的东西——不是钱，是恐惧。

四、王阿四的羊

轮到王阿四的时候，他家只剩一只羊了。王阿四的老娘病在床上，羊奶是老太太唯一的补品。王阿四没有把羊交出去。他把羊藏在自家地窖里，地窖口用柴火堆堵死。那天夜里，大蟒来了，没找到羊，进了王阿四的屋。蟒没有吃人，只是把王阿四的腿撞断了——不是咬，是蟒尾扫过来时他正好站在门框边，蟒尾扫断门框的力撞碎了他小腿胫骨。断骨戳破皮肤，血流在地上，渗进他老娘床下那块被羊奶碗底磨凹了的泥地。泥地吸饱了血，颜色从深褐变成黑，黑里透着一层极淡的白——那是羊奶碗底蹭上去的瓷釉末。

第二天，王阿四拄着拐杖把羊牵到老槐树下，拴好。羊在槐树下啃了一整天的树皮。傍晚王阿四把羊牵回家，羊还在——大蟒今晚没来。第三天他又把羊牵去，拴好。大蟒还是没来。他把羊牵回家的时候，羊蹄在门槛上绊了一下，他弯腰去扶，拐杖滑倒在门框边，那截被蟒尾扫断又被楔子接上的新茬口刚好顶在他小腿断骨的皮肤表面。他低头看了看，把拐杖拿起来，重新拄在腋下。他在门槛上坐了很久，看着屋里老娘床边那碗凉了的羊奶。奶面上凝了一层乳皮，乳皮上落着一根极细的羊毛——是羊今天在槐树下蹭掉的，被他衣襟带回来，又飘进碗里。他把羊奶端起来，用手指挑掉那根毛，把碗放在老娘嘴边。老娘喝了一口。羊在窗外叫了一声。这声羊叫和大蟒叼走牛那晚他听到的声音一模一样——不是惨叫，是脖子被勒住时气流挤过喉管发出的闷响。那时他趴在自己窗后不敢出声，今晚他也没有出声。

五、土地公的公文

驼罗庄的土地公姓蒋。不是大名，庄里姓蒋的多，都叫他蒋土地。他的庙在庄西头一棵老槐树下——不是贡牲口的那棵，是另一棵。那棵槐树比庙还老，树根从庙基下面横穿过去，把神案顶歪了半寸。神案上供的不是果品，是庄民偶尔放的一碗水。水碗底沉着细沙——是树根从庙基底下带上来的，每天早晨他端起碗喝水时，都能闻到树根的苦味。

土地公往上递过很多次文书。第一次是蟒刚出现的时候——他写了急报，说驼罗庄有妖蟒为害，请天庭派兵收妖。公文递到城隍，转给判官，判官呈送阴司，阴司转呈天庭，天庭批给雷部，雷部转给值日功曹，值日功曹批了两个字：“待查”。待查就是没查。第二次，他写了详报，附上蟒的行踪和习性，说明此蟒非妖，是兽，不在雷部的管辖范围，请天庭转交山神处理。公文递到山神那里，山神说他只管山不管水，蟒是从七绝山深处下来的，七绝山是荒山，荒山无主，他管不了。第三次，他写了哭报——不是公文格式，是用自己坟前的纸钱纸写的，蘸的不是墨，是庙门前槐树根冒出来的水。纸上没有抬头，没有落款，只有一行字：蟒又吃了一头牛，今年春耕无牛，人拉犁。

公文递上去，没有回音。不是被驳回了，是没人收。天庭的公文系统有一条潜规则——如果一件事不在任何部门的管辖范围内，它就会被丢进“无主公文”的筐里。那个筐在天庭后殿走廊尽头，筐子满了就倒进天河，河水把墨迹泡烂，纸浆沉进河底喂鱼。天河的鱼吃公文长大，鳞片上偶尔会闪过半行未泡烂的字。有一年王母娘娘的侍女捞了一条鱼准备蒸给蟠桃会的宾客吃，剖开鱼腹，发现里面塞满纸浆，纸浆里还有半个没化掉的“蟒”字——虫旁还在，莽声已烂。那道公文在鱼腹里又被转了一次手，最终还是没到玉帝案前。

土地公后来不写公文了。他用槐树根在庙墙上划道。一道是一头牛，一道是一只羊，一道是一口猪。墙上划了很多道，歪歪扭扭，像蟒游过泥地留下的痕迹。最后一道特别深，划穿了墙皮露出庙墙内侧的土坯——那是王阿四的羊，但不是羊被吃了，是羊被拴在老槐树下的那个傍晚，王阿四把羊牵回家，羊没死，但土地公听见王阿四在门槛上坐了很久没出声。他想了想，还是划了一横。他划的不是羊，是恐惧。

六、取经人来了

玄奘师徒到了驼罗庄。庄民围上来，说这里有一条大蟒害人。悟空问吃什么，庄民说吃牲口。悟空问吃过人没有，庄民说没有。悟空问那为什么不去打，庄民不说话了。悟空懂了。不是不能打，是不敢打。一条不吃人的蟒，比吃人的蟒更难办。吃人的蟒是妖怪，可以请神仙收，可以叫官兵剿，可以写公文。不吃人的蟒，什么都不是，什么部门都不管，公文不知道往哪投。它只是活得久、长得大、挡了路。它不是恶，它是存在。存在本身成了恐惧——这比恶更无解。

悟空去打蟒。没有悬念。蟒很大，但不会法术，不会变化，不会吐毒，不会分身。它在七绝山的山洞里盘成一团，被悟空的金箍棒从洞里赶出来，在七绝山沟里打了几个滚，腹部被金箍棒砸中，皮裂了一道大口子。不是致命伤——它的内脏没有破，但那道裂口让它再也爬不快了。它试着往山里缩，缩到半路被碎石卡住裂口边缘，碎石越卡越深，把裂口撑得更大。它停下，把腹部贴在溪水里。溪水很凉，是从山顶积雪化的，流过它的裂口时带走了一些血，又带走了一些泥。泥里有七绝山上特有的红砂土，遇水不化，沉在溪底像一滩褪色的锈。

沙僧赶到时，大蟒已经不动了。不是死，是不动了。裂口很长，从腹中部一直延伸到尾部，皮肤翻开露出里面淡粉色的肌肉。沙僧没有补刀。他蹲下来，撕下自己僧袍下摆的麻布条，从溪边抓了一把止血的艾草，放在石头上用降妖杖的杖头捣烂，糊在裂口上，然后用麻布条一圈一圈缠好。布条缠得紧，勒进蟒的鳞片缝隙。蟒的身体微微起伏——还在呼吸。沙僧站起来，对悟空说：大师兄，它不是妖。悟空收起金箍棒，说：我知道。他让八戒把蟒拖到更深的山里放掉。八戒拖着蟒尾往山里走，路过一片碎石坡时，蟒的尾巴无意间扫过一棵枯了半边的老柿子树。树枝上还挂着几颗去年没落的红柿子，被蟒尾扫落，掉在蟒的裂口旁边，摔碎了，柿肉和溪水混在一起，流进蟒被缠好的裂口里。柿肉很甜，蟒的肌肉尝到了甜味，痉挛了一下。那是它这辈子第一次也是最后一次尝到甜。

七、驼罗庄的恐惧

驼罗庄的恐惧不在那条蟒。恐惧在庄民自己心里。大蟒被赶走之后，驼罗庄发生了什么？什么都没发生。牛还是那头老黄牛的骨头埋在土里，羊还是那只羊拴在老槐树下啃树皮，地还是那块地，犁还是那把犁。庄民们站在庄口看着取经人远去，很久没有说话。然后，慢慢地，大家散了。有人去牵羊，有人去修被蟒压塌的篱笆，有人去地窖里把藏起来的红薯翻出来，红薯已经发芽了，芽是白的，在黑暗里长了几寸长。有人去土地庙那面划满横杠的土墙上加了一道——这次不是横，是竖，竖贯穿了前面所有的横，从上到下，像一道门缝，关上了。

恐惧消失了。但恐惧留下的空洞还在。那个空洞不需要被填满。它只是留在那里，像枯了一半的柿子树被蟒尾扫过后，枝头再也结不出红柿子——不是树死了，是柿子的记忆和蟒的血混在一起渗进了树根。树根在黑暗里往下扎，每一寸新根都绕开土地公庙墙根下那块土坯——土坯上最后那道划穿墙皮的竖，还在。

八、后来

后来，驼罗庄的地还是被耕出来了。不是用牛，是用人。几户人家合起来拉一张犁，前面四个人，后面一个人扶犁。犁尖耕开干裂的土，土里翻出去年被蟒压塌的篱笆桩的残片——木头上还缠着几圈当年拴羊的麻绳，绳已经朽了，手指一捻就碎成灰。傍晚收工，扶犁的老人在自家院子磨犁尖。磨石上蘸着水，水是从土地庙门前那棵老槐树下接的。槐树根还在往外渗水，水味还是苦的，和老人每天早起喝的那碗水一样的苦。他把磨好的犁尖举到夕阳下端详——犁尖在夕阳下反着光，光弧边缘有一道极细的暗痕，是他虎口被犁杖磨破那年留下的旧血印，和犁尖的钢纹融在一起，磨不掉了。

后来，有人在七绝山深处见过那条大蟒。它的伤好了，沙僧缠的麻布条早就烂掉了，腹部的裂口长出了新的鳞片。新鳞比旧鳞颜色浅，阳光照上去会泛一层淡淡的青灰色，和它年轻时刚从蛇蛋里孵出来那层胎膜的颜色一模一样。它不再靠近驼罗庄。每年秋末，它从七绝山最深的溪谷里往上游爬，爬到山顶，盘在当年被金箍棒砸过的碎石坡上晒太阳。碎石坡旁那棵老柿子树又枯了半边，但每年还是结红柿子。有一年秋末，柿子熟透了自己落下来，砸在它背上。它把柿子卷进嘴里，连皮带核咽下去了。核卡在喉咙里。那是它第一次被卡住。也是最后一次。
