# 孙悟空：成佛之后，他先摸了摸头

第一百回，灵山受封。如来道：

"孙悟空，汝因大闹天宫，吾以甚深法力，压在五行山下，幸天灾满足，归于释教，且喜汝隐恶扬善，在途中炼魔降怪有功，全终全始，加升大职正果，汝为斗战胜佛。"

悟空成佛了。从石猴到美猴王，从弼马温到齐天大圣，从五行山下的囚徒到取经路上的行者——五百年的颠沛流离，终于在"斗战胜佛"四个字里落下帷幕。

然后他做了一个动作，原著写得很轻：

"行者举手去摸一摸，果然无之。"

他去摸头。摸那顶戴了十四年的紧箍儿。摸了半天，箍儿果然没了。唐僧说："今已成佛，自然去矣，岂有还在你头上之理！"

成佛的瞬间，他先检查的不是自己的果位，不是灵山的金殿，而是自己头上的那顶箍儿。

这个动作，暴露了斗战胜佛内心最深的东西：他从来不信"成佛"是真的，他信的是"不疼了"。

**一、摸头的动作**

紧箍儿消失的那一刻，悟空的第一反应不是欣喜，是"摸"。

他摸了很久。原著只写了"摸一摸，果然无之"六个字，但我们可以想象那只手：指尖在头顶上划过去，划到当年箍儿嵌进皮肉的位置——那里应该还有一圈浅浅的痕迹。十四年来，紧箍儿勒进肉里，勒出印子，念咒时箍儿往肉里陷，陷出一寸来深的疼。现在箍儿没了，但那一圈"被勒过"的记忆，还在。

他摸了摸。确定没有了。然后他把手放下来。

他没有欢呼。成佛的瞬间，他沉默得像一尊佛。

这太不像孙悟空了。大闹天宫时的悟空，偷蟠桃会高喊"玉帝老儿"；五行山下的悟空，见人第一句是"师父救我"；取经路上的悟空，打赢了妖怪要"耍子耍子"。可成佛的悟空，只会摸头。

因为五百年来，他终于学会了不吵不闹。

**二、斗战胜的习惯**

"斗战胜佛"这个佛号，细想是个悖论：佛是不需要斗争的，但"斗战胜"三个字，是悟空一辈子的手艺。

他成佛之后，灵山没有妖怪可打。四大部洲的妖怪，取经路上剿灭的剿灭，收编的收编，剩下的听到"斗战胜佛"的名号，躲还来不及。他的金箍棒——那根"如意金箍棒，一万三千五百斤"——挂在灵山的一间偏殿里，落了灰。

他偶尔会去偏殿看它。棒子还是那根棒子，两头是两个金箍，中间是乌铁，上刻"如意金箍棒"五个字。他伸手握住，掂一掂——一万三千五百斤，还是那个分量。但他已经没有地方挥它了。

灵山不需要打妖怪的佛。灵山需要的是讲经的佛、渡人的佛、坐禅的佛。他坐在蒲团上听经，听了一百年，一个字也没听进去。他的耳朵还留着"妖怪的脚步声"——那种三更半夜、山风骤起、有妖气逼近的动静。灵山没有妖气。灵山的夜里只有风声，和风里的梵唱。

他闭上眼睛。耳朵里全是当年花果山的水声。

**三、花果山的梦**

成佛之后，悟空做过一个梦，梦了无数次：

花果山。水帘洞。瀑布从高处落下，砸在潭水里，溅起的水雾在阳光下架起彩虹。猴子们在树上跳来跳去，摘桃子，抢果子，追着闹。一个老猴跑过来，拽着他的衣角喊："大王！大王！山下来了一队天兵！"

他在梦里醒了。睁开眼，是灵山的偏殿。檀香。梵唱。蒲团。

他坐起身，想了一下：花果山现在怎么样了？

他成佛之后没有回去过。不是不想回，是不敢回。他怕看到花果山没有他，猴子们照样过日子——不，他怕的是：花果山没有他，猴子们照样过日子。那他五百年的奔波、十四年的取经、一辈子的"大圣""行者""佛"，到底为了什么？

花果山是他唯一的"家"。可"家"这个概念，在他成佛之后变得很模糊。他回不去花果山——回去了，他还是那个齐天大圣吗？不，他是斗战胜佛。佛回花果山做什么？看猴子？

他坐在蒲团上，坐了一整夜。天亮时，他做了一个决定：不回去了。

他怕的不是猴子不认识他。他怕的是，猴子们还是叫他"大王"，而他，已经不是大王了。

**四、紧箍儿不在了，但头痛还在**

紧箍儿消失之后，悟空有一个秘密，谁都没告诉：

他的头，偶尔还会疼。

不是真疼，是"习惯性疼"。每当他想做一件"出格"的事——比如用金箍棒把某个不顺眼的罗汉打翻，比如在讲经会上跟如来顶嘴——他的太阳穴就会突突地跳，仿佛箍儿还在，仿佛咒语还念着。

紧箍儿是他的约束，也是他的"刹车"。十四年里，每到他想任性的时候，唐僧就念咒，头疼就把他拽回正轨。久而久之，"头疼"成了他的一部分——不是箍儿在疼，是"不能任性"的恐惧在疼。

现在箍儿没了，没人念咒了，他的太阳穴还在跳。

"今已成佛，自然去矣。"唐僧说得对，箍儿自然去了。但箍儿留下的"紧箍咒反射"还在——他的身体记住了"被约束"的感觉，即使约束已经解除。斗战胜佛的"斗"字还在，"胜"字也还在，只有那个"佛"字，他还穿得不太合身。

他坐在蒲团上，摸了摸头。头不疼了。但那个"摸头"的动作，他这辈子大概改不掉了。

**五、灵山的孤独**

斗战胜佛在灵山，其实很孤独。

唐僧成了旃檀功德佛，住在灵山的另一头，每天讲经，忙得很。八戒成了净坛使者，满世界跑，吃供品，一年也见不着一面。沙僧成了金身罗汉，跟在他师父身边，安安静静。白龙马成了八部天龙马，盘在灵山后山的柱子上，再也不开口说话。

取经路上，他们是一个团队；灵山之上，他们是五个"部门"。

悟空偶尔去找八戒——不，八戒不在灵山。他去找沙僧——沙僧在听唐僧讲经，讲的是《心经》，悟空听了两句就出来了。他去找唐僧——唐僧看见他，慈眉善目地点头："斗战胜佛，可有事？"

"没事。"悟空说，"路过。"

他路过灵山的每一条走廊，走过莲池，走过讲经堂，走过藏经阁。灵山很大，佛很多，罗汉揭谛金刚伽蓝，乌泱泱一片。但没有一个佛，会像花果山的猴子那样，拽着他的衣角喊他"大王"。

也没有一个佛，会像当年的八戒那样，喊他"猴哥"。

**六、雨天的痒**

很多年后，一个下雨的黄昏，斗战胜佛坐在灵山的莲池边。

灵山很少下雨。但这一天下了。雨点落在莲叶上，砸出细小的水珠。他坐在那里，忽然觉得头上有点痒——不是头疼，是痒。他伸手去挠，挠到了头顶那一圈"被勒过"的痕迹。

那圈痕迹已经淡得看不见了。但下雨天，它还会痒。

他挠了挠，笑了。笑了很久。

灵山的雨停了。他站起来，把金箍棒从偏殿里取出来，掂了掂，又放回去。他走出偏殿，走进讲经堂，在最后一排的蒲团上坐下。前面的佛在讲经，讲的是"放下"。

他闭上眼睛。耳朵里，花果山的水声，还在很远很远的地方响着。

他已经是斗战胜佛了。但他知道，他这辈子，大概永远也放不下那根棒子。

也放不下，花果山的那场梦。

**延伸思考：**

1. 悟空成佛后先"摸头"——确认紧箍儿没了。一个人用一生的时间挣脱某种约束，真正挣脱的那一刻，他是先感到自由，还是先感到"不习惯"？"约束"被解除后，身体还记得约束，这算不算另一种囚禁？
2. 从齐天大圣到斗战胜佛，悟空一路都在"证明自己"：向天庭证明，向如来证明，向师父证明。成佛之后，没有人需要他证明了。一个人奋斗的目标达成之后，"奋斗的意义"会消失吗？悟空在灵山的孤独，是不是"意义真空"的孤独？
3. "紧箍儿不在了，但头痛还在"——外在的管束内化成自我的规训。这种内化是成长的标志，还是自由的消失？当"不想任性"变成一种本能，人还分得清"自愿"和"被驯化"吗？
