# 人物谱系表

> 轨标：教学讲解

## 谱系总览

《西游记》中人物可按阵营划分为五大谱系：

1. **取经团队**：以唐僧为首，西行取经的五人组
2. **天庭**：以玉帝为首的道教神系
3. **佛界**：以如来为首的佛教神系
4. **妖魔**：散布于取经路上的各类妖精
5. **凡间**：沿途各国君主与百姓

## 一、取经团队

| 人物 | 原型/前身 | 法号 | 封号 |
|---|---|---|---|
| 唐僧 | 金蝉子 | 玄奘、三藏 | 旃檀功德佛 |
| 孙悟空 | 天产石猴 | 行者 | 斗战胜佛 |
| 猪八戒 | 天蓬元帅 | 悟能 | 净坛使者 |
| 沙僧 | 卷帘大将 | 悟净 | 金身罗汉 |
| 白龙马 | 西海龙王三太子 | 敖烈 | 八部天龙 |

### 师承关系

```
唐僧（金蝉子转世）
├── 孙悟空（师承菩提祖师）
├── 猪八戒（师承不明，原天蓬元帅）
├── 沙僧（师承不明，原卷帘大将）
└── 白龙马（师承不明，原西海龙太子）
```
