## 一、定位：与佛教宇宙观、器物、丹经命名分层

术语表「二、佛教术语」组共 10 条，内容参差：既有「取经须历 81 道劫难方成正果」「色受想行识（五蕴）」「心如猿躁意如马奔」「佛教静坐修定（禅定）」「佛教解脱生死之境（涅槃）」「善恶报应前因后果（因果）」「六道生死流转（轮回）」这类教义/目的论条目，也有「僧人法衣（袈裟）」「僧人化饭器皿（钵）」「大乘佛经」这类器物/载体条目，甚至把「心如猿躁意如马奔（心猿意马）」也归入佛教术语。

本文只取其中最可清点、最成系统的**劫难—正果轴**（取经须历难方能成正果），把其余三条的归属厘清，避免重复或越界：

- **袈裟、钵**（器物类）已由 [W1182 法器与兵器器物体系专题](法器与兵器器物体系专题.md) 处理，本文不重做；
- **心猿意马**（丹经命名）已由 [W1186 金公木母与心猿意马称谓专题](金公木母与心猿意马称谓专题.md) 处理，本文仅在「命名层」一笔带过；
- **四大部洲、三界**（佛教宇宙观）已由 [W1184 四大部洲与三界空间框架专题](四大部洲与三界空间框架专题.md) 作文本内证，本文谈的是**取经的目的与路径结构**，不是空间框架，二者互补不重叠。

因此本文的实证人对象是：**《西游记》如何用「劫难 / 难簿 / 九九归真 / 正果」这套佛教目的论词汇，把一百回叙事框定为一场必须数足苦难才能完成的救赎工程**。

## 二、核心证据：难簿与九九归真

第十九十九回，取经功成、金刚送归，观音菩萨展开一份「难簿」清点全程：

> 蒙差揭谛皈依旨，谨记唐僧难数清：金蝉遭贬第一难，出胎几杀第二难，满月抛江第三难，寻亲报冤第四难，出城逢虎第五难……

这是一份**从头编号、按次第排列的灾难清单**——劫难不是随机磨难，而是被预先登记、可被逐条勾销的「账目」。清单末尾，菩萨复核后做出一个关键动作：

> 佛门中九九归真，圣僧受过八十难，还少一难，不得完成此数。

文本自己给出了两个硬事实：① 难簿实际登记 **八十难**；② 观音判定「还少一难」，须补满方合「九九归真」。于是补上最后一难（通天河落水晒经），总数成 **八十一难**。值得注意的是，「九九归真」是文本自陈的数術逻辑，而非后人归纳——第八十九回的回目「九九数完魔刬尽，三三行满道归根」同样以「九九 / 三三」（81 / 9）点明这套数字背后是道教式的内炼数術与佛教式圆满的混用。本文只实算文本明示的「八十难 + 补一难 = 八一」，不自行重数难簿条目（清单为连写长串，逐条枚举易错，以文本自陈为准）。

## 三、正果授职：五圣成真

第一百回，取经团抵达灵山、如来亲授果位，把「历难」的目的兑现为「正果」：

> 加升大职正果，汝为旃檀功德佛。（唐僧）
> 加升大职正果，汝为斗战胜佛。（孙悟空）
> 加升汝职正果，做净坛使者。（猪八戒）
> 加升大职正果，为金身罗汉。（沙僧）
> 加升汝职正果，为八部天龙马。（白龙马）

五人各得果位，且授职理由与沿途功过一一对应（唐僧「取去真经甚有功果」、悟空「炼魔降怪有功全终全始」、八戒「挑担有功」、沙僧「登山牵马有功」、白龙马「驮负圣僧圣经」）。**「正果」是劫难的目的端，授职理由又把「难」与「功」绑定**——苦难被叙述为可折算的功绩，这正是佛教目的论在叙事里的落地方式。

## 四、目的论框架：劫难是机制，正果是目标，九九归真是数術，因果是底色

把以上证据连起来，可把这个佛教术语组的第一条（取经须历 81 道劫难方成正果）读作全书的结构性主轴：

1. **劫难是机制**：难簿把一百回的降妖、遭难、试炼编码为一份可勾销的清单，叙事推进即「灾难被逐条登记—勾销」的过程。
2. **正果是目标**：第一百回的授职把终点钉死在「成正果」，且授职理由与沿途功过挂钩，使「目的」反过来解释「过程为何必须如此漫长」。
3. **九九归真是数術外壳**：八十难须补一难以合「九九」，回目再以「三三行满」呼应——取经的佛教圆满被套上道教内炼式的数字框架，是佛道术语混用的又一例（参见 W1186 对诗赞「般若波罗到彼家」的讨论）。
4. **因果是底色**：劫难非纯偶然，而是前因（如「金蝉遭贬第一难」源于唐僧（本名玄奘）前世轻慢佛法）的兑现；但本文不展开「因果 / 轮回 / 五蕴」的教义梳理——那些属于术语组其余条目，且全库「因果」629 次、「轮回」425 次多为泛用，单独成篇容易滑向教义概论，超出文本内证的纪律边界。

## 六、方法论边界

1. **难数取文本自陈，不自行重数。** 难簿为连写长串，逐条枚举易错；本文以第 99 回「圣僧受过八十难，还少一难，不得完成此数」与回目「九九数完」为据，认定总数为 81，不另做条目级点数。
2. **只作文本内证，不作教义断言。** 「九九归真」「正果」「因果」的佛教/道教义理，本文只呈现文本如何*使用*这些词，不引申其宗教哲学内涵；学术索引虽录有佛教研究条目，本文未引作教义依据。
3. **零命中之类的表述只针对本项目语料。** 未做跨版本、跨评点的难簿对照（如清代评本对八十一难的不同编排）。
4. **术语组其余条目（因果 / 轮回 / 五蕴 / 涅槃 / 禅定）留白。** 本文聚焦劫难—正果轴，不强行把十条术语塞进一篇，避免泛化概论。
