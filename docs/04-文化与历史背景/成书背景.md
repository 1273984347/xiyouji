# 成书背景

> 轨标：学术研究
> 主题类别：文化与历史背景
> 出处：v2.2.42 初始导入（无 W 编号·W424 溯源回填）

## 一、作者之谜

### 一、吴承恩说

传统说法认为《西游记》作者为明代吴承恩（约 1500-1582），淮安山阳（今江苏淮安）人，字汝忠，号射阳山人。此说主要依据：

- 明天启《淮安府志》卷十九《艺文志》载："吴承恩，《射阳集》四卷，《春秋列传序》一卷，《西游记》。"
- 鲁迅《中国小说史略》采纳此说，遂成定论。
- 苏兴《西游记及明清小说研究》（1989）为吴承恩说的重要辩护，详考吴承恩生平与成书年代。（[学术论文索引·A09](../../source/引用与网络解读/学术论文索引.md)）

### 二、质疑

20 世纪 80 年代起，章培恒等学者提出质疑：
- 天启《淮安府志》所记"西游记"未必是百回小说，可能是游记散文。
- 世德堂本《西游记》未署吴承恩之名，仅题"华阳洞天主人校"。
- 全书涉及大量北方方言与道教内丹术语，与吴承恩的南方文士身份不完全吻合。（[学术论文索引·A05](../../source/引用与网络解读/学术论文索引.md)）

### 三、其他候选

- **丘处机说**：清代部分版本以全真教道士丘处机为作者，已被现代学界否定。
- **华阳洞天主人说**：即世德堂本的校者，可能是真实作者或最终定稿者，身份不明。
- **集体累积说**：认为《西游记》是数百年民间说唱与文人加工的累积成果，无单一作者。张锦池《西游记考论》论证'世代累积型'成书说，并提作者'鲁府尹'新说。（[学术论文索引·A07](../../source/引用与网络解读/学术论文索引.md)）

**目前学界主流**：仍以吴承恩说为通行说法，但承认存在争议，倾向于"吴承恩定稿 + 前人积累"的折中观点。刘荫柏《西游记研究资料》（1990）辑录历代作者、版本、本事、评论的原始文献，为现代西游学奠定文献学基础。（[学术论文索引·A06](../../source/引用与网络解读/学术论文索引.md)）

## 二、版本演变

### 一、重要版本谱系

| 年代 | 版本 | 特点 |
|---|---|---|
| 南宋 | 《大唐三藏取经诗话》 | 现存最早西游故事文本，猴行者已出现 |
| 元代 | 杨景贤《西游记》杂剧 | 已有"齐天大圣"封号 |
| 1592（明万历二十年） | 世德堂本 | **现存最早完整百回刻本**，以之为底本 |
| 清代 | 证道本（汪象旭、黄周星） | 加入大量道教内丹派注释 |
| 清代 | 真诠本（陈士斌） | 亦为内丹派注释 |
| 1955 | 人民文学出版社整理本 | 以世德堂本为底，参校他本 |

### 二、世德堂本的地位

世德堂本（全名《新刻出像官板大字西游记》）是现存最早、最接近原著面貌的版本。本书项目即以世德堂本为底本，必要时参校其他版本。

**已知世德堂本缺陷**：卷三、卷九、卷十三、卷十五、卷十八有缺页，后世整理本多据他本补入。蔡铁鹰《西游记成书研究》（2013）系统梳理从取经诗话到百回本的层累演化，对'大唐三藏取经诗话'年代有新考。（[学术论文索引·A10](../../source/引用与网络解读/学术论文索引.md)）

## 三、历史玄奘与小说玄奘

| 维度 | 历史玄奘 | 小说唐僧 |
|---|---|---|
| 时代 | 唐（602-664） | 唐贞观 |
| 出身 | 河南陈留人，俗姓陈 | 海州陈光蕊之子，母子江流 |
| 取经动机 | 感国内经论不全，西行求法 | 奉太宗之命，水陆大会 |
| 同行 | 一人独行，间有胡人向导 | 孙悟空、猪八戒、沙僧、白龙马 |
| 路线 | 经西域、中亚至印度 | 经诸国、遇诸妖 |
| 时长 | 17 年（627-645·学界亦有 629 出发说） | 14 年（按原著口径） |
| 归来 | 带回经卷 657 部，译经 75 部 | 取回真经 5048 卷 |
| 结局 | 圆寂于长安玉华宫 | 封旃檀功德佛 |

**小说的虚构程度**：历史玄奘的独行 → 小说唐僧的团队护送，是**一次从历史到神话的彻底改造**。这一改造主要发生在南宋《取经诗话》之后，明代世德堂本定稿。（[学术论文索引·V02](../../source/引用与网络解读/学术论文索引.md)）

## 四、社会背景

### 一、明代中后期的宗教生态

吴承恩生活的明嘉靖、万历年间，是**三教合一**思潮的高峰：
- 道教：嘉靖帝崇道，宫中斋醮无虚日
- 佛教：民间信仰兴盛，但官方地位下降
- 儒教：王阳明心学兴起，"心即理"的观念深入人心

《西游记》中佛道互渗、儒释道并存的现象，正是这一时代的反映。**悟空的"心猿"称谓，与阳明心学有深层呼应。**

### 二、明代官场

- 弼马温对应的御马监，是明代真实官职
- 天庭的等级森严，对应明代的九品官制
- 妖怪的"有背景者被接走，无背景者被打死"，对应明代官场的**荫庇与株连**

### 三、商业经济的兴起

明中后期商业繁荣，市民阶层兴起。《西游记》作为白话长篇小说，其**娱乐性、世俗化、口语化**正是市民文化的产物。悟空的市井气、八戒的贪婪、妖怪的人情味，都源于此。

## 五、思想渊源

### 一、佛教

- 取经主题直接源自佛教
- "九九八十一难"对应佛教修行的次第
- "心猿"、"意马"是佛教禅宗的常用隐喻
- 如来、观音、弥勒等角色直接出自佛教神系

### 二、道教

- 菩提祖师的身份（佛名道装）是三教合一的典型
- 太上老君、玉帝、王母等出自道教神系
- 全书大量道教内丹术语（如"金公"、"木母"、"黄婆"）
- 清代证道本将《西游记》解读为道教内丹修炼寓言

### 三、儒家

- 师徒关系是儒家"君臣父子"的映射
- 唐僧的"忠君"与悟空的"忠师"是儒家伦理
- 取经的"奉旨"色彩，是儒家政治秩序的延伸

### 四、阳明心学

- "心猿"概念与阳明"心即理"高度契合
- 悟空从"放心"到"收心"的全过程，是阳明"致良知"的演义
- 真假美猴王（"二心搅乱大乾坤"）是心学"破心中贼"的具象。李时人《西游记考论》（1991）提出'西游是明代心学思潮的文学投影'说，与本章互为印证。（[学术论文索引·A08](../../source/引用与网络解读/学术论文索引.md)）

## 六、文学地位

《西游记》与《三国演义》《水浒传》《红楼梦》并称**四大名著**，是浪漫主义神魔小说的巅峰之作。其影响：

- **国内**：衍生出戏曲、评书、影视、游戏无数改编
- **国际**：被译为英、法、德、日、俄等多国文字，英文译名 *Journey to the West*
- **学术**：形成"西游学"，研究专著数以百计。黄霖《关于〈西游记〉的作者和主要精神》（1998）折中吴承恩说与质疑派，提出'主要精神是反抗'的经典论断。（[学术论文索引·A11](../../source/引用与网络解读/学术论文索引.md)）

## 七、延伸思考

1. 若吴承恩不是作者，《西游记》的"作者"会是一个什么样的人？
2. 历史玄奘的独行与小说唐僧的团队，哪种更接近真实的"求道"？
3. 阳明心学对《西游记》的影响，是显性的还是隐性的？
4. 若《西游记》成书于今天，它会写什么？
