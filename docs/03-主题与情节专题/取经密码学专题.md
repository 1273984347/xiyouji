## 二、理论框架

### 2.1 克劳德·香农：信息熵与密钥密码体制

克劳德·香农（Claude Shannon）在《通信的数学理论》中奠定信息论与密码学基础。其核心命题：

- **信息熵**（information entropy）：信息的不确定性度量，熵越高信息越难预测
- **信道容量**（channel capacity）：信道传输信息的最大速率
- **编码定理**（coding theorem）：通过编码可逼近信道容量
- **密钥密码体制**（key cipher system）：密码 = 密钥 + 算法，安全性基于密钥保密

香农的框架适用于分析《西游记》中的咒语与真言——紧箍咒是密钥，观音传授是密钥分发，悟空的疼痛是解码结果。真经是高信息熵的密文，需取经团队作为信道传输。

### 2.2 艾伦·图灵：图灵机与机器识别

艾伦·图灵（Alan Turing）在《计算机器与智能》中提出图灵机与模仿游戏。其核心命题：

- **图灵机**（Turing machine）：通用计算模型，可模拟任何算法
- **通用计算**（universal computation）：单一机器可执行任何可计算问题
- **机器识别**（machine recognition）：机器能否识别身份
- **模仿游戏**（imitation game）：通过对话判断是人还是机器

图灵的框架适用于分析真假美猴王——观音的照妖镜是图灵机式的识别尝试，但失败；谛听的"知而不敢言"是识别的边界；如来的识别是元层的解码。

### 2.3 雅克·德里达：延异与文字学

雅克·德里达（Jacques Derrida）在《论文字学》中提出"延异"（différance）与文字学。其核心命题：

- **延异**（différance）：意义在差异与延迟中生成，永不确定
- **文字学**（grammatology）：文字不是语音的附属，而是意义的源初
- **补充**（supplement）：补充是本质的补足，也是本质的替代
- **印迹**（trace）：每个符号都承载其他符号的印迹

德里达的框架适用于分析真经的密码结构——真经不是固定的意义，而是延异的印迹。取经不是获取固定文本，而是参与意义的延迟生成。

### 2.4 让·鲍德里亚：拟像与超真实

让·鲍德里亚（Jean Baudrillard）在《象征交换与死亡》中提出"拟像"（simulacra）与"超真实"（hyperreality）。其核心命题：

- **拟像**（simulacrum）：不是真实的复制，而是无原本的模型
- **仿真**（simulation）：拟像的生产与传播过程
- **超真实**（hyperreality）：比真实更真实的符号状态
- **符号交换**（symbolic exchange）：非经济的、可逆的交换

鲍德里亚的框架适用于分析妖怪的伪装——白骨精的村姑、老妇、老翁形态是拟像，无原本（白骨是原本，但已被拟像遮蔽）。六耳猕猴是孙悟空的拟像，比孙悟空更孙悟空。

### 3.2 解码：火眼金睛与谛听的识别极限

**图灵机器识别视角**：悟空的火眼金睛是图灵机式的识别装置——通过特征匹配识别妖怪。第27回 line 2890 三打白骨精，悟空识别白骨精的拟像伪装，是解码的极限案例。

**观音照妖镜的图灵测试**：观音的照妖镜是图灵测试式的识别——通过外观判断真伪。但第58回 line 4950 真假美猴王，照妖镜无法区分，是图灵测试的失败。

**谛听的"知而不敢言"**：谛听能识别真假，但不敢说。这是识别与言说的分离——识别是技术问题，言说是政治问题。谛听的沉默揭示了密码学的政治维度：知道不等于能说。

**鲍德里亚拟像视角**：妖怪的伪装是拟像生产。白骨精的村姑、老妇、老翁是三层拟像，每一层都遮蔽前一层。第27回 line 2890 白骨精的伪装，是拟像的极致案例。

**拟像的层级**：
- 第一层拟像：妖怪的原本形态（白骨）
- 第二层拟像：妖怪的变化形态（村姑、老妇、老翁）
- 第三层拟像：妖怪的叙事形态（受害者故事）

**六耳猕猴作为终极拟像**：第58回 line 4950 真假美猴王，六耳猕猴是孙悟空的终极拟像——不仅外观一致，连声音、记忆、能力都一致。这是鲍德里亚所说的"比真实更真实"——六耳猕猴比孙悟空更孙悟空。
