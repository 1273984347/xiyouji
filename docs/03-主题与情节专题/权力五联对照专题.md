## 二、理论框架

### 2.1 福柯：微观权力与规训社会

米歇尔·福柯（Michel Foucault）在《规训与惩罚》中颠覆了"权力集中于主权者"的传统想象，提出权力是**弥散的、生产性的微观网络**——它不主要靠镇压，而靠规训（discipline）将肉体塑造成"驯顺而有用的身体"。全景敞视（panopticon）是规训权力的理想形态：被观察者始终可见、观察者不可见，规训由此内化为自我监视。

《西游记》的权力结构正是福柯意义上的规训网络：紧箍儿不是一次性镇压工具，而是将孙悟空纳入持续自我规训的装置（见 W079 法宝政治学）；天庭通过"招安 / 归化 / 围剿"三套技术，将妖怪肉体规训为顺民或战士。

### 2.2 韦伯：三种支配类型

马克斯·韦伯（Max Weber）在《支配社会学》中提出合法支配三类型：传统型（基于历来传统）、卡里斯马型（基于领袖超凡特质）、法理型（基于理性规则）。

西游权力呈现三类型并存与转化：天庭传统型（玉帝"苦历一千七百五十劫"）+ 如来卡里斯马型（降伏大闹天宫）+ 取经法理型（金紧禁三箍规则化授权）。五联对照的"制度化"维度（W078）正是法理型支配的落地——天条将主权意志转化为可计算的律令。

### 2.3 阿甘本：主权者与赤裸生命

乔治·阿甘本（Giorgio Agamben）在《主权者》中指出，主权者的核心权力是"决定例外状态"，在例外中法律被悬置却仍生效，特定个体被剥离法律保护成为"赤裸生命"（homo sacer）。

五行山镇压孙悟空（第7—14回）是典型例外状态：天庭法律（封齐天大圣）被悬置，如来主权仍生效，孙悟空被剥离法律保护却不可杀。五联的"权力来源"维度（W077）追问的正是：谁有资格被承认为"正统"，谁被划入"妖"而被剥夺承认。

### 2.4 列斐伏尔：空间的生产

亨利·列斐伏尔（Henri Lefebvre）在《空间的生产》中提出空间不是容器，而是社会关系的产物——空间三元辩证（空间实践 / 空间表征 / 表征空间）揭示空间如何被权力生产。

取经路线（第13—99回）不是地理通道，而是权力空间化的过程：经途三国（车迟 / 乌鸡 / 祭赛…）是天庭—佛界势力此消彼长的空间表征。五联的"空间化"维度（W080）即取经路线社会学研究专题的核心。

### 2.5 布尔迪厄：场域与象征暴力

皮埃尔·布尔迪厄（Pierre Bourdieu）在《区隔》中以"场域"（champ）与"资本"（经济 / 文化 / 社会 / 符号）分析权力如何通过分类与区隔自然化。象征暴力（violence symbolique）是被支配者默许的、看似中立的分类暴力。

妖怪谱系（W081）正是符号暴力的一次大规模运作：天庭通过"正 / 妖""神 / 魔"的分类，将异己妖怪标记为待收编或待诛灭的他者。五联的"谱系化"维度即妖魔谱系政治学专题的研究对象。

## 三、主题分析：五联对照闭环

权力不是单点现象，而是沿"来源→制度化→工具化→空间化→谱系化"五个环节展开的闭环。每一环节对应一个深化专题，本篇为闭环概论，五篇为各环节深化。

| 环节 | 核心问题 | 深化专题 | 西游对应 |
|:---|:---|:---|:---|
| 来源 | 谁被承认为正统，谁被剥夺承认 | [身份政治三联对照方法论](../02-人物深度分析/黑熊精.md)（W077）| 大闹天宫的身份挑战 / 招安归化 |
| 制度化 | 主权意志如何转为可计算律令 | [明代司法制度镜像专题](明代司法制度镜像专题.md)（W078）| 天条量刑 / 诏狱 / 廷杖 |
| 工具化 | 权力如何具身为可操作的装置 | [法宝政治学专题](法宝政治学专题.md)（W079）| 金紧禁三箍 / 紧箍儿 |
| 空间化 | 权力如何在空间中展开与边界化 | [取经路线社会学研究专题](取经路线社会学研究专题.md)（W080）| 经途三国 / 五行山 |
| 谱系化 | 权力如何通过分类与谱系自然化 | [妖魔谱系政治学专题](妖魔谱系政治学专题.md)（W081）| 金紧禁三箍谱系 / 妖怪谱系 |

### 3.1 权力来源·身份政治（W077）

权力的第一环节是"承认"（recognition）：谁被承认为"正"，谁被划入"妖"。孙悟空大闹天宫（第7回 line 864）是对天庭垄断承认权的挑战；黑熊精被收为守山大神（第16—17回）则是"妖"通过招安获得重新承认的个案（见 W077 身份政治三联对照方法论）。

### 3.2 制度化（W078）

当承认确立，权力必须制度化以求稳定。明代司法制度镜像专题研究天条如何把"正统—妖"的二元转化为可计算的量刑体系（《大明律》/厂卫/诏狱/廷杖对照），使主权意志脱离个人任性。

### 3.3 工具化（W079）

制度需要可被操作的装置。法宝政治学专题以金紧禁三箍为核心，分析紧箍儿如何将唐僧对孙悟空的主权关系具身为"戴帽即头痛"的物质装置（第14回 line 1393）——权力的微观物理学。

### 3.4 空间化（W080）

权力在空间中标定边界。取经路线社会学研究专题将八十一难路线读为权力空间化的轨迹：每一"国"都是天庭—佛界势力范围的表征，五行山则是例外状态的空间化（见 W089 空间政治学）。

### 3.5 谱系化（W081）

权力最后通过分类自然化自身。妖魔谱系政治学专题梳理金紧禁三箍的谱系与妖怪的分类学，揭示"正 / 妖"标签如何作为符号暴力固化统治秩序。

## 四、古今对位

| 古代 | 现代 | 转化逻辑 |
|:---|:---|:---|
| 权力来源·承认（正统 / 妖）| 身份认证 / 公民权 / 户籍 | 当代身份政治的核心仍是"谁被承认为完整成员"——难民、无证者、边缘群体对应西游的"妖" |
| 制度化·天条 | 成文法 / 行政法 / 算法规则 | 主权意志转为可计算规则是古今共通，但算法规则的不透明制造新型"不可控律令" |
| 工具化·紧箍儿 | 监控手环 / 社会信用 / 算法评分 | 福柯全景敞视的技术化——规训从物理装置转向数据装置 |
| 空间化·经途三国 | 边境 / 自贸区 / 势力范围 | 空间始终是权力边界化的场域，一带一路与经途三国同构 |
| 谱系化·妖怪分类 | 种族 / 阶级 / 算法标签 | 布尔迪厄象征暴力的当代形态——分类看似中立却固化区隔 |

## 七、总结

《西游记》的权力图景不是单一的"天宫压迫妖怪"叙事，而是一个沿"来源→制度化→工具化→空间化→谱系化"五环节展开的动态闭环。身份政治（W077）确立承认的边界，司法制度（W078）将边界转为律令，法宝政治（W079）将律令具身为装置，空间政治（W080）在空间中标定边界，妖魔谱系（W081）通过分类自然化整套秩序。

五联对照的价值在于提供一把"权力解剖刀"：它既解释了孙悟空从妖到佛的轨迹（被承认→被制度接纳→被工具规训→被空间安置→被谱系收编），也解释了每一个妖怪的不同命运（打死 / 归化 / 围剿 / 任职）取决于其在五联中的落点。与 W105（神话政治学）、W089（空间政治学）、W088（时间哲学）共同构成取经项目的政治哲学矩阵。
