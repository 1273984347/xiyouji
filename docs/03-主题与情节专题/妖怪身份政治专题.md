## 二、理论框架

### 2.1 泰勒：承认与身份的本真性

查尔斯·泰勒（Charles Taylor）在《承认的政治》中指出，现代身份（identity）本质上是对话性的——"我之所是"依赖于他者的承认。被错误承认（misrecognition）不是疏忽，而是压迫的一种形式，它贬损被承认者的身份。

《西游记》的"正 / 妖"二分正是承认的政治：天庭—佛界垄断承认权，凡未被纳入的精怪皆被标记为"妖"，其存在意义被剥夺。孙悟空的"妖猴"称号、取经团队的"异类"处境，都是错误承认的文学呈现。

### 2.2 霍耐特：三种承认秩序

阿克塞尔·霍耐特（Axel Honneth）在《为承认而斗争》中提出三种承认秩序：情感承认（爱 / 亲密）、法律承认（权利 / 平等）、成就承认（社会贡献 / 自尊）。三种承认的缺失分别对应不同的蔑视体验（虐待、剥夺权利、侮辱）。

西游妖怪的命运差异，恰可映射三种承认的获得与缺失：被招安者（黑熊精→守山大神）获得成就承认；被诛灭者（白骨精）连法律承认都被剥夺；被收为童子者（红孩儿→善财童子）介于情感与成就之间。承认的有无，决定妖的生死去向。

### 2.3 法农：殖民身份的内化

弗朗茨·法农（Frantz Fanon）在《黑皮肤，白面具》中揭示，被殖民者的身份是被他者建构并内化的——黑人通过白人的目光认识自己，陷入存在性分裂。

西游中"妖"的自我认知深受天庭目光塑造：许多妖怪以"得道""成正果"为终极目标，本质上是接受了统治者的价值标尺。黑熊精听经讲道却仍窃宝（第16回），正是"被教化者"身份与本性张力的尖锐呈现——他内化佛门价值，关键时刻仍按本性行动。

### 2.4 斯皮瓦克：底层不可代表性

盖亚特里·斯皮瓦克（Gayatri Spivak）在《底层人能说话吗》中质疑：底层（subaltern）能否在被代言的框架内真正发声？代言本身可能复制压迫结构。

《西游记》的妖怪几乎无自我叙述——他们的故事都由取经视角（正统视角）讲述。白骨精、蝎子精、蜘蛛精的"恶"是被叙述出来的，而非自我陈明的。本专题因此必须与 W077 个案（黑熊精的自述式深读）互为补充：总论揭示结构，个案打捞被代言者的细微声音。

## 三、主题分析

### 3.1 妖作为他者：身份政治的边界生产

身份政治的第一机制是划界——通过"我们 / 他们"的生产确立自我。西游的"正（神 / 佛 / 人）vs 妖"不是本质区分，而是权力划界的产物：凡未纳入天庭—佛界秩序者即为妖。妖因此是被"生产"出来的他者，而非先天类别。

### 3.2 承认的三秩序与妖的落点

借用霍耐特三秩序，可重读妖怪命运：

- **法律承认缺失**（白骨精）：被打死三次，连被审判的资格都没有，是最彻底的蔑视。
- **成就承认获得**（黑熊精）：被观音收为守山大神，"被任职"而非"被管教"，获得重新承认（见 W077）。
- **情感—成就之间**（红孩儿）：收为善财童子，归化但非任职，承认不完全。

承认的有无，是妖"活 / 死 / 归"的分水岭。

### 3.3 招安·归化·围剿：身份政治的三联技术

西游处理"妖"这一他者，有三套标准化技术（详见 W077 身份政治三联对照方法论）：

| 技术 | 机制 | 个案 | 承认结果 |
|:---|:---|:---|:---|
| 招安 | 授予职位，纳入体制 | 黑熊精→守山大神 | 成就承认 |
| 归化 | 收为侍从 / 童子 | 红孩儿→善财童子 | 部分承认 |
| 围剿 | 武力诛灭 / 原主领回 | 白骨精 / 金角银角 | 承认剥夺 |

三种技术共同服务于同一目的：将"不可控的他者"转化为"可被分类与安置的身份"。

### 3.4 "妖"标签的政治功能

"妖"不仅是对精怪的称谓，更是统治秩序的治安标签——它将被反抗者（大闹天宫的孙悟空）、被竞争者（牛魔王）、被误判者（许多本无大恶的妖）一并归入待处置类别（呼应 W081 妖怪谱系的分类学）。标签的功能不是描述，而是授权处置。

### 3.5 自我认同的挣扎：被内化者的分裂

法农意义上的身份分裂，在孙悟空身上最典型：他既被叫作"妖猴"，又被许以"斗战胜佛"。紧箍儿（第14回 line 1393）是身份规训的装置——它不消灭妖，而是让妖"自愿"规训自己。身份政治的最高形态，是被统治者内化统治者标尺，自我监视、自我归顺。

## 七、总结

《西游记》的妖不是童话怪物，而是身份政治的操作对象。通过"正 / 妖"二分的划界（泰勒的承认垄断）、三种承认秩序的分配（霍耐特）、价值的被迫内化（法农）与叙事权的垄断（斯皮瓦克），小说呈现了一套完整的身份政治机器：它决定谁被承认为"正"、谁被划入"妖"、以及被划入者将面临招安、归化还是围剿。

本专题作为权力五联"权力来源"维度的总论，与 W077 黑熊精个案、W078 司法制度化、W081 妖怪谱系、W089 空间政治共同构成"来源—制度—谱系—空间"的身份政治闭环。孙悟空从"妖猴"到"斗战胜佛"的轨迹，正是身份政治机器如何收容、规训并最终重新承认一个他者的完整寓言。
