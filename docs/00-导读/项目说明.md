## 这是什么

《详解西游记》是一个混合型的西游解读项目。它不替你读完原著，但试着帮你把读完后的"是什么"延伸成"为什么"和"还有什么"。

项目由四个层次组成：

1. **原文本层**：原著文本与分回切分（`source/`）
2. **解读层**：逐回解读、人物分析、主题专题、文化背景（`docs/`）
3. **可视化层**：可浏览的 HTML 站点与时间线（`site/`、`timeline/`）
4. **数据层**：Python 文本分析脚本与输出（`scripts/`）

## 为什么做这件事

《西游记》读了一代又一代人，每一代都有自己的西游。明代人读出讽喻，清代人读出证道，二十世纪读出革命，二十一世纪读出职场。我们这一代人读它，又能读出什么？

这个项目想做的不是给出答案，而是把解读过程本身整理出来——把每一次重读的痕迹、每一个反复出现的母题、每一个被争论了四百年的问题，都安顿下来，让下一个想读它的人不必从零开始。

## 项目目标

- **可读**：每篇文档独立成章，不依赖阅读顺序
- **可查**：人物、回目、主题之间互相链接，便于跳跃
- **可扩**：目录结构与命名规范稳定，便于持续追加内容
- **可算**：原著文本可被脚本处理，产出词频、关系图等数据视图

## 写作风格约定

本项目采取「双轨写作」，每篇文档开头标注轨别：

| 轨标 | 适用读者 | 写作特征 |
|---|---|---|
| 大众普及 | 一般读者 | 语言通俗，重故事性与现实映射 |
| 学术研究 | 学者、研究者 | 语言严谨，引经据典，注版本对比 |
| 教学讲解 | 学生、教师 | 通俗为主，每章含延伸思考题 |
| 个人创作 | 同好创作者 | 自由文体，可诗词、可札记、可随笔 |

## 如何参与

项目采用 AI 代理协作模式产出文档：主代理派发任务并设定 W### ID，subagent 按模板并行产出文档，主代理按 checklist 复核后统一同步索引。

### 协作三段式

1. **主代理派发**：明确目标目录、W### ID、写作风格，引用模板与命名规范
2. **subagent 产出**：基于 [文档骨架模板](../_templates/article-template.md) 填充内容，完成后按 [交接清单](../_templates/handoff-checklist.md) 自检 8 项
3. **主代理验证**：按 [验证 checklist](../_templates/validation-checklist.md) 执行 6 项 spot-check，通过后统一同步索引

### 文档模板

- 新文档骨架：[docs/_templates/article-template.md](../_templates/article-template.md)
- subagent 交接清单：[docs/_templates/handoff-checklist.md](../_templates/handoff-checklist.md)
- 主代理验证清单：[docs/_templates/validation-checklist.md](../_templates/validation-checklist.md)

### 命名规范

- `docs/` 子目录下用 `主题.md` 或 `YYYY-MM-DD-主题.md`
- 逐回解读用 `第NNN回-标题.md`
- 文件名关联本次 W### ID，便于双索引追溯

### 双索引链接格式

每篇文档元信息区必须含两条链接，以 W### ID 为锚点：

- **正向**：指向 [CHANGELOG.md](../../CHANGELOG.md) 的本次 W### ID 段（四件套：来源/文件/验证/状态）
- **反向**：指向 [file-index.md](../../scripts/output/file-index.md) 的本文件条目

详细规范见 [双索引可追溯改造](../10-方法论沉淀/双索引可追溯改造.md)。
