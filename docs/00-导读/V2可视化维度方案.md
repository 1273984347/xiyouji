## 三、详细方案

### 方案 A（全新·主交付）：西游地理 3D 可视化

**目标**：把取经路线从二维地图升级为可旋转、可缩放、带示意地形的 3D 场景，直观呈现「从东土大唐到西天灵山」的地理纵深。

**技术选型（W456 修订后口径）**：
- 渲染库：**Three.js r128**，本地引用 `site/static/js/three.r128.min.js`（W456 全站 D3/Three 本地化后口径；原「cdnjs + SRI 引入」约定作废——外域 CDN 单点故障已整体消除，file:// 与大陆网络均不再依赖外域）。版本锁定 r128，禁止升级到 r142+（其 `CapsuleGeometry` 等新 API 不可用）。
- 地形：**程序化生成示意地形**（value-noise/Perlin 山体 + 贝塞尔河流曲线），**不引外部 DEM / 瓦片 / 远程纹理**（file:// 下外部资源不可用）。图例必须显式标注「地形为程序化示意，非真实地理高程」，避免读者误读为真实地形。
- 相机控制：**手动实现 OrbitControls，禁止引入外部 OrbitControls 模块**（r128 需额外 `examples/js` 文件，破坏 file:// 零依赖约定）。复用 `character-relationship-3d.html` 中 `setupOrbitControls()` 的既有模式（`mousedown/mousemove/mouseup` 拖拽 + `cameraRadius/cameraPhi/cameraTheta` 球坐标定位相机）。
- 路线数据：复用 `journey-map-interactive.html` 已有关键节点坐标（长安/两界山/鹰愁涧/高老庄/火焰山/通天河/女儿国/灵山等）。

**页面文件**：`site/data/journey-geo-3d.html`（固定文件名）。

**页面结构（元素 id 固定）**：
- 顶部：标准 `topnav` + `hero`（沿用现有模板，含中文 back-link）。
- 主体：`<div id="three-container">` 承载 Three.js 场景，含示意地形、取经路线折线、关键节点标记。
- 交互：鼠标拖拽旋转 / 滚轮缩放；点击节点弹出该节点的「章节 + 地点」信息；提供「路线高亮 / 地形透明」两个切换按钮。
- 图例：节点按 4 类着色——人间 / 妖界 / 天庭 / 灵山。
- 性能预算：关键节点数 **≤ 40**；动画走 `requestAnimationFrame` 批量更新，禁止每帧直接写几何属性。

**数据来源**：新增 `scripts/output/data/journey_geo_3d.json`（字段：节点坐标 / 分类 / 对应回目）。页面按项目「fetch + EMBEDDED fallback」约定，内嵌 `window.EMBEDDED_DATA.journey_geo_3d` 作为回退，保证 file:// 双击可用。

**验收标准（逐条可验证）**：
1. file:// 双击直接渲染出场景，DevTools console 无 `error`（`EMBEDDED_DATA` 回退的 `console.warn` 属设计预期，不算 error）。
2. 断网或改名 JSON 后 fetch 失败，页面自动回退 `EMBEDDED_DATA` 仍正常渲染（冒烟断言：节点 mesh 数 > 0）。
3. **零外域请求**（W456 本地化后口径）：除 goatcounter 统计（自托管 count.js + goatcounter.com 回传）外无任何外域请求；地形程序化生成，无远程纹理。
4. 相机控制为手动 `setupOrbitControls` 模式，源码中无外部 OrbitControls 引用。
5. 移动端 375px 视口降级生效（降低地形面数、关闭阴影）：拖拽旋转帧率 **≥ 30fps**；桌面 **≥ 55fps**（用 `scripts/_perf_measure.js` 的 CDP trace 做前后对比，确认无连续 Layout/Paint 风暴）。
6. 通过 `python scripts/generate_csp.py` + `--check`（0 漂移）、`python scripts/lint_links.py`（0 broken）、`python scripts/verify_delivery.py`（核心门禁全绿）。

### 方案 B（深化）：人物关系动态网络

**现状**：`character-dynamic-network.html`（85 chrome + 212 script 字面量，已英化）+ `character-relationship-3d(-view).html`。

**深化项（3 项，全部落地）**：
1. **时间轴播放**：新增回目进度条（范围 1–100）。播放时按 cooccurrence 时间线数据，使关系边随回目推进逐条出现/消失；提供播放 / 暂停 / 重置三态。
2. **角色过滤**：点击某角色节点进入邻域模式，仅显示该节点 + 一度邻接边；再次点击或按 ESC 退出邻域模式、恢复全图。
3. **边权重视觉**：关系强度在现有颜色映射基础上，叠加线宽（1–5px）与透明度（0.3–1.0）双编码。

**验收标准**：
1. 上述 3 项交互均可用，且不破坏现有 hover tooltip（hover 仍显示节点详情）。
2. 移动端 375px 交互 **≥ 30fps**：动画 rAF 节流，d3-force 加 `alphaDecay` 收敛，停止后不再持续重绘。
3. `scripts/_smoke_batch.js` 通过：无 pageerror、节点正常定位、无 transform/cx/cy 双重定位。

### 方案 C（深化）：八十一难难度热力图

**现状**：`hardship-difficulty-heatmap.html`（难度 × 回目热力图）+ `hardship-heatmap.html`。

**深化项（3 项，全部落地）**：
1. **难度-结局交叉联动**：点击单元格弹出该难的「结局类型 / 是否搬救兵」明细。
2. **回目双向联动**：热力图单元格 hover/选中时，八十一难清单表对应行同步高亮（反向亦然）。
3. **排序维度切换**：提供「难度 / 章节 / 结局」三个排序按钮，点击后热力图行序即时重排。

**验收标准**：同方案 B 的 2、3 两条（交互可用 + 移动端帧率 + 冒烟通过）。

### 方案 D（深化）：取经路线时间-空间双轴

**现状**：`journey-spacetime.html`（时空双轴）+ `journey-map-interactive.html`（交互地图）。

**深化项（3 项，全部落地）**：
1. **双轴真正联动**：拖动时间轴滑块时，地图侧对应当前回目（±1 回）的路线节点同步高亮。
2. **回目导航**：路线节点点击跳转 A1 对应回目解读页。目标文件遵循 `docs/01-全书逐回解读/第NNN回-<真实回目>.md` 命名（如 `第001回-灵根育孕源流出.md`）。**W459 修订**：回号→文件名必须经页面内嵌映射表解析（`A1_DOC_MAP`，从目录实际文件名生成），禁止运行时字符串拼接文件名——本条原约定 `第NNN回-回目摘要.md` 为错误命名（该类文件不存在），W455 照此实现致全 100 条跳转死链，W459 修复并新增 `check_dynamic_links.py` 门禁防回归。页面位于 `site/data/`，相对路径须上溯两级（`../../docs/...`）。
3. **距离/时长可视化**：在每段路线上叠加「里程 / 耗时」辅助刻度标注。

**验收标准**：同方案 B 的 2、3 两条（交互可用 + 移动端帧率 + 冒烟通过）。

## 五、风险与依赖

- **Three.js 版本**：固定 r128（本地 `site/static/js/three.r128.min.js`·W456 起；原 cdnjs+SRI 约定作废）。禁止 r142+ 的 `CapsuleGeometry` 等新 API。
- **动态链接盲区**：lint_links 只扫静态 href/src，JS 运行时拼接的链接不在覆盖内。涉及 JS 拼链接的改动必须过 `python scripts/check_dynamic_links.py`（W459 新增·已挂 verify_delivery），优先用内嵌映射表代替字符串拼接文件名。
- **OrbitControls**：禁止外部模块，必须手动实现（复用 `setupOrbitControls()` 模式），否则破坏 file:// 零依赖。
- **file:// 约束**：3D 地理禁止外部瓦片/远程纹理/DEM，地形一律程序化生成或内嵌。
- **CSP 内联哈希**：任何新页/改脚本后必须重跑 `python scripts/generate_csp.py`，确保 `script-src` 哈希 0 漂移。
- **英文站一致性**：若做 EN 版，复用现有 EN 模板 + 角色名对照表，过 `python scripts/validate_en.py`（chrome CJK 白名单 + script CJK=0）。
- **移动端**：Three.js 场景在 375px 视口必须降级（降低地形面数 / 关闭阴影），目标 ≥ 30fps。
- **防重叠**：方案 A 落地后，需在 `dashboard.html` 与 `visualizations.html` 的地理类条目中，用一句话标注新页与既有 4 个地理入口的差异（立体纵深 vs 2D 路线/符号学），避免读者困惑。
