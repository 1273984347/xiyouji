# 术语表

> 轨标：教学讲解
> 主题类别：读者导读 · 术语速查

## 一、人物称谓

《西游记》人物多名多号，同一角色在不同回目里换称谓是常事——尤其是内丹派评本里，师徒四人对应五行术语，初读易混。下表收最常见的几组。

| 称谓 | 指代 | 出处 / 说明 |
|---|---|---|
| 心猿 | 孙悟空 | 内丹术语，喻心动不宁。全书回目多用 |
| 行者 | 孙悟空 | 取经途中称呼，意为修行人 |
| 金公 | 孙悟空 | 内丹五行配属，猴属申金 |
| 木母 | 猪八戒 | 内丹术语，对应五行之木 |
| 黄婆 | 沙僧 | 内丹术语，对应五行之土，调和金木 |
| 意马 | 白龙马 | 喻意念奔逸，与"心猿"合成"心猿意马" |
| 唐僧 / 唐三藏 | 玄奘 | 法号"三藏"，俗姓陈 |
| 圣僧 | 唐僧 | 各国君王、神仙对唐僧的尊称 |
| 弼马温 | 孙悟空 | 初入天庭所封小官，悟空视为奇耻 |
| 齐天大圣 | 孙悟空 | 悟空自封封号，后获天庭追认 |

## 二、佛教术语

《西游记》取经故事以佛教为表层框架，但书中佛教词汇多为文学化使用，不必一一对应教义。

| 术语 | 含义 | 书中用法 |
|---|---|---|
| 八十一难 | 取经须历 81 道劫难方成正果 | 全书主线，末回由观音点算 |
| 五蕴 | 色、受、想、行、识，构成身心 | 偶见于回目诗偈 |
| 心猿意马 | 心如猿躁，意如马奔 | 喻师徒须收摄身心，反指悟空与白龙马 |
| 禅定 | 佛教静坐修定之法 | 多见于唐僧静坐、参禅场景 |
| 涅槃 | 佛教解脱生死之境 | 取经终点的隐喻，非严格教义 |
| 因果 | 善恶报应、前因后果 | 推动情节的核心逻辑 |
| 轮回 | 六道生死流转 | 唐僧十世修行、金蝉子转世 |
| 袈裟 | 僧人法衣 | 观音所赐锦襕袈裟，是唐僧身份信物 |
| 钵盂 | 僧人化饭器皿 | 唐僧持紫金钵盂化斋，后赠阿傩迦叶 |
| 真经 | 大乘佛经 | 取经目标，象征终极智慧 |

## 三、道教术语

清代评本将《西游记》读作内丹修炼寓言，道教术语贯穿全书——读懂这些，才读懂清人眼中的西游。

| 术语 | 含义 | 书中用法 |
|---|---|---|
| 内丹 | 以身为炉、以气为药的修炼之法 | 清代评本的总体解读框架 |
| 金丹 | 内丹修炼所成之"药" | 悟空求道、八卦炉炼身的隐喻 |
| 金公木母黄婆 | 悟空、八戒、沙僧的内丹代号 | 对应五行金、木、土 |
| 八卦炉 | 太上老君炼丹之炉 | 悟空被投入炼了七七四十九日 |
| 炼丹 | 道教烧炼金丹之术 | 老君、镇元大仙等多有涉及 |
| 天罡三十六变 | 道教变化术之一 | 八戒所学之变 |
| 地煞七十二变 | 道教变化术之一 | 悟空所学之变 |
| 火候 | 内丹修炼的进阶节奏 | 喻九九八十一难为修炼火候 |
| 金箍 | 收束心猿的法器 | 紧箍咒的功能在内丹解读中被放大 |
| 灵山 | 西天佛地 | 取经终点，内丹读法中喻修炼圆满 |

## 四、回目结构

《西游记》是章回体小说，回目与体例有固定格式——读懂这些术语，读原文不卡壳。

| 术语 | 含义 |
|---|---|
| 回 | 章回体小说的章节单位，全书 100 回 |
| 回目 | 每回标题，多为对仗双句 |
| 章回体 | 明清长篇小说主流体裁，分回叙事、有套语 |
| 上联 / 下联 | 回目双句的上下两半，各表一事或对照 |
| 且听下回分解 | 每回结尾的悬念套语 |
| 诗曰 | 回首或回中以诗起兴、收束的标记 |
| 有诗为证 | 引诗作论据的套语 |
| 话说 | 回首承上启下的开篇套语 |
| 欲知后事如何 | 制造悬念的过渡套语 |

## 五、地理名词

取经路横跨四大部洲，地名既是地理坐标，也是情节舞台。

| 地名 | 位置 | 书中角色 / 事件 |
|---|---|---|
| 东土大唐 | 南赡部洲 | 唐僧出发地，长安所在 |
| 西天灵山 | 西牛贺洲 | 取经终点，佛祖所居 |
| 花果山 | 东胜神洲 | 悟空出生与称王之地 |
| 水帘洞 | 花果山内 | 悟空称"齐天大圣"的洞府 |
| 天庭 | 三界之上 | 玉帝所居，悟空大闹之处 |
| 地府 | 阴间 | 悟空勾改生死簿之地 |
| 龙宫 | 东海之底 | 悟空取金箍棒之地 |
| 火焰山 | 西行途中 | 牛魔王、铁扇公主所在 |
| 流沙河 | 西行途中 | 沙僧收服之地 |
| 通天河 | 西行途中 | 老鼋驮渡、经书湿水之地 |

## 六、法宝兵器

《西游记》里的法宝各有归属，功能鲜明——记清这些，打斗场面一目了然。

| 法宝 | 归属 | 功能 |
|---|---|---|
| 如意金箍棒 | 孙悟空 | 大禹定海神针，可大可小，重一万三千五百斤 |
| 九齿钉耙 | 猪八戒 | 天蓬元帅所持，全名上宝逊金耙 |
| 降妖宝杖 | 沙僧 | 卷帘大将所持，木叉所制 |
| 紧箍咒 | 唐僧念、悟空戴 | 收束悟空的禁制法器 |
| 紫金红葫芦 | 金角银角 | 闻名者应声被吸入 |
| 羊脂玉净瓶 | 金角银角 | 功能同葫芦，亦吸人 |
| 芭蕉扇 | 铁扇公主 / 老君 | 扇灭火焰山之火，或扇人千里外 |
| 金刚琢 | 太上老君 / 青牛精 | 套取一切兵器法宝 |
| 紫金铃 | 观音坐骑金毛犼 | 放火、放烟、放沙 |
| 人种袋 | 弥勒佛 / 黄眉童子 | 吸尽一切人神 |
