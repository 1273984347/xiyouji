## 3. 数据维度 = 133 维（含趣味实验）

**性质分层**：A-L 与 Q+ 为学术向；M-U、V-AH、Q++ 含趣味跨界实验；Q+++ 为工具向。趣味维度刻意保留（雅集成分），引用时按维度名判断，不承担学术论证。

**算法**：README「数据维度全景」Phase 1-7 各阶段维度数之和：42 + 28 + 43 + 8 + 11 + 1 = 133。

**语义**：133 是**维度清单**计数，不是页面数；其中含趣味跨界实验维度（MBTI、卡牌、职场黑话等）。

**宣传口径**：首屏/英雄位不把 133 维作为主指标（避免「维度注水」误读）；确需展示时标注「含趣味实验」。

**算法**：`source/引用与网络解读/学术论文索引.md` 编号条目行数（V/C/A/S/T/P/M/N 八类合计 = 6+6+13+3+11+6+4+6 = 55）。

## 5. 版本号口径

- `vX.Y.Z` 是**内容发布批次编号**，不适用 SemVer 兼容性承诺：MAJOR/MINOR 对应内容阶段（v2.x = 内容体系成熟期），PATCH 随每次发布（一个 W### 条目）递增。
- 唯一持有者：`site/dukou-engine.html` 页脚；其余文档经 `scripts/bump_version.py` 同步。
- 判断「某版本改了什么」一律查 CHANGELOG.md，不要从版本号推断兼容性。

## 6. 维护规则

1. 任何对外数字（README / site/index.html / dashboard.html / 交接文档）引用前，先在本文件查口径。
2. 计数口径变更必须先改本文件，再同步所有引用处；禁止只改宣传文案不改口径。
3. 发布前运行 `scripts/verify_delivery.py`（A1-A6 磁盘==README 声明 + A4==209 强制校验）与 `scripts/lint_links.py --internal`。
4. 历史误值（首页 625 / 80 等）已于 W450 统一修正；该次修正后所立数值再次漂移的根因与处置见第 5 条。如再发现不一致，按本文件口径修正。
5. 数字修正溯源：W505（commit cd6d7b8）向 `docs/02-人物深度分析/` 追加 4 篇<!--doc-sync:exempt--> 方向二深化文档，A1-A6 由 611 变为 615；当时仅 README 同步声明值，其余元文档漏更，W514 统一校正。今后任何板块增删文档，按第 2 条规则先改本文件再同步引用方。

## 7. 人名用字口径（语料/引文强制简体 · 展示面两态并存）

> 口径来源：W699 A-04 盘点报告（[docs/10-方法论沉淀/人名用字两态盘点-魏征-2026-10-11.md](../10-方法论沉淀/人名用字两态盘点-魏征-2026-10-11.md)）三选项裁决 → **W756 执行选项 3+2**。

- **语料与引文层：强制简体「魏征」**——权威源 `source/原文/分回/`（含 `shendu/` 深度解读语料）与镜像容器 `dataset/text-search.json`、`site/static/js/text-search-app.js` 一律简体；W756 实测语料面残留 0 处（改前 4 处：第068回×2 / 第091回×1 / SD039×1）。
- **散文与展示面：两态并存，不作强制**——`docs/02`-`docs/04` 散文、`docs/01` 原文照录区、`dataset/*.json` 可视化数据、`site/**` 页面对「魏徵/魏征」两种写法**均予接受**（繁体形态在人物名、专题标题、外传篇名中占多数）。任何批次**禁以“统一用字”为名批量改展示面**（全仓统一约 400 处属选项 1，未经作者裁决不得执行）。
- **机器防线**：`scripts/check_citations.py`（第 20 门禁三检）——规范引文行与归属对白行须精确命中 `dataset/text-search.json`，语料保真检要求 json 与分回 md 逐回全等；因此**改语料必须同批同改三容器**（分回 md + dataset json + app 内嵌），否则第 20 门禁即红。

## 8. 文本与数据基础及适用性限制（W800）

| 环节 | 现状 | 已知限制 |
|---|---|---|
| 原文底本 | `source/原文/分回/` 100 回（古诗文网抓取·W286 整理为 md；去空白实测 706,586 字符）；`shendu/` 深读切片为辅助材料 | 未做多版本校勘；**两真源分歧已消解（W1020 核实）**：`text-search.json` 100 回与 `source/原文/分回` 逐回全等（`check_citations.py --check-corpus` 实测通过·判据为逐回全等断言），权威源明确为 `source/原文/分回` |
| 分词 | 结巴（jieba）分词（`scripts/` 分析链使用） | **未做明代白话适配**：专名、异体字、佛道术语可能切错；词频类指标为近似值 |
| 情感极性 | 批评家评论的**人工极性标注**（如情感热力图 8 批评家 × 20 难），非通用情感词典自动打分 | 无跨文本校准；标注颗粒度受评论原文约束 |
| 数据生成 | `run_all.py` → `dataset/*.json` → site 内嵌副本（双路径：W691 起配「页面内嵌残留扫」） | 生成器逻辑变更须整链重跑；残留扫为唯一双路径防线 |
| 引用建议 | 用于**趋势与相对比较**（谁多谁少、先后变化）可信度较高 | 用于**绝对统计结论**（精确字数/词频排名）需回原文复核；本项目不提供学术级统计保证 |
