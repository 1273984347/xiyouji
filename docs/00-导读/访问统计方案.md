## 二、退役依据（事实记录）

1. **后端失效**：`py -3 scripts/fetch_gate_stats.py --json` 返回 `HTTP 404 {"error":"not found"}`（2026-10-20 实测）。断链起点 2026-09-30，至退役裁决日**未恢复**。
2. **采不到任何数据**：页面上的自托管 `count.js` 与 RUM 的 `__rum__` 事件均回传到同一个失效站点代码——两者都是"在跑但收不到"的状态。退役不损失任何现存数据能力。
3. **纯成本**：每页加载一次自托管脚本 + 一次到外域的无效请求（且需在 CSP `connect-src` 放行该域），与项目「零外域请求」口径（W456 起）相悖。
4. **判定链失效**：`fetch_gate_stats.py` → `judge_gate.py` 的 UV 判定链自 2026-09-30 起不可用；`judge_gate.py` 本身不依赖该脚本（UV 由命令行参数传入），保留可用。

## 三、历史决策记录（2026-08 选型·存档用）

当时的约束：GitHub Pages 纯静态、**无法运行任何服务端进程**（Node.js/数据库都不行）、要求零注册零付费、需真实跨访客统计。

| 维度 | **GoatCounter** | **Umami** |
|---|---|---|
| 开源协议 | AGPL-3.0 | MIT |
| 托管版 | **免费**（个人站/小中站点免费·百万级 PV/天除外） | Hobby 免费：10 万 events/月·最多 3 站点·6 个月数据保留·社区支持；Pro $20/月（100 万 events·3 站点以上·2 年保留）；Enterprise 定制 |
| 自托管难度 | **极低**：单二进制 + SQLite，无外部依赖 | 较高：需 Node.js + PostgreSQL/MySQL，多服务运维 |
| 脚本体积 | ~3.5 KB·极轻量；支持无 JS 像素追踪、日志导入 | 稍重；标准 script 加载 |
| 数据保留 | 取决于自托管策略；托管版长期可用 | Hobby 6 个月；付费 12-60 个月（按档） |
| 功能范围 | **克制**：PV/访客/来源/浏览器/位置/屏幕/活动；突出简洁 | **丰富**：漏斗、留存、UTM、目标、用户旅程、自定义事件、实时看板、API、会话回放（Business） |
| 隐私合规 | 无 cookie、不存唯一标识、无需 GDPR 弹窗 | 无 cookie、无个人数据、GDPR/CCPA 合规、无需 cookie banner |
| 数据所有权 | 可导出、可随时取消、可自托管 | 可导出、无锁定；Cloud 数据在 US/EU 服务器 |
| 无障碍 | 高优先级（读屏友好） | 标准 |
| 本项目适配 | **命中所有约束**：免费、无需服务器、单 script 即插、隐私友好 | Cloud 需注册且免费档有额度/保留期限制；自托管超出本项目能力 |

**当时结论**：本项目流量小、要求零服务器、不想注册付费，GoatCounter 托管版是唯一同时满足"免费 + 零服务器 + 真实跨访客统计"的方案。Umami 更适合需要漏斗/留存等深度分析、团队协作、或有服务器可自托管、且愿意接受事件额度与保留期限制的场景。

> 该结论的**前提**（站点代码有效、能采到数）在 2026-09-30 后已不成立——见第二节。

## 四、若将来要恢复跨访客统计（重建路径）

1. **选型**：按当下约束重评——托管零成本方案（GoatCounter 重建账号 / 其他免注册托管分析 / Cloudflare Web Analytics 需 CF 账户）；本项目仍无服务端能力，Umami 自托管仍不适用。
2. **接入**：新建注入器（幂等 + 相对路径深浅计算）→ 注入页面 → 同步 CSP `connect-src` 放行（**顺序不可反**：先改 CSP 生成源并重跑 `py -3 scripts/generate_csp.py`，否则页面被 CSP 拒执行）→ 重建防回退守卫判据。
3. **取数**：`scripts/fetch_gate_stats.py` 保留在库（CLI 工具·无运行时成本），账号重建后把新 token 写入本地 `.env`（`GOATCOUNTER_API_TOKEN`·gitignore）即可复用；`judge_gate.py` 不需改动。
4. **纪律**：恢复前先确认"为了什么裁决"——没有裁决输入需求时，不应引入外域链（与 W806 退役裁决同源）。
