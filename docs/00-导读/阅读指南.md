# 阅读指南

> 轨标：教学讲解

## 给不同读者的建议路径

### 如果你是第一次接触《西游记》

1. 先看 [项目说明](项目说明.md) 了解项目结构
2. 跳到 `docs/01-全书逐回解读/` 按回目顺序读
3. 卡住时回到 `docs/00-导读/` 查术语
4. 读完整本书后，再到 `docs/02-人物深度分析/` 与 `docs/03-主题与情节专题/` 重读一遍

### 如果你已经读过原著，想看深度解读

1. 直接到 `docs/02-人物深度分析/` 选你感兴趣的人物
2. 再到 `docs/03-主题与情节专题/` 看专题分析
3. 最后到 `docs/04-文化与历史背景/` 看文化背景

### 如果你是学术研究者

1. 先看 `docs/04-文化与历史背景/成书背景.md` 了解版本源流
2. 重点看 `docs/02-人物深度分析/` 与 `docs/03-主题与情节专题/`
3. `scripts/` 下有词频与共现网络数据可供引用

### 如果你是教师

1. `docs/01-全书逐回解读/` 可作为备课材料
2. `timeline/` 可作为时间线教学辅助
3. `docs/05-诗词歌赋/` 可作为诗词赏析素材

### 如果你是创作者

1. `docs/06-个人随笔/` 是自由创作空间
2. `docs/05-诗词歌赋/主题诗词创作.md` 收录同人诗词
3. 欢迎补充自己的解读到对应板块

### 如果你是数据可视化爱好者

1. 从 `site/dashboard.html` 入口浏览 38 个 D3.js 可视化页面（支持 `file://` 协议直接打开）
2. 重点看 v0.7 Q+ 批评史双联（[criticism-history.html](../../site/data/criticism-history.html) 学术长卷 + [concept-device.html](../../site/data/concept-device.html) 观念装置 6 大交互装置）
3. v0.8 Q++ 名人弹幕博物馆（[cross-time-danmaku.html](../../site/data/cross-time-danmaku.html) 全年龄弹幕墙 + [century-dialogue.html](../../site/data/century-dialogue.html) 世纪对话 + [famous-time-travel.html](../../site/data/famous-time-travel.html) 名人穿越）
4. 所有页面采用古典宣纸风配色（CSS 变量 `--bg:#faf7f2 / --accent:#c8463a / --accent-2:#3a6b8c`），含折线图、柱状图、桑基图、雷达图、散点图、饼图、热力图、矩阵图等多种图表类型

## 阅读时的术语约定

- **回**：西游记原文的章节单位，全书共 100 回
- **回目**：每一回的标题，通常为对联形式
- **取经团队**：唐僧、孙悟空、猪八戒沙僧、白龙马五人合称
- **九九八十一难**：取经路上经历的 81 个劫难
- **大闹天宫**：指第 1-7 回孙悟空反抗天庭的情节
- **西天取经**：指第 8-97 回唐僧师徒西行的主体情节
- **归真**：指第 98-100 回取经归来、修成正果的情节

## 关于版本

《西游记》现存主要版本：

- **世德堂本**（明万历二十年，1592）：现存最早完整刻本，100 回
- **清代证道本**：加入大量道教内丹派注释
- **人民文学出版社整理本**：以世德堂本为底，参校其他版本
- **李卓吾批评本**：明末李卓吾（实为叶昼伪托）批注本

本项目解读以**世德堂本**为底本，必要时参校其他版本并标注。

## 关于引用

- 引用原著时标注回目，格式：`「原文」—— 第 N 回`
- 引用他人解读时标注来源与链接，存档到 `source/引用与网络解读/`
- 学术引用使用 GB/T 7714 格式
