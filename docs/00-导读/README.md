## 文件命名规范

- 用 `主题.md`（如 `术语表.md`、`阅读指南.md`）
- 文件名关联本次 W### ID

## 双索引链接格式

每篇文档元信息区须含：

- 正向：[CHANGELOG.md](../../CHANGELOG.md) 本次 W### ID 段（四件套：来源/文件/验证/状态）
- 反向：[file-index.md](../../scripts/output/file-index.md) 本文件条目

## 文档协作

- 新文档骨架：[article-template.md](../_templates/article-template.md)
- 交接清单：[handoff-checklist.md](../_templates/handoff-checklist.md)
- 协作流程详见 [项目说明「如何参与」](项目说明.md)
