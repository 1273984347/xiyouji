## 常见误区澄清
1. **“站点全部 MIT”错误**  
   → 站点属三层：结构（MIT）+ 内容（CC BY-NC 4.0）+ 数据（MIT 生成但站点内嵌为 MIT）  
   → 页面中可见的解读文字永远属 CC BY-NC 4.0。

2. **“docs/ 全部 CC BY-NC 4.0”错误**  
   → `docs/00-导读/` 是协作区，除内容板块外全部属 MIT（用于项目维护）。  
   → 只有 `docs/01-09`、`docs/10-`、`docs/11-`、`docs/S1-` 属 CC BY-NC 4.0。

3. **“引用原著即可自由用”需注意**  
   → 原著《西游记》公有域，但本项目对原著的**分析、解读、组织方式**受 CC BY-NC 4.0 保护。  
   → 直接复制本项目解读段落构成侵权，即使加了“出处：《西游记》原著”。
