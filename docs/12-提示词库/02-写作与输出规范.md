## 一、计划与方案的写作要求

写计划方案必须满足四条：

1. **表述明确具体**——消除模糊措辞与歧义；
2. **可量化、可验证**——用数值、比例、时间、频次、评分替代笼统表述；
3. **跨读者自包含**——其他 Agent、跨 session 或其他读者无需额外解释即可准确理解方案内容与执行方式；
4. **符合实际**——方案须与真实情况一致；存在偏差时标注偏差、影响与修正方案。
