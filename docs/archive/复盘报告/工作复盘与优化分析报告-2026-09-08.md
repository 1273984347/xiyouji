### 5.2 根因 5Why（两项 P1 级系统性根因）

**P02 全站 CSS 缺分号（1006 处）**：为什么有缺分号？→ 部分页面 CSS 由脚本/模板生成时未补分号。为什么没被发现？→ 无分号的声明只是静默失效，页面大体可用，无门禁检测声明级语法。为什么长期积累？→ 影响（圆角/溢出裁剪/边距丢失）分散且不阻断功能。根因：**CSS 无声明级语法门禁 + 失效影响渐进不可见**。→ 已机械修复 1006 处；预防 = check_structure 可考虑增声明级语法检查（登记评估，未挂载）。

**P01 contentavoid 幻影隐藏**：为什么 5 页豁免后其余页继续坏？→ 豁免是页面级、根因是补丁算法级。为什么选择豁免？→ W553 时以「不动 W550 已验收外观」为约束求最小 diff。为什么全局修推迟？→ 无全站复审数据支撑改动范围。根因：**最小 diff 约束下根因修复被降级为止血**。→ W557 有复审数据后一次根治；预防 = 止血措施登记时必须同时登记「全局根治的触发条件」（本期为复审触发，已兑现）。
