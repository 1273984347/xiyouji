## 与其他目录的分工

- **本目录（11-报告复盘）**：复盘/审查/调研类**报告**——面向「过去一个周期发生了什么、学到什么」。
- **`docs/10-方法论沉淀/`**：可复利**方法论**——面向「以后同类事怎么做」（DRL 真循环/E1 铁律/诊断 SOP 等）。
- **`archive/docs/复盘报告/`**：已退役报告的历史归档（W734 归档体系·只读）。
- 报告正文中沉淀的可复利经验，仍按惯例提炼入 `docs/10-方法论沉淀/` 并互链。
