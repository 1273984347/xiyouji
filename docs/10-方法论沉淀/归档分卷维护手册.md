## 一、一句话定位

归档系统是**三层容器 + 一份清单 + 六个判据**：正本（滚动）→ 一级归档（按 1MB 线）→ 二级分卷（按 250 号宽）；
清单回答「W### 在哪个文件」，判据回答「有没有丢、有没有超」。

**维护者只需记住一条**：任何搬段动作都走工具、搬完刷清单——**不许手工剪贴**（见 §六 反面清单）。

## 二、系统全貌

### 2.1 三层容器

| 层 | 文件 | 承载 | 迁出触发 | 工具 |
|:--|:--|:--|:--|:--|
| 正本 | `CHANGELOG.md` / `scripts/output/file-index.md` | 最近版本段 | 段数窗 110 / 字节窗 262144 | `archive_segments.py` |
| 一级归档 | `archive/docs/CHANGELOG-ARCHIVE.md` / `file-index-ARCHIVE.md` | 较老段 | 单件超 **1MB** | `archive_tier2.py` |
| 二级分卷 | `archive/docs/<原名>-tier2-W<lo>-W<hi>.md` | 最老段 | 单卷超 1MB（按 250 号宽新开卷） | `archive_tier2.py --range-width 250` |

### 2.2 冻结边界（不可逆，务必先读）

| 对象 | 状态 | 理由 |
|:--|:--|:--|
| `CHANGELOG-ARCHIVE-tier2.md`（实装 W277–W672） | **冻结只读** | 文件名不含范围，继续追加会让「哪卷装哪段」失去可判定性 |
| `file-index-ARCHIVE-tier2.md`（实装 W980–W1169） | **冻结只读** | 同上 |
| 全部 `archive/docs/*ARCHIVE*.md` | **只增不改**（§11.2） | 历史段逐字节保真；改动会让守恒断言与溯源失效 |

冻结卷的真实区间由 [ARCHIVE-MANIFEST.md](../../archive/docs/ARCHIVE-MANIFEST.md) 登记——**文件名不是权威，清单才是**。

### 2.3 六个判据

| 判据 | 内容 | 位置 | 阻断性 |
|:--|:--|:--|:--|
| T1 | 一级归档件 vs 1MB 线（≥800KB WARN） | `check_archive_health.py` | 报告面 |
| T1b | tier2 各卷 vs 1MB | 同上 | 报告面 |
| T2 | archive/scripts 台账对账（顶层/子目录/段目录） | 同上 | 报告面 |
| T3 | batches/README 冷存储标注在位 | 同上 | 报告面 |
| **T5** | **覆盖完备性**：台账声明已收官的号必须有段；同家族不得一号多卷 | 同上 `--gate` | **阻断（第 84 槽）** |
| **T6** | `archive/docs/` 递归总量 ≤ 12MB | 同上 `--gate` | **阻断（第 84 槽）** |

第 84 槽在 `verify_delivery.py` 里以 `check_archive_health.py --gate` 挂载，且登记在恒跑集 `_SCOPE_CORE`——**任何 scope 都会跑**。

| 文件 | 唯一写入者 | 其他方禁写 |
|:--|:--|:--|

## 四、场景操作手册

### 场景 A：正本超窗（第 74 槽红 / preflight 点名）

```bash
python scripts/archive_segments.py --max-bytes 262144 --apply   # 体积模式（推荐·自动二分求最小迁出）
python scripts/archive_segments.py --keep 56 --apply            # 段数模式（等价但需自己算数）
```

判断依据：FAIL 行会给「正本 N 段 > 窗口 60」或字节量。搬完记得跑 §场景 C。

### 场景 B：一级归档破 1MB

```bash
python scripts/archive_tier2.py --file changelog --apply     # 按 250 号宽开新卷
python scripts/archive_tier2.py --file file-index --apply
```

要点：迁出上界由 `align_boundary` 对齐到 250 的整数倍；若一级一次压不回 1MB 内，`--rounds`（默认 5）会连开多卷；命中冻结卷会直接断言失败（这是设计，不是 bug）。

### 场景 C：盘面变了 ⇒ 刷清单（否则第 84 槽间接红）

```bash
python scripts/gen_archive_manifest.py --refresh   # 重建 ARCHIVE-MANIFEST.md + archive-manifest.json
python scripts/gen_archive_manifest.py --check     # 复核：卷谱系/冻结/卷宽一致才算过
```

判据面只有三项（卷谱系、冻结清单、卷宽）；其他归档件体积属信息面，变了不会判过期——这是刻意的，否则台账归档每批变动都会逼你刷清单。

### 场景 D：第 84 槽红（T5/T6）

先跑不带档的探针看明细：

```bash
python scripts/check_archive_health.py
```

三种成因与处置：

| 症状 | 含义 | 处置 |
|:--|:--|:--|
| `T5 台账登记但正本与归档均无段：N 号（…）` | 台账说已收官，但找不到段 | ① 先确认是否真丢（`git log --grep=wNNNN` + 家族全量 grep）；② 若属合并/追记/作废，修台账该行措辞（加自述词）；③ 若确属历史缺口，登记豁免簿并写明核实动作 |
| `T5 X 家族同号多卷` | 同一 W 号出现在两卷 | 保留一卷，另一卷人工核实后迁出（禁删段） |
| `T6 archive/docs 总量超 12MB` | 归档区总量失控 | 先按 §场景 B 分卷（分卷不减总量）⇒ 真超就是历史体量问题，需评估归档分流/裁量，属决策项 |

### 场景 E：查「W### 在哪个文件」

```bash
# 首选：看清单
grep "W0951\|W1278" archive/docs/ARCHIVE-MANIFEST.md
# 兜底：家族全量搜（清单过期时用）
grep -l "^### W950（\|^### v.*W950" archive/docs/CHANGELOG-ARCHIVE*.md CHANGELOG.md
```

### 场景 F：台账行窗超 60 段

```bash
python scripts/archive_ledger_rows.py --apply    # 迁最老一行到 W批次编号对账表-ARCHIVE.md
```

## 五、断言与可证伪演练

### 5.1 搬段的守恒断言（工具内建，失败零落盘）

`archive_segments`：A1 段数守恒 / A2 内容逐字节 / A3 锚点与末尾块不动 / A4 降序完好 / A5 归档序。
`archive_tier2`：A1 段数 / A2 内容 / A3 头部只追加 / A4 号序前缀 / A5 字节守恒。

**看到断言失败不要绕过**——它拦的正是「历史被悄悄改写」这一类不可逆损失。

### 5.2 第 84 槽的可证伪演练（建议每次改动判据后跑一遍）

```bash
copy archive/docs/ARCHIVE-T5-EXEMPTIONS.md %TEMP%\t5.bak
# 移出任意一条豁免（例：W934 行）
python scripts/check_archive_health.py --gate    # 期望：T5 … 1 号（W934…）· EXIT=1
copy %TEMP%\t5.bak archive/docs/ARCHIVE-T5-EXEMPTIONS.md
python scripts/check_archive_health.py --gate    # 期望：0 FAIL · EXIT=0
```

判据不能只证明「会绿」，还要能证明「该红时真红」——否则就是装饰。

## 六、反面清单（这些做法会让系统退化）

| 做法 | 后果 |
|:--|:--|
| 手工剪贴段到归档 | 绕过 A1-A5；段序/字节/锚点任一破坏后无法自动恢复 |
| 手改 `ARCHIVE-MANIFEST.md` | 下次 `--check` 必红，且清单与磁盘的信任链断裂 |
| 往冻结卷追加 | 断言直接失败；即便强行写入，「哪卷装哪段」将永久不可判定 |
| 为让门禁变绿往豁免簿加行 | **本项目最忌讳的补丁形态**；豁免必须带可复算的核实动作 |
| 改 `--range-width` 后不刷清单 | 新卷名与清单登记不符 ⇒ `--check` 红 |
| 只分卷不刷清单 | 同上；且第 84 槽会以 T5/T6 之名报红 |
| 用 `archive_segments` 搬二级分卷 | 分工错位：正本→一级归 segments，一级→分卷归 tier2 |

## 七、复算命令附录

```bash
python scripts/gen_archive_manifest.py --check          # 清单 vs 磁盘
python scripts/check_archive_health.py                  # T1-T6 全量报告
python scripts/check_archive_health.py --gate           # 第 84 槽阻断判据（只 T5/T6）
python scripts/archive_tier2.py --file changelog        # 干跑（默认不落盘）
python scripts/archive_segments.py --dry-run            # 两面演练
make archive-manifest                                   # 清单对拍的编排入口（需 GNU make）
```
