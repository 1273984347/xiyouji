## 一、问题背景

治理文档（规则、坑位、门禁、经验）天然单调递增，单文件承载会同时坏三件事：

1. **加载成本**：CHANGELOG 一度 236KB、file-index 289KB（W735/W736 实测），通读一遍 ≈ 数万 token，而 99% 的内容与当次任务无关；
2. **纪律稀释**：摘要与全量混在一处时，新规则不断插进正文中部，读者无法判断"哪条是现役判据、哪条是历史案例"；
3. **同步漂移**：同一事实被抄成多处（摘要一句 + 全量一段），改一处漏一处——W754 审计实证：本目录索引写"报告现役 13 篇"而 [11-报告复盘](../11-报告复盘/README.md) 已 16 篇，复利经验总览表停在 W086 而 HANDOVER「三」已 37 条。

## 二、四层结构（每层一个职责，不重复）

| 层 | 载体 | 职责 | 体量纪律 |
|:---|:---|:---|:---|
| **L0 指针层** | [CLAUDE.md](../../CLAUDE.md) | 一行规则 + 权威指针；宿主自动加载 | ≤60 行·**禁写会漂移的数字与现役值** |
| **L1 摘要层** | [AGENTS.md](../../AGENTS.md) §4.2/§4.3/§4.4、README/STRUCTURE | 索引式摘要：槽位清单、主题视图、何时读 | AGENTS ≤450 行（第 41 门禁 C3） |
| **L2 全量层** | [docs/agent/gates.md](../agent/gates.md)（门禁全量）、[pitfalls.md](../agent/pitfalls.md)（坑位全量）、[agent-web.md](../agent/agent-web.md)（子项目细节） | 口径/豁免/历史实证的**唯一权威** | 只增不改历史段·按主题分节 |
| **L3 归档层** | `archive/docs/*`、`archive/scripts/*` | 退役/超阈值内容的只读沉淀 | 只追加归档段·禁回溯修改 |

**关键判据**：一个事实**只能有一处权威**。摘要层写"是什么 + 去哪查"，全量层写"为什么 + 怎么判"。

## 三、阅读契约：把"读什么、何时读"写进文件头

索引型文档（L0/L1）必须在头部声明阅读契约，并给出**触发条件**而非目录：

- **索引型**：`不要线性通读；先跑 python scripts/agent_start.py --task 拿本次任务相关清单，按需读节`；
- **通读型**：`本文件 ≤60 行，一屏读完即全部；正文唯一权威在指针目标`；
- **查表型**：`查"当前版本/最近批次"只读顶段 1 个版本段；历史段用 grep`。

判据：契约行必须能被机器门禁检查到——第 41 门禁 C1 要求 L2 三件均含"阅读契约"字样与"何时"引导（见 [check_agents_layers.py](../../scripts/check_agents_layers.py)）。

## 四、分层守恒的机器防线

| 门禁 | 查什么 | 失守后果 |
|:---|:---|:---|
| **第 41 槽 AGENTS 分层完整性** | C1 L2 三件存在且含阅读契约；C2 三方编号对账（AGENTS §4.2 max == gates.md max == verify_delivery 实况最高槽位）；C3 AGENTS ≤450 行；C4 指针目标存在 | 摘要与全量脱钩——读者按摘要找全量找不到 |
| **第 17 槽 索引健康** | file-index 段完整性/倒序/最新段残留；**方法论 README 覆盖**（目录 md ↔ 索引链接一一对应）；编号上限 == 最新段 | 新文件不入索引 → 事实源出现"影子文档" |
| **第 16 槽 Skills 索引**（已退役） | skills/ 目录退役后门禁同步退役，编号保留 | 反面教材：载体退役必须同步退役其门禁与同步工具 |
| **第 32 槽 CLAUDE.md 速查层** | 指针存在 / 锚点对拍 / 行数 ≤60 / 禁漂移值 | L0 层长胖或写死现役值 |
| **第 31 槽 文档口径体检** | 现役叙述面句式对账（C5）+ stats 实算对账（C5d） | 现役口径与 stats 不一致仍能提交 |

## 五、数字与指针纪律

1. **递增数字禁字面量**（W520）：门禁数/篇数/页数等会随批次演化的计数，在**现役状态描述**中写裸字面量必然漂移 → 改引用式（"以 verify_delivery 输出为准""见 stats.json"）或绑定实测时点与来源。
2. **统计实体化**（W704）：可由磁盘计算的量一律进 [scripts/output/stats.json](../../scripts/output/stats.json)，文档用 `<!--stats:key-->` 标记引用，第 31 门禁 C5b 对账失配即 FAIL。
3. **标识符禁令**：叙述引用实体用**标题/键锚点**，禁写行号（插一行即全链失效）；存量"索引第 N 行"写法属历史形态不回改。
4. **新增聚合量按登记制**：新引入会过期的声明，必须二选一——纳入 doc-sync 句式白名单，或改为引用式表述。
