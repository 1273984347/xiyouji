## 一、四层创意飞轮总览

| 层 | 方法 | 用途 | 风险 |
|:---:|:---|:---|:---|
| 1 | 反向约束提示词（认知摩擦） | 突破思维定式，产生反常视角选题 | 低 |
| 2 | 跨时空强制嫁接 | 跨界类比，产生新解读框架 | 低 |
| 3 | 逆向幻觉驱动（隐藏暗线） | 从原著缝隙生成"学术猜想/同人蓝本" | 中（需标注） |
| 4 | 风格失控演化 | 视觉灵感启发 | 高（与设计方向冲突，仅灵感用） |

## 二、反向约束提示词（认知摩擦）

人类解读西游容易陷入"斗争哲学""修心成长"等固有范式。反向约束强制 AI 从违背常识的角度生成大纲，人类不直接采用，而是**被这些"荒谬"角度刺痛，激发全新原创视角**——AI 负责制造认知摩擦，人类负责在摩擦中点火。

```
对【情节/人物】写大纲，但必须从以下刁钻角度各写一版：
- 反派是受害者 / 主角动机是自私的 / 事件是政治秀 / 一切是个误会
每版 150 字，只写情节骨架，不评判。
```

示例：对"三打白骨精"，反向角度包括"白骨精是受害者""唐僧是刻意驱赶""孙悟空是为了政治秀"。收敛时选可考据的种子，其余弃用。

## 三、跨时空强制嫁接

强制将西游元素映射到非关联领域，AI 输出粗糙类比框架，人类编辑做深度润色与逻辑自洽，产出人类独自写不出的跨界洞察。

```
把【西游元素】映射到【非关联领域】，输出 5 个类比框架：
- 九九八十一难 = 产品迭代的 81 次用户反馈
- 取经团队 = 一个初创公司的组织架构
只列映射关系，各 1 句话。
```

**项目既有范例**："王阳明与唐僧心学对照专题"即跨时空嫁接的成功实践（心学 ↔ 唐僧），证明该路径在本项目可行。新选题可参照（如"取经团队 ↔ OKR 管理""妖怪体系 ↔ 地缘博弈"）。

## 四、逆向幻觉驱动：西游隐藏暗线

故意让 AI 编造"隐藏剧情"（红孩儿和太上老君私下什么关系？沙僧的流沙河之前是谁的地盘？），AI 会生成看似合理实则虚构的情节。人类作者将这些**幻觉当作"学术猜想"或"同人蓝本"**，经考据和改编后转化为趣味专题。

**红线（必须遵守）**：

1. 产出必须明确标注**"学术猜想/同人蓝本，非原著事实"**（对应 A3 外传的"外传创作"标注规则）。
2. 猜想必须有原著缝隙可依（至少 1 处回目线索），不得凭空全虚构。
3. 不得与正典情节冲突；引文必须真实。

## 五、风格失控演化（审慎，仅灵感）

将现有可视化用"赛博朋克+敦煌壁画""水墨+数据流"等矛盾风格重绘，从"残次品"中提取纹样、配色、构图规律。**注意**：本项目设计方向锁定"新中式·数字雅集"（DESIGN.md），且 87 个可视化页已建立统一令牌体系——本方法**只用于灵感启发**（如情绪板讨论），不落地为页面，避免破坏设计一致性与动效契约。

## 七、工程侧可落地候选（backlog）

以下六条来自同一分析，属工程改进建议，登记备忘（第 4、5 条已落地，其余未排期）：

1. **术语一致性门禁**：项目已有 `docs/00-导读/术语表`，可仿照 token 覆盖率门禁模式做自动校验。价值：防术语漂移；成本：新门禁脚本 + verify_delivery 挂载，需新 W 批次。
2. **安全扫描纳入 archive 目录**：`scripts/audit/archive` 等历史归档目录被扫描范围排除，存在"灯下黑"。价值：消除安全盲区；注意：`SECURITY-AUDIT` 档在禁改清单（文档规范 §11.2），需单独评估。
3. **skill frontmatter version 字段**：`skills/` 的 SKILL.md 可补 version 字段并维护变更记录（create-skill 规范本就支持），实现"Prompt 代码化"的版本可追溯。价值：低；成本：低，随 skills 治理批次顺带做。
4. **issue/PR 模板（人类贡献入口）**：**【已落地 2026-08-24】** `.github/ISSUE_TEMPLATE/`（bug_report / feature_request / question / config）+ `PULL_REQUEST_TEMPLATE.md` 已建立——现有 CONTRIBUTING.md 是 AI Agent 协作版，人类贡献者入口此前缺失，模板覆盖"内容错误/链接失效/显示问题/建议/提问/提交检查"六类场景。
5. **学术引用真实性抽查**：**【已落地 2026-08-24】** 全量审计 105 篇学术研究轨文档：`> 引用：` 链接 0 断裂、0 缺行；学术论文索引.md 55 条现役条目无占位符、无"（待反哺）"残留（该词仅存于修订记录历史描述）；1 条待考项（M01 毛泽东 1945 重庆谈判史料出处）已显式标注处置与核查方向。审计通过，无需修复。注意：verify_delivery 的 W452 门禁只查"引用行存在"，本审计补上了"链接可解析 + 索引条目完整"两个维度。
6. **可视化数据 ↔ 原著语义核验**：check_data_drift 只保证"页面内嵌 == JSON"，不验证"数据值 == 原著"。全量核验成本高，可作抽检候选（低优先级）。

## 八、明确不做的方向

以下内容在同一分析中出现但**与项目灵魂冲突或纯大厂空想，明确不采纳**：云原生/图数据库/前端框架迁移/内容中台/云端渲染推流（违反 file:// 零外域依赖铁律与"双击即用"定位）、对抗性双模型与影子模式（超重）、所有商业化变现（CC BY-NC 禁止，项目定位公益学术）、版本号遵循 SemVer（项目"版本号即内容批次"是刻意设计）。
