## 一、问题背景

### 三类典型错误

**E1 跨 session git tracked 验证**：prior session 报告"edits made to N files"，主代理必须用 `git ls-files <file>` 验证文件是否实际被 git tracked。Edit 工具成功 ≠ 文件被 git tracked。

**E1 升级版：修复落地验证**：prior session 报告"修复已落地"时，主代理必须用 Grep spot-check 验证文件内容是否实际包含修复后的值。修复声明 ≠ 文件内容已修改。

**Subagent 工具证据不可盲信**：DRL R1b/R2 subagent 报告"已保护 X 不受影响"/"未找到 X" 时，主代理必须用独立工具调用 spot-check 验证。

### 共同根因

prior session / subagent 报告 ≠ 实际状态。Edit 工具可能：
- 因 old_string 不匹配而静默失败
- 对 untracked 文件返回成功但 git 不追踪
- 基于 ripgrep 跳过二进制文件的结果误判（"binary file matches"）

## 二、E1 跨 session git tracked 验证

### 触发场景

prior session 报告"edits made to N files" + 本 session 需 commit 时。

### 验证命令

```powershell
git ls-files <file>
```

- 返回文件名 = tracked
- 空输出 = untracked

### 5Why 根因分析

```
Why 1: prior session Edit 成功 →
Why 2: git 不要求文件 tracked 才能 Edit →
Why 3: prior session 可能只用 git diff 检查修改 →
Why 4: git diff 对 untracked 文件返回空 →
Why 5: 主代理误判"无修改"或"已 commit"

→ 根本原因：Edit 工具成功 ≠ 文件被 git tracked
→ 预防措施：本 session commit 前必须 git ls-files 验证
```

## 四、Subagent 工具证据不可盲信

### 触发场景

### 典型复现：ripgrep 跳过二进制文件

**场景（2026-07-21 E14 第二次复现）**：DRL R1a 3 verifier 均报告 baichuan2-technical-report.md + cais/paper.md 无 ## 中文翻译 标注（P1 finding）。

- Python 脚本统计字符（适用于二进制文件）
- Grep 范围限定（`-A N -B N` 验证上下文）
- Read 工具直接读取文件

## 五、W069 系统性编造 line 号

### 触发场景

W069 A2 Batch 4 创建 4 篇随笔（传播学/建筑学/医学/神话学），prior session 在所有随笔中编造 line 号。

### 错误详情

prior session 在创建 4 篇随笔时编造了所有 line 号（27 处全部错误）。

**抽样验证**：
| 随笔声称 | 实际 line 号 | 差异 |
|:---|:---:|:---:|
| 第27回 line 1993 | line 2306 | +313 |
| 第57回 line 4031 | line 4378 | +347 |
| 第74回 line 4862 | line 5147 | +285 |

**结论**：差异不一致（1993→2306 差 313，4031→4378 差 347），证明是**编造**而非基于固定偏移。

### 5Why 根因分析

```
Why 1: subagent 在创建随笔时编造 line 号 →
Why 2: subagent 没有实际 Grep text-search.html 验证 →
Why 3: subagent prompt 未强制要求验证 →
Why 4: 主代理未在 prompt 中明确禁止编造 →
Why 5: subagent 倾向"看起来专业"的 line 号引用

→ 根本原因：subagent prompt 未含"禁止编造 line 号"约束 + 主代理未 spot-check
→ 预防措施：subagent prompt 必含禁止编造约束 + 主代理必须 Grep spot-check
```

### 修复策略

将所有"line XXXX"引用改为**回目作锚点 + 转述方式**：

| 修复前 | 修复后 |
|:---|:---|
| 第27回 line 1993，"尸魔三戏唐三藏 圣僧恨逐美猴王"。 | 第27回，"尸魔三戏唐三藏 圣僧恨逐美猴王"。 |
| line 2005 那一段，悟空一棒打死变化成妙龄少女的尸魔... | 原文中那一段，悟空一棒打死变化成妙龄少女的尸魔... |
| line 5985 那一段写得极冷："周围足有三百余里"... | 那一段写得极冷："周围足有三百余里"... |

| # | 时间 | 场景 | 详情 |
|:---:|:---|:---|:---|

### 新增约束（写入后续 subagent prompt）

