## 第零、UV 取数方式（W535 自动化 · 替代人工抄表）

> 前两项（7 日 / 30 日 UV）不再需要登后台手抄，一条命令即可取回并可随时复算。

**一次性准备**（只需做一次）：GoatCounter 后台 → 右上角用户名 → API → 生成密钥 → 写入仓库根 `.env`：

```
GOATCOUNTER_API_TOKEN=你的密钥
```

`.env` 已在 .gitignore 内，**严禁入库**。

**取数 + 判定**：

```bash
py -3 scripts/fetch_gate_stats.py                 # 输出 uv7 / uv30 + 推荐命令
py -3 scripts/judge_gate.py --uv7 <值> --uv30 <值> --report
```

口径与实现要点（接口依据为 2026-08-30 核对的官方 OpenAPI `https://www.goatcounter.com/api.json`）：

- 端点 `GET /api/v0/stats/total?start=YYYY-MM-DD&end=YYYY-MM-DD`，鉴权 `Authorization: Bearer <token>`
- **页面访客 UV = `total` − `total_events`**（GoatCounter 的 `total` 含事件访客，闸门口径要的是页面访客）
- 时间窗为闭区间且含今天：近 7 日 = `[today-6, today]`，近 30 日 = `[today-29, today]`
- 脚本自带 `--self-test`（14 项，覆盖缺字段 / 事件数倒挂 / 401·403 / 缺令牌等负样本）与 `--fixture`（离线演练，不联网）
- 后三项（UV 曲线 / 来源占比 / 跳出率）API 不直接提供等价口径，仍需后台截图留档
