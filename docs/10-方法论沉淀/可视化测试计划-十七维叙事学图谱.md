## Scope

- **可视化页面**：`site/data/narratology-13d-network.html`（D3.js v7 力导向图 + 桑基图 + 雷达图 + 时间线 + 概览卡片 + 汇总表，共 6 个渲染组件）
- **编辑论点保护**：十七维叙事学框架（W161-W167 七感 + W169-W171 文本 + W173 性别 + W174 文化 + W182-W185 四维 + W191 网络叙事学）的内部一致性
- **用户决策/工作流保护**：研究者通过该图谱理解维度间的理论关联、理论家归属、应用案例映射；不可因数据漂移或渲染失败而误导
- **最高风险回归**：
  1. KPI 卡片数字与 `EMBEDDED_DATA` 实际数据量不一致（已知 17/16、64/16 编辑差异，需文档化）
  2. `links` 引用完整性破坏（source/target 指向不存在的维度 id）
  3. `dimensions[*].color` 与类别配色映射漂移
  4. `fetchJson` 协议分支退化（http 协议下意外发起 fetch 导致 404）
  5. D3 加载失败时 4 个 SVG 渲染崩溃（仅 sankey 有降级防御，force/radar/timeline 无）
  6. dim-card 键盘合约破坏（Enter/Space 不触发 tooltip，或 Space 滚动页面）
  7. summary-table 排序状态丢失或排序规则漂移

## 已知问题与后续工作

### 已知问题（编辑决策，非 bug）

1. **KPI 17 vs 数据 16**：标题「十七维」含 W191 网络叙事学专题（独立文档 `docs/03-主题与情节专题/取经网络叙事学专题.md`），但 W191 未加入 `EMBEDDED_DATA.dimensions` 数组。若未来将 W191 纳入数据数组，需同步更新 KPI 与单元测试期望值。
2. **KPI 64 理论家 vs 数据 16**：64 为历史累计去重理论家数（含 dimensions[*].theorists 数组展开后的去重学者），`theorists` 数组仅展开 16 位代表。建议在 KPI 旁加 tooltip 说明口径。
3. **`#dataSource` 文案死代码**：http(s) 协议下 `fetchJson` 直接返回嵌入数据，`fetchStatus.anyFetched` 永远 false，`#dataSource` 文案更新分支永不触发。建议删除该分支或修复逻辑。
4. **`||` fallback 边界 bug**：`nr.dimensions || EMBEDDED_DATA.narratology.dimensions` 在外部 JSON 返回空数组 `[]` 时不会触发 fallback（空数组 truthy）。建议改为 `nr.dimensions?.length ? nr.dimensions : EMBEDDED_DATA.narratology.dimensions`。
5. **force/radar/timeline 无降级防御**：仅 sankey 有 `typeof d3.sankey === 'undefined'` 防御，其它三个 SVG 在 d3.v7 加载失败时会直接抛错。建议统一加降级。
6. **dim-card tooltip 无 ESC 关闭**：3.5s 自动隐藏，键盘用户无法主动关闭。建议加 ESC 监听。
7. **force 节点拖拽无键盘替代**：WCAG 2.1 SC 2.5.7 拖拽移动失败案例。建议加方向键移动节点的 a11y 路径。
