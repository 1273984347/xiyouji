# 素材批处理与判据自证方法论

> **一句话核心**：成套素材（题图 / 图标 / 插画）的质量保证**不能靠事后拼凑**，必须由「母版程序化复用 + 判据可证伪 + 人工关前置 + 落位页先验」四条构造性机制承担；经验沉淀**必须入仓**（本项目是多 Agent 协作仓），只写 Agent 私有记忆等于没沉淀。
>
> **创建于 2026-10-27（W975）**·来源：W974 批「内页题图成套批·第三组」实战沉淀（12 张 3:4 竖版线描墨稿·人物 6 + 主题 6）
> **关联**：[../agent/pitfalls.md](../agent/pitfalls.md)（现役坑表·本文的条目化载体）· [E1铁律.md](E1铁律.md)（prior session ≠ 实际状态）

## 一、问题背景

### 1.1 撞坑场景

W974 批要在既有 `plate-set`（已 40 张）之上再出 12 张，**且必须与前 40 张同族**。四种失败模式在同批内全部出现：

| # | 撞坑场景 | 复现计数器 | 严重度 |
|---|---|---|---|
| ① | 母版「风格描述」人工重写 ⇒ 与上批漂移 | 每批必查（构造保证后归零） | 高 |
| ② | **机器判据全绿但图是错的**（形制误读 / 噪点污染裁切线） | W974 内 3 次 | 高 |
| ③ | **自己的检查脚本恒真**，却每次打印「无冲突」 | W974 内 1 次 | 高（隐性） |
| ④ | 经验只沉淀进 Agent 私有记忆 ⇒ 仓内其他 Agent 读不到 | W974 内 1 次（用户当场纠正） | 高（协作面） |

### 1.2 为什么「机器判据全绿」不足以验收

W974 的 24 号题图：顶部第 18 行只有 **3 个孤立像素**（差值 41）——放大取证显示 0–260 px 是纯宣纸底、只有几处极淡墨点污渍、**零主体笔触**。但站点版裁切线取「整图墨迹包围盒顶」，于是：

- 包围盒顶被拉到 **18 px**（真主体顶在 437 px）
- 站点版几乎没裁（1588 px ≈ 母版高）
- 页面标题与画面主体之间仍多留约 **160 px** 空白，**肉眼第一眼像「图缺了一块」**
- 而全部机器判据（J1–J10）**全绿**——因为顶部留白墨量确实 ≈ 0

**教训**：判据只能证明「量」对不对，证明不了「位置指的是不是主体」。凡涉及「按墨迹边界定位主体」的裁切/对齐/检测，必须先验 bbox 顶是否被孤立噪点污染。

## 二、方法论

### 2.1 母版程序化复用（一致性由构造保证）

成套图跨批一致，**唯一可靠做法是让母版成为程序化产物**：

```
读上批出图参数 JSON → 取「主体：」之前的母版段 → 直接拼本批 SUBJECT 段
⇒ 风格一致性 = 构造的副产品，而非事后拼凑
```

配套三条断言（**fail-closed**，任一不满足即中止不写盘）：

1. 批内 N 条母版**逐字一致**；
2. 本批母版与上批母版**逐字相同**；
3. 母版长度下限（防母版被改坏）。

**边界**：改母版 ⇒ **全组重出**（否则同套内出现两种风格）。

### 2.2 判据可证伪（比「判据全绿」更重要）

判据的价值不在「没报错」，在**「坏了它会红」**。落地要求三条：

1. **负样本自证**：每条判据都要有「已知坏样本走同一判据必须 FAIL」的证据；
2. **覆盖面对账**：自检函数实际覆盖了哪几条判据要**逐条列明**——本批实测 `negative_check()` 只覆盖 J1/J2/J3/J4/J6/J8，**J5/J7/J9/J10 从未被自检**（J10 实测 9.333 > 阈值 5.0 完全可证伪，只是没被函数覆盖）；
3. **自合成多维负样本**：一个坏样本踩中多条判据，才能一次看清判据族的边界（实心黑块 ⇒ J6 / 贯穿暗框 ⇒ J8 / 纯白竖带 ⇒ J10）。

### 2.3 人工关必须前置为逐张自检表

机器判据查不出「画的是什么」。W940 批第 9 张在 J1–J9 全绿的情况下被用户一眼否掉（画成了农夫挑担）。⇒ 逐张自检表固定两问：

- ① **靠哪个《西游记》具体元素认出**（独占标志物）
- ② **形制对不对**（形状类别 + 数量 + 颜色）

**重出判准**：形制偏差**达到「会被误读成别的题材」**才重出；仅数量 / 饱和度级偏差**不误读**⇒ 记入「已知取舍」，不为此反复抽图。

**器物描述的写法**：模型对「器物名」的理解会退化成最常见的几何体（写「金铙」⇒ 画成圆环，因为圆环是它见过的「环」）；写「**倒扣的金钵 · 半圆盘 · 钵面一圈回纹 · 绝不是圆环或手镯**」⇒ 一次画对。⇒ **给几何形状 + 排除项，禁只给器物名**。

### 2.4 落位页先验（选题阶段就绑页面）

出图前做「题材 × 落位页」双向核对：页面**存在** + **尚无题图**。W974 原定「虎力大仙」在 people 库**无独立页面**（只有「车迟国三国师」这类合并页）⇒ 出图完成后才发现无处可放，浪费一次生成。

### 2.5 资产分层：母版 vs 站点版

同一批图**刻意存两个版本**，不共用同一文件：

| 位置 | 内容 | 用途 |
|---|---|---|
| `assets/promo/plate-set/plate-line-*.png/.webp` | 完整母版（含上部留白） | 卡片叠字 / 分享图裁切 / 二次加工的源 |
| `site/static/images/plate-line-*.webp` | 站点版（只裁掉主体上方的留白） | 内页题图（页面实际呈现） |

**只裁上部留白、保留下部「地面留白」**——下部留白是构图的一部分，裁掉会把人物从地面上「拔起来」（浏览器实跑实证）。

**主体顶的正确口径**（见 §1.2）：`主体顶 = 面积 ≥ A 的墨迹连通簇的最小顶`（A 实测 200 px²）。**快速路径**：若 bbox 顶所在簇面积已达标 ⇒ bbox 顶即主体顶；否则只扫上部区域。**反向坑**：按「行内墨迹像素数 ≥ K」设阈值**过粗**，会把主体稀疏顶部（冠尖 / 羽饰 / 旗尖）切掉 ⇒ 整目录复算差异清单留档，既有资产**人眼判定后再决定是否批量改**，不自动化批量改。

### 2.6 经验沉淀必须入仓（多 Agent 协作仓）

本仓由多个 Agent 会话并行施工，**Agent 私有记忆只有本会话读得到**。沉淀载体分工（W507 上移映射）：

| 类别 | 载体 |
|---|---|
| 规则类 | `AGENTS.md` |
| 批次经验 | `HANDOVER.md`「三、方法论沉淀」 |
| **深度篇** | `docs/10-方法论沉淀/`（本文所在） |

**坑表**（`docs/agent/pitfalls.md`）是**现役必读入口**：条目化（一行一条·含根因与修法），按主题分节；改条目 ⇒ **必须同步各节标题条数与 AGENTS.md / HANDOVER 的计数声明**（门禁 N4 核对「AGENTS 声明数 == pitfalls 实数」）。

### 2.7 判据覆盖面的边界：机器判据只查「暗」，彩色平涂与器物刻字必须靠人眼关

W983 批把这件事测到了底：**J1–J10 全绿 ≠ 画面符合母版段**。

| 母版段约束 | 机器判据覆盖情况 | 实证 |
|---|---|---|
| 画幅 / 顶部留白 / 墨量 / 朱砂有无 / 边框 / 纸色 / 背景均匀 | J1–J10 **覆盖** | 64/64 全绿 |
| **无实心色块填充** | **只覆盖「暗」实心块**（J6 统计暗像素占比）⇒ 彩色平涂（黄袍 / 玄色帝服 / 乌纱帽）**完全逃逸** | 第 26 张 J6 = 0.203 而帝服整片实心黑；第 27 张黄袍整片实心 |
| **不得出现任何文字 / 书法 / 印章** | **不覆盖**（J5 只查朱砂像素 > 0，查不出「有几处」也查不出器物表面的字） | 第 36 张官印印面有红色篆字，且额外多出一处朱砂 ⇒ 打破「仅一处点睛」 |

⇒ **两条硬纪律**：

1. **带颜色词 / 本体承载文字的器物，必须在主体段显式写死**：衣物写「只用墨线勾出衣纹·通体不涂任何实心色块」；印/牌/卷/旗/碑写「表面完全留白·不刻任何字迹·不涂朱砂色」。
2. **人眼关从「题材辨识度」扩到「母版段逐条对读」**：逐张放大核对**平涂、刻字、朱砂处数、背景均匀**四类机器查不出的项；发现即重出，不记例外（W983 批 12 张里 3 张因此重出：#26 / #27 / #36）。

> 一句话口径：**判据管「画得对不对」，人眼关管「画得像不像这一族」；两者都要，且人眼关是硬关不是抽查。**

## 四、修复策略

| 场景 | 动作 | 判据 |
|---|---|---|
| 改既有文本/二进制 | `io.open(p+".tmp","wb")` 写完再 `os.replace(tmp,p)` | 中途失败原文件毫发无损 |
| 写完立刻核对 | `git diff --numstat` | 增删比 ≠ 1:1 且非新增文件 ⇒ 立即查行尾 |
| 检查脚本自证 | 把本批 key 塞进「假想既有集合」 | 检查必须报冲突（否则中止） |
| 判据自证 | 自合成多维负样本 | 一次踩中多条判据，逐条留证 |
| 出图 prompt 器物 | 几何形状 + 排除项 | 形制类别正确（数量偏差可记取舍） |
| 选题 | 先验落位页存在且无题图 | 双向核对表 |
| 主体顶定位 | 连通簇面积法（A=200 px²） | 孤立点滤除·稀疏顶保留·整目录差异清单留档 |
| 沉淀 | 入仓（坑表 / 深度篇 / AGENTS / HANDOVER） | 计数链同步（门禁 N4） |
| 本地起服务 | 先清端口再起·独立进程 + 重定向日志 | curl 200 |
