### 3.3 skill-creator 优化任务卡

#### 任务卡 S-04《渲染等值确定性验收》

- **定义**：对指定页面集合在改动前后生成逐像素等值判定报告。触发条件=「渲染等值/前后对比」类验收；输入=页面清单（相对 site/ 路径）+改动说明；输出=before/after 截图对 + 逐像素 diff 报告 + PASS/FAIL。
- **当前差距**：_w672_shot_equiv.js 已具备能力但为一次性脚本——页面清单硬编码样例、无 CLI 化页面参数文档、确定性口径无自检（当前实现若漏 fonts.ready 无报警）。
- **优化目标**：任意页面清单零代码改动可用；确定性口径五件套内建自检（缺项即 WARN）；单页采集 ≤20s。
- **skill-creator 规格**：目标=把五件套口径固化为工具默认行为；边界=file:// + 拦截外域；输入=pages.txt；输出=PNG 对+diff JSON；步骤=capture×2→diff→报告；依赖=playwright（scripts/node_modules）；约束=不引入网络；异常=CAPTURE-FAIL 单页隔离不中断；验收=对 _w672 已验收 5 页回归 diff 全 0 + 新页面冒烟 3 页成功。
- **执行步骤**：现状分析（0.5d）→ CLI 化改造（0.5d）→ 自检内建（0.5d）→ 试运行（批次四验收实战）→ 评估迭代 → 入库。
- **时间表**：W1 批次四动工日启动，随批次四验收首次实战，批次四收官时定版。
- **责任人**：执行 Agent（改造+试运行）/ 用户（定版拍板）。
- **验收标准**：批次四全部前后对比断言经此工具产出且零假红；自检缺项 WARN 在故意移除 fonts.ready 时触发。

#### 任务卡 S-05《批量修复器生成模板》

- **定义**：从「扫描器判定内核 + 修复规则 + 自断言 + 触达清单输出」四要素生成批量修复脚本。触发=「N 处机械修复」类工作包；输入=方案附录扫描器代码 + 修复规则表；输出=_wXXX_fix_*.py（--dry-run/--apply 双模式）。
- **当前差距**：三批各手写一个（semicolons/orphans/var_drift），共用骨架重复实现三遍；首版两 bug 均出在骨架（注释剥离遗漏、span 重组覆盖）。
- **优化目标**：新修复器脚手架化——骨架一次写对，工作包只填「判定内核引用+规则表」；首版缺陷率降至 0；自动产出触达清单文件（W654 教训）。
- **skill-creator 规格**：目标=骨架模板 + 填空规约；边界=行级文本替换类（结构化解析除外）；输入=冻结扫描器代码+规则表 JSON；输出=修复器+触达清单+自断言报告；约束=CRLF 保持/utf-8 newline=''；异常=定位串不唯一即 FAIL；示例=_w673 双脚本改造回放；验收=用批次四/五的下一个机械工作包实战（首版零假阳性/零覆盖 bug）。
- **时间表**：W1 模板抽取（从三脚本提炼）→ W1-W2 批次四实战 → W2 定版入库。
- **责任人**：执行 Agent / 用户（定版）。
- **验收标准**：实战工作包首版 dry-run 即与方案冻结计数一致；触达清单⊆staged 复核通过。

#### 任务卡 S-06《e2e 探针编写规约》

- **定义**：d3/DOM 交互断言的标准探针写法集（事件类型选择、同步信号、世界/作用域、字体/时序前置）。触发=e2e 断言编写；输入=断言目标描述；输出=探针代码。
