- **OBS-14 首 token 延迟（W844）**：`server/chat.ts` 的 `/api/chat` handler **最前**取 `reqStartedAt`（入参校验与会话读写也属用户等待，靠后计时会系统性低估），首个 **text delta** 记 `firstTokenMs` 并打结构化日志 `问答首 token 计时`（含 `first_token_ms`/`model`/`session_id`）；`sse.init` 是会话元信息帧**不计**；整轮无文本增量（纯工具调用）记 `reason: "no_text_delta"`，**不得把缺样本当 0 ms**。窗口与分位在 `server/metrics.ts`（滚动最近 100 样本·最近秩法 p50/p95·非有限值与负值丢弃），`GET /api/metrics` 只读返回 `{count,window,p50,p95,min,max,sloMs}`，**不落盘不外发**——长期分布看日志，短窗看现网手感。门槛口径：SLO 首 token < 2 s（架构方案 §11.5）**先作告警级**，连续 10 批实测稳定后再议升硬门槛。回归面 `server/metrics.test.ts`（7 例：空窗给 null 不给 0/分位/滚动淘汰/脏数据/取整/重置/快照语义）。
