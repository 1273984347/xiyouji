# 06-个人随笔

> 与 [项目说明](../00-导读/项目说明.md) / [CHANGELOG](../../CHANGELOG.md) / [file-index](../../scripts/output/file-index.md) 配套使用。

---

## 文件命名规范

- 用 `西游与XX.md`（如 `西游与心理学.md`、`西游与生态学.md`）
- 学科名统一，便于跨篇检索
- 文件名关联本次 W### ID

## 双索引链接格式

每篇文档元信息区须含：

- 正向：[CHANGELOG.md](../../CHANGELOG.md) 本次 W### ID 段（四件套：来源/文件/验证/状态）
- 反向：[file-index.md](../../scripts/output/file-index.md) 本文件条目
