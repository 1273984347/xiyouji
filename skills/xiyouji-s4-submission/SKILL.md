# 西游记项目 S4 学术投稿前准备

给 xiyouji 项目（`D:\1\xiyouji`）的学术论文做投稿前硬伤清理的固定流程。每条流程都已在 S4 两篇成稿与 S2 三篇候选上逐字验证过，含多个非显然陷阱（见「陷阱清单」与 `reference.md`）。所有 line 号校核必须「引文能在 text-search.json 里精确命中」为准，不得凭记忆或猜测。

## 何时触发

触发（正向）：

- 用户要求"S4 投稿准备"、"投稿前检查"、"投稿前硬伤修复"、"学术投稿准备"。
- 用户说"line 号复核 / 校验"、"生成匿名稿 / 盲审稿"、"补英文摘要"。
- 用户要求"方法论转论文"、"内容改写"、"删生产指标"、"孤儿行号重定位"、"参考文献纠错"、"去 W### 列"。
- 对 `docs/S4-学术投稿/` 成稿或 `docs/S2-学术投稿/` 候选做投稿前的任何技术性清理。

排除（反向）：

- 纯选题讨论、纯润色（不涉及方法论→论文改写、line 号、匿名化的），不强制走本流程。
- 版本 bump / 六文档同步（那是 `xiyouji-version-bump` 技能，与本流程无关，二者不要混用）。

## 前置条件

- 项目在 `D:\1\xiyouji`，git 分支 `main`，remote `origin`。
- 目标论文在 `docs/S4-学术投稿/`（成稿）或 `docs/S2-学术投稿/`（候选）。
- 权威检索数据：`dataset/text-search.json`（JSON，`chapters[]` 每章含 `num`/`title`/`fullTitle`/`text`）——这是**唯一可靠**的验证数据源。
- ⚠️ `scripts/audit/line_check.py` 已失效（它读的 `site/data/text-search.html` 内嵌语料已迁出页面，运行返回 `CHAPTER_NOT_FOUND`）。验证一律改用内联 Python 读 text-search.json，或用同目录批量脚本 `verify_anchors.py`（命令见 `reference.md`「验证方法」/「批量校验脚本」）。
- 已删除的 `source/原文/西游记-全文.txt`：历史论文（如中国文论候选）的 line 号可能引用它，属「孤儿行号」，需重定位（见 `reference.md` 第 9 节）。
- 详细技术说明、精确匿名化映射表、残留检查 grep 模式、方法论→论文改写映射，见同目录 `reference.md`——执行前必读。

## 标准流程（六阶段）

严格按顺序执行。阶段一（方法论→论文改写）与阶段二（line 号）是硬门槛，未过不准进入阶段四（匿名稿）。

### 阶段 0：定位目标论文

确认目标论文路径与当前状态。若用户未指定，默认先处理 `docs/S4-学术投稿/` 下的成稿（心学、驿递两篇），再考虑 `docs/S2-学术投稿/` 候选。

### 阶段 1：方法论→论文内容改写（硬门槛）

把「方法论总结体」改成「有论断的研究论文体」，这是 S2 候选（尤其带 W### 编号、生产指标密集的那些）投稿前的必要前置。五步按序做：

1. **删生产指标**：删掉「产出 N 篇专题 / N 位理论家 / N+ 锚点 / 对应 N 篇人物文档 / W### 文档」这类项目生产指标，改成「由此得出什么实质发现」。
2. **摘要/结论改框架**：摘要从「提出 XX 方法论」改成「提出研究问题 + 研究发现」；「方法论价值」章节改「讨论与价值」；去掉「S2 第 X 篇续篇」等自我指涉，全局改「此前研究」。
3. **去完整版表格 W### 列**：完整版（非匿名稿）表格里若有 W### 列（如 W237/W238 项目内部编号列），投稿前也要去掉——匿名稿虽已剥离，但完整版直接投同样暴露项目痕迹。
4. **纠错参考文献**：逐条核对参考文献是否与引用主题匹配，剔除张冠李戴（如把记忆研究文献误当性别研究文献）。
5. **孤儿行号重定位**：若论文 line 号来自已删除文件（如 `source/原文/西游记-全文.txt`），属孤儿行号——先把「line 号来自 xxx 文件」的表述改成「逐回全文检索文本库」，再进阶段 2 用 `verify_anchors.py` 把孤儿行号重定位到单回口径。

详细映射与案例见 `reference.md` 第 9 节。

### 阶段 2：line 号全量校核（硬门槛）

先判定口径，再逐条验证，最后修。

1. **判定口径**：读论文全文，抓出所有 `第 N 回 line X` 或 `line X` 锚点。若 X 是大数字（如 1459 / 4378 / 4432），是「全书累计行号」口径，很可能已崩坏；若 X 是 1~99 的小数字，是「单回内行号」口径（正确口径，以 text-search.json 的 `text` 按 `\n` 拆行、1-based 定义）。
2. **逐条验证**：每条锚点都要在 `dataset/text-search.json` 的对应回 `text` 字段里精确命中引文。用内联 Python 或 `verify_anchors.py batch` 批量验证（命令见 `reference.md`「验证方法」/「批量校验脚本」）。仓库内文档若使用 `> 原文引文（第N回）：“…”` 引文块格式（文档规范 §4.8），直接跑 `python scripts/check_citations.py --file <文件>` 核验（W503 第 20 门禁同款脚本，去空白归一后精确子串匹配）。
3. **回目陷阱**：回目标题（如"心猿归正 六贼无踪"）只存在于 `title`/`fullTitle` 字段，**不在 `text` 正文里**，因此「回目 + line 号」这个组合本身不成立。凡指向回目的锚点，一律删掉 line 号，改写成「第 N 回回目『…』」形式。
4. **孤儿行号重定位**：承接阶段 1 第 5 步，对引用已删文件的孤儿行号，用 `verify_anchors.py locate/batch` 按「回号 + 关键词」重定位到单回口径。
5. **统一口径**：所有锚点统一为「第 N 回 line X + 原文精确引文」；无法精确命中的诠释性表述（如"大鹏占城、文牒无处可验"），要么补原文精确引文，要么从「关键文本锚点」挪到正文解读段，不要硬凑 line 号。

### 阶段 3：补英文标题 / 摘要 / 关键词

在 `**关键词**` 行之后追加三行（多数核心刊硬性要求）：

```
**English Title**: ...

**Abstract**: ...

**Keywords**: ...
```

英文摘要要与中文摘要语义对齐，不是机翻；专名按学科惯例（如 *Journey to the West*、Wang Yangming、*tongguan wendie*）。

### 阶段 4：生成匿名盲审稿

程序化剥离，不手工重抄（手工易漏、易错）。对每篇完整版生成 `-匿名稿.md`：

1. **剥头部 blockquote**：删除标题与首个 `---` 之间所有 `> ` 开头的元信息行（W###、v 版本号、创建于、投稿目标、与…构成关系的内部说明）。保留标题、`---`、摘要起。
2. **剥「关联文档」段**：删除文末 `## 关联文档` 及其后全部列表项。
3. **替换项目专属表述**：按 `reference.md` 的「匿名化精确映射表」逐条替换，重点是 `text-search.html` / `line_check.py` / `本项目` 三个项目工具名 → 通用学术表述。
4. **保留**：英文 Title/Abstract/Keywords（投稿标准要素）；方法论术语（`line 号锚点`、`通关文牒叙事数据集`）可保留，它不是项目痕迹。

### 阶段 5：残留检查 + 收尾

```bash
cd /d/1/xiyouji && grep -nE "W[0-9]{3}|v[0-9]\.|创建于|投稿目标|关联文档|本项目|text-search|line_check|\.md|S4|S2|W386" "docs/S4-学术投稿/"*匿名稿.md
```

必须输出「无残留」。然后 git 提交：

```bash
cd /d/1/xiyouji && git add "具体文件路径" && git commit -m "..." && git push origin main
```

commit message 用 `fix(s4): ...` 或 `feat(s4): ...` + 要点列表，只 `git add` 本次改动的具体文件（不用 `git add .`，避免误提交工具脚本）。

## 陷阱清单

- **两套 line 号口径混用**：单回内行号（小数字，正确）vs 全书累计行号（1459/4378/4432 等大数字，常崩坏）。同篇论文若混用，逐条重做。判定与示例见 `reference.md`。
- **回目不在 text 正文**：回目标题在 `title`/`fullTitle` 字段，`text` 字段只含正文（不含回目），所以「第 14 回 line 1459 回目『心猿归正』」这种锚点永远无法命中，必须改成「第十四回回目『心猿归正 六贼无踪』」。
- **诠释 ≠ 引文**：「文牒无处可验」是论文自己的解读，不是原文引文，无法挂 line 号。硬挂会制造假精确。
- **生产指标未删**：正文仍留「产出 N 篇专题 / N 位理论家 / N+ 锚点」等生产指标，是「方法论总结」而非「论文」。投稿前必须清。
- **自我指涉残留**：「S2 第 X 篇续篇」「本项目提出方法论」这类自我指涉，匿名稿即使剥了 W### 也还露馅，要全局改「此前研究」「研究发现」。
- **误引文献**：参考文献张冠李戴（如把诺拉《记忆之场》当性别研究文献），投稿前逐条核对引用主题与文献一致。
- **孤儿行号未重定位**：line 号指向已删除文件（`source/原文/西游记-全文.txt`），无法复核，必须重定位到单回口径（text-search.json）。
- **匿名稿 3.1 标题不动**：`### 3.1 line 号锚点体系` 是方法论术语，保留；只改正文第一句里的项目工具名。
- **手工重抄匿名稿**：容易漏删 W### 或改坏引文，务必程序化（脚本剥离 blockquote + 替换映射），改完 grep 验证。
- **英文摘要机翻**：要语义对齐中文摘要，专名按学科惯例，不是逐句直译。
