# 四家族模板（来自线上真实文件）

## 1. 基础七段（de-facto 模板，人物主档案）

结构：H1 → blockquote 元信息 → `一、出处与身世` … `六、…` → footer 双索引。
段顺序（按线上 41 篇基础人物）：出处与身世 / 性格弧线 / 关键情节 / 关系网络 / 主题意义 / 人物评传（各篇略有差异，保持"一~六 + 双索引"即可，不必强求完全同名）。

```markdown
# 孙悟空

> 轨标：教学讲解
> 人物类别：取经团队 · 第一大弟子
> 数据指标：出场 100 回（全书），总提及 ~5000 次（待全量数据验证）

## 一、出处与身世

### 诞生
孙悟空由东胜神洲傲来国花果山山顶一块仙石孕育而生。……（引原文+回目）

### 封号演变
| 阶段 | 封号 | 性质 | 出处 |
|---|---|---|---|
| 出世 | 石猴 | 自称 | 第 1 回 |
…
```

footer 双索引（收尾）：
```markdown
## 双索引
- 正向：[CHANGELOG.md](../../CHANGELOG.md) W### 段
- 反向：[file-index.md](../../scripts/output/file-index.md) 本文件条目
- 关联：[人物谱系表.md](人物谱系表.md) · A1：[第NNN回](../../01-全书逐回解读/第NNN回-*.md)（如适用）
```

## 2. 外传（文学创作）

命名：`<人物>外传.md`。元信息含"来源：人物X.txt 章节"（素材来源），正文为长篇散文。

```markdown
# 白骨精·外传：那具白骨在遇见取经人之前

> 轨标：个人创作
> 来源：人物七.txt 章节 "白骨精·外传：那具白骨在遇见取经人之前"
> 双索引链接：
> - 正向：[CHANGELOG.md](../../CHANGELOG.md) W285 段（待补）
> - 反向：[file-index.md](../../scripts/output/file-index.md) 本文件条目（待补）
```

要求：允许文学想象与心理铺陈，但**不与原著事实冲突**；可以加"设定注"区分想象与原文依据。

## 3. 深化专题（学术向）

命名：`<人物>深化专题.md`。元信息 W 溯源式 + `一、范围界定` + 理论框架 + 多节分析。

```markdown
# 孙悟空深化专题

> W156·A3 方向第 10 个深化专题（取经五众深化系列第 1 篇）
> 基于孙悟空身份政治变迁素材
> 创建于 2026-07-28（v2.2.9 取经五众深化系列第一篇）
> 与 W152 天庭体系深化 + W148 地府体系深化 + W144 边缘神祇深化形成"天庭-地府-边缘-取经五众"体系

## 一、范围界定

> "那猴在山中，却会行走跳跃……"——第一回（石猴出世）

《西游记》的孙悟空不是单一的"英雄形象"，而是一部**身份政治的活体编年史**……（引用身份政治理论家）
```

要求：原著引文标注回目；引入理论框架（身份政治/叙事学/比较文学等）；与既有深化专题建立显式互链（"承接 W152…"）。

## 4. 方向二深化（长篇创作散文）

命名：`<人物>-方向二深化.md`。元信息同外传（轨标：个人创作 + 来源 + 双索引），正文为长章节散文。

```markdown
# 二郎神：听调不听宣的孤独者

> 轨标：个人创作
> 来源：人物二.txt 章节 "二郎神：听调不听宣的孤独者"
> 双索引链接：…（同上）
```

正文用 `一、…` `二、…` 分节（如"劈山救母：不靠编制活下来的孩子"），叙事+评论交织。
