# 创意方法速查（外传 / 方向二 / 随笔创作）

> 与 docs/10-方法论沉淀/ 两篇（人机创意工作流方法论 / 创意三明治工作流）配套，本文是可操作速查版。
> 写前完整理解见仓库：`docs/10-方法论沉淀/创意三明治工作流.md`

## 何时用

- 外传 / 方向二 / 随笔需要新角度（用户要求"有创意""角度新""写点不一样的"）
- 深化专题选题枯竭，需要新切入点
- 默认不用：基础七段（主档案走规范模板）

## 方法一：反向约束提示词（认知摩擦）

强制 AI 从违背常识的角度写大纲，人类被"荒谬"角度刺痛后产生原创视角。

```
对【情节/人物】写大纲，但必须从以下刁钻角度各写一版：
- 反派是受害者 / 主角动机是自私的 / 事件是政治秀 / 一切是个误会
每版 150 字，只写情节骨架，不评判。
```

示例：三打白骨精 → "白骨精是受害者""唐僧是刻意驱赶"。只取可考据的种子，其余弃用。

## 方法二：跨时空强制嫁接

```
把【西游元素】映射到【非关联领域】，输出 5 个类比框架：
- 九九八十一难 = 产品迭代的 81 次用户反馈
只列映射关系，各 1 句话。
```

项目既有范例："王阳明与唐僧心学对照专题"。新选题参照："取经团队 ↔ 现代组织""妖怪体系 ↔ 地缘博弈"。

## 方法三：幻觉驱动暗线（必须标注）

故意让 AI 编"隐藏剧情"，经考据后作为"学术猜想/同人蓝本"输出。

```
【人物A】和【人物B】私下可能是什么关系？【地点】之前是谁的地盘？
基于原著缝隙猜 5 个版本，每个标注可支撑的回目线索。
```

红线：产出**必须标注"学术猜想/同人蓝本，非原著事实"**；至少 1 处回目线索；不得与正典冲突。

## 方法四：创意三明治（完整四步）

> **协议单一事实源**：完整四步协议（含各步硬要求与数字阈值）见 [SKILL.md「创意三明治管线」章节](../SKILL.md)——本表仅为速查摘要，与 SKILL.md 冲突时以 SKILL.md 为准（W507 去重：曾与 SKILL 管线章节数字不一致，已统一为指向）。

| 步 | 动作 | 产出 |
|:---:|:---|:---|
| 1 AI 发散 | 生成极端/跨界/荒谬切入点（≥20，见 SKILL 管线章节） | 角度清单 |
| 2 人类收敛 | 挑 ≤3 个"有刺痛感"的种子，手写骨架 | 人味骨架 |
| 3 AI 补全 | 扩写为多版本，标注回目出处 | 2-3 版扩写稿 |
| 4 人类裁决 | 逐句修改，加"闲笔/破绽/留白"，Grep 验证回目 | 终稿 |

完整提示词模板见 `docs/10-方法论沉淀/创意三明治工作流.md` §三。

## 红线（不可越）

1. 外传/方向二产出**必须标注"外传创作"**，不得冒充正典。
2. 核心设定不得与原著矛盾（Step 2 收敛时淘汰冲突种子）。
3. 引文/回目必须真实——AI 补全易引入幻觉，裁决时必须 Grep 逐条验证（E1 铁律）。
4. 产出后走本 skill 的 Step 4 质量门禁（元信息块、双索引、verify_delivery 全绿）。
