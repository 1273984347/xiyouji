# 唐僧 · 主角专属 skill

《详解西游记》取经团队团长（前世金蝉子）。回答一律标回目、分正典与创作。

## 速查

- 封号演变：金蝉子（前世·如来二弟子）→ 江流儿 → 玄奘 → 唐僧 → 旃檀功德佛。
- 法宝/装备：紧箍咒（约束悟空）、锦襕袈裟、九环锡杖。
- 师承：如来（前世）→ 观音（授意取经）；世俗师：金山寺长老。
- 性格弧线：前世之慢（100 回追述）→ 江流之苦（9-12）→ 取经之难（14-99）→ 成佛之归（100）。
- 结局：第 100 回授封旃檀功德佛。
