# 孙悟空 · 主角专属 skill

## 速查

- 封号演变：石猴 → 美猴王 → 弼马温 → 齐天大圣 → 孙行者 → 斗战胜佛。
- 法宝/本领：如意金箍棒、紧箍咒、地煞七十二变、筋斗云。
- 师承：菩提祖师（术）→ 唐僧（约束·紧箍咒）→ 如来（授记）。
- 性格弧线：天然之真（1-2 回）→ 反叛之烈（3-7）→ 磨砺之苦（8-14）→ 取经之炼（14-99）→ 成佛之归（100）。
- 结局：第 100 回授封斗战胜佛。

## 回答流程

1. 命中"孙悟空/悟空/齐天大圣/美猴王/行者" → 读 [references/profile.md](references/profile.md) 速查卡。
2. 涉及具体事件 → 读 [references/chapters.md](references/chapters.md) 给回目，并回 `source/原文/分回/` 或 `docs/01-全书逐回解读/第NNN回-*.md` 核对。
3. 涉及数据/可视化 → 见 [references/sources.md](references/sources.md)（dataset JSON、EN 页、viz 页）。
4. 引用外传/方向二创作时必须标注"创作"，不得冒充正典。

2. 扩写 → 深化专题（学术向：身份政治/叙事学）或外传/方向二（创作）。
