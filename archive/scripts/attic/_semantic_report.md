# 语义级数据核验报告（2026-08-06）

> 范围：对 `dataset/` 42 个结构化数据集做"语义级"核验——数据是否准确、有无编造/丢失、
> 是否能追溯到《西游记》原著依据。配合本轮"49 处数字刻度轴精修"一并交付。

## 一、数据链路与核验方法

`dataset/*.json` 并非独立生成，而是 `site/data/*.html` 内 `EMBEDDED_DATA` 的**导出副本**
（README 明示，由 `scripts/extract_datasets.js` 于 2026-08-02 提取）。真实链路：

```
dataset/*.json  ←  site/data/*.html 的 EMBEDDED_DATA
                 ←  (scripts/A_~X_*/ 下 Python 构建脚本  或  HTML 内直接定义)
                 ←  source/原文/分回（100 回，740,192 字）+ 项目原创分析标注
```

自动化核验分三层：
- **T6 内部自洽**：全量扫描 42 JSON 的结构合法性（NaN/Inf、非法负数、网络节点-边引用断裂）
- **T4 可追溯性**：为每个数据集定位构建出处（独立 py 脚本 / HTML 内嵌原创标注）
- **T7 抽样对照原文**：对高曝光图表（角色、八十一难、洞府）抽取关键数据点，在 100 回原文中检索依据

> 边界：自动化核验证明"结构自洽 + 抽样有据"。逐图表全量原文核（即重做全文统计）超出自动化范围，
> 如需可单独启动；本报告把"需人工校对"项明确列出而非假装覆盖。

## 二、内部自洽性（T6，全量 42 JSON）

扫描全部数值字段与网络引用：
- **NaN / Infinity：0 处**
- **结构性负数（非语义）：0 处**
- **网络节点-边引用断裂（link.source/target 不在 nodes）：0 处**

仅 4 个负值，经核验均为**合法语义值**，非错误：
- `concept-device/detective/candidates[2]/rot = -1` —— 旋转角度，允许为负
- `intertextuality-network/.../年份 = -400 / -500` —— 公元前纪年，负数即"公元前"

**结论：42 个数据集内部逻辑自洽，无任何非法值、无悬空引用。**

## 五、脚本一致性（T5，边界说明）

  可重跑脚本比对（需 source 原文路径环境）。本次未全量重跑，列为**可选深化项**。
