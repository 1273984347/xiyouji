# O3 契约对账门禁评估（W577 复盘报告 WBS 表 O3·W583 落地）

> 创建：2026-09-19。评估问题：生成器 schema vs 页面消费字段的字段级对账——**并入第 25 门禁还是独立新门禁？**
> 结论先行：**以「运行时契约冒烟」实现为独立 CI step（挂 dark-state-gate job）**，字段级静态对账否决。

## 1. 三个候选方案对比

| 方案 | 做法 | 判定 |
|---|---|---|
| A. 字段级静态对账（第 25 门禁扩展） | 正则/AST 提取页面 JS 消费的字段路径，对 dataset/生成器输出 schema 断言存在性 | **否决**——W560 实证静态解析只覆盖 17/38 页（无引号键/尾逗号/模板字符串），动态访问与可选链误报面不可控；第 25 门禁为静态同页数字矛盾检查，塞入运行时语义会破坏其确定性口径 |
| B. 运行时字段级对账 | Playwright 读取页面全局数据对象，与 dataset/ 对象键集合 diff | 部分可行但依赖全局变量名（EMBEDDED_DATA 仅 46/86 页使用·其余页面各异），键集合 diff 需逐页白名单——维护成本高于收益，**列为远期** |
| C. 运行时产量冒烟（**采纳**） | file:// 加载全部含 svg 页面：pageerror==0 + svg 图形产量 ≥ 基线×50% | 端到端无解析：契约错位的两种症状（运行时 TypeError、静默零渲染——W565 character-appearance 0/0 实证形态）均被覆盖；file:// EMBEDDED 路径与暗色门禁的 http 路径**互补成双路径覆盖** |

## 2. 实现（方案 C）

- `scripts/check_contract_smoke.js`：163 页（zh+en 含 svg 口径）file:// 滚动穿透加载；
  判定 pageerror==0（阻断）+ 图形产量塌方（<基线×50%，阻断）；基线 `scripts/output/contract-smoke-baseline.jsonl`。
- 挂载：dark-state-gate job 内新增 step（file:// 无需 http server·与既有步骤共用环境）。
- 验证：`--self-test` 6 负样本 6/6；实弹负样本（构造 EMBEDDED_DATA.config 缺失页→pageerror→门禁 FAIL→移除）拦截实证；全量跑批 163 页全绿（基线已生成）。
- 回滚：删除 step 即回滚。

## 3. 残余边界（如实）

- 产量基线是「不塌方」守门，不校验数据内容正确性（内容一致性仍归第 25 门禁/L2 对账）；
- 50% 阈值对「合法的半页图表」页面可能误报——当前 163 页基线全量实测无边界页，后续如出现以 --update-baseline 显式刷新并记录原因。
