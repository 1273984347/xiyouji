# v0.7 审查 + v0.8 落地 推进计划

> 轨标：教学讲解
> 创建日期：2026-07-21
> 覆盖范围：全站综合推进（v0.7 现有 35 页质量审查与修复 → v0.8 弹幕博物馆 3 页落地）
> 方法论：writing-plans skill 规范 + 用户铁律三 skill 闭环（DRL → mem-wrap-up → self-evolution）+ preflight interface analysis + scope-lock

**Goal:** 在不破坏 v0.7 现有 35 个可视化页面可用性的前提下，完成全站质量审查与修复（DRL 真收敛），并落地 v0.8 弹幕博物馆 3 个新 HTML 页面 + dashboard 卡片入口，使项目从 v0.7 升级到 v0.8。

**Architecture:** 两阶段串联。Phase A 用 Chrome DevTools MCP + DRL skill 做审查→修复→重新审查循环，直到真收敛（连续 N 轮 0 新问题）。Phase B 用 pm-spec → 写 HTML（沿用 EMBEDDED_FALLBACK 模式 + 宣纸风 CSS 变量）→ dashboard 追加入口 → 再次 DRL。两阶段之间执行 mem-wrap-up + self-evolution 完成三 skill 闭环。

**Tech Stack:** HTML5 / CSS3（CSS 变量）/ 原生 JS / D3.js v7（CDN）/ Chrome DevTools MCP / deep-review-loop skill / pm-spec skill / executing-plans skill（含 preflight + scope-lock 子步骤）
