## PRD 规格（3 页）

### 页面 1：cross-time-danmaku.html（跨时空弹幕博物馆主页）

**目标用户**：全年龄段（幼儿/小学、初中、高中、大学）
**交互模块**（3 个，对应 CHANGELOG 模块 1+5+6）：
1. **四层全年龄弹幕墙**：4 个年龄段 tab 切换，每个 tab 显示对应内容卡片网格（D3 渲染）
2. **当代打工人嘴替板块**：金圣叹反内卷 + 八戒人间清醒 2 张大卡片
3. **留言博物馆**：用户输入留言 → localStorage 存储 → D3 渲染到"读者弹幕墙"，完成"读者→批评家"身份转换

**数据维度**（8 维）：
- 名人档案（id/name/era/role/quote/modern_translation/suitable_age/historical_detail）
- 年龄段内容（age_group/title/form/content）
- 嘴替语录（character/role/quote/modern_translation）
- 用户留言（user_content/timestamp/age_group_tag）

**视觉规范**：复用 F4 CSS 变量 + F7 hero 渐变 + F8 noscript

### 页面 2：century-dialogue.html（世纪对话动态海报）

**目标用户**：高中+（涉及政治隐喻与学术论争）
**交互模块**（2 个，对应 CHANGELOG 模块 2）：
1. **三方主旨会谈**：李卓吾 vs 胡适 vs 毛泽东，3 个语音气泡 + CSS 动画依次浮现 + D3 force layout 摆位
2. **角色圆桌讨论**：议题"如何评价猪八戒"，八戒画像中心 + 3 位名人观点环绕（v0.8 仅含 1 议题，结构预留 click 切换扩展位，后续版本可追加 topic）

**数据维度**（8 维）：
- 三方会谈（speaker/position/argument/quote/era）
- 圆桌议题（topic/participants[]/views[]）

**视觉规范**：同上

### 页面 3：famous-time-travel.html（名人穿越入戏）

**目标用户**：全年龄（含插画吸引低龄）
**交互模块**（2 个，对应 CHANGELOG 模块 3+4）：
1. **6 位名人穿越卡片网格**：每卡正面身份 + hover/click 翻转显示穿越身份 + 会做的事
2. **2 个入戏场景插画区**：纯 SVG 绘制（鲁迅地府线稿 + 钱钟书纠错信明信片），无 `<img>` 标签

**数据维度**（8 维）：
- 穿越身份（celebrity_id/original_role/travel_role/would_do）
- 入戏场景（scene_id/character/setting/judgment/svg_description）

**视觉规范**：同上 + 卡片翻转用 CSS `transform: rotateY(180deg)` + `backface-visibility: hidden`

const fetchStatus = { anyFetched: false };
async function fetchJson(path, fallbackKey) {
    try {
        const response = await fetch(path);
        if (!response.ok) throw new Error('fetch failed: ' + path);
        fetchStatus.anyFetched = true;
        return await response.json();
    } catch (e) {
        console.warn('[INFO] 使用嵌入数据 (' + fallbackKey + ')：', e.message);
        return EMBEDDED_DATA[fallbackKey];
    }
}
async function loadData() {
    const base = '../../scripts/output/data/';
    const [profiles, ageGroups, mouthpiece] = await Promise.all([
        fetchJson(base + 'v08_celebrity_profiles.json', 'celebrity_profiles'),
        fetchJson(base + 'v08_age_groups.json', 'age_groups'),
        fetchJson(base + 'v08_mouthpiece.json', 'mouthpiece_quotes')
    ]);
    return { profiles, ageGroups, mouthpiece };
}
async function main() {
    const data = await loadData();
    window.__lastData = data;
    // fetchStatus 读取：更新数据源提示（与 F6 骨架一致）
    if (fetchStatus.anyFetched) {
        document.getElementById('dataSource').innerHTML =

    renderMouthpiece(data.mouthpiece);
    renderMessageWall();
}
let resizeTimer;
window.addEventListener("resize", () => {
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(() => {
        if (window.__lastData) {
            renderDanmakuWall(currentAgeGroup, window.__lastData.ageGroups);

});
