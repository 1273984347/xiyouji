## 项目定位

本项目以「**一源多形**」的方式组织《西游记》的解读工作：

- **源（Source）**：原著文本、引用与网络解读汇集
- **文档（Docs）**：以 Markdown 写就的逐回解读、人物分析、主题专题、文化背景、诗词赏析、个人随笔
- **站点（Site）**：可浏览的 HTML 页面，含导航、时间线、人物关系图等
- **脚本（Scripts）**：Python 文本分析工具，做词频、章节摘要、人物关系图等计算
- **时间线（Timeline）**：取经路线、大事年表、人物时间线
- **资源（Assets/References）**：图片、地图、字体、参考文献

**数据可视化特色**：所有数据维度均配套 D3.js 可视化页面，采用古典宣纸风配色（#faf7f2/#c8463a/#3a6b8c），含折线图、柱状图、桑基图、雷达图、散点图、饼图、热力图、矩阵图等多种图表类型，所有页面均支持 `file://` 协议直接打开（fetch + 嵌入式 fallback 数据模式）。

**术语速查**：阅读中遇到"心猿""木母""黄婆"等内丹术语或佛教、道教专有名词，参见 [术语表](docs/00-导读/术语表.md)。

**学术引用**：如本项目对您的研究有帮助，请按 [CITATION.cff](CITATION.cff) 中的格式引用；学术参考文献见 [学术论文索引](source/引用与网络解读/学术论文索引.md)。

## 使用方式

### 阅读文档

直接在 `docs/` 下浏览 Markdown 文件即可。建议从 `docs/00-导读/` 开始。

### 浏览站点

在 `site/` 目录下双击 `index.html` 或 `dashboard.html` 即可在浏览器中打开（纯静态，无需服务器）。所有数据可视化页面均支持 `file://` 协议直接打开。

### 运行分析脚本

```bash
cd scripts
pip install -r requirements.txt
python word_frequency.py --input ../source/原文/西游记-全文.txt --output output/data/word_freq.json
```

### 截图审查

项目内置增强版截图审查流程，用于在发布前自动发现布局偏移、截断、表格溢出等问题：

```bash
# 1. 安装依赖（Node ≥ 18 + Python 3.8+）
cd scripts
npm install          # 自动安装 playwright 并下载 chromium
pip install -r requirements.txt   # Pillow 用于切片

# 2. 批量截图 + 布局断言 + 自动切片（默认输出到 output/screenshots/）
npm run screenshots
# 或自定义输出目录
node batch_screenshots.js --output-dir ./my-screenshots

# 3. 仅运行静态表格扫描（双轨检查之一）
python detect_unwrapped_tables.py

# 4. 仅重新切片（不重跑截图，需指定截图所在目录）
python slice_screenshots.py --output-dir output/screenshots --slice-height 800

# 5. 查看报告与切片（路径相对于 scripts/ 目录）
# - output/screenshots/layout-audit-report.md   ← 风险页面汇总
# - output/screenshots/screenshot-summary.md    ← 截图耗时/控制台错误/布局异常总表
# - output/screenshots/slice-index.md           ← 切片索引
# - output/screenshots/slices/{desktop,mobile}/ ← 800px 高度 PNG 切片
```

审查采用"化整为零 + 双管齐下 + 像素级检查"：先读结构化报告定位风险页，再查看对应切片进行人工确认。详细收敛记录见 [scripts/output/drl-screenshot-review.md](scripts/output/drl-screenshot-review.md)。

### E2E 测试（v2.2.27 W204 新增）

项目内置三层 Playwright E2E 测试体系，覆盖 63 个 HTML 页面的可用性、5 个关键页面的交互行为、5 个关键页面的视觉回归：

```bash
cd scripts
npm install          # 确保 playwright + chromium 就绪

# 1. 冒烟测试：扫描全部 63 页面（site/data/*.html + dashboard + index）
#    验证 file:// 可打开 + 无 JS 错误 + 关键元素存在 + D3.js 已加载
npm run test:smoke

# 2. 深度交互测试：5 关键页面 17 交互用例
#    dashboard(filter-tab + 搜索) / index(导航卡片) /
#    narratology-13d-network(力导向图 + tooltip) /
#    chapter-stats(图表 hover) / timeline(era 过滤 + 事件 hover)
npm run test:deep

# 3. 视觉回归测试：5 关键页面 desktop 截图 baseline 管理
#    首次运行需生成 baseline：
npm run test:visual:update
#    后续运行对比当前 vs baseline（文件大小差异阈值 15%）：
npm run test:visual

# 4. 串联运行冒烟 + 深度（不含视觉回归）
npm run test:e2e
```

测试脚本位于 [tests/e2e/](tests/e2e/)，baseline 截图位于 [tests/e2e/baseline/](tests/e2e/baseline/)。file:// 协议下 Fetch API 失败为预期行为（项目使用 EMBEDDED_DATA fallback），测试脚本已过滤此类预期错误。

## 写作风格约定

本项目采取「**双轨写作**」：

1. **大众普及轨**：语言通俗，重故事性与现实映射
2. **学术研究轨**：语言严谨，引经据典，注版本对比

每篇文档开头以 `>轨标：大众普及 / 学术研究 / 教学讲解 / 个人创作` 标明轨别，便于读者按需选择。
