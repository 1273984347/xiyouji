## 收录说明

本文件汇编优秀的网络《西游记》解读文章，含原文链接与存档位置，作为本项目解读的外部参照与延伸阅读。

**收录标准**：
- 学术普及类：学者博客、公众号文章、知识社区长文（有学术依据但面向大众）
- 影视解读类：西游记影视改编的深度解读（86 版央视、动画、电影等）
- 游戏改编类：西游题材游戏的解读（《黑神话：悟空》等）
- 网络随笔类：有独到视角的网络随笔（非学术但有洞见）

**收录字段**（每条）：
- 编号 / 作者 / 标题 / 来源平台 / 原文链接 / 发布日期 / 存档位置 / 收录理由

**存档原则**：网络文章易失联，收录时同步存档到 `source/引用与网络解读/存档/` 下（PDF 或 Markdown 快照），存档文件名格式 `NXX-作者-标题简写.md`。

**不收录**：学术论文与专著（见 [学术论文索引.md](学术论文索引.md)）、纯营销水文、无独到视角的复述。

## 收录流程

1. **发现**：日常阅读或用户推荐发现优质网络解读文章
2. **评估**：按收录标准判断是否收录（学术依据/独到视角/非营销水文）
3. **存档**：存档到 `source/引用与网络解读/存档/` 下，文件名 `NXX-作者-标题简写.md`
4. **登记**：在本文件对应分类表格中登记编号/作者/标题/来源/链接/日期/存档/收录理由
5. **关联**：若本项目某篇 docs 引用了该文章观点，在 docs 中补充引用链接

## 编号规则

- N01-N99：按收录顺序编号
- 跨分类不重新编号（N01 可能是学术普及，N02 可能是影视解读）
