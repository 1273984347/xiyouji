# tmpe — 本地临时文件区契约

> **W737 后建（2026-10-14）**。本文件是 `tmpe/` 的唯一权威约定；与 `archive/README.md` 共同界定「退役件入库、过程件可弃」两条线。

## 1. 定位（与 archive 的本质区别）

| | `archive/` | `tmpe/` |
|---|---|---|
| 性质 | **退役入库件**——有引用价值，永久保留 | **过程产物**——使命终即可弃 |
| git | 跟踪（git mv 归位·file-index 登记） | **gitignore 未跟踪**（本地私有·任何会话可写） |
| 台账 | 必须登记（archive/README.md） | 不建台账（建了就是给垃圾办博物馆） |
| 检索 | 引用写新路径，按名/号可查 | 靠桶目录约定 + `scripts/tmpe_tidy.py` 盘点 |
| 清理 | 禁删（只增不删） | **到期列清单→主人确认→回收站** |

**一句话**：archive 是博物馆，tmpe 是工地——工地需要的是「材料分类堆放 + 完工清场流程」，不是档案学。

## 2. 桶约定（新建文件归桶·历史件见盘点报告）

| 桶 | 放什么 | 保留策略 | 清理触发 |
|---|---|---|---|
| `w###/` | 某 W 批次的工作件（spec 草稿、级联清单、一次性脚本、消息稿） | 该批施工期 | 批收官 + 下批开工时，经主人确认整桶清 |
| `_bak/` | 文档备份（docx/pdf 投稿稿的备份代） | 最近 2 代 | 出现第 3 代时，主人确认删最老 |
| `_shot/` | 审查中间产物（截图 png、review pdf、ocr 产物） | 30 天 | 超龄列清单，主人确认 |
| `_profile/` | 浏览器/工具 profile（edge_cdp 等可再生配置） | 0 天 | 主人一句话即清 |
| `_misc/` | 顶层散件收容（一次性 py/txt/log/yml） | 90 天 | 超龄列清单，主人确认 |
| `review/` 等既有热目录 | **并行会话可能正在使用** | 冻结 | 主人显式点名才动 |

## 3. 清理纪律（个人文件安全铁律）

1. **任何清理必须先列清单**（`python scripts/tmpe_tidy.py --plan` 或 --plan --older 30），逐条展示，主人确认后才执行；
2. 删除走**回收站**（PowerShell 移 `$Recycle.Bin` / 资源管理器），**禁 `rm -rf`、禁 `del /S /Q`**；
3. **docx/pdf 个人稿件（投稿稿/匿名稿/装饰稿）永不自动清**——属个人文件，只按 `_bak/` 代际规则由主人处置；
4. **活跃冻结区**（近 48 小时有写入的目录）一律不碰——并行 主会话与本地工作流共用本区（W737 即由并行会话经本区完工）；
5. 每批 ≤10 个文件/目录，批间验证，失败即停。

## 4. 工具

`scripts/tmpe_tidy.py`（W737 后建）：
- 盘点（默认）：按桶规则分类统计 + 超龄报告 + 活跃冻结区告警
- `--plan` / `--plan --older N`：生成迁移/清理计划清单（不执行）
- `--apply`：执行迁移（只移动不删除·删动作一律留给主人）
