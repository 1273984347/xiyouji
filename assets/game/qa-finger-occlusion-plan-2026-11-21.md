# 手指遮挡专项处理方案（第二轮）

> 2026-11-21 ｜ 范围：火焰山、夜探瑶池、黄风岭、白虎岭、筋斗云、通天河
>
> **状态：已实施并复验（2026-11-21）**。实施结果与实测数据见 `qa-report-2026-11-21.md` 第六节。
>
> 依据：第一轮 P1–P3 修复后的移动端实测（430×844 / 844×390，DPR 2，`pointer: coarse`）。本轮只解决“手指遮挡关键信息”和“拇指热区与控件冲突”，不改变玩法数值与难度。

## 一、问题定义与验收口径

**判定为遮挡**：直径 44px 的触点圆与关键可视元素（角色、判定点、塔位、张力条、暂停键）相交，且持续超过 200ms。

**验收硬指标**

| 指标 | 口径 |
|---|---|
| 关键元素可见 | 拖拽/按住期间，角色或目标不被触点圆覆盖 |
| 触控目标 | 高频操作按钮 ≥44×44px；次级 HUD 按钮 ≥40×40px；塔位命中直径 ≥44px |
| 控制区分离 | 竖屏按钮在舞台外；横屏在右侧栏；与舞台间距 ≥8px |
| 键鼠回归 | 桌面布局与键盘操作零变化 |
| 工程约束 | 零外域依赖、单文件、`file://` 直开、无测试钩子 |
| 稳定性 | 0 console error、0 横向溢出、15/15 smoke 通过 |

## 三、总体方案

### 3.1 三层分离

1. **观察层**：画布与关键 HUD，始终在拇指热区之外。
2. **操作层**：触点锚点、牵引线、塔位浮标，负责“手指在哪里”。
3. **控制甲板**：舞台外的按钮区，负责“按什么”。

原则：**手指下方不放必须持续观察的目标**；操作点与观察点分离。

### 3.2 相对拖拽（火焰山 / 夜探瑶池）

把“手指坐标 = 角色目标”改为“手指位移 = 角色位移”：

```
pointerdown: 记录 touchStart、goal = 当前角色位置
pointermove: goal += (touch - lastTouch)；clamp 到可行区域
每帧:       player 向 goal 平滑靠近（保留现有 lerp 手感）
```

收益：手指在角色下方、侧面或任意位置都能操作，角色不会追到指尖下面。

配套反馈：

- 触点锚点：半径 22px 的半透明圆环，按下出现、抬起消失。
- 牵引线：锚点到角色的虚线，长度 ≥40px 时显示。
- 操作说明：开始页写明“从角色下方相对拖拽”；首次拖拽即显示锚点与牵引线，不用浮层提示遮挡角色。
- 判定点强化：火焰山角色中心增加 2px 白色核心 + 6px 金色外环；命中判定不变。

### 3.3 塔位吸附（黄风岭）

- 命中半径 34 → **54 世界px**（竖屏 46px、横屏 55px 直径）。
- 按下时取 60 世界px 内最近塔位，显示金色光环与浮标“塔位 3”。
- **抬起确认**：位移 <14px 才选中；拖动超过阈值视为取消，避免误触。
- 浮标画在触点上方 36px，指尖不遮住塔位名称。
- HUD 按钮（定身/倍速/暂停）在 coarse 指针下 `min-height:40px`。

### 3.4 控制甲板（白虎岭 / 筋斗云）

- 竖屏：舞台与按钮之间保留 8px；按钮区加半透明底板、内边距 6px、圆角 10px，形成明确“拇指之家”。
- 横屏：沿用右侧栏，底板与按钮同款；栏宽 140–160px。
- 按钮：白虎岭 54→58px（跃 64px）；筋斗云 56→58px（跃 70px）；间距 8–10px。
- 左右手：提供“左手模式”，把移动组与动作组对调；存 `localStorage`，默认右手。
- 安全区：`padding-bottom: max(8px, env(safe-area-inset-bottom))`。

### 3.5 画布点跳限区（筋斗云）

- 触控设备上，画布点跳只响应上方 78% 区域；下方 22% 为“拇指休息区”，不触发跳跃。
- 休息区加一条极淡的渐变提示，不遮挡跑道。
- 专用“跃”按钮保留，作为主要操作。

### 3.6 张力 HUD 上移 + 收线键（通天河）

- 触控设备上，`.bars` 从右下移到**右上 HUD 下方**（`top:44px; right:10px; bottom:auto`），拇指按住底部时仍能读到张力与收线进度。
- 新增“按住收线”触控键：竖屏在舞台下方右侧，横屏在右侧栏；64×64px，`pointerdown/up` 映射现有 `actionDown/actionUp`。
- 保留“按住画布任意处收线”作为备用；首启提示两种方式。
- 桌面端布局不变（仅 `pointer: coarse` 生效）。

## 六、验证方法

- **触摸模拟**：CDP `Emulation.setTouchEmulationEnabled` + `pointer: coarse`，覆盖 430×844、844×390、375×667。
- **遮挡判定**：截图中角色包围盒与触点圆求交；火焰山/夜探瑶池以“角色始终在锚点上方 ≥40px”为通过。
- **塔位判定**：对 8 个塔位各做中心点与 ±20px 偏移点击，记录打开的面板标题，要求 8/8 正确。
- **HUD 判定**：读取 `.bars` 与触控键 `getBoundingClientRect()`，要求矩形不相交。
- **回归**：键盘操作逐项复测；桌面 1440×980 截图与第一轮对比无布局变化。
- **工程**：15/15 静态检查、0 console error、0 横向溢出、`check_repo_layout.py` 0 FAIL。
