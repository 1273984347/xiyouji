# alternatives

> 文件角色：目录导读（人读·与 index.md 分工：本文件讲用途约定、index.md 列清单）

## 这个目录装什么

四个**未选定**方向的图形标矢量源（SVG · 浅底版）。定稿是方向 H「山·门槛」（见 `../logo/`），
这四个保留为备选 —— 若后续要改方向，不必重画，直接取这里的源文件。

| 文件 | 方向 | 配名 | 构成 |
| --- | --- | --- | --- |
| `e-mark-light.svg` | 棒 · 器物 | 《取经录》 | 金箍棒 + 鎏金箍纹 + 朱砂钤印（第一轮名字，后让位给方向 H） |
| `f-mark-light.svg` | 幡 · 引路 | 《问津》 | 路旗经幡：竖杆 + 双线飘带 + 杆顶朱珠 |
| `g-mark-light.svg` | 卷 · 载体 | 《拾遗》 | 经卷简牍：两端木轴 + 卷面竖排文 + 朱批 |
| `i-mark-light.svg` | 图 · 路书 | 《十万八千里》 | 取经路舆图：卷筒 + 摊开纸面 + 山脊 + 路线 + 朱点 |

## 与定稿的关系

四者与定稿共用同一套笔触引擎（`../tools/brush.py`）与配色令牌
（墨 #23201A / 淡墨 #6B6455 / 朱砂 #C8463A / 赭金 #B98A4A / 宣纸 #FAF7F0），
改配色或字重可整批重出。

## 维护约定

改图形请改 `../tools/svgkit2.py` 后重跑 `../tools/build_assets.py --check`，
产出同步到本目录与 `site/static/icons/`。
