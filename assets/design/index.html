Logo 探索 · 第二轮：具象符号 + 楔形笔触

第一轮（方框 + 线条的抽象制图）判定作废：它们像 UI 图标，不像品牌标志，既无西游的具体性，也无独占的轮廓。 本轮三处改动：① 图形换成具象母题（金箍棒 / 筋斗云 / 经卷 / 五行山）；② 线条换成有起收提按的楔形笔触； ③ 字标组合去掉朱砂分隔线，改为一枚钤记点睛。

配色仍以站点 tokens.css 为底色基准，但不再强制等同：墨为主、朱砂只点一处、赭金只用于金属。

二、品牌名候选（5 个）

名字问题与图形无关，沿用上一轮的候选与核验结论：「取经」「十万八千里」为原著语， 「问津」「拾遗」「阅微」原著 0 命中，典出后出文献，已如实标注。

候选名寓意提炼出处（已核）适配风险
取经录「录」是史书体例后缀（自《隋书·经籍志》以来的「录」体），数字人文的本分就是录、载；与「取经」主线构成双关。第 100 回：「圣僧努力取经编，西宇周流十四年」（原文 254 处「取经」）3 字 · 字标比例最佳 · 器物方向首选「录」略平，需副标补足品类信息
十万八千里悟空筋斗云一纵的距离，也是全书的刻度与数据体量；数字与路程合成一个尺度。第 7 回：「会驾筋斗云，一纵十万八千里」（原文多处）5 字 · 数字人文气质最强 · 云形方向首选5 字偏长，组合标最小宽度要求高
问津问路、寻渡、问法；读者向文本问路，正是这个品牌的日常动作。原文 0 命中 —— 典出《桃花源记》「后遂无问津者」，非原著语，须在文案中交代2 字 · 学术气质最浓 · 山形方向首选今日日常语义偏「打听消息」，需副标或释义兜底
拾遗辑佚之学的「拾遗」，也指拾起阅读中被略过的细节 —— 与项目「一源多形」的方法论一致。原文 0 命中 —— 典出辑佚学传统（《拾遗记》），非原著语2 字 · 学术型首选 · 经卷方向首选2 字略短，需与图形标强绑定或加副标
阅微自清·纪昀《阅微草堂笔记》化出，「从细微处察看」，对应细读与微观史学。原文 0 命中 —— 晚出典籍，非西游语境2 字 · 气质最雅 · 备选晚出（18 世纪）与西游语境无直接血脉，需额外解释

经卷是文本的容器：两端轴头，中间展开的卷面上是竖排的字。这个符号直接对应数字人文的对象——不是「西游记」四个字，而是一卷被反复展开、检索、批注的文本。

「拾遗」的落点在这里：卷面上有一处朱砂朱批。散佚的东西被拾起来，是因为有人在上面批了字。

四、AI 概念稿（造型上限探索）

手工路径画不出工笔质感的东方纹样，因此另用生成模型做了一轮纯图形概念探索 （提示词已锁死：无文字、单色墨 + 一处朱砂、宣纸底、无渐变无 3D 无卡通）。六张里三张可用、三张已判废—— 可用的棒 / 云 / 山，其形制已被回写成矢量：如意云的「闭合轮廓 + 内部涡卷」构造，就是从概念稿反推的。

第二轮扩批（12 张）：再出 12 个母题，把概念板做厚。 其中取经路舆图被回写成矢量（方向 I）；玉印（伪篆乱码）与芭蕉扇（写实过密）判废。
