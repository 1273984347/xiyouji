# screenshots

> 文件角色：目录导读（人读·与 index.md 分工：本文件讲用途约定、index.md 列清单）

## 这个目录装什么

《取经录》Logo 设计过程的**视觉留档**（拼版对比、方向分区、落地图标实测、站点实拍）。

| 文件 | 内容 |
| --- | --- |
| `preview-sheet.png` | 五个方向 × 深浅底拼版（定稿选型时的总览） |
| `concept-sheet.png` / `concept-sheet2.png` | 两批 AI 概念稿拼版（18 张总览） |
| `dir-e.png` … `dir-h.png` | 四个未选定方向的分区呈现（含寓意、配色、适配说明） |
| `landing-icons.png` | 落地图标三档实测（512 / maskable / 48·32·16） |
| `logo-lockup-light-preview.png` / `logo-lockup-light-sub-preview.png` | 定稿组合标预览（无副标 / 带副标） |
| `mark-i-check.png` | 方向 I（舆图）特写 |
| `site-home-after.png` | 站点实拍：页眉图形标 +《取经录》字标 + hero 主标题 |
| `full-page-light.png` | 预览页整页截图 |

## 维护约定

截图是**派生证据**，源在 `../tools/`（`preview_png.py` / `build_landing.py` 可重出）；
改了图形请重出后覆盖本目录，避免截图与源不一致。
