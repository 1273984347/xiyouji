# ai-concepts

> 文件角色：目录导读（人读·与 index.md 分工：本文件讲用途约定、index.md 列清单）

## 这个目录装什么

18 张 AI 生成的**纯图形**概念稿（两批 · 640×640 · 宣纸底），
用于《取经录》Logo 的造型探索留档。

**它们不是最终 Logo。** 定稿是方向 H「山·门槛」（见 `../logo/`），
造型已回写成矢量。这 18 张的价值有两个：
① 保留造型探索的完整轨迹（含被判废的，便于复盘"为什么废"）；
② 可作项目内容的插画素材复用（器物、景物、纹样母题齐全）。

## 生成口径（可复算）

- 提示词锁死：**无文字 / 单色墨 + 一处朱砂 / 宣纸底 / 无渐变 / 无 3D / 无卡通**；
  提示词原文见 `../tools/concept_args.json` 与 `concept_args2.json`。
- 工具：`../tools/gen_concepts.py`（自动按 10 张分批调用 + 下载归一）。
- 两次都出现**文字污染**（印面伪篆乱码、卷内混入汉字）→ 生成后必须专门查这一项，
  判废的两张即因此而来。

## 维护约定

新增概念稿时同步本表（母题 / 判定 / 说明），并重跑
`python scripts/gen_folder_docs.py --refresh` 刷新 `index.md`。
