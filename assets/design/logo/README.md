# logo

> 文件角色：目录导读（人读·与 index.md 分工：本文件讲用途约定、index.md 列清单）

## 这个目录装什么

《取经录》Logo 的**源文件级**资产（W856 定稿批，方向 H「山·门槛」）。

| 文件 | 用途 |
| --- | --- |
| `logo-mark-light.svg` | 图形标（山形）矢量源 —— 页眉用，零字体依赖 |
| `logo-lockup-light.svg` | 组合标（图形 + 《取经录》字标）矢量源 |
| `icon-512.png` / `icon-192.png` | 应用图标（宣纸底 + 图形占 72%） |
| `icon-maskable-512.png` | maskable 版（图形收至 56%，留圆形裁切安全区） |
| `favicon-16/32/48.png` | 浏览器标签页 / 收藏夹 |
| `favicon.ico` | 多档 ico（16/32/48） |

## 站点在用版本

本目录是**源**；站点在用的是 `site/static/icons/`（同一批产出，已落库）。
两处内容一致，改动请走 `tools/` 重出后同时更新，避免漂移。

## 图形构成

山脊一笔连绵（起收顿挫、提按变化）· 地平线与云气为淡墨次级 ·
山顶一点朱砂（远寺的灯）——全图朱砂只此一处。
字标为思源宋体 Heavy 转成的 SVG 路径，**运行期不依赖任何字体文件**。

## 维护约定

改字重 / 换配色 / 出新尺寸：从 `../tools/` 重跑（见该目录 README），不要手工改 SVG。
