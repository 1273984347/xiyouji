- **画幅**：`5472×3072`（约 5.5K 宽·16:9 近似·实测比例 1.7812）
- **文字安全区**：**画面左侧 25%–35% 为纯绢地留白**（保守实测下限——两法交叉测量区间 22%–43%，下界取最保守值；仅老化接缝、绢丝纹理、极淡晕染·无绘画细节），供标题 / 副题 / CTA 叠加；主体一律落在右侧三分之二

## 接入首页

站点 Pages 只发布 `site/` 目录，本目录在站点外，**接入前须先复制到站点内**：

```bash
cp assets/promo/silk-hero-set/silk-hero-01-yunhai-fosi.webp site/static/images/
```

```css
background-image: url('static/images/silk-hero-01-yunhai-fosi.webp');
background-size: cover;                 /* 16:9 源 · 与容器同宽高比时几乎无裁切 */
background-position: center right;      /* 主体在右侧 · 左侧留白区完整保留 */
```

**`background-position` 取 `center right`**：主体落右侧、留白在左侧，取 `center` 会把主体推到画面中央而吃掉留白位。

**当前可用范围**：12 张已统一到 A 档画风（v2 参考图重做后），可整组上线。取单张时注意两个已知弱项——`08` / `09` 因「点景小人物 + 只勾轮廓」约束，人物特征弱、悟空辨识度低；`04` 的鬼火带荧光蓝发光感。

## 维护约定

- **新增同族成员**必须沿用同一风格块与留白规则，否则成套一致性破裂；命名沿用 `silk-hero-NN-主题拼音`（两位序号 + 连字符 + 英文小写）。
- **改题材不改规格**：画幅、留白位、色板、禁项四条不可动。
- 新增文件后重跑 `python scripts/gen_folder_docs.py --refresh` 刷新同目录 `INDEX.md`（脚本按 git 索引收集清单·新件需先 `git add`）。
