## 正反面分工

| 面 | 受众 | 承担 |

| 第 1 面（正面） | 大众读者 | 品牌 → 主视觉 → 一句话主张 → 4 个 KPI → 3 条卖点 → 行动 CTA |

**分工纪律**：正面不出现引用格式与协议细则（打断大众阅读节奏）；背面不重复主视觉与口号（避免两面像同一页）。

## 维护约定

**改文案或改版式后必须重导出**（否则 PDF/PNG 与真源脱节）：

```bash
node scripts/_w892_export_flyer.mjs          # 起本地静态服务器导出（推荐·字体必加载）
node scripts/_w892_export_flyer.mjs --file   # 走 file:// 复核「双击直开」的降级表现
```

导出脚本会顺带打印三项探针：**思源宋体是否真加载**、**外域请求数（应为 0）**、**每页溢出像素（应为 0）**。三项任一异常即不可交付。

**数字口径警示**：单页上的 `615 篇` / `87 个可视化页` / `133 个数据维度` / `34 类分析脚本` / `49 项门禁` 取自项目现役统计口径（口径见 `docs/00-导读/统计口径说明.md`）。**这些数字随项目演进而变**——改动项目统计口径时，必须同步改本目录的 HTML 文案并重导出，否则单页会与仓库实况脱节。

**体积说明**：PDF 约 6.1 MB，主因是思源宋体完整字集嵌入 + 主视觉 PNG。若需更小的邮件附件，可把主视觉转 JPEG（q92，约省 1.2 MB），但深墨边缘会出现 JPEG 压缩伪影，**印刷场景不建议**。

**不要**：① 不要把本目录的 HTML 移进 `site/`（它是物料不是站点页面，会触发 sitemap / 导航 / 站内门禁的接入要求）；② 不要改 `output/` 里的产物而不同步真源；③ 不要在单页里引入外域 CSS / JS / 字体（file:// 铁律）。
