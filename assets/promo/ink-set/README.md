## 这个目录装什么

《取经录》第四套视觉资产线（**未上线**）：**48 张淡墨写意插画**——同一套 12 个题材，按四个画幅各出一版。

**画风定位**：**宣纸淡彩·写意水墨**——宣纸底（真实纸纹与暖色）· 焦墨退为淡灰层次的湿笔晕染 · 矿物色点染（石青 / 石绿 / 赭石三选一）· **全图仅一枚朱砂点** · 大面积留白。与仓内另三套视觉语言（古画绢本 / 工笔白描 / 水墨晕染带印章）**并行且不可混排**（边界见「维护约定」）。

**题材配额**（12 题材 × 4 画幅）：西游具体场景 4 · 中式神话泛用 3 · 抽象构成呼应数据页 2 · 四时景致 3。

## 成套硬约束（量化口径 · 机械探针实测）

- **墨色**：全图最深处只到淡灰，**焦墨（亮度<60）像素占比 ≤0.69%**，48/48 无纯黑块面。
- **朱砂单点**：每张至多一枚朱砂点（`#C0392B`），占比 ≤0.35%（唯一例外 `og-09-fenjie` 为 1.03%——该题材本身是「一根朱砂带标记峰值」的设计）。
- **零文字**：48/48 无题跋 / 印章 / 落款 / 签名 / 水印。
- **文字安全区**：hero 左 1/3、og 左 40%、plate 下 1/3、card 四边 12% 环带——留白率 ≤2.92%（最高者为 `plate-12-qiujing` 的枝梢轻触下缘）。
- **主体可辨**：12 题材各自的主体（火焰山 / 五指山 / 水乡 / 白骨荒院 / 行旅 / 云海 / 风铃 / 数据河流 / 分节 / 桃枝燕 / 荷塘 / 秋林雁）在四画幅下均可辨。

## 生成方法（可复算）

- **一次出图 = 一次 `connector__matrix__generate_image` 调用**；每张带 `reference_images` = 风格锚点。
- **风格锚点**：`ink-style-key.jpg`（2048×2048）是**不进成品的样例**——只传递淡墨调性、纸色与留白习惯，不携带题材，故不会把构图复制到成品。
- **同一条 brief 贯穿全部 48 张**：墨色压淡（禁纯黑）、朱砂单点、色板收敛（墨灰 + 一矿物色 + 一朱砂）、禁闭合轮廓线、禁装饰性小物、零文字。

## 迭代收敛记录（可复算 · 附失败样本原因）

| 轮次 | 变化 | 结果 |
| --- | --- | --- |
| v1 | 文字风格块 | 朱砂多点多色、留白被侵占、主体跑位 —— **整批作废重做** |
| v2 | 加「朱砂单点 + 稀疏构图 + 留白硬规则」 | 朱砂单点达成；锚点构图在左 ⇒ 主体系统性偏左 |
| v3 | 换「右置构图」锚点 + 位置规则前置 | 位置与留白全达标 |
| v4 | 加「体量坐底 + 去噪点」 | hero-11 / og-06 违规 + 风格漂移 ⇒ 回退 |
| **v5（定稿）** | 换**淡墨锚点** + 墨色压淡硬约束 | 焦墨占比 5.98%→0.33%（降 18×），画面淡雅通透 |
| 收官 | 48 张全量后逐张复核，返工 8 张（焦墨超标 4 / 多色灯笼 2 / 留白不足 1 / 朱砂成簇 1） | 48/48 达标 |

**两条教训**（同源）：① **风格锚点会连带迁移构图**，不只是画风——锚点必须与目标版式同构图，否则成套一致性被带偏；② **量化判据全绿 ≠ 风格成立**——「朱砂单点 + 留白达标」这类指标能证明一致性，不能证明「画得好看、主体可辨、能用」，后者只能靠目视。

## 维护约定

- **不与 `silk-hero-set/`（古画绢本）/ `plate-set/`（工笔白描）/ `site/static/images/card-*`（水墨晕染带朱红印章）混排**：画幅与画风均不同；本族**零印章零文字**，与 `card-*` 的「带印章浓墨」是两族。
- **本族暂存 `assets/promo/`，未接入 `site/`**：接入需复制到 `site/static/images/`、按族规登记 alt 文本与容器类名（属另批工作，勿在本批顺手改）。
- **无 webp 轻量版**：模型直出 jpg；站点用轻量版需另行转码，该转码不在本批范围。
- **OG 双语**：本族 12 张为**无文字底图**，中英两版共用同一套底图，文案后期叠加。
- **暗色模式**：本族底色为暖宣纸亮底，暗色态下需隐藏或加浅底容器（与 `plate-line-*` / `card-*` 同一处理）。
