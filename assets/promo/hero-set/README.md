## 这个目录装什么

《取经录》首页用的 **Hero 横幅成套素材**——8 张同规格横幅，画幅统一 `2400×1017`，可整组替换或逐张取用。

与站内既有 `site/static/images/hero-01~09`（渲染型水墨/淡彩·`2560×1440`）**是两套并行的视觉语言**：那套是水墨渲染场景，本套是**极简线描器物**（与 `assets/design/ai-concepts/` 的 c2 系列同源）。两者混排进同一轮播会出现风格跳变，**择一套用**。

**一览预览**：`preview-contact-sheet.png`（同目录）是 8 张缩略拼图，用于一眼验成套一致性。

## 统一规格（成套一致性的硬约束）

- **画幅**：`2400×1017`（`21:9` 出图后按 `2400/1017` 精确裁切，不拉伸变形）
- **文字安全区**：**画面左侧 46% 为纯纸面留白**（实测墨量占比 0.0000–0.0014），供标题 / 副题 / CTA 叠加；主体一律落在右侧
- **色板**（与 `site/tokens.css` 同源）：宣纸底 `#FAF7F0` · 墨 `#23201A` · 赭金 `#8A6D3B` · 朱砂 `#C8463A`
- **笔触**：纯墨线轮廓（有粗细变化），**无实心填充块**、无渐变、无渲染阴影、无光效
- **点睛**：每张**仅一处朱砂红**，位于主体右侧，作唯一彩色焦点
- **禁项**：无文字、无书法、无印章、无水印、无边框

## 接入首页

站点 Pages 只发布 `site/` 目录，本目录在站点外，**接入前须先复制到站点内**：

```bash
cp assets/promo/hero-set/hero-line-01-ruyi-staff.webp site/static/images/
```

首页 hero 现有写法是背景图（`site/index.html` 的 `.hero` 覆写层）：

```css
background-image: url('static/images/hero-line-01-ruyi-staff.webp');
background-size: cover;
background-position: right center;   /* 主体在右，文字压在左侧留白 */
```

`background-position` 取 `right center` 保住「主体在右、文字在左」的版面约定；不要用 `center`，否则会把主体推回画面中部、压掉左侧留白。

## 维护约定

- **重出单张**：用 `mcode-tools connector call connector__matrix__generate_image --args-file <参数文件>`，参数文件须完整复用本目录同一套**风格母版**（宣纸底 / 墨线 / 赭金细节 / 单朱砂点 / 左侧留白 / 禁文字），只替换 `SUBJECT` 与 `POSITION` 段——**风格母版逐字不动**，否则该张会与同套其余 7 张脱节。
- **`raw/` 是出图原件**（`3168×1344` JPG，8 张）：保留用于追溯与再裁切。删掉不影响成品，但会失去「重出基准」——同一提示词再跑不会得到同一张图。
- **改动后必跑一次校验**：确认 ① 尺寸为 `2400×1017`；② 左侧 46% 墨量为 0；③ 无 AI 伪文字（生成模型容易在器物纹样里塞乱码字符，需**放大人工看一眼**，机器判据抓不到）。
- **不要**：① 不要把 PNG 母版直接塞进站点（体积差 20 倍，站点用 webp）；② 不要改 `raw/` 里的原件；③ 不要单独给某张换风格或换留白约定（会破套）；④ 不要在此目录引入外域资源（`file://` 铁律）。

## 已知取舍

- **朱砂点睛强度不均**：各张朱砂占墨量比在 1.55%–19.63% 之间（金箍棒那颗偏大）。肉眼可辨但不破坏成套观感；若要严格对齐，需逐张局部重绘点睛，成本高于收益。
- **部分主体出血**：卷轴（02）、锡杖杆（06）刻意出界延展，与站内既有 hero 的出血处理一致；若版式要求主体完整入框，须重出该张。
