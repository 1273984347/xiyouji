## 统一规格（成套一致性的硬约束）

- **画幅**：`1200×1600`（精确 3:4·`3:4` 出图后按比例裁切缩放，不拉伸变形）
- **文字安全区**：**画面上方 28% 为纯纸面留白**（实测墨量占比 0.0000–0.0015），供标题 / 副题叠加；主体一律落在中下部
- **主体体例**：**完整全身立像**、占画面高度约五成、居中、完整入框不裁切（8/8 一致）
- **色板**（与 `site/tokens.css` 同源）：宣纸底 `#FAF7F0` · 墨 `#23201A` · 赭金 `#8A6D3B` · 朱砂 `#C8463A`
- **笔触**：纯墨线轮廓（有粗细变化），**无实心填充块**、无渐变、无渲染阴影、无光效
- **点睛**：每张至少一处朱砂红，位于主体右侧，作唯一彩色焦点
- **禁项**：无文字、无书法、无印章、无水印、无边框

## 出图母版（成套一致性的机器保证）

风格母版共 **252 字符**，在 8 条提示词中**逐字复用**（只替换「主体：」之后的 SUBJECT 段）。
母版逐字一致性由 `python scripts/_w945_check_prompts.py` 断言（`==` 比较，非"看着像"）：

```
中国传统工笔白描线描风格插画，竖版 3:4 构图。宣纸底色（暖米白 #FAF7F0），纯墨线勾勒轮廓，
线条粗细有变化、笔触干净利落、墨色饱满清晰；无实心色块填充、无渐变、无阴影、无光效、
无背景场景、无边框。局部细节以赭金色 #8A6D3B 勾勒。画面中仅有一处朱砂红 #C8463A 点睛，
位于主体右侧。画面上方 28% 保持完全空白的纯纸面（不得有任何笔触或色彩），用于叠放标题文字；
主体为完整全身立像、居画面中下部、占画面高度约五成、完整入框不被裁切。
画面中不得出现任何文字、书法、印章、水印、题跋。
```

出图参数文件：`scripts/output/_w945_batch1.json`（01–04）、`_w945_batch2.json`（05–08）、`_w945_batch3.json`（重出 02 / 08）。

**重出某张时**：母版**逐字不动**，只改 SUBJECT 段 ⇒ 该张仍与其余 7 张同族。
改母版则必须**全组重出**（否则母版不一致，成套一致性即断裂）。

## 维护约定

- **改成品图后必跑两条**：
  ① `python scripts/_w945_prepare.py`（裁切 3:4 → 纸色归一 → 母版/站点版 → 拼图）；
  ② `python scripts/_w945_plates_verify.py`（J1–J9）。
  只改站点版 `.webp` 而没跑① ⇒ 纸色会与页面底色出现色边。
- **纸色归一**：出图模型的纸色与页面底色差 1–9/255，**图块边界会露色** ⇒ 按亮度加权加性平移归一到 `#FAF7F0`（残差 ≤1/255·墨线区不动）。母版 `.png` 是归一后的产物；`raw/` 保留原始纸色。
- **`raw/` 是出图原件**（模型返回的 JPEG 字节·1792×2400）：保留用于追溯与再裁切；同一提示词再跑不会得到同一张图。
- **不要**：① 不要把母版 `.png` 直接当站点图用（站点用 `.webp`）；② 不要改 `raw/` 原件；③ 不要单独给某张换风格或换留白约定（会破套）；④ 不要在此目录引入外域资源（`file://` 铁律）；⑤ 不要只重出一张就换母版。

## 已知取舍

- **图内上部留白 × 页面标题位置**：本批 8 张按规格在**图内**上部保留 28% 纯纸面（供叠字用），而内页版式里页面标题 `<h1>` 本就在图的**上方** ⇒ 标题与画面主体之间会出现一段留白（实测约 190 px @1280 视口）。这是「资产规格」与「当前版式」各自的合理取向，非缺陷：若要紧凑版（主体紧贴标题），改法是在**页面上**裁掉这段留白（`.chapter-plate` 加 `overflow:hidden` + `img{margin-top:-37.33%}`，裁切量 = 0.28 × 图高 = 0.3733 × 容器宽），**资产不动**（留白版仍可用于卡片叠字 / 分享图裁切），代价是改 8 个页面的内联 CSS。
- **数量级形制偏差（2 处）**：02 锡杖画成六个环（原著九环）、04 骷髅项链画成约六颗（原著九颗）——生成模型对"精确计数"的控制有限；两处**形制类别正确、不会误读成别的题材**（读者凭"五佛冠 + 合十 + 田相袈裟 + 念珠 + 锡杖"识别唐僧，凭"月牙铲 + 骷髅项链 + 络腮胡"识别沙僧）。与 `hero-line-06`（站内首页那张九环锡杖）**环数不一致**，属已知差异。
- **朱砂点睛形态不统一**：模型给出圆点 / 竖椭圆 / 帔帛飘带等不同形态（01/03/04/06/07 为圆点，02 为竖椭圆，05 为一条红帔帛）；与 W931 hero-set 的同一取舍一致（朱砂强度不均），未为此重出。
- **08 红孩儿发色偏赭红**：模型对高饱和红的控制有限，实际呈赤棕红而非纯红；因"红"是红孩儿之名源，仍记为「赤红发」达成。
- **04 沙僧头戴莲花金冠**：原著沙僧多作光头或毗卢帽，本图作冠，属可接受的通俗化处理。
