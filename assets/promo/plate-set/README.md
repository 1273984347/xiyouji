## 统一规格（成套一致性的硬约束）

- **画幅**：`1200×1600`（精确 3:4·`3:4` 出图后按比例裁切缩放，不拉伸变形）
- **文字安全区**：W945 首批 16 张母版**上部 28% 纯纸面留白**（实测墨量 0.0000–0.0015）；W952 起各批按「主体上方只留约一成呼吸空间」构图（页面标题在图外⇒ 不再设标题区）——**判据 J2 取二者交集「顶部 10% 必为纯纸面」**；W974 本批 12 张实测顶部墨量 0.0–0.0（顶部 10% 全为纯纸面）
- **主体体例**：**完整全身立像**、占画面高度约五成、居中、完整入框不裁切（16/16 一致）
- **色板**（与 `site/tokens.css` 同源）：宣纸底 `#FAF7F0` · 墨 `#23201A` · 赭金 `#8A6D3B` · 朱砂 `#C8463A`
- **笔触**：纯墨线轮廓（有粗细变化），**无实心填充块**、无渐变、无渲染阴影、无光效
- **点睛**：每张至少一处朱砂红，位于主体右侧，作唯一彩色焦点
- **背景整幅均匀**：四边不留白边、不装裱、不加框（见判据 J10）
- **禁项**：无文字、无书法、无印章、无水印、无边框

## 资产分层：母版 vs 站点版（W951 起）

同一批图有**两个版本**，用途不同，**刻意不共用同一文件**：

| 位置 | 内容 | 尺寸 | 用途 |
|---|---|---|---|
| `assets/promo/plate-set/plate-line-*.png` / `.webp` | **完整母版**（含上部 28% 留白） | 1200×1600 | 卡片叠字 / 分享图裁切 / 二次加工的**源** |
| `site/static/images/plate-line-*.webp` | **站点版**（只裁掉上部留白） | 1200×955–1458（全目录实测·随主体顶浮动；W974 本批 1030–1301；W983 本批 1147–1415） | 内页专题题图（页面实际呈现） |

**为什么站点版要裁**：出图规格要求「上部 28% 纯纸面留白（供叠字）」，而内页版式里页面标题 `<h1>` 本就在图的**外面上方**
⇒ 标题与画面主体之间会多出约 190 px 冗余空白（浏览器实跑 1280 视口量得），第一眼像「图缺了一块」。
用户 2026-10-25 裁决「裁掉·页面更紧凑」⇒ 站点版**只裁掉主体上方的留白**（逐张裁切线 = 该张主体顶 − 6 px），
**保留下部空白**——那是画师留的「地面留白」，裁掉会把人物从地面上「拔起来」，破坏「人物站在地上」的构图关系。

- 站点版由 `scripts/_w945_prepare.py` 自动生成（与母版同源，不手工维护）；
- 验算脚本 `scripts/_w951_check_crop.py`：站点版宽 = 1200、**主体顶未被切**（bbox 顶 ≥ 1 px）、
  **主体底未被切**（bbox 底 < 画布高）、**下部地面留白 > 0**（人物不悬空）⇒ 16/16 PASS（主体顶 6–7 px·地面留白 62–141 px）；
- 站点版对照拼图：`preview-site-sheet.png`（母版对照拼图是 `preview-contact-sheet.png`）。

## 维护约定

- **改成品图后必跑两条**：
  ① `python scripts/_w945_prepare.py`（裁切 3:4 → 纸色归一 → 母版/站点版 → 拼图）；
  ② `python scripts/_w945_plates_verify.py`（J1–J10）。
  只改站点版 `.webp` 而没跑① ⇒ 纸色会与页面底色出现色边。
- **纸色归一**：出图模型的纸色与页面底色差 1–9/255，**图块边界会露色** ⇒ 按亮度加权加性平移归一到 `#FAF7F0`（残差 ≤1/255·墨线区不动）。归一迭代**最多 6 轮**、收敛条件 |delta| < 0.3（偏色较重的纸面 2 轮不够，W948 实证残差会停在 1.36/255 ⇒ 越过 J9 阈值；正确处置是让归一收敛，**不是放宽判据**）。母版 `.png` 是归一后的产物；`raw/` 保留原始纸色。
- **`raw/` 是出图原件**（模型返回的 JPEG 字节·1792×2400）：保留用于追溯与再裁切；同一提示词再跑不会得到同一张图。
- **不要**：① 不要把母版 `.png` 直接当站点图用（站点用 `.webp`）；② 不要改 `raw/` 原件；③ 不要单独给某张换风格或换留白约定（会破套）；④ 不要在此目录引入外域资源（`file://` 铁律）；⑤ 不要只重出一张就换母版。
